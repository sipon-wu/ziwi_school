- 前端 `ExerciseGenerator` / `XiaoWeiChat` 手写 `fetch('/api/v1/ai/...')`，而后端代理与 ai-service 服务的是 `/api/ai/`（无 v1）→ 前缀不符全 404。

- 三层证据：源码 grep 无 `/api/v1/ai` 残留；线上 `ExerciseGenerator` chunk 实测含 `/api/ai/exam/generate` 且无 v1；curl `/api/ai/exam/generate`→**200**（v1 路径仍 404 对照）。

- 保留 `message` 字段 → 前端 `api.ts`（`data.message || data.error`）**零破坏**，已通过 e2e 与 API 回归验证。
- 涉及文件：`middleware/auth.go`、`cloud_auth.go`、`rbac.go`、`handler/auth_cloud.go`、`auth_handler.go`、`school_class_handler.go`、`main.go`（ai 代理错误）。
