## 二、测试场景（按重要性排列）

### 场景 1：AI 出题（核心场景，必测）

**步骤**：
1. 登录 → 左侧菜单点击「出题」→「新建出题」
2. 选择学科、年级（跟你的账号学科一致）
3. 填写**课题名称**（如"分数的意义""Unit 3 Weather"）
4. 选择**题目数量**（3-5 题）、**难度**
5. 可选：勾选**知识点**进行精准出题
6. 点击「AI 生成」
7. 等待 3-8 秒 → 看到 AI 生成的题目
8. 🎯 **产出验证**：
   - 点击「编辑」修改某道题的题干或选项 → 保存
   - 点击「导出」下载试卷文档
   - 把生成的题目加入题库

**预期结果**：AI 能出该学科的题目、内容通顺、答案正确、可直接编辑修改。

---

### 场景 2：AI 写教案（核心场景，必测）

**步骤**：
1. 左侧菜单点击「教案」→「新建教案」
2. 选择学科/年级/课题（如"观潮""认识平行四边形""Unit 3 Weather"）
3. 选择**教案模板**（标准模板 / 详细模板）
4. 可选：关联**知识点**
5. 点击「AI 生成教案」
6. 等待 5-10 秒 → 看到完整教案（含教学目标、重难点、教学过程、板书设计）
7. 🎯 **产出验证**：
   - 点击教案任一区块，直接**编辑修改**文字
   - 调整教学环节的顺序
   - 点击「保存草稿」
   - 点击「发布」

**预期结果**：AI 生成的教案结构完整、内容符合当前学科特点、可自由编辑保存。

---

### 场景 3：小微 AI 助手（辅助教学）

**步骤**：
1. 点击底部或侧边栏的「小微」图标（💬 对话框）
2. 输入问题，例如：
   - "帮我设计一个课堂导入活动，五年级数学"
   - "写一段关于春天的50字短文"
   - "给我3道四年级英语选择题"
   - "解释平行四边形和梯形的区别"
3. 小微会实时回复
4. 🎯 **产出验证**：
   - 小微回复的内容可以**一键引用到教案或出题**
   - 复制粘贴到教案中

**预期结果**：小微理解教学场景、回答准确、可为备课提供素材。

---

### 场景 4：查看已有的示范成果

**步骤**：
1. 登录后，左侧菜单点击「教案」→ 草稿箱列表会看到**3 条示范教案**
2. 点击任意一条查看完整内容
3. 左侧菜单点击「出题」→ 题库中会看到**3 条示范习题**
4. 🎯 **产出验证**：
   - 示范教案的 Markdown 格式是否正确渲染
   - 示范习题的选项和答案是否显示完整
   - 可以基于示范内容修改后另存

## 四、常见问题

**Q：页面加载不出来？**
A：刷新即可，或检查网络是否正常。

**Q：AI 生成内容时报错？**
A：截图发给技术人员，包含报错信息。

**Q：保存失败？**
A：检查当前是否仍处于登录状态，尝试重新登录。

**Q：修改后没有生效？**
A：确认已点击「保存」按钮，不要直接关闭页面。

## 四、系统设置 · 教材版本（新增，普通老师可用）

进入「系统设置 → 教材版本」即可为本校任教学科选择教材版本，**无需走 IT 管理后台**：

- 默认只显示你本人任教的学科（如张老师=语文；冯老师=英语、数学）。
- 每个学科下按年级列出，每格一个下拉，选项来自平台预置的出版社+版本。
- 保存后写入「学校自用覆盖层」，**仅对本校生效、不影响公共库**，并立即同步到出题/教案/作业/考试的教材版本显示。
- 权限说明：教材版本现对 **教师 / 班主任 / IT 管理员** 开放读写（原为 IT 管理员独占）。

> 验证点：用张老师(15100000001)进入「系统设置 → 教材版本」，确认能看到「语文」并可下拉选择版本，保存后出题页顶部教材版本随之变化。
