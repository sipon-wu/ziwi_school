# 媒介纪律 · H5（流式场景 · 移动端）

> 本文件是 **courseware-h5** 专属纪律，**不适用于 PPT**（PPT 见 `courseware-ppt/references/媒介纪律-PPT.md`）。
> 通用约束（跨媒介）在 `shared/质量宪法.md`；本文件只写「H5 这个媒介**特有**的纪律」。

## 0. 媒介本质（**与 PPT 根本不同**）

| 维度 | H5 的事实 | 与 PPT 的差别 |
|---|---|---|
| 画布 | **窄屏、可伸缩流**（手机竖屏为主） | PPT 是固定宽画布 |
| 可见性 | **一屏一景**，看不满就滚/翻 | PPT 同屏全可见 |
| 观看距离 | **手持近观**（30–40cm） | PPT 远观 |
| 推进 | **学生自己点**，节奏由学习者控制 | PPT 讲者控制 |
| 时间维度 | **有**（渐隐渐出、入场、揭示、进度条） | PPT 几乎没有 |
| 排版模型 | **流式**（场景 + 段落流 + 互动组件） | PPT 分块绝对定位 |

**一句话**：H5 是「时间 + 空间」双维度的媒介——**层次可以靠"什么时候出现"建立，不必只靠"多大字号"**。

## 1. 铁律（Hard Rules）

### R1 单屏信息量上限（一屏一景）
每场景 **≤60 字**；旁白 **≤2 句**（≤40 字）；气泡 **≤3 条**（每条 ≤20 字）。

- 理由：竖屏一屏放不下更多；放不下就要滚，一滚就丢失"场景感"。
- 与既有阈值一致（SKILL.md 的 8~16 场景、每场景 ≤60 字），本文件是它的**媒介依据**。

### R2 可读性硬下限
正文 **≥16px**；行高 **≥1.6**；中文行宽约 **20–35 字/行**。

- 依据：移动端正文 16px 是业界事实标准（WCAG 本身未强制字号，但可读性研究一致指向 16px）；行宽 45–75 字符是通用可读区间，中文折算约 20–35 字。

### R3 触控目标 ≥44×44px
所有可点元素（选项、按钮、词卡）**有效触控区 ≥44×44 CSS px**。

- 依据：**W3C WCAG 2.5.5**（44×44）；**Apple HIG** 44pt；**Material Design** 48dp。
- 推论：选择题**不要**做成小 chip；点读词卡要够大。宁可减少选项数，也不要缩小触控区。

### R4 层次"可辨"即可，**不强制字号阶梯**
H5 建立层次的手段**不止字号**——可以是**出现顺序、渐隐渐出、强调色、位移/缩放**。只要求：

1. 最低可读字号达标（R2）；
2. **相邻层级可感**（有手段让人看出"这是标题、这是正文"）；
3. 同一层级在全篇**用法一致**（不能这页用动效、那页用字号表示同一件事）。

- 与 PPT 的差别：**PPT 必须硬阶梯**（同屏全可见时，字号是唯一区分手段）；**H5 可以是软约束**（有时间维度可用）。
- 反例（本项目实测）：把 PPT 的硬阶梯照搬到 H5 → 出现"标题必须大于一切内容"的过严约束，反而和动效/节奏打架。

### R5 动效是"信息"，不是"装饰"
入场/揭示/翻页淡入承担**分步呈现**（一次只给一点信息）；但**关闭动效后信息仍必须完整可读**（无障碍 + 性能兜底）。

### R6 互动必须是"动手"
互动 **≥2 处**，且是**学生真正操作**（点读、跟读、选择、揭示、绘图），不是"点下一页"。

### R7 流式允许留白，但**首屏即重点**
- 滚动本身是节奏，**允许**场景内适度留白（这与 PPT 的"不许空洞"**相反**，因为 H5 有滚动维度）。
- 但**首屏**必须给到本场景的核心（移动端不保证有人滚到第二屏）。

## 2. 由此推出的**禁止项**

| 禁止 | 原因 |
|---|---|
| 把 PPT 的 bullets/学习目标页/小结页搬进 H5 | 媒介错配（历史教训：文字堆砌、零互动） |
| 关键信息只存在于动效里 | 关动效/低端机即丢失（R5） |
| 选择题做成小 chip（触控区 <44px） | 手指点不准（R3） |
| 用缩小字号塞更多字 | 近观也不可读（R2）；应拆场景 |
| 一屏塞 >60 字 | 必须滚动才看得完 → 破坏"一屏一景"（R1） |
| 假互动（只有"下一页"） | 不算互动（R6） |
| 全篇靠字号硬阶梯分层 | 浪费 H5 的时间维度，且与动效冲突（R4） |

## 3. 自检清单（S4 用）

- [ ] 场景数 ∈ [8, 16]；每场景 ≤60 字；旁白 ≤2 句；气泡 ≤3 条
- [ ] 互动 ≥2 处，且类型 ≥2 种（read/readalong/quiz/reveal/draw）
- [ ] 所有可点元素有效触控区 ≥44×44px
- [ ] 正文 ≥16px；行高 ≥1.6
- [ ] 层次可辨（字号/动效/顺序任一手段成立，且全篇用法一致）
- [ ] 关闭动效后信息仍完整
- [ ] 首屏含本场景核心信息
- [ ] 无元内容（画面描述/风格说明）；无占位符
