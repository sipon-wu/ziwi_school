# 版式与组件选型（硬约束）

> 本文件是 `courseware.generate` Skill 的领域知识，S3 课件生成阶段必须遵守。
> 违反任一条 → S4 关卡1 判定不合格，回退重生成。

**为什么需要这份约束**：渲染层把每条要点渲染成并列卡片，卡片横向列宽有限。
单条越长、列数越多，字被压得越小。历史上「学习目标页字密到看不清」「对比表出现空列」
都是因为**先定了版式，再把长句硬塞进去**。

---

## 一、版式选型 = 条数 × 单条字长（两条都满足）

选定 layout 前，**必须先写完该页 bullets 并逐条数字数**：

| 单条 bullets 长度 | 可用 layout | 说明 |
|---|---|---|
| ≤12 字（词/短语/短句） | `content-grid`（5~6 条）/ `content-2col`（2~4 条） | 卡片装得下，字可放大 |
| 13~30 字（中长句） | **严禁 `content-grid`**；只能 `content-2col`（≤3 条）或 `title-body` | 多列卡片会压字 |
| >30 字 | **严禁任何多列版式**；走 `title-body` 竖排，或先拆成多条短句 | — |

**自检判据**：写完一页要点后逐条数——
任一条 >12 字就不得选 `content-grid`；任一条 >30 字就不得选 `content-2col`。

### 字数分拆：动笔前先拆，别等写完再改

**先定版式再把长句塞进去，是字密的根源。** 正确顺序是：
**先拆句 → 数一遍 → 再选版式**。写完再改等于整页推翻重来。

拆句的三条手法（按优先级用）：

1. **砍修饰**：一句只留一个信息点，删掉"的"字串、程度副词、重复主语
2. **按序断句**：有时间 / 步骤顺序的，一步一句
3. **主谓拆分**：一个主语带多个动作时，一句一个动作

同一句原文的三种合格处理（原文 37 字）：

> 潮来时，先听到隆隆的响声，接着看到一条白线，最后白浪翻滚而来

- **走 `content-grid`**（拆 3 条，每条 ≤12 字）
  - 先闻隆隆响声（6 字）
  - 再见一条白线（6 字）
  - 后观白浪翻滚（6 字）
- **走 `content-2col`**（拆 2 条，每条 ≤30 字）
  - 先闻隆隆响声，再见一条白线（13 字）
  - 白浪翻滚，浪潮越来越近（11 字）
- **拆不动就别硬拆**：语义连贯不宜拆的（如原文金句）整块走 `annotate`，
  **严禁**把一段话切成 N 张卡片——会断裂

**反面案例**：

> 把"通过学习本课，学生能够掌握比喻的修辞手法并运用到写作中"（27 字）
> 塞进 `icon-card` 的 desc（上限 12 字）→ 字被压到看不清。
> 正确做法：desc 只写"比喻·运用"（5 字），完整表述放 `bullets`。

**特殊版式约束**：
- `edu-goal` / `edu-summary` / `edu-homework`：bullets 每条 ≤30 字（这些版式同样按卡片呈现）
- `edu-explain`：只有 2 个槽位，禁止放 3 条以上

**反面案例**：
> 学习目标页 3 条长句（每条 30+ 字）走 `content-grid`，字被压到极小看不清。
> 正确做法：先拆句（每条 ≤12 字）再选 grid，或改用 `title-body` 竖排。

## 二、组件选型 = 语义 × 形态（两条都满足）

### ① 先看形态（决定容器装不装得下，硬约束）

| 内容形态 | 可用组件 |
|---|---|
| 连续文本 / 段落（单项 >60 字，或语义连贯不宜拆分） | **annotate**（保留整块 + 关键词高亮） |
| 金句 / 名人名言 | **quote** |
| 单项 ≤6 字（词 / 短语） | sequence / icon-card / char-card（可放大呈现） |
| 单项 7~12 字（短句） | icon-card / flow / timeline |
| 单项 13~60 字（中长句，需 2~4 行） | annotate / compare-table / compare-card / structure |

> **长文本（>12 字）严禁进 icon-card / diagram / sequence / flow / timeline**
> ——card 类组件横向列宽不足，字会被压到极小。
> **严禁把连续段落拆成 N 个卡片**（会断裂），应整块走 annotate。

### ② 再看语义（决定具体用哪个）

| 语义 | 组件 |
|---|---|
| 层层推进 / 有先后顺序 | sequence（≤6字）或 flow（7~15字）或 timeline（时间节点） |
| 二维对照（多对象 × 多维度） | compare-table |
| 两项辨析（易混概念 / 多音字） | compare-card |
| 知识层级（父子关系） | structure |
| 并列多方面 | diagram（中心+分支）或 icon-card（图标网格） |
| 识字 / 词语 | char-card |
| 文本分析 / 古诗文赏析 | annotate |

## 三、字段字数契约（超限即不合格）

| 字段 | 限制 |
|---|---|
| title | 4~16 字 |
| sequence | items 3~6 个，label 2~16 字，hint ≤20 字 |
| compare-table | cols 2~4 列（每列 ≤12 字），rows 2~5 行（label ≤12 字，cell ≤28 字） |
| timeline | nodes 3~6 个，label 2~12 字，desc ≤30 字 |
| char-card | chars 4~12 个 |
| compare-card | pairs 2~4 组，label 1~6 字，left/right 2~28 字 |
| quote | text 8~100 字，from ≤20 字 |
| diagram | center 2~14 字，branches 3~6 个（label ≤16 字，desc ≤26 字） |
| icon-card | items 3~6 个（label ≤10 字，desc ≤12 字；**禁止把长学习目标直接当 label/desc**） |
| structure | levels 2~4 层（label ≤12 字，每层 children 2~6 项，每项 ≤14 字） |
| flow | steps 3~8 步（label ≤16 字，desc ≤24 字） |
| annotate | text 30~180 字，marks 2~5 个（每个 1~10 字，且**必须在 text 中真实出现**） |

---

## 四、丰满度标准（不达标即不合格）

- **compare-table**：cols 是**比较对象/阶段的正式名称**（如"分封制""郡县制"），
  rows 是**比较维度且至少 2 行**，cells 填对应内容；
  **严禁把 ×/✓/vs/？ 等符号当列名**；严禁只有 1 行；
  **cells 长度必须等于 cols 长度，每一格都必须填具体内容——严禁空串、"—"、"同上"等留空或占位**
  （出现空格的对比表是残表）
- **timeline**：nodes 至少 3 个，每个带简短 desc
- **sequence**：items 至少 3 项
- **char-card**：chars 至少 4 个字，每个带 pinyin 与 word
- **compare-card**：pairs 至少 2 组
- **quote**：text 必须是课文/知识点中的一句完整原话，from 标明出处
- **diagram**：center + branches 至少 3 个分支
- **icon-card**：items 至少 3 个，icon 用 emoji
- **structure**：levels 至少 2 层，每层 children 至少 2 项
- **flow**：steps 至少 3 步
- **annotate**：text 一段完整文本，marks 至少 2 个（必须是 text 中真实出现的词）

**同一课件内必须用到至少 3 种不同组件**（如 sequence + timeline + compare-table 混用）。

---

## 五、版式与组件的关系（易混淆点）

- **layout**（版式）：决定**这一页 bullets 怎么排**——是否渲染成并列卡片
- **visual**（可视化组件）：决定**核心知识用什么图形表达**

两者都要满足字数约束。常见错误：visual 选对了（如 compare-table），
但 bullets 是长句且 layout 选了 `content-grid`，结果下方卡片字被压小。

## 六、常见违规与反例

> 以下全部来自**真实生成被拦截的记录**，不是 hypothetical。每生成一页都要避开。

| 违规 | 反例（错误） | 正确做法 |
|---|---|---|
| **发明组件类型** | `{"type": "example"}` | 无此类型。例题用 `annotate` 或 `compare-table` |
| icon-card 描述过长 | `desc: "通过具体例子理解函数的对应关系"`（15 字） | desc ≤12 字，长内容放 `bullets` |
| compare-table 行名过长 | `label: "三种表示法各自的适用场景"`（12 字，顶格） | label ≤12 字，越短越好 |
| structure 层名过长 | `label: "函数的定义及其三要素"`（10 字尚可，`函数的定义与它的三个基本要素` 超限） | ≤12 字 |
| compare-card 内容过长 | `right: "对于同一个自变量 x 存在两个不同的值与之对应"`（24 字，接近 28 上限） | ≤28 字，超限就进 `bullets` |
| quote 过长 | `text` 102 字 | ≤100 字；更长改用 `annotate`（30~180 字） |
| annotate 关键词过长 | `marks: ["点 (x, f(x))"]` | 每个 mark ≤10 字，且必须真实出现在 text 中 |

### 判断口诀（先数字数，再选组件）

- 短词 / 短语（≤6 字） → `sequence` / `char-card`
- 短句（7~12 字） → `icon-card`（label ≤10、desc ≤12）
- 中长句（13~60 字） → `annotate` / `compare-table` / `compare-card`
- **超过 60 字 → 不要塞进任何组件**，放 `bullets` 或拆成多条

### 交卷前自检（逐项数一遍）

- [ ] `visual.type` 属于 11 种合法类型之一，没有自创
- [ ] `icon-card`：label ≤10、desc ≤12
- [ ] `compare-table`：cols 每列 ≤12、cell ≤28、行数 2~5
- [ ] `compare-card`：label ≤6、left/right 各 ≤28
- [ ] `structure`：层名 ≤12、每项 ≤14
- [ ] `quote`：text ≤100
- [ ] `annotate`：text 30~180、marks 每个 ≤10 且真实出现

> 不通过会被判不合格并重生成。与其被退回，不如一次写对。
