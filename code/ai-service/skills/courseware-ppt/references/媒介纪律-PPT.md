# 媒介纪律 · PPT（固定画布分页）

> 本文件是 **courseware-ppt** 专属纪律，**不适用于 H5**（H5 见 `courseware-h5/references/媒介纪律-H5.md`）。
> 通用约束（跨媒介）在 `shared/质量宪法.md`；本文件只写「PPT 这个媒介**特有**的纪律」。

## 0. 媒介本质（先认清，再谈纪律）

| 维度 | PPT 的事实 |
|---|---|
| 画布 | **固定**（16:9 / 4:3），一页 = 一个取景框，**空间有限** |
| 可见性 | **同屏全可见**——观众一眼看到全部，无法"滚下去" |
| 观看距离 | 投影/大屏，**远观**，字小即不可读 |
| 推进 | **线性翻页**，节奏由讲者控制（不是学生自己点） |
| 时间维度 | **几乎没有**（静态投屏；动效不可靠） |
| 排版模型 | **分块绝对定位**（标题带 / 版心 / 栏 / 卡片 / 槽位） |

**一句话**：PPT 是「一屏定胜负」的媒介——所有信息必须**在同一时刻**成立。

## 1. 铁律（Hard Rules）

### R1 一页一主张（1-6-6 的中文落地）
每页只承载**一个**核心观点；要点 **3–5 条**（宪法 4 条为准则；行业 1-6-6 的上限 6 条为**天花板**，本项目取更严值）；每条 **≤14 字**。

- 依据：业内 1-6-6 / 6×6 规则（SlideModel、WPS、SlideUplift 等）。
- **与宪法的关系**：`shared/质量宪法.md` 第 4 条已定「每页要点 ≤5（理想 3~4）、正文 ≤120 字」。
  本文件**不另立数字**——取更严者：**条数 ∈ [3,5]**、每条 ≤14 字（6 条 × 14 字 ≈ 84 字，也自然满足 ≤120 字）。

### R2 字号必须"远观可读"
标题 **36–44pt**、正文 **22–36pt**（中文投影惯例）；**正文不得低于 22pt**。

- 依据：中文 PPT 制作规范（标题 36–44、正文 22–36）。
- 推论：**字小就意味着内容太多**——正确做法是拆页或减字，不是缩字号。

### R3 层次必须"同屏可分"
`主标题 > 副标题 > 小标题 > 正文 ≥ 注释`，且相邻档差 **≥1.25 倍**。

- 理由：同屏全可见，层次一糊，观众立刻失去阅读顺序。
- 反例（本项目实测）：正文与标题同号 → 观众不知道先看哪。

### R4 空间是"分配"出来的，不是"剩下"的
固定画布下**不允许**"内容撑不满版心"造成的空洞；也不允许为填满而注水。

- 落地：**内容条数 ↔ 版式骨架**必须匹配（见 `版式与组件选型.md`）。
  三栏版式就要求 ≥3 条；只有 1–2 条就**不要**选三栏。
- 反例（本项目实测）：4 条要点硬塞进三栏 → 后两栏空 + 文字溢出卡片。

### R5 静态可读（不依赖动效）
所有信息必须**静态成立**：投屏、打印、截图三种场景下都完整可读。

- 推论：不能有"点一下才出现"的关键信息（那是 H5 的手段，不是 PPT 的）。

### R6 一致性
全篇**字体 ≤2 种**；颜色只用主题语义槽（主色/强调色/弱化色），禁止裸色值。

- 依据：中文 PPT 规范（一两种字体，靠字号/字重拉层次）。

## 2. 由此推出的**禁止项**

| 禁止 | 原因 |
|---|---|
| 整页只放 1–2 条要点 | 固定画布下必然大片空洞（R4） |
| 长句当标题（>14 字） | 挤占版面、远观读不完；应拆「短标题：副标题」 |
| 同页混排 >6 条 | 观众无法同屏处理（R1） |
| 用缩小字号来塞内容 | 投影不可读（R2）；应拆页 |
| 关键信息靠动效呈现 | 投屏/打印失效（R5） |
| 相邻页同版式 | 线性翻页中会丧失"翻页感"，且浪费版式多样性 |

## 3. 自检清单（S4 用）

- [ ] 每页要点数 ∈ [3, 5]，且**均分到各栏**（无空栏）
- [ ] 每条要点 ≤14 字；标题 ≤14 字或已拆「主标题：副标题」
- [ ] 同页字号层次清晰（主 > 副 > 小 > 正文）
- [ ] 所选版式的栏数 ≤ 本页要点数
- [ ] 任一文本块**不溢出**其容器（含卡片）
- [ ] 相邻页版式不同；全篇版式种类 ≥8
- [ ] 无"待补充/占位/XXX"占位符；无元内容（画面描述/风格说明）
