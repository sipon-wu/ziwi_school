# 风格提示词 · 森林童趣（forest）

> 结构说明见 `code/backend/docs/风格提示词库方案.md`
> 原则：**只描述语义与倾向，不给具体色值**；配色由 Skill 当次生成并随 styleDNA 快照进课件。
> 状态：draft（首条样例，颗粒度已确认，待补齐其余风格）

```yaml
id: forest
name: 森林童趣
version: 1

# ── 语义层：人的定义，永不自动改 ──
semantic:
  气质: 自然、亲切、有生机，像走进林间
  形态: 有机曲线、柔和圆角；避免锐利直角与机械感
  母题: 叶片、树、花草、阳光光斑
  禁忌: 霓虹色、金属质感、密集几何、科技感元素（齿轮/电路/像素）

# ── 适用边界：硬约束，必须由人定义 ──
# 教训：曾把「森林童趣」用于初中数学《函数》，花草瓢虫蘑菇的母题与数理内容严重违和，
# 即便把色调调淡也救不回来——母题本身就是童趣符号。
# 「这个风格适合哪些学段/学科」是硬边界，不交给数据学；
# 数据只负责学「在该风格下素材给多少、给几片」。
fit:
  gradeFit: [小学低段, 小学高段]
  subjectFit: [语文, 英语, 科学]
  excludeGrade: [初中, 高中]
  excludeSubject: [数学]

# ── 适配层：数据驱动，可学习 ──
adaptation:
  场景:
    公开课:     { 密度: spacious, 装饰强度: rich,   说明: 视觉优先 }
    导入课:     { 密度: spacious, 装饰强度: rich,   说明: 情境吸引，集中在前 1~2 页 }
    新授课:     { 密度: normal,   装饰强度: medium, 说明: 结构清晰 }
    探究实验课: { 密度: normal,   装饰强度: medium, 说明: 突出步骤与观察 }
    起始导览课: { 密度: normal,   装饰强度: medium, 说明: 突出知识地图 }
    复习课:     { 密度: compact,  装饰强度: light,  说明: 内容密度优先 }
    讲评课:     { 密度: compact,  装饰强度: light,  说明: 题目与批注为主 }
    练习课:     { 密度: compact,  装饰强度: none,   说明: 留白给解题 }
  学段:
    小学低段: { 色彩丰富度: 多彩,   字号倾向: 大 }
    小学高段: { 色彩丰富度: 中等,   字号倾向: 中 }
    初中:     { 色彩丰富度: 克制,   字号倾向: 常规 }
    高中:     { 色彩丰富度: 近单色, 字号倾向: 常规 }

# ── 素材范围：平台维护，按匹配度进化 ──
# ID 与 code/frontend/src/lib/visualAsset/presets.ts 的 DECOR_ASSETS 一致
asset_scope:
  常用: [leaf-sprig, leaf-single, fallen-leaf]
  可用: [tree, blossom, sun, mushroom, ladybug]
  禁用: []

  # 学科收敛：初始先验，可学习（不是硬规则）
  学科收敛:
    数学: { 优先: [leaf-sprig, leaf-single, fallen-leaf], 慎用: [ladybug, mushroom], 理由: 拟物装饰干扰抽象思维 }
    语文: { 优先: [leaf-sprig, blossom, fallen-leaf], 说明: 文本意境为主 }
    英语: { 优先: [sun, tree, leaf-single], 说明: 重情境 }
    科学: { 优先: [tree, sun, leaf-sprig], 说明: 重观察与现象 }
    默认: { 说明: 未覆盖学科走 常用+可用 全集 }

  说明: >-
    最终候选集由平台按 匹配度(素材×风格×学科×学段×场景) 计算后取 top N 注入 Skill。
    本文件的常用/可用/学科收敛只是冷启动的先验值，会被真实使用数据覆盖。

# ── 输出契约 ──
output_contract:
  必须输出: styleDNA（配色 / 字号 / 密度），快照进课件
  禁止输出: 装饰引用中出现裸色值（只能用 主色 / 强调色 / 弱化色 等语义槽）
  素材约束: 只能从平台注入的候选素材 ID 中选用，不得自造新素材

# ── 进化边界：一切都叫匹配度 ──
learning:
  可进化:
    - 候选集排序        # 选用匹配度
    - 各素材默认参数     # 参数匹配度
    - 场景适配值
    - 学段色彩丰富度
    - 学科收敛规则       # 初始先验可被数据推翻
  不可进化:
    - semantic 语义层    # 风格身份由人定义

  匹配度信号:
    多候选选中其一: 强正
    选用后未改动:   弱正
    选用后调参:     中性（方向对，量不对）
    候选内未选用:   弱负
    主动删除:       强负
    触发重新生成:   中负

  收敛规则:
    最小样本: 20        # k-anonymity，低于此不采纳
    迟滞: 收紧易、放宽难
    衰减: 新样本权重递减
    分类型: defect 入全局池；preference 只写个人画像，绝不改全局
```

## 与现有资产库的对应

| 素材 ID | 名称 | 形态特征 | 当前 forest 默认值 |
|---|---|---|---|
| `leaf-sprig` | 草叶 🌿 | 有机 / 簇状 / 轻 | count 2, opacity 0.32 |
| `leaf-single` | 叶片 🍃 | 有机 / 单个 / 轻 | count 1 |
| `fallen-leaf` | 落叶 🍂 | 有机 / 散点 / 轻 | count 2 |
| `tree` | 树 🌳 | 有机 / 单个 / 中 | count 1 |
| `blossom` | 花 🌸 | 有机 / 簇状 / 鲜艳 | count 1 |
| `sun` | 太阳 🌞 | 几何 / 单个 / 鲜艳 | count 1 |
| `mushroom` | 蘑菇 🍄 | 有机 / 单个 / 鲜艳 | count 1 |
| `ladybug` | 瓢虫 🐞 | 有机 / 单个 / 鲜艳 | count 1 |
