# 风格库索引

> 本目录存放**风格提示词**，每条风格一个文件。
> 原则（见 `code/backend/docs/风格提示词库方案.md`）：
> **只描述语义与倾向，不给具体色值**；配色由 Skill 当次生成，随 `styleDNA` 快照进课件。
>
> 本文件由此前的「受控风格词表」改造而来——旧版预置配色表，与上述原则冲突，已废弃其配色部分。

---

## 机制

```
用户选风格（style_tag）或自由描述（style_profile）
      ↓
匹配到本库某条风格提示词（只取语义，不取色值）
      ↓
平台结合 学科 × 学段 × 场景 × 课题，按「匹配度」算出候选素材 ID
      ↓
语义 + 候选素材列表 注入 Skill
      ↓
Skill 发挥配色 → styleDNA 快照进课件 → 渲染层按 styleDNA 执行
```

- `style_tag`：指定风格大类，对应本库一个文件
- `style_profile`：自由描述，由平台匹配到最贴近的一条
- `style_mode`：`auto`（自动）/ `preset`（指定）/ `free`（自由描述）

**版式标注（`<!-- layout -->`）仍须从受控版式集合取，不得因风格自创版式。**

## 风格提示词的边界

| 提示词负责（人定义，部分可学习） | 提示词不负责 |
|---|---|
| 语义：气质 / 形态 / 母题 / 禁忌 | 具体色值（Skill 生成并快照） |
| 适配：场景 × 学段 的倾向 | 字号（Skill 自带排版规范） |
| 素材范围与学科收敛（仅作冷启动先验） | 结构（Skill 跟随内容纲要自选） |

> 学科收敛是**先验而非规则**——若数据显示低年级数学用瓢虫反馈很好，
> 匹配度会自行把它升上来。人的先验只提供冷启动起点。

## 与视觉资产的关系

- 风格通过 `styleDNA` 快照进课件（几十字节），渲染时**只读快照，不读 template_id**
  —— 避免提示词优化一次，所有历史课件外观全变。
- 装饰资产（叶片、花、太阳等）通过 `asset.search` 按风格检索，
  其默认参数由用户反馈持续校准，即**匹配度进化**（详见 `风格提示词库方案.md` 3.4 节）。
- 资产只存形状不存颜色，颜色由 `styleDNA` 在渲染时填入。
