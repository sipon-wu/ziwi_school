## 与相邻风格的区别

| | tech 科技 | academic 严谨学术 |
|---|---|---|
| 气质 | 精密、未来感、数据驱动 | 理性、克制、秩序感 |
| 母题 | 节点连线、网格、数据流、电路 | 几何、线条、坐标系、刻度 |
| 适用 | 数学 / 物理 / 化学 / 生物 / 信息技术 | 数学 / 科学 / 信息技术 / 语文 |
| 色彩倾向 | 冷色为主（蓝青紫） | 中性低饱和（蓝灰墨） |

两者都适合理科，可按课题调性二选一：偏数据与现象选 tech，偏推导与论证选 academic。

## 骨架形态语言（layout_language · 2026-09-03）

> 风格不止是配色与 SVG 母题——**骨架（分栏 / 留白 / 卡片形态 / 图形语言 / 节奏）本身就是风格的一维**。
> 以下约定在该风格下**强制影响版式与分栏选择**，而非仅换色。

- 分栏：**模块化双栏 / 三栏、轴线分区、网格底纹清晰**；结构对称、层级分明。
- 留白：仅保留**功能性留白**（留给数据 / 图），不追求艺术留白；块面饱满、信息密度高。
- 卡片：几何卡片、**发光描边、模块化分区**；强调"框"与"层级"。
- 图形语言：节点连线、网格、坐标轴、电路纹样、数据流；母题作**结构元素**。
- 节奏：以"问题 → 数据 → 结论"或"步骤 → 变量 → 结果"推进；多用**表格 / 对照 / 流程图**。
- 交互承载：重在"测 / 算 / 证"——选择、拖拽、绘图、现象模拟为主。

## 结构序（内容结构骨架 · 2026-09-11）

> 与"骨架形态语言"并列的另一维：**内容按什么顺序、什么范式组织**（顺序本身就是风格）。

- 范式：**问题 → 数据/证据 → 结论**（或 步骤 → 变量 → 结果）。
- 页序参考：抛问题/现象 → 列数据或结构框图 → 模块化拆解 → 验证/推演 → 结论输出。
- 忌：抒情铺陈、故事化旁白堆叠；宜框架先行、层级分明。
