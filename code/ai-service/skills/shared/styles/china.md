## 骨架形态语言（layout_language · 2026-09-03）

> 风格不止是配色与 SVG 母题——**骨架（分栏 / 留白 / 卡片形态 / 图形语言 / 节奏）本身就是风格的一维**。
> 以下约定在该风格下**强制影响版式与分栏选择**，而非仅换色。

- 分栏：偏好**非对称**、竖排标题；以"留白"作为内容呼吸的空间，**避免机械对称网格**。
- 留白：页边与块间大量留白，内容块只占页面约 60~70%，**忌满铺**。
- 卡片：少用圆角实心卡片；多用**细线边框、卷轴/窗棂式分区、印章角标**点缀。
- 图形语言：以**线条勾勒、水墨晕染、云纹窗棂**为主，母题作"点缀"而非"填充"。
- 节奏：以"起承转合"的韵味推进；少用密集列表，多用**图文左右、上题下释**。
- 交互承载：重在"读/赏/品"——点读、朗读、揭晓为主，慎堆选择题。

## 结构序（内容结构骨架 · 2026-09-11）

> 与"骨架形态语言"并列的另一维：**内容按什么顺序、什么范式组织**。
> 它改的是"先讲什么、后讲什么"，不只是"长什么样"（顺序本身就是风格）。

- 范式：**起承转合**——起（意境/背景铺陈）→ 承（层层递进）→ 转（高潮/关键点）→ 合（余韵收束）。
- 页序参考：封面意境 → 背景铺垫 → 品读关键句 → 情境体验 → 生成感悟 → 余韵收束。
- 忌：直给结论、机械并列要点、编号清单式推进。
