# 输出契约（PPT 与 H5 共用骨架）

> 本文件是 `courseware.generate`（PPT）与 `courseware.h5`（H5）的**共用部分**。
>
> **页面内部怎么排，由各自的 references 规定**：
> - PPT：`courseware-ppt/references/版式与组件选型.md`（bullets + `VISUAL_JSON` 组件）
> - H5：`courseware-h5/references/场景与互动规范.md`（`scene` + 角色气泡）
>
> 本文件只讲两者**相同**的部分：分段方式、注释白名单、互动标记、meta、通用禁忌。
> 历史教训：曾把 PPT 结构套到 H5 上（15 页 + bullets + VISUAL），
> 产出"PPT 化的 H5"——文字堆砌、无气泡、无情节。两者不可混用。

---

## 一、输出分两段

严格输出下面两段标记包裹的内容，不要有任何额外说明文字：

```
<<<COURSEWARE>>>
（课件正文，结构见各自的 references）
<<<META>>>
{"style_dna": {"colors": {"primary": "...", "accent": "...", "bg": "..."}, "rendering": "line 或 fill"}, "decor_refs": [{"asset_id": "...", "count": 2, "scale": 1.0, "opacity": 0.15}]}
```

- `style_dna.colors`：**由你按风格卡语义生成**（风格卡只给气质，不给色值）
- `rendering`：按风格选 `line`（克制描边）或 `fill`（饱满面性）
- `decor_refs`：只能从平台给的候选素材清单里选 `asset_id`，**不得自造**；不需要就给空数组

---

## 二、注释白名单（最重要）

平台只认识下面几种注释。**写在页面上的任何其他注释都会原样显示给学生看**，
变成乱码：

```
允许的：layout / VISUAL_JSON / read / readalong / quiz / reveal / draw
```

- **严禁自创任何注释名**
  （`calendar` / `check` / `clock` / `eye` / `drawHint` / `icon` 等一律禁止）
- 想表达"这里配个图标/插图"，**不要写注释**——写进 `decor_refs`，或在正文里用文字说明
- 每个注释**必须以 `-->` 闭合**，写成单行

> 实测：模型自创的 `drawHint` / `check` / `eye` 注释会直接出现在页面上；
> 把 `STYLEDNA` 写进 markdown 同样会显示出来。**承载数据用 meta，不要用注释。**

---

## 三、互动标记（两种课件共用）

直接写标记，平台原样保留。**不要**把互动塞进 `VISUAL_JSON` 的 `type`——
那不是组件，会被丢弃，等于白写（实测因此出现过 0 处互动）。

| 标记 | 用途 | 示例 |
|---|---|---|
| `<!-- read: ... -->` | 点读 | `<!-- read: 苹果 apple / 香蕉 banana -->` |
| `<!-- readalong: ... -->` | 跟读 | `<!-- readalong: 那声音如同山崩地裂 -->` |
| `<!-- quiz: ... -->` | 随堂选择 | `<!-- quiz: 潮来的顺序是？ \| 白线→闷雷→战马 \| 闷雷→白线→战马 \| 战马→白线→闷雷 \| 1 -->` |
| `<!-- reveal: ... -->` | 点击揭示 | `<!-- reveal: 温度怎么变？ => 冷→结冰 / 热→蒸发 -->` |
| `<!-- draw: ... -->` | 现场绘图 | `<!-- draw: 画出水的三态循环 -->` |

格式要点：
- `quiz` 用 `|` 分隔，最后一项是**正确答案索引（0 起）**
- `reveal` 用 `=>` 分隔提示与答案
- **至少 2 处互动**（H5 是硬要求，PPT 同样要求）
- 多道 quiz 的**正确答案位置要打散**：别让所有题的答案都落在同一项
  （如全是 `| 1`）——学生发现规律就不用思考了。实测出现过连续 5 道都是第 2 项。
- 干扰项要有**辨析价值**（设置典型错误），不要放明显荒谬的选项

---

## 四、通用禁忌

- **严禁占位符**：待补充 / 占位 / XXX / TODO / 待定 / （略）
- **严禁 `null` / `None` / 空数组 / 空串**
  ——写 `None` 会在页面上直接显示成"None"；空数组的组件会被整块丢弃（等于白写）
- **严禁字段值出现变量名或半截残词**（如 `title` / `desc` / `误区`）
- 拿不准就用文字说清楚，不要用空值占位

---

## 五、交卷前自检（通用部分）

逐条数一遍再交，下面这几条是实测中最高频的违规：

- [ ] 互动 ≥2 处，且**没有**把互动写成 `VISUAL_JSON` 的 `type`
- [ ] 页面上没有任何白名单外的注释
- [ ] 无占位符、无 `None`、无空数组
- [ ] `style_dna` 给了具体色值（不是空对象）
- [ ] `decor_refs` 的 `asset_id` 全部来自候选清单

> 各自的字数 / 结构自查见对应 references（PPT 看版式与组件选型，H5 看场景与互动规范）。
