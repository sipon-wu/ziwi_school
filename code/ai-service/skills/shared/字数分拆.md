# 字数分拆（通用手法，上限按课件类型取）

> PPT 与 H5 共用**拆句手法**，但**字长上限不同**——投屏卡片与手机气泡的
> 可视宽度不一样，不能共用同一组数字。

**核心原则：动笔前先拆句，别等写完再改。**
先定版式再把长句塞进去，是字密的根源；写完再拆等于整页推翻重来。

---

## 一、拆句的三条手法（按优先级用）

1. **砍修饰**：一句只留一个信息点，删掉"的"字串、程度副词、重复主语
2. **按序断句**：有时间 / 步骤顺序的，一步一句
3. **主谓拆分**：一个主语带多个动作时，一句一个动作

**拆不动就别硬拆**：语义连贯不宜拆的（如原文金句）整块保留，
改走能容纳长文本的形式（PPT 走 `annotate`，H5 放旁白），
**严禁**把一段话切成 N 张卡片——会断裂。

---

## 二、字长上限

### PPT（投屏，卡片横向列宽有限）

| 位置 | 上限 |
|---|---|
| 每页正文（标题 + 全部要点） | ≤120 字 |
| 每页要点条数 | ≤5 条 |
| `content-grid` 每条 | ≤12 字 |
| `content-2col` 每条 | ≤30 字 |
| `edu-goal` / `edu-summary` / `edu-homework` 每条 | ≤30 字 |
| 组件字段 | 见 `courseware-ppt/references/版式与组件选型.md` |

### H5（手机，气泡宽度更窄）

| 位置 | 上限 |
|---|---|
| 每场景（旁白 + 所有气泡） | ≤60 字 |
| 旁白 | ≤40 字 |
| 气泡每条 | ≤20 字 |
| 每场景气泡数 | 2~4 条 |

---

## 三、英文课件（英语课）的换算

上面的数字按**中文字**设计。英语课按**单词数**计，标准约为中文的一半：

| 位置 | 中文 | 英文 |
|---|---|---|
| 标题 | 4~16 字 | 2~8 词 |
| `content-grid` 每条 | ≤12 字 | ≤6 词 |
| `content-2col` 每条 | ≤30 字 | ≤15 词 |
| `annotate` text | 30~180 字 | 15~90 词 |
| `diagram` center | 2~14 字 | 1~7 词 |
| PPT 每页正文 | ≤120 字 | ≤60 词 |

**拿不准就宁短勿长**——英文单词本身占位宽，同样的格子装得更少。
另外 annotate 是用来承载**一段完整文本**的，只有一两句话的作业要求
不要用它（放 `bullets` 即可）。

---

## 四、示例（同一句原文的三种处理）

> 原文（37 字）：
> 潮来时，先听到隆隆的响声，接着看到一条白线，最后白浪翻滚而来

**PPT · 拆成 `content-grid`**（每条 ≤12 字）

- 先闻隆隆响声（6 字）
- 再见一条白线（6 字）
- 后观白浪翻滚（6 字）

**PPT · 拆成 `content-2col`**（每条 ≤30 字）

- 先闻隆隆响声，再见一条白线（13 字）
- 白浪翻滚，浪潮越来越近（11 字）

**H5 · 拆成气泡**（每条 ≤20 字）

```
**角色**：老师，小明
老师: 潮来时先听到什么？
小明: 隆隆的响声！
老师: 接着看见什么？
小明: 一条白线移过来！
```

**反面案例**

> 把"通过学习本课，学生能够掌握比喻的修辞手法并运用到写作中"（27 字）
> 塞进 `icon-card` 的 desc（上限 12 字）→ 字被压到看不清。
> 正确：desc 只写"比喻·运用"（5 字），完整表述放 `bullets`。
