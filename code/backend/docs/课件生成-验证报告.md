## 五、本轮发现并修复的问题

| # | 问题 | 修复 |
|---|---|---|
| 1 | 候选集无区分度：命中项同分→按 id 排序→森林风推 `alien`(外星人) | 引入**风格语义关键词**打分 |
| 2 | 语义刷屏：`alert-circle/square/triangle` 占满候选 | **词根去重**，同词根最多 2 个 |
| 3 | 图标对风格无差异，仍按字母序 → `alert-hexagon` 排前 | 引入**常用度**权重 |
| 4 | 索引 5.0 MB，前端不可用 | 枚举索引化 + 紧凑输出 → **419 KB** |
| 5 | 13M SVG 在 `src/` 下会被打进 bundle | 素材库移至**后端** `ai-service/assets/` |
| 6 | 24 个早期样本 `variants` 为空（`v={}`）导致渲染崩溃 | 回退到默认 `svg/{id}.svg` |
| 7 | Tabler tags 混有数字/None 导致拼接崩溃 | 过滤非字符串 |
| 8 | 装饰含 `-off` 状态变体（如 `leaf-off`） | 装饰类排除 `-off` |

## 六、待确认 / 待办

1. **中文名缺失** —— 批量导入的 2512 个资产 `name` 仍是英文 id（`christmas-tree`、`bookmark`）。
   Skill 能读懂，但教师端显示素材名时需要中文。建议后续用 AI 批量翻译一次。
2. **补真实模型调用** —— 拿到 key 后跑一次，验证模型是否遵守「只从池中选用」「不写裸色值」等约束。
   这也是检验输出契约是否合理的关键。
3. **候选池粒度** —— 当前是整套课件共用一个池（15 装饰 + 15 图标 + 9 组件）。
   若发现模型选用过于集中，可细化到**按页**计算候选。
4. **候选池尾部质量** —— 森林风池子前 9 个都是相关素材，但凑满 15 个时尾部混入了 `alien`、`balloon`。
   可通过提高阈值或扩充森林类素材解决。
5. **匹配度尚无真实数据** —— 当前排序全靠先验规则。需要接上反馈采集，才能开始进化。
