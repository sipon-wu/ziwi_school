# 《观潮》真课件设计稿

> 四年级语文 · 30 分钟 · 国风水墨（zgf-ink-wash）
> 设计原则：**呈现"知识是什么结构"，而非"教学走什么流程"**
> 与前一版（教案变体）的本质区别见文末对照表

## 0. 设计总则

| 原则 | 要求 |
|------|------|
| 一页一焦点 | 一屏只承载 1 个核心信息，其余都是它的支撑 |
| 图为主、文为辅 | 每页至少 1 个视觉主体（图/表/结构），文字只做标注与点睛 |
| 知识结构化 | 关系用结构表达：递进用箭头、对比用表、顺序用轴、并列用网格 |
| 互动当堂可操作 | 不是"建议做"，而是页面上就有可执行的任务/选择 |
| 零占位符 | 无"待补充""占位""XXX" |

## 1. 页面设计（14 页）

### P1 封面
- **视觉**：钱塘江大潮全景图作全屏背景，课题《观潮》居中大字（楷体）
- **组件**：`image-full` + 标题层
- **文案**：《观潮》 / 四年级 · 语文 / 授课教师：李老师
- **素材**：大潮全景图

### P2 这节课我要学会（目标卡）
- **视觉**：4 个图标卡片横排，每卡一个图标 + 一句目标
- **组件**：`icon-card` × 4（图标卡）
- **文案**：
  - ✍ 认 12 个生字，写 15 个字
  - 🔊 读准「号」「闷」多音字
  - 📖 背诵第 3、4 自然段
  - 👁 学会按顺序观察
- **差异**：不是"3~4 条文字目标"，而是可扫视的图标卡

### P3 导入：什么叫"天下奇观"
- **视觉**：大潮视频/动图占左半屏，右侧一个大问号 + 问题
- **组件**：`image-text`（图左文右）
- **文案**：问题——"潮水会是什么样子？用一个词形容"
  - 小知识：农历八月十八，钱塘江大潮最壮观
- **互动**：学生口头说一个词，教师板书关键词
- **素材**：大潮视频（15 秒）

### P4 生字卡墙
- **视觉**：生字卡片网格（12 张），每卡：田字格大字 + 拼音 + 一个组词
- **组件**：`char-card`（生字卡）★ 新组件
- **内容**：盐 屹 昂 鼎 沸 贯 崩 震 霎 余（会认）
- **互动**：点读——点一张卡，读一个字（可接 TTS 或教师带读）
- **差异**：不是"会认的字：盐、屹、昂…"一行文字，而是可点读的字卡墙

### P5 多音字辨析
- **视觉**：左右对比卡，每个多音字两栏（读音 + 例词）
- **组件**：`compare-card`（对比卡）★ 新组件
- **内容**：
  - 号：háo（号叫）｜hào（号码）
  - 闷：mēn（闷热）｜mèn（烦闷）
- **互动**：选词填空——"钱塘江大潮的声音如同山崩地裂，令人震（hàn/háo）"

### P6 课文脉络（时间轴）★ 核心结构页
- **视觉**：横向时间轴，3 个节点（潮来前 → 潮来时 → 潮头过后），每节点配小图 + 关键词
- **组件**：`timeline`（时间轴）★ 新组件
- **内容**：
  - 潮来前：江面平静、人群等待
  - 潮来时：白线→水墙→战马（重点）
  - 潮头过后：余波漫天卷地
- **差异**：不是"理脉络：潮来前→潮来时→潮头过后"一行文字，而是**可视化的时间结构**

### P7 潮来前（图文）
- **视觉**：平静江面 + 等待人群的图，右侧关键词 + 一句原文
- **组件**：`image-text`
- **文案**：
  - 关键词：平静、昂首东望、等着 盼着
  - 原文：「江面上很平静……大家昂首东望，等着，盼着。」
  - 心情：急切、期待
- **素材**：平静江面图

### P8 潮来时（递进图）★ 最核心页
- **视觉**：
  - 左侧：浪潮大图
  - 右上：**样子递进**——白线 ⟶ 水墙 ⟶ 千万匹白色战马（三格递进，配小图）
  - 右下：**声音递进**——闷雷滚动 ▁ → 越来越大 ▃ → 山崩地裂 ▇（音量条递进）
  - 底部：原文金句大字居中
- **组件**：`sequence`（递进图）★ 新组件 ×2 + `quote`（金句大字）★ 新组件
- **文案**：
  - 金句：「浪潮越来越近，犹如千万匹白色战马齐头并进，浩浩荡荡地飞奔而来；那声音如同山崩地裂，好像大地都被震得颤动起来。」
- **互动**：模仿读——从"闷雷滚动"到"山崩地裂"，声音层层递进
- **素材**：浪潮如战马图
- **差异**：这是全课高潮页，用**双递进图 + 金句**承载，而非 5 条文字要点

### P9 潮头过后（图文）
- **视觉**：余波翻涌图 + 关键词 + 原文
- **组件**：`image-text`
- **文案**：霎时 / 漫天卷地 / 风号浪吼
  - 原文：「霎时，潮头奔腾西去，可是余波还在漫天卷地般涌来……」

### P10 三阶段对比表 ★ 知识结构化核心
- **视觉**：3×3 对比表——行=样子/声音/人群，列=潮来前/潮来时/潮头过后
- **组件**：`compare-table`（对比表）★ 新组件
- **内容**：

|  | 潮来前 | 潮来时 | 潮头过后 |
|--|--------|--------|----------|
| 样子 | 江面平静 | 白线→水墙→战马 | 余波漫天卷地 |
| 声音 | 无声 | 闷雷→山崩地裂 | 风号浪吼 |
| 人群 | 昂首东望、等着盼着 | 人声鼎沸 | 久久不能平静 |

- **差异**：这是**知识结构**，不是教学环节。前一版完全没有这一页

### P11 作者怎么观察的（示意图）
- **视觉**：由远及近的观察顺序示意图（横向箭头 + 距离刻度：远处 → 近处 → 眼前），
  下方两个感官图标（👁 看到的 / 👂 听到的）各挂关键词
- **组件**：`diagram`（示意图）+ `icon-tag`（图标标签）★ 新组件
- **内容**：
  - 顺序：时间顺序 + 由远及近
  - 看到：白线、水墙、白色战马
  - 听到：闷雷滚动、山崩地裂

### P12 修辞赏析（标注文本）
- **视觉**：原句大字，修辞处**高亮标注**（比喻=蓝框，夸张=红框），下挂效果说明
- **组件**：`annotate`（标注文本）★ 新组件
- **内容**：
  - 「浪潮越来越近，[犹如千万匹白色战马齐头并进]（比喻：写出气势与速度）」
  - 「那声音[如同山崩地裂，好像大地都被震得颤动起来]（夸张：突出声势）」

### P13 小练笔：我是小导游（任务卡）
- **视觉**：任务卡（角色 + 任务 + 三个必用词 + 顺序提示），麦克风图标
- **组件**：`task-card`（任务卡）★ 新组件
- **内容**：
  - 角色：小导游
  - 任务：向游客介绍钱塘江大潮
  - 必用词：人声鼎沸 / 浩浩荡荡 / 山崩地裂
  - 顺序：潮来前 → 潮来时 → 潮头过后
- **互动**：当堂口语展示，同学互评

### P14 课堂小结（知识结构图）
- **视觉**：结构图——中心"观潮"，三个分支（顺序 / 方法 / 写法），每分支 2 个关键词
- **组件**：`structure`（结构图）★ 新组件
- **内容**：
  - 顺序：潮来前 → 潮来时 → 潮头过后
  - 方法：按顺序观察、抓特点、多感官
  - 写法：比喻 + 夸张
- **差异**：不是 4 条文字罗列，而是**结构化的知识图**

> 分层作业合并进 P14 底部小字条或作为 P15，三档：基础（抄写背诵）/ 提高（观察写话）/ 拓展（搜集奇观资料）

### 实现说明（B 阶段已完成部分）

- **数据层**：`OutlineSlide.visuals` / `CwSlide.visuals`，通过 `<!-- VISUAL:base64 -->` 内嵌
  （与既有 `CW-EL`/`CW-IT` 同款机制），一页可挂多个组件
- **组件层**：`frontend/src/components/VisualBlocks.tsx`（预览渲染）
  + `exportPptx.ts` 的 `renderVisualToPptx()`（导出为 PPTX 原生形状/表格，非图片）
- **生成层**：`cmd/seed/courseware` 支持 `slide.visuals`（JSON → base64）
- **验证**：staging 实测 14 页，递进图/对比表/时间轴/生字卡/金句/对比卡均正确渲染；
  导出 PPTX 15 页，组件内容完整落地

## 4. 与前一版（教案变体）的对照

| 维度 | 前一版（教案变体） | 本设计稿（真课件） |
|------|------------------|------------------|
| 主线 | 教学环节流（导入→新授→练习→小结→作业） | 知识结构（脉络→对比→写法→运用） |
| 每页内容 | 5 条文字要点（活动清单） | 1 个视觉主体 + 标注文字 |
| 知识关系 | 文字罗列 | 递进图/对比表/时间轴/结构图 |
| 生字 | "会认的字：盐、屹、昂…" 一行文字 | 12 张可点读字卡 |
| 潮来时 | 5 条文字（含整段金句） | 双递进图 + 金句大字 |
| 三阶段对比 | 无 | 3×3 对比表 |
| 小结 | 4 条文字罗列 | 知识结构图 |
| 素材 | 无（文字描述"播放视频"） | 5 张图 + 1 视频实际引用 |

## 5. 实现路径（B 阶段）

1. **数据层**：提纲 markdown 扩展语法，支持组件块与素材引用
   - 组件：`:::sequence` / `:::compare-table` 等块语法，或 `<!-- comp: ... -->` 注释语法
   - 素材：`![说明](asset:xxx)` 引用素材库
2. **组件层**：`cwTemplate.ts` 的 placeholder 增加 `kind`（sequence/table/timeline/...），
   或在 `OutlineSlide` 上挂 `components: VisualComponent[]`
3. **渲染层**：`PptxPreview.tsx` 预览 + `exportPptx.ts` 导出分别实现各组件的绘制
4. **宪法层**：`api_server.py` 提示词增加"输出结构化组件"的要求

> 建议先做 P0 四个组件（sequence / compare-table / timeline / char-card），
> 让《观潮》先立起来，再逐步补齐。
