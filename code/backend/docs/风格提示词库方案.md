# 风格提示词库方案

> 定位：**风格的生产方式** —— 用提示词描述风格语义，让 Skill 自行发挥；用适配矩阵承接经验，让数据持续进化。
> 核心判断：**风格不是配置表，是提示词**；**配色不是预置值，是 Skill 的产出并快照**。
> 目标：好看、省时、省 token。

---

## 一、为什么不预置配色

预置 9 套配色（风格 → 色值映射）看起来省事，实际是**用新的硬编码替换旧的硬编码**：

| 问题 | 说明 |
|---|---|
| 捆住 Skill 手脚 | Skill 本就自带配色与排版能力（见能力清单），预置反而是干扰 |
| 上限锁死 | 新增风格要改代码、加配置，不是加一条提示词 |
| 忽略上下文 | 同样「森林童趣」，二年级和初二本就不该一个配色 |
| 维护成本 | 每套配色都要人调、人验 |

**风格的表达方式应该是描述，不是赋值。**

---

## 二、两层结构：语义不变，适配可学

```
┌─ 语义层（风格身份）───────────────┐
│  "森林童趣 = 自然、有机形态、柔和圆角" │  ← 人定义，永不自动改
└────────────────────────────────┘
┌─ 适配层（经验值）─────────────────┐
│  场景 × 学段 → 密度/装饰/色彩丰富度   │  ← 数据驱动，持续进化
└────────────────────────────────┘
```

**语义是身份，适配是分寸。** 学习内容永远是后者——
系统学会的是「初二复习课用森林风时装饰给多少」，而不是「森林风是什么」。

## 三、上下文维度

风格提示词的输出不是单一方案，而是**随上下文变化的分寸**：

### 3.1 学龄段 → 色彩丰富度

| 学段 | 色彩策略 | 教学依据 |
|---|---|---|
| 小学低段 | 多彩活泼，4~6 色，字号偏大 | 吸引注意力，形象思维为主 |
| 小学高段 | 主色 + 2~3 辅助色 | 建立秩序感 |
| 初中 | 主色 + 1 强调色，克制 | 抽象思维发展，减少干扰 |
| 高中 | 近乎单色，靠层次与留白 | 内容密度高，色彩让位信息 |

### 3.2 场景 → 密度与装饰强度

原「公开/新授/复习/练习」四分漏了几类真实课型，扩充为八类：

| 场景 | 视觉取向 | 装饰强度 | token |
|---|---|---|---|
| **公开课/展示课** | 视觉优先，要"好看" | rich | 高 |
| **导入课** | 情境感、吸引力（集中在前 1~2 页） | rich | 高 |
| **新授课** | 结构清晰、引导性强 | medium | 中 |
| **探究/实验课** | 步骤、观察记录 | medium | 中 |
| **起始/导览课** | 知识地图、全局结构 | medium | 中 |
| **复习课** | 密度优先、重归纳对比 | light | 低 |
| **讲评课** | 题目呈现 + 批注 | light | 低 |
| **练习课** | 留白给解题 | none | 最低 |

> **按场景控制装饰强度，是省 token 最直接的杠杆**——比压缩提示词有效得多。
> 日常课不需要公开课那套装饰；练习课的装饰纯属浪费。

### 3.3 学科 → 素材收敛

学科参与素材收敛，且**这种收敛不是硬规则，是平台学习出来的能力**（见 3.4 匹配度）。

初始倾向（先验，供学习起步）：

| 学科 | 素材倾向 | 说明 |
|---|---|---|
| 数学 | 收敛：几何、点线、网格；慎用拟物 | 装饰过多干扰抽象思维 |
| 语文 | 开放：金句、文本、意境元素 | 文本呈现为主 |
| 英语 | 情境化：对话、场景 | 重情境 |
| 科学 | 实验器材、观察记录 | 重步骤与现象 |

**注意**：这些只是**初始先验值**，不是写死的规则。
例如"数学课不用瓢虫"不应由人写死——如果数据显示低年级数学用瓢虫反馈很好，
匹配度会自己把它升上来。人的先验只是给学习一个起点，避免冷启动时胡选。

### 3.4 匹配度：统一的进化标尺

> **一切都叫匹配度。** 素材该不该用、用多少、风格是否合适——统一用匹配度衡量与进化。

#### 定义

```
匹配度(素材 × 风格 × 学科 × 学段 × 场景) ∈ [0, 1]
```

#### 两类匹配

| 类型 | 回答什么 | 输出 |
|---|---|---|
| **选用匹配度** | 这个素材该不该用 | 候选集排序、淘汰 |
| **参数匹配度** | 用多少、多大、多透明 | 默认值 |

#### 信号与权重

| 信号 | 方向 | 说明 |
|---|---|---|
| 多候选选中其一 | 强正 ⭐⭐⭐⭐⭐ | 对比式偏好，无歧义 |
| 选用后未改动 | 弱正 ⭐ | 默认接受 |
| 选用后调参 | 中性 ⭐⭐⭐ | 方向对，量不对 |
| 候选内未选用 | 弱负 | 被比下去 |
| 主动删除 | 强负 ⭐⭐⭐⭐ | 明确否定 |
| 触发重新生成 | 中负 ⭐⭐ | 不满，但不知不满在哪 |

#### 收敛规则

- **最小样本**：分组样本 < 20 不输出、不入表（k-anonymity）
- **迟滞**：收紧易、放宽难，防震荡
- **衰减**：新样本权重递减，避免少量反馈颠覆长期共识
- **分类型**：`defect`（通病）入全局池；`preference`（偏好）只写个人画像，**绝不改全局**

#### 匹配度的用途

1. 计算候选集（取 top N，直接注入 Skill）
2. 决定各素材的默认参数
3. 淘汰长期低匹配的素材
4. 反哺新素材入库时的初始标注

#### 与三目标的关系

| 目标 | 匹配度的贡献 |
|---|---|
| **好看** | 高匹配组合 = 经真实使用验证过的搭配 |
| **省时** | 平台直接给 top N，Skill 不必试错、不必检索 |
| **省 token** | 候选精准 → 不现造；排序靠前 → 少折腾 |

## 四、StyleDNA 快照：稳定与可演进的分离

| 层 | 稳定性 | 说明 |
|---|---|---|
| 风格提示词（语义+适配） | 🔄 可演进 | 服务端持续优化，**只影响新生成** |
| **StyleDNA（具体配色/字号/密度）** | ✅ **快照进课件** | Skill 当次生成决定，此后永不漂移 |

**Skill 每次自由决定具体配色，一旦产出即快照。** 于是：

- 同一份课件内部统一、重开不变（读快照，不重新问 Skill）
- 老课件不受提示词后续优化影响
- 不同课件可有细微差异，但都在风格语义内

这落实了《课件视觉资产架构方案》里「风格描述卡可演进 / 风格 DNA 快照」的分层不可变性——
两者此前被混为一谈，是预置配色念头的根源。

---

## 五、资产不存颜色

```
资产（存库）：  只存形状，不存颜色
Skill 产出：    StyleDNA（配色/字号/密度），快照入课件
渲染层：        按 StyleDNA 给资产上色
```

- 装饰资产绝大多数是单色或双色，SVG 用 `currentColor`（单色）或主/辅两个占位即可
- **一份资产复用所有风格**：同一片树叶，森林风是绿的、极简风是灰的
- 输出契约只约束一句：**装饰引用里不许出现色值**，只能写「用主色」还是「用强调色」

## 六、学习闭环

```
生成（学段 × 场景 × 风格）
   ↓
用户改动："装饰太多了" / "字太小" / "太素了"
   ↓
结构化：{context: 初二×复习课×forest, param: decor, op: decrease}
   ↓
累积判定：同类 ≥N 次 且 样本 ≥20（k-anonymity），收紧易、放宽难（迟滞防震荡）
   ↓
修正该组合的适配值：复习课×forest → decor: light → minimal
   ↓
下次同场景生成自动生效
```

### 三类反馈必须分开

| 类型 | 例子 | 处理 |
|---|---|---|
| **个案** | "这个例子不合适" | 只改当前，不入池 |
| **通病** | "刻度太密" | 入池，累积校准 |
| **偏好** | "我不喜欢圆角" | 写个人画像，**绝不改全局** |

**偏好误判成通病是最大污染**——一个教师不喜欢圆角，不该让全校课件变直角。

### 度量：引用命中率

```
命中率 = 1 − (用户修改过的装饰资产数 / 引用的装饰资产总数)
```

按 `风格 × 场景 × 学段` 分组统计，低命中组合即优先校准对象。

## 七、三目标如何同时达成

| 目标 | 依靠 |
|---|---|
| **好看** | 语义给方向 + 场景/学段给分寸（该多的多、该少的少）+ 素材复用保证品质一致 |
| **省时** | 适配值是现成经验，Skill 不必每次从零推演；素材引用不现造 |
| **省 token** | 场景控制装饰强度（练习课零装饰）+ 资产只引用不生成 |

三者同源：**素材复用与经验复用，同时贡献省时、省 token 和品质稳定。**

## 八、提示词模板

```yaml
# styles/forest.md
id: forest
name: 森林童趣
version: 1
semantic:                        # ← 语义层：人定义，不自动改
  气质: 自然、亲切、有生机
  形态: 有机曲线、柔和圆角、避免锐利直角
  母题: 树叶、藤蔓、光斑、木纹
  禁忌: 霓虹色、金属质感、密集几何

adaptation:                      # ← 适配层：数据驱动，可学习
  场景:
    公开课: { 密度: spacious, 装饰: rich,   说明: 视觉优先 }
    新授课: { 密度: normal,   装饰: medium, 说明: 结构清晰 }
    复习课: { 密度: compact,  装饰: light,  说明: 内容密度优先 }
    练习课: { 密度: compact,  装饰: none,   说明: 留白给解题 }
  学段:
    小学低段: { 色彩丰富度: 多彩, 字号倾向: 大 }
    小学高段: { 色彩丰富度: 中等, 字号倾向: 中 }
    初中:     { 色彩丰富度: 克制, 字号倾向: 常规 }
    高中:     { 色彩丰富度: 近单色, 字号倾向: 常规 }

output_contract:
  必须输出: StyleDNA（配色/字号/密度），快照进课件
  禁止输出: 色值直接写在装饰引用里（只能用主色/强调色等语义槽）
```

**新增风格 = 新增一个这样的文件，零代码。**

## 九、素材供给管线与进化归属

> 核心原则：**进化是平台的职责，不是 Skill 的。**

Skill 是无状态执行者——每次调用都是新会话，不记得上次教师说过"云朵太多"。
指望它替平台积累经验是不可能的，必须由平台承接。

### 9.1 职责切分

| | Skill（当次） | 平台（跨次） |
|---|---|---|
| 素材 | 从候选里选、给参数 | 维护素材库、计算候选集 |
| 风格 | 按语义发挥配色 | 维护语义、收集反馈、进化适配值 |
| 记忆 | 无 | 命中率统计、默认值校准 |

### 9.2 供给管线：把候选素材直接给 Skill

生成风格提示词时，平台**已经知道内容与素材库**，因此应当直接给出候选素材，
而不是让 Skill 自己检索或现造。

```
风格提示词（静态母题 / 禁忌）
      ＋
内容理解（学科 × 学段 × 场景 × 课题）
      ↓  平台计算
候选素材 ID 列表（按历史命中率排序）
      ↓  注入 prompt
Skill 直接选用，不自造、不检索
      ↓
选用结果回流 → 更新命中率 → 优化候选集与排序
```

**给 ID，不给素材定义。** Skill 拿到的是：

```
可用素材：leaf-cluster(常用)、vine-border(常用)、sun-spot、wood-texture
请从中选用并给出参数，不要自造新素材。
```

Skill 省去检索与现造开销，平台保证风格不串味。

### 9.3 进化什么（平台侧）

| 对象 | 进化依据 |
|---|---|
| 候选集排序 | 哪些素材被频繁选中 → 升入「常用」 |
| 素材淘汰 | 命中率持续偏低 → 移出候选 |
| 默认参数 | 用户反复调整同一参数 → 修正该 素材×风格×场景 的默认值 |
| 场景适配值 | 某场景下装饰被频繁调少 → 下调该场景装饰强度 |

信号强度：多候选选中其一 ⭐⭐⭐⭐⭐ ＞ 主动删除 ⭐⭐⭐⭐ ＞ 主动调参 ⭐⭐⭐ ＞ 重新生成 ⭐⭐ ＞ 默默接受 ⭐

### 9.4 这为什么省 token

Skill 现造一片叶子 ~500 tokens；平台给一个 ID ~30 tokens。
**给候选 ID 列表，同时省掉了"检索"和"生成"两段开销。**
