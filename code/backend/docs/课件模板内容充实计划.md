# 课件模板内容充实计划（PPT / H5）

> 关联：[模板外移方案.md](./模板外移方案.md)
> 状态：计划已定，第 1 步执行中

## 1. 背景与问题

模板外移（见 `0008_courseware_templates.sql` + `CoursewareTemplate` model）已完成：
PPT 模板池 `PPT_TEMPLATE_DEFS` 53 套、H5 模板池 `H5_TEMPLATE_DEFS` 36 套，结构统一、标签体系一致。

但盘点发现当前模板**"内容不充分"**，根因在 `frontend/src/lib/cwTemplate.ts` 的工厂实现：

```ts
function pptTemplate(id, def, kind = 'ppt'): CwTemplate {
  return {
    ...
    layouts: { ...EDU_LAYOUT_SKELETONS },   // ① 所有模板共用同一套骨架
    demoOutline: eduDemoOutline(),          // ② 所有模板共用同一套 7 页通用提纲
  }
}
```

即 89 套模板**视觉上只是换配色/装饰，内容骨架与示例提纲完全雷同**——教师套用国风语文、卡通幼儿园、科技物理时，看到的都是同一个《课程标题》填空模板，没有贴合场景的差异化内容。

## 2. "内容充分"的标准

一套"内容充分"的课件模板应满足：

| 维度 | 现状 | 充分标准 |
|------|------|----------|
| `layouts` | 全部 `{ ...EDU_LAYOUT_SKELETONS }` | 允许按风格/学科声明差异化版式骨架（如语文封面更强调整体意境、幼儿园更强调图文大字） |
| `demoOutline` | 全部 `eduDemoOutline()`（7 页通用） | 按 **风格 × 学科 × 学段** 提供贴合场景的示范提纲（标题、要点、版式、备注均场景化） |
| 学科贴合 | 模板有 `subjects` 标签但提纲无关 | 提纲内容体现该学科典型教学环节（语文：作者背景/意象赏析；物理：概念/例题/易错；幼儿园：情境/游戏/亲子） |
| 学段贴合 | 模板有 `grades` 标签但提纲无关 | 幼儿园用童趣语言+游戏环节；高中用探究/归纳环节 |

## 3. 覆盖矩阵（待充实范围）

PPT（53 套）按风格分布：china 7、minimal 7、tech 5、fresh 5、academic 4、cartoon 8、flat 3、business 2、basic 3。
H5（36 套）同理。

优先填充顺序（按使用频率/价值）：
1. **语文 / 历史**（国风、china-chinese）
2. **幼儿园 / 小学低段**（卡通、fresh、cartoon-kindergarten）
3. **数理化学科**（tech / academic + math/physics/chemistry）
4. **通用班会 / 开学第一课**（cartoon-class-meeting）
5. H5 互动场景（同上映射）

- [x] 本计划文档

## 5. 风险与纪律
- **零回归**：PPT 池其余 51 套 + H5 池 36 套（未显式声明 `demoOutline`）回落 `eduDemoOutline()`，视觉与内容行为不变；第 2、3 步按学科/学段逐个充实后，每套模板将各自套用贴合其套路（语文/数理/幼儿园等）的差异化提纲
- **类型安全**：`demoOutline` 严格为 `OutlineSlide[]`，复用已有 `OutlineSlide` 类型
- **不重写骨架**：`layouts` 差异化仅在后续按需补充，本期以 `demoOutline` 为主抓手（版式骨架已通用够用）
- 每步独立可验证，便于 review
