# 存量 H5 课件「展示性升级」执行方案

> 日期：2026-09-03 ｜ 目标：让存量 H5 课件（几百套）不重做也吃上新能力
> （真实主题形态 / styleDNA morph 形态字典 / v2 自然科学组件 / phenomenon 版式）。

## 为什么存量"展示性不行"——三个根因

1. **扫码/预览读的是发布时的旧快照**（`materials.h5_html` 是当时生成的自包含 HTML）。
   渲染器升级不会自动进入快照 —— 新能力只对新生成/重新发布生效。
2. **渲染入口硬编码 `themeId: 'storybook'`**（已修，见 §3）：库里存了 theme_id
   （forest/night…），但渲染从不使用 → 皮肤只一种，morph 默认形态也永远 storybook。
3. **内容结构同构**：需要内容级重生成/改稿，渲染升级治不了。

## 分层执行（由轻到重）

| 层 | 动作 | 见效 | 成本 |
|---|---|---|---|
| L0 渲染修 bug | CoursewareBuilder 渲染改用真实 themeId（**已完成**，见 §3） | 下次发布/编辑即不同皮肤+形态 | 已合入 |
| L1 一键重渲染 | 批量把旧快照 h5_html 用新引擎回填（脚本 §4） | **扫码页立即**升级 morph/主题/现象页 | 跑一次脚本 |
| L2 形态兜底 | styleDNA 无 morph 时按主题默认（已生效）；可选回填 morph 到 color_root | 渲染端已自动 | 无需 |
| L3 内容级 | 挑"结构最单一"的少量课件重生成（新 skill 会产出 phenomenon+多风格） | 同构页被根治 | 少量 AI 调用 |

## 已完成的代码（本方案前置）

- `styleDNA morph` 形态字典：`parseStyleDNA` 解析 morph（density/motion/motif），
  H5 renderer 按主题默认 + 显式 morph 渲染不同疏密/动效/装饰母题（9 项 E2E 全过）。
- H5 互动组件 v2：`weather / storm / cycle`（解析+渲染+WebAudio 音效+质检白名单+Skill 规范）。
- notice 家校宣发全链路（后端 + 红线 + Skill + 前端页面）——非课件宣发，与升级无关。
- **CoursewareBuilder 三处 `themeId:'storybook'` → 真实 `themeId` state**（加载回放 / AI 生成 / 发布）。

## 执行步骤

### ① 盘点（只读）
```bash
# 在能连目标库（staging/prod）的 ai-service 环境：
DATABASE_URL=postgresql://... .venv/bin/python scripts/audit_h5_materials.py --csv /tmp/audit_h5.csv
```
输出：可重渲染份数 / 旧快照份数 / morph 覆盖情况 / theme_id 分布。

### ② 重渲染（先 DRY-RUN，再 --apply）
```bash
cd qa
npm init -y && npm i pg            # 一次性（Node 端 pg 客户端）
# 先确保 dist-h5/courseware-h5.mjs 是最新（frontend: npx vite build --config vite.lib.config.ts）
DATABASE_URL=postgresql://... node rebuild-h5.mjs                 # DRY-RUN 报告
DATABASE_URL=postgresql://... node rebuild-h5.mjs --apply --limit 20   # 试点 20 份
DATABASE_URL=postgresql://... node rebuild-h5.mjs --apply         # 全量
```
说明：
- 只处理 `format='h5'` 且 content 为场景 markdown 的课件；已是新引擎快照（含 `morph-`）自动跳过。
- 按 `theme_id + color_root` 渲染，与前端 CoursewareBuilder 同一渲染入口（保证一致）。
- 失败逐条记录不中断；建议分批（--limit）先试点抽查扫码页效果。

### ③ 抽查验收
任选 3~5 份：打开扫码链接 `/api/materials/<id>/h5`（手机扫码）对照：
- 不同 theme_id 课件应呈现不同皮肤 + 疏密/动效差异（不再清一色）；
- 页面含 `data-motif`、CSS 中 `--deco-dur` 即确认新引擎。

### ④ 内容级（可选）
针对盘点里"结构最单一/用户点名"的课件：在小微用"风格多样化/换个场景组织"提示词改稿并重新发布；
或让 AI 用 courseware-h5 Skill 新语法重生成（含 scene-phenomenon 与 v2 组件）。

## 注意
- 脚本会改写 `materials.h5_html`（发布留痕在 versions 表，建议跑前人工备份或先 --limit 试点）。
- 重渲染只升级"快照与形态"，**不改变已发布内容正文**（content 不动）。
- PPT 课件的展示升级不在本方案（PPT 模板消费 morph 为后续小步）。
