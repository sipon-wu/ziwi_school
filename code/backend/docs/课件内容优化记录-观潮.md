# 《观潮》PPT 课件优化记录

> 示范样本：四年级语文《观潮》（30 分钟课时）
> 目的：验证"什么样的课件才够格"，成功后抽象为通用原则写入生成宪法
> 状态：已优化并部署 staging 验证通过

## 一、基线问题（优化前的样子）

基线版本 8 页（1 封面 + 7 内容页），导出 PPTX 后暴露的核心问题：

| 问题 | 表现 | 性质 |
|------|------|------|
| **教案语言 ≠ 学习内容** | "会认会写本课 12 个生字词"（没说哪 12 个）、"教师点拨：作者怎样把…结合起来写"（学生看不懂） | 内容定位错误 |
| **没有真实教学内容** | 无生字表、无课文原文、无词句赏析——学生看不到任何可学的具体知识 | 内容空洞 |
| **趣味性为零** | 7 页全是文字要点，四年级学生需要图片/游戏/角色扮演 | 学段错位 |
| **撑不起 30 分钟** | 7 页密度太低，按每分钟 1 页都讲不满 | 课时不匹配 |
| **占位符泄漏到成品** | "思维导图占位"直接出现在 slide7/8 上 | 完成度缺陷 |
| **版式错配** | 4-5 条要点页用 `edu-explain`（2 槽位教学版式），内容被挤到溢出、被装饰遮挡 | 呈现缺陷 |

**根因判断**：内容源是"教师视角的教案提纲"，而课件的服务对象是**学生**——这是内容策划层的定位错误，不是排版问题。

## 二、优化方案

### 2.1 内容重构：从"教案语言"到"学生学习内容"

| 维度 | 基线 | 优化后 |
|------|------|--------|
| 生字词 | "会认会写 12 个生字" | 列出具体字：会认（盐屹昂鼎沸贯崩震霎余）、会写（潮称罩蒙薄雾昂沸贯旧恢）、多音字（号 háo/hào、闷 mēn/mèn） |
| 课文内容 | 无 | 引用原文金句："浪潮越来越近，犹如千万匹白色战马齐头并进…" |
| 词句赏析 | "品析关键词句"（抽象） | 具体对比：样子（白线→水墙→战马）、声音（闷雷→山崩地裂） |
| 作业 | "布置分层作业"（抽象） | 基础/提高/拓展三级，每级有具体任务 |

### 2.2 结构重构：撑起 30 分钟

按课时节奏分配，每页标注时间预算（12 页 ≈ 30 分钟）：

| 页 | 标题 | 时间 | 版式 | 趣味设计 |
|----|------|------|------|----------|
| 1 | 封面 | 1' | edu-cover | — |
| 2 | 这节课我们要学会什么 | 1' | edu-goal | 学生能懂的语言 |
| 3 | 情境导入：天下奇观 | 3' | content-2col | 视频 + 提问 + 小知识 |
| 4 | 第一关：生字词闯关 | 5' | content-grid | 摘苹果游戏、造句挑战 |
| 5 | 初读感知：课文写了什么 | 4' | content-2col | 排序任务 |
| 6 | 精读一：潮来前 | 3' | content-2col | 朗读指导 |
| 7 | 精读二：潮来时（最壮观） | 6' | image-text | 配图、模仿秀（声音渐变） |
| 8 | 精读三：潮头过后 | 2' | content-2col | 前后对比 |
| 9 | 写法探究 | 3' | content-2col | 积累本 |
| 10 | 小练笔：我是小导游 | 3' | content-2col | 角色扮演 |
| 11 | 课堂小结 | 1' | edu-summary | — |
| 12 | 分层作业 | 1' | edu-homework | 基础/提高/拓展 |

### 2.3 呈现优化

- **版式按内容形态选**（而非一刀切）：生字表用 `content-grid`（6 条网格）、精读重头戏用 `image-text`（图文）、普通要点用 `content-2col`（双栏）、首尾页用 `edu-*` 教学版式。
- **去除占位符**：不再出现"思维导图占位"等未填充内容。
- **装饰避让内容**：国风印章从 11×11 缩到 8×8 并上移，避开正文区。

## 三、实现方式

| 改动 | 文件 |
|------|------|
| 新增《观潮》专属提纲（12 页黄金样本） | `backend/cmd/seed/courseware/main.go` → `guanchaoOutline` |
| seed 支持"课件级专属提纲优先，未命中回落通用套路" | 同上 → `customOutlines` + `main()` 取值逻辑 |
| 国风装饰缩小避让正文 | `frontend/src/components/PptxPreview.tsx` → `SlideDecor` china 分支 |
| **导出成品去占位符** | `frontend/src/lib/exportPptx.ts` → `layoutElements()` + 导出骨架分支 |

### 2.4 占位符泄漏修复（自查发现）

首轮优化后导出 PPTX 自查，发现**自己的产出违反了自己定的"零占位符"原则**：

| 现象 | 根因 | 修复 |
|------|------|------|
| 每页多出"标题"二字 | `layoutElements()` 未跳过骨架的 `title` 占位，而导出走 `s.elements` 分支（优先于骨架分支），把占位文字写进成品 | `layoutElements()` 增加 `if (ph.key === 'title' && layout !== 'cover') continue`（页标题已由顶部色带统一渲染） |
| 课堂小结页仍有"思维导图占位" | 无内容的 placeholder 仍渲染 `ph.placeholder` 文字 | 导出路径 + `layoutElements()` 均改为：无内容则跳过，不渲染占位文字 |

**设计取舍**：占位提示文字在**编辑态**保留（提示教师该填什么），仅**导出成品**去除——编辑态占位由 `PptxPreview` 的 `renderStaticSlide` 单独负责。

修复后验证：导出 PPTX 13 页，占位符残留 **0**。

## 四、验证结果（staging）

| 指标 | 基线 | 优化后 |
|------|------|--------|
| 页数 | 7（+封面） | **12**（+封面） |
| 正文字数 | ~800 | **1943** |
| 生字表 | 无（只说"12 个"） | **具体列出，含多音字** |
| 课文原文 | 无 | **有金句引用（3 处）** |
| 趣味环节 | 0 | **5 处**（视频、摘苹果、排序、模仿秀、角色扮演） |
| 占位符泄漏 | 2 处（思维导图占位） | **0** |
| 版式标注 | 无（全走自适应） | **12 页全标注** |

浏览器实测：12 页结构正确、content-grid 6 条完整渲染、image-text 页原文金句完整、印章不再遮挡内容、无幽灵页。

## 五、抽象为宪法原则（已落地）

验证通过后，上述经验已抽象为生成原则，写入小微生成课件的提示词（宪法）：

**落地位置**：`ai-service/api_server.py` → `gen_courseware()` 的 `structure_hint`（PPT 分支）

写入的原则：

| 原则 | 宪法中的表述 |
|------|-------------|
| 学生视角 | 每条写"学生将看到/学会什么"，禁止"教师引导学生…""教师点拨…" |
| 目标具体化 | 禁止"会认会写 N 个生字词"这类抽象目标，必须列出具体是哪 N 个字/哪句原文/哪道例题 |
| 引用真实内容 | 文科须出原文金句+生字表+赏析；理科须出公式+例题数据+解答步骤 |
| 趣味按学段 | 低段游戏/竞赛/角色扮演，中段情境/探究，高段问题链/辩论/实验；每课≥2 处互动，用【互动】【游戏】标注 |
| 时长匹配 | 按课时反推页数密度，每页支撑 2~4 分钟 |
| 零占位符 | 禁止"思维导图占位""图片占位""待补充" |
| 版式服从内容 | 补充 `content-2col`/`content-grid`/`image-text` 选型规则；明确 `edu-explain` 只有 2 槽位，>3 条要点禁用 |
| 教案章节不单独成页 | "教学重难点""板书设计"属教师备课信息，融入内容页或一句话带过 |

**为什么改这两处**：原提示词的章节顺序含"教学重难点""板书设计"（教案章节，是"教案语言"问题的源头），
版式取值只有 `edu-*` + `title-body`（缺通用版式，导致多要点页只能挤进 2 槽位的 `edu-explain`）。

**影响面**：所有 PPT 课件生成（`fmt == "ppt"`）。H5 分支未改动（其 `structure_hint` 已是绘本情景结构）。
