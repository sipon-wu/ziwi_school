# 教学内容审查机制

> 定位：教学内容的**内容安全红线体系**，是质量之外的一票否决层。
> 核心原则：**质量差可以返工，内容出问题就是事故。**
> 依据：《教育法》《义务教育法》、《中小学教材管理办法》（教材〔2019〕3号）、
> 《生成式人工智能服务管理暂行办法》（2023）。
>
> **适用主体说明**：本平台服务**校内教学**（教师备课与课堂教学），**不属于校外培训机构**，
> 故**不以**《中小学生校外培训材料管理办法（试行）》为规范依据；该办法仅在其第八条
> 负面清单层面作为**参照**，不引为义务来源。

## 〇、适用范围：全部教学内容，不是只有课件

### 先厘清定性：教案 / 习题 / 课件 **不是**法定"教材"

| 文件 | 定义 | 我们的内容 |
|------|------|-----------|
| 《中小学教材管理办法》第二条 | 教材 = 根据国家课程方案编写的、供中小学使用的**教学用书**，及**作为教材内容组成部分的教学材料** | ❌ 不属于（AI 生成教学资源，非教科书、非教材组成部分） |
| 《中小学生课外读物进校园管理办法》第二条 | 课外读物 = 教材教辅之外、进校园供学生阅读的**正式出版物**（含数字出版） | ❌ 不属于（非正式出版物） |

**推论**：
- ❌ 不走教材的**国家审定**程序。「凡编必审、凡选必审」是针对**教材**与**校外培训材料**的原则，
  **不直接适用于校内校本教学资源**（此前引用属不当类推，已修正）
- ❌ 不适用课外读物的推荐程序
- ✅ 但**内容安全责任依然成立，且因缺少外部关口而更重**

### 真正的依据链（校内教学资源适用）

| 依据 | 约束 |
|------|------|
| **《教育法》** | 坚持立德树人、加强社会主义核心价值观教育 —— 覆盖**一切教育教学活动**，不限教材形态 |
| **《义务教育法》**第三、三十五条 | 贯彻国家教育方针，实施素质教育，达到国家规定的基本质量要求 |
| **《生成式人工智能服务管理暂行办法》** | **对平台直接适用**：不得生成违法内容；提高准确性与可靠性；AI 生成标识；违法内容处置义务 |
| 《中小学教材管理办法》（学校职责条款） | 学校须健全内部管理制度、选好用好教材 → 校本资源由**学校自行把关** |
| 《新时代中小学教师职业行为十项准则》 | 教师对其使用的教学内容负责 |

### 关键推论：没有外部关口，自主把关的责任反而更重

```
教材（教科书）  → 国家审定（外部关口）→ 学校选用
校本教学资源    → 无外部关口 ────────→ 学校/教师自己把关（唯一关口）
                                        ↑
                                 平台在此提供"把关能力"
```

教材有国家帮着审；AI 生成的教案、习题、课件**没有这道关口**，全靠学校自己。
这正是本机制的价值定位：**不是替代国家审定，而是赋能学校的自主把关**。

### 责任主体（三层，互不替代）

| 主体 | 责任 |
|------|------|
| **平台**（AI 服务提供者） | 不输出违法内容；AI 生成标识；提供审查工具；留痕可追溯 |
| **学校** | 内部管理制度；校本资源审核的组织责任 |
| **教师** | 选用/使用教学内容的**直接责任**（课堂上的最终责任主体） |

> **两个时刻都要把关**：生成时（编）与投放到班级时（用）。
> 后者属教师的直接责任环节，平台须提供"投放前可复核"的能力。

### 内容类型与风险画像

| 类型 | 接触深度 | 风险形态 | 高危点 |
|------|---------|---------|--------|
| 课件 | 课堂展示 | 显性（图/文直接可见） | 素材版权、图片不当、页面表述 |
| **教案** | 教师执行 | 半隐性（藏在"怎么教"里） | 活动设计导向、举例不当、教师引导语/提问、情境设置 |
| **习题/试卷** | **学生动手做，最深** | **深度隐性（藏在题干情境里）** | **刻板印象、数据造假、超标超前、选项诱导** |

> **习题风险长期被低估**，三个"隐形杀手"：
> 1. **刻板印象藏情境**——"小明是农民工子弟""女生不擅长理科"。不出现任何违禁词，关键词扫描 **100% 检不出**，却正踩歧视红线（R8）。
> 2. **数据真实性**——AI 编造或过时数据被学生当成事实记住 → 科学性错误（R12），教材办法明列的**退出情形**。
> 3. **超标超前**——超出国家课程标准对该学段的内容要求（违反《义务教育法》第三十五条质量要求），AI 出题极易超纲。
>
> 且习题会被**反复/跨班/跨校使用**，一份问题习题的影响面远大于一页课件。

## 一、法规依据（红线不是自定义，是法定）

### 《中小学教材管理办法》关键条款

| 条款 | 要求 |
|------|------|
| 第三条 | 教材必须体现党和国家意志；体现社会主义核心价值观；加强爱国主义、集体主义、社会主义教育 |
| 第四条 | 意识形态属性较强的教材、涉及**国家主权、安全、民族、宗教**内容的，实行国家统一编写、统一审核、统一使用 |
| 第九条(四) | 选文篇目内容积极向上、导向正确；**选文作者历史评价正面，有良好的社会形象** |
| 第九条(五) | 不得有**民族、地域、性别、职业、年龄歧视**；不得有**商业广告或变相商业广告** |
| 第十八条 | 严把**政治关、科学关、适宜关**；政治审核重点审核政治方向和价值导向；**严格执行重大选题备案制度** |
| 第三十七条 | 退出情形：①政治方向/价值导向有问题 ②严重科学性错误 ③植入商业广告 ④不正当手段影响审核选用 |
| 第三十九条 | **数字教材、教参参照本办法管理** ← 课件属此范畴 |

### 《生成式人工智能服务管理暂行办法》关键要求

- 不得生成煽动颠覆国家政权、推翻社会主义制度等内容
- 尊重知识产权、他人合法权益
- 提高生成内容的准确性和可靠性
- **对生成内容进行标识**（AI 生成需可识别）
- 发现违法内容的处置义务

## 二、红线清单（审查维度）

### 一类红线（block —— 拦截，必须修改）

| # | 维度 | 典型表现 |
|---|------|---------|
| R1 | **政治方向** | 反对宪法基本原则；危害国家统一、主权、领土完整；损害国家荣誉利益 |
| R2 | **国家主权与领土** | 台湾/香港/澳门/西藏/新疆/南海等表述错误；地图国界错误 |
| R3 | **民族团结** | 国内各民族差异化/对比/优劣呈现；煽动民族仇恨歧视 |
| R4 | **历史观** | 历史虚无主义；歪曲党史国史军史；诋毁/戏说英雄烈士 |
| R5 | **宗教政策** | 教育与宗教相分离；不得传教、不得宣扬宗教教义进课堂 |
| R6 | **国家安全** | 泄露国家秘密；危害国家安全的内容 |
| R7 | **违法内容** | 淫秽色情、赌博、毒品、暴力恐怖、自残自杀引导 |
| R8 | **歧视** | 民族、地域、性别、职业、年龄歧视 |
| R9 | **商业广告** | 品牌植入、变相广告、营销引流 |
| R10 | **亚文化符号** | 商业亚文化（麦当劳/肯德基等）、外来亚文化（日漫/二次元/漫威等） |
| R11 | **未成年人危害** | 危害身心健康；不良示范；危险行为模仿 |
| R12 | **科学性错误** | 严重错误知识、伪科学（教材办法列为退出情形） |

### 二类风险（warn —— 提醒，不阻断）

| # | 维度 | 说明 |
|---|------|------|
| W1 | **价值观说教** | 价值观/行为准则以说教方式灌入（应改为互动体验承载） |
| W2 | **轻微超纲** | 超出 ±1 年级档 |
| W3 | **素材来源不清** | 引用素材未注明来源 |
| W4 | **选文作者存疑** | 引用作品的作者历史评价/社会形象存在争议 |

> **防误判红线**（必须写死，避免误伤正常教学）：
> 「中华民族」「中国」「中国人民」「民族自豪感」「爱国主义」等均为**合规对齐表述**，
> **严禁**因出现这些词就判为问题。现有 `policy.py` 已含此设计，须保留并强化。

## 二·五、类型差异化检测（通用红线之上加挂）

统一红线网（R1-R12 / W1-W4）对**所有内容类型生效**；在此基础上按类型**加挂专项检测维度**：

```
通用红线 R1-R12（政治/主权/民族/历史/宗教/安全/违法/歧视/广告/亚文化/未成年人/科学性）
        │
        ├── 课件  + 专项 C1-C3
        ├── 教案  + 专项 L1-L4
        ├── 习题  + 专项 Q1-Q5   ← 最高优先，隐性风险集中区
        └── 试卷  + 专项 E1-E3
```

### 课件专项

| # | 维度 | 检测要点 | 级别 |
|---|------|---------|------|
| C1 | 素材版权 | 图片/音视频是否有授权、是否标注来源 | warn（商用 block） |
| C2 | 图片不当 | 配图是否含暴力/成人化/不适宜形象 | block |
| C3 | 页面表述 | 标题、正文、页脚文字（机检常漏掉图片外的独立文字） | block |

### 教案专项（风险在"怎么教"，不只是"教什么"）

| # | 维度 | 检测要点 | 级别 |
|---|------|---------|------|
| L1 | 活动设计导向 | 课堂活动/游戏是否隐含不当导向（如模拟战争、角色扮演敏感身份） | block/warn |
| L2 | 案例举例 | 举例是否涉及地域/职业/性别/家庭背景刻板印象 | block |
| L3 | 教师引导语 | 教师提问、引导话术是否预设不当立场 | warn |
| L4 | 情境设置 | 教学情境是否虚构事实、误导认知 | block |

### 习题专项（最高优先）

| # | 维度 | 检测要点 | 级别 | 备注 |
|---|------|---------|------|------|
| Q1 | **题干刻板印象** | 人物设定的职业/地域/性别/家庭背景是否构成歧视 | block | **关键词扫不出，必须 AI 语义评审** |
| Q2 | **数据真实性** | 引用数据是否编造/过时（人口、经济、科技等） | block | 科学性错误，教材办法退出情形 |
| Q3 | 材料引用 | 引用原文/新闻/图表是否核实来源 | warn | |
| Q4 | 选项诱导性 | 干扰项是否含错误价值观、是否诱导不当结论 | warn | |
| Q5 | **超标超前** | 是否超出国家课程标准对该学段的内容要求 | warn | 违反《义务教育法》第三十五条质量要求 |

### 试卷专项

| # | 维度 | 检测要点 | 级别 |
|---|------|---------|------|
| E1 | 分值权重 | 是否存在导向性失衡（某类内容过度集中） | warn |
| E2 | 公平性 | 是否对特定群体系统性不利（如情境仅面向城市学生） | warn |
| E3 | 参考答案表述 | 答案/评分标准是否含不当导向 | block |

> **实现要点**（决定这套机制是否真的有效）：
> 1. 机检（防线②）按 `content_type` 加载不同词库与规则；
> 2. AI 语义评审（防线③）的 prompt **必须按类型注入对应专项维度**——
>    否则习题的 Q1 情境刻板印象 **100% 漏检**（无违禁词、纯语境问题）；
> 3. `policy_gate_publish()` 需新增 `content_type` 参数：
>    `courseware | lesson_plan | exercise | exam`；
> 4. 习题/试卷因跨班跨校复用，建议**留存期加长**（参照办法第十四条"不少于使用完毕后 3 年"）。

## 三、四道防线

```
① 生成前预防 ──► ② 生成后机检 ──► ③ AI 语义评审 ──► ④ 人工审核
   源头约束        规则过滤          理解语义           高风险把关
   (S0/S2)        (S3后)           (S4关卡2)         (S4关卡4)
```

### 防线①：生成前预防（源头不出问题）

在 **S2 提示词生成**与 **S0 用户输入**两处注入约束：

- **S0 输入侧**：用户输入含诱导违规内容（如"加些敏感话题"）→ 小微**拒绝并说明**，不生成
- **S2 提示词侧**：生成提示词固定附加安全约束段：
  ```
  【内容安全约束·必须遵守】
  1. 不得涉及国家主权、民族宗教、政治立场的不当表述
  2. 不得出现商业品牌、外来亚文化符号
  3. 不得有民族/地域/性别/职业/年龄歧视
  4. 不得有商业广告或变相广告
  5. 价值观内容以互动体验承载，不说教式灌入
  6. 引用作品时作者须历史评价正面、社会形象良好
  ```

### 防线②：生成后机检（规则过滤）

扩展现有 `policy.py` 的负面清单：

| 现有 | 需补充 |
|------|--------|
| 商业亚文化符号 | 主权领土表述库（台港澳等规范表述与错误表述对照） |
| 外来亚文化符号 | 民族宗教违禁词 |
| 民族差异化 | 暴力/色情/自残/赌博词库 |
| — | 歧视性表述库（地域黑、性别刻板印象等） |
| — | 商业品牌库（扩展至常见品牌） |
| — | 英烈姓名 + 诋毁类动词组合检测 |

**输出**：`{level: block|warn, type, message, suggestion, position}`

### 防线③：AI 语义评审（理解语义，不止关键词）

关键词检不出的问题：
- 隐晦的政治隐喻
- 不当类比（如把历史事件类比为某些敏感事件）
- 价值观偏差（虽无违禁词但导向有问题）
- 历史虚无主义的委婉表达

**实现**：用 LLM 按 R1-R12 + W1-W4 逐维度审查，返回结构化判定。
**要求**：prompt 必须写明防误判规则（中华民族等合规表述不判问题）。

### 防线④：人工审核（高风险必过）

**必须人工的情形**：
| 情形 | 原因 |
|------|------|
| 意识形态属性强的学科（语文、历史、道德与法治） | 办法第四条要求国家统一审核 |
| 涉及国家主权、民族、宗教、党史国史的内容 | 办法：专题审核 + 重大选题备案 |
| 机检或 AI 评审判定为 `warn` 且累计 ≥2 项 | 风险累积 |
| AI 评审不确定（置信度低） | 机器不替代人 |
| 用户举报内容 | 事后监督 |

**审核留痕**：审核人、时间、结论、修改意见——可追溯。

## 四、分级处置

| 判定 | 处理 | 用户可见 |
|------|------|---------|
| **pass**（无问题） | 直接交付 | 无提示 |
| **warn**（二类风险） | 可发布，但展示提醒 | "建议优化：价值观表述偏说教，可改为互动形式" |
| **block**（一类红线） | **拦截，不可发布** | "内容存在问题需修改：xxx（位置：第3页）"，附修改建议 |
| **人工待审** | 挂起，进人工队列 | "已提交审核，预计 x 小时内完成" |

**关键设计**（沿用现有 policy.py 的好设计）：
> **草稿永远可编辑，只有"发布进素材库"才强制校验。**
> 避免阻断创作过程，但守住出口。

## 四·五、版本记录：留痕的载体

> **没有版本记录，留痕就只是一堆散落的日志，串不成证据链。**
> 事后必须能回答：**当时投的是哪一版？谁改的？审没审？谁审的？AI 参与多少？**

### 现状与缺口

现有 `versions` 表仅 7 个字段（`id/school/user/resource/label/payload/created_at`），
本质是个"**快照袋**"——能证明存过一份，但**证明不了审没审、谁审的、结论是什么**。

| 留痕必需 | 现状 |
|---|---|
| 版本号（"第3版"可引用） | ❌ 缺 |
| 审核结论（当时判定可复现） | ❌ 缺 |
| 审核人（责任人） | ❌ 缺 |
| AI 生成标识 | ❌ 缺 |
| 投放记录（当时用的哪版） | ❌ 缺 |

**同时发现的明确合规缺口**：
- 习题 `questions.audit_status` 创建时**硬编码 `"approved"`**，且 `AfterFind` 直接映射为 `published`
  → **生成即"审核通过"，审核形同虚设**
- 教案 `lesson_plans.published_at` **字段存在但后端从不写入** → 发布无时间戳，无法追溯

### 设计：versions 表扩展（已实施，向后兼容）

用 `kind` 区分两种语义，**不破坏**现有"草稿期手动快照"功能：

| kind | 语义 | 生命周期 |
|---|---|---|
| `snapshot` | 草稿期手动快照（原行为） | 可存、可回退 |
| `release` | 正式版本 + 审核留痕 | **只追加，不可改、不可删** |

新增字段分组：

| 分组 | 字段 | 作用 |
|---|---|---|
| 版本链 | `version_no` `parent_id` `change_note` | "第几版"可引用、可 diff |
| **审核留痕** | `review_status` `check_result(jsonb)` `reviewer_id` `review_comment` `reviewed_at` | **核心**：证明审过、结论可复现、有责任人 |
| AI 归属 | `ai_generated` `ai_model_version` `human_edited` | 落实《生成式AI办法》标识要求 |
| 投放追溯 | `published_at` `published_by` | 锁定当时实际使用的版本 |

**`review_status` 五态**：

```
none 未提交审查 → pending 待人工 → auto_pass 机检+AI评审通过自动放行
                                 → approved 人工审核通过 / rejected 驳回（须修改）
```

### 三条硬性规则

1. **版本即证据**：release 版本**只追加**，禁止 UPDATE / DELETE——留痕的前提是不可篡改
2. **AI 标识不因人工修改而摘除**：教师改过的版本 `ai_generated` 仍为 `true`，
   同时 `human_edited=true`——如实反映 AI 参与程度，而非"被人碰过就算人的作品"
3. **投放锁定版本**：投放时写入 `published_at / published_by`；
   后续即便内容再改，仍能还原"当时实际投放的是哪一版"
