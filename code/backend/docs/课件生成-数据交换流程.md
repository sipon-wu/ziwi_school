# 课件生成 · 数据交换流程（字段级）

> 说明：本文档描述课件生成流水线中**数据如何在各环节流转**，细化到数据结构与关键字段。
> 配套文档：《课件生成流程方案》（流程与质检）、《课件质量规则》（输出判定标准）、《课件生成Skills架构方案》（运行时架构）。

## 二、各环节数据契约（字段级）

### S0 需求澄清

**输入**

| 数据 | 来源 | 格式 | 关键字段 |
|------|------|------|---------|
| `UserRequest` | 用户输入 | 自然语言文本 | `text`（如"生成《观潮》课件，30分钟"） |
| `UserContext` | `users`/`teachers`/`schools` 表 | 对象 | `teacher_id`, `school_id`, `subject`（任教学科）, `grade`（任教年级）, `classes[]` |
| `KnowledgeHints` | 知识点库 | 数组 | `nodes[{id,name,subject,grade,unit}]` |
| `CurriculumHints` | 课标库 | 数组 | `items[{code,text,subject,grade}]` |

**处理**
1. LLM 意图识别 → `intent = courseware.generate`
2. **生成条件校验**：检查必需字段（subject / grade / title / period_minutes）
3. 缺失 → 生成提问（一次问完，带推断与默认值）
4. 无教案但知识库可查 → 推断 objectives / key_points 并请用户确认
5. 3 轮后仍缺必需字段 → 中止或全部标记 `pending_confirm`

**输出：`CoursewareSpec`**

```json
{
  "subject": "语文",
  "grade": "四年级",
  "title": "观潮",
  "period_minutes": 30,
  "unit": "第一单元",
  "objectives": ["认识12个生字…", "有感情朗读…"],
  "key_points": ["按顺序观察的方法"],
  "difficulties": ["体会潮来时的壮观描写"],
  "knowledge_nodes": ["kn_001", "kn_002"],
  "curriculum_align": ["课标条目A"],
  "source": "lesson_plan:lp_xxx | user_input | inferred",
  "pending_confirm": ["objectives", "difficulties"]
}
```

**校验（S0-QC）**：`subject`/`grade`/`title`/`period_minutes` 全部非空 → 放行。

---

### S1 教案解析

**输入**

| 数据 | 来源 | 格式 | 关键字段 |
|------|------|------|---------|
| `CoursewareSpec` | S0 输出 | JSON | 见上 |
| `LessonPlan` | `lesson_plans` 表 | 记录 | `id`, `title`, `subject`, `grade`, `unit`, `period`(课时), `content`(Markdown), `knowledge_node_ids`, `curriculum_alignments`, `material_links` |

**处理**
1. 规则解析 `content`：按 `##` 分节，识别「教学目标」「重难点」「教学过程」「作业」
2. 解析 `period` → `period_minutes = period × 40`（或按学校课时配置）
3. 缺失节 → LLM 补全
4. 合并 CoursewareSpec 与教案信息（教案优先，用户补充次之）

**输出：`LessonPlanStruct`**

```json
{
  "subject": "语文",
  "grade": "四年级",
  "title": "观潮",
  "period_minutes": 30,
  "objectives": [
    {"text": "认识12个生字，会写15个字", "bloom": "记忆"},
    {"text": "有感情朗读并背诵3-4段", "bloom": "理解"}
  ],
  "key_points": ["按顺序观察的方法"],
  "difficulties": ["体会潮来时的壮观描写"],
  "stages": [
    {"name": "情境导入", "minutes": 3, "activity": "播放大潮视频，提问"},
    {"name": "初读感知", "minutes": 5, "activity": "朗读，梳理脉络"},
    {"name": "精读品析", "minutes": 15, "activity": "品读潮来时的描写"},
    {"name": "小结作业", "minutes": 7, "activity": "总结与练笔"}
  ],
  "knowledge_nodes": ["kn_001", "kn_002"],
  "homework": {"basic": "抄写生字词", "advanced": "观察写话"}
}
```

**校验（S1-QC）**：`objectives` ≥3 条、`key_points` ≥1、`stages` ≥3、各环节 `minutes` 之和 ≈ `period_minutes`（误差 ≤20%）。

### S2 提示词生成

**输入**

| 数据 | 来源 | 格式 | 关键字段 |
|------|------|------|---------|
| `LessonPlanStruct` | S1 输出 | JSON | 见上 |
| `Constitution` | 课件宪法（配置） | 文本/规则 | 学生视角、目标具体化、零占位符、版式服从内容等 8 条 |
| `SegmentRules` | 学段课时规则表 | 配置 | `{20分钟:8-10页, 30分钟:12-14页, 40分钟:14-16页}` |
| `ComponentCatalog` | 组件清单 | 配置 | `sequence/timeline/compare-table/char-card/compare-card/quote` 及适用场景 |
| `TemplateMeta[]` | `courseware_templates` 表 | 数组 | `id, kind, name, style, theme_id, tags[], subjects[], grades[]` |

**处理**
1. 按 `SegmentRules` 确定页数区间
2. 按 `objectives` 分配页面（每条目标至少 1 页承载）
3. 按内容特征选组件（顺序→timeline、递进→sequence、对比→compare-table…）
4. 匹配模板（按 style/subject/grade 查 `TemplateMeta`）
5. 规划互动点（学段决定数量）
6. 输出结构化提示词

**输出：`GenerationPrompt`**

```json
{
  "lesson_ref": {"subject":"语文","grade":"四年级","title":"观潮","minutes":30},
  "page_plan": [
    {"idx":1,"title":"封面","layout":"edu-cover","minutes":1,"component":null},
    {"idx":2,"title":"这节课我要学会什么","layout":"edu-goal","minutes":1,"objective_ref":[0,1]},
    {"idx":4,"title":"生字卡墙","layout":"content-grid","minutes":5,
     "component":{"type":"char-card","chars":[{"char":"盐","pinyin":"yán","word":"盐水"}]},
     "interaction":"点读"},
    {"idx":6,"title":"课文脉络","layout":"blank","minutes":3,
     "component":{"type":"timeline","nodes":[
       {"label":"潮来前","desc":"江面平静"},
       {"label":"潮来时","desc":"白线→水墙→战马"},
       {"label":"潮头过后","desc":"余波漫天卷地"}]}},
    {"idx":10,"title":"三阶段对比","layout":"blank","minutes":3,
     "component":{"type":"compare-table","cols":["潮来前","潮来时","潮头过后"],
       "rows":[{"label":"样子","cells":["江面平静","白线→水墙→战马","余波漫天卷地"]}]}}
  ],
  "style": "china",
  "theme_id": "zgf-ink-wash",
  "interactions": [{"page":4,"type":"点读"},{"page":13,"type":"角色扮演"}],
  "assets_needed": [{"page":1,"type":"image","desc":"钱塘江大潮全景"}],
  "dok_plan": {"L1":3,"L2":5,"L3":3,"L4":1}
}
```

**校验（S2-QC）**：目标全覆盖、页数在区间、组件选型合规、互动数达标、符合宪法、DOK 层次 ≥3。

### S3 课件生成

**输入**

| 数据 | 来源 | 格式 | 关键字段 |
|------|------|------|---------|
| `GenerationPrompt` | S2 输出 | JSON | 见上 |
| `Template` | `courseware_templates` + `pptThemes`(代码) | 对象 | `theme_id`, `style`, `layouts`, `globalDecor` |
| `Assets[]` | `materials` 表（category=素材） | 数组 | `id, name, type, url` |
| `ComponentRenderers` | `VisualBlocks.tsx`（代码） | 组件库 | 6 类组件渲染器 |

**处理**
1. 按 `page_plan` 逐页生成 Markdown（`## 标题` + `<!-- layout -->` + `- 要点`）
2. 组件页生成 `<!-- VISUAL:base64 -->`（组件 JSON → base64）
3. 素材匹配（按 `assets_needed` 查素材库；缺失 → 矢量占位并标记）
4. 调用 Skill（pptx skill / 百炼 LLM）产出内容

**输出：`CoursewareDraft`**

```json
{
  "title": "观潮",
  "markdown": "## 课文脉络\n<!-- layout: blank -->\n- 课文按时间顺序写…\n<!-- VISUAL:eyJ0eXBlIjoidGltZWxpbmUiLC... -->\n",
  "pages": [
    {"idx":1,"title":"封面","layout":"edu-cover","bullets":[],"visuals":null},
    {"idx":6,"title":"课文脉络","layout":"blank","bullets":["课文按时间顺序写…"],
     "visuals":[{"type":"timeline","nodes":[...]}]}
  ],
  "theme_id": "zgf-ink-wash",
  "assets_ref": [{"page":1,"asset_id":"mat_001","url":"...","placeholder":false}],
  "unresolved_assets": [{"page":7,"desc":"浪潮图","placeholder":true}]
}
```

**校验（S3-QC）**：layout 合法、VISUAL JSON 合法、页数一致、素材可达、base64 可解码。

### S4 质量检验

**输入**

| 数据 | 来源 | 格式 | 关键字段 |
|------|------|------|---------|
| `CoursewareDraft` | S3 输出 | 对象 | 见上 |
| `QualityRules` | 《课件质量规则》 | 配置 | L1对齐/L2深度/L3负荷/L4呈现/L5科学 五层指标与阈值 |

**处理（三关）**
- **关卡1 自动规则**：解析 markdown/pages，计算可量化指标（目标覆盖、页数、单页信息量、组件合法性、占位符）
- **关卡2 AI 评审**：LLM 按 A5/D1/D2/D4/E1/E2/E4 等语义维度打分（1-5）
- **关卡3 视觉检查**：导出 PPTX → 转图 → subagent 检查（重叠/裁切/留白/对比度/字号层级）

**输出：`QualityReport`**

```json
{
  "passed": false,
  "scores": {
    "A1_目标覆盖": {"value":1.0,"threshold":1.0,"pass":true},
    "A5_评价匹配": {"value":0.6,"threshold":0.8,"pass":false},
    "D1_DOK层次": {"value":3,"threshold":3,"pass":true},
    "D2_高阶占比": {"value":0.25,"threshold":0.30,"pass":false},
    "C1_单页信息量": {"value":6,"threshold":5,"pass":false},
    "E3_占位符": {"count":0,"threshold":0,"pass":true}
  },
  "issues": [
    {"dim":"A5","severity":"高","desc":"目标2无对应检测任务","page":8},
    {"dim":"C1","severity":"高","desc":"第8页要点6条超出上限","page":8},
    {"dim":"D2","severity":"中","desc":"DOK3-4占比25%低于30%","page":null}
  ],
  "visual_issues": [],
  "verdict": "返工（硬指标未达：C1；软指标累计2项）"
}
```

### S5 交付入库

**输入**：`CoursewareDraft`（已通过质检）+ `CoursewareSpec`（来源/归属信息）

**处理与输出**

| 输出 | 去向 | 关键字段 |
|------|------|---------|
| `CoursewareRecord` | `materials` 表 | `id, name, type='courseware', format, category='courseware', content`(markdown), `subject, grade, theme_id, school_id, user_id, source_lesson_plan_id, status` |
| `ExportArtifacts` | 文件（用户下载） | PPTX / PDF / H5 |

> **历史缺陷提醒**：`school_id`/`user_id` 必须写入，否则课件列表查不到（曾出现过该问题）。

## 三、数据存储与外部依赖一览

| 数据 | 存储位置 | 读/写 | 使用环节 |
|------|---------|------|---------|
| 教案 | `lesson_plans` 表 | 读 | S1 |
| 知识点 | 知识点库 | 读 | S0 / S1 |
| 课标 | 课标库 | 读 | S0 / S1 |
| 模板元数据 | `courseware_templates` 表 | 读 | S2 / S3 |
| 配色（CwTheme） | `pptThemes.ts`（代码） | 读 | S3 |
| 组件渲染器 | `VisualBlocks.tsx`（代码） | 读 | S3 |
| 素材 | `materials` 表（素材类） | 读 | S3 |
| 成品课件 | `materials` 表（课件类） | **写** | S5 |
| 用户上下文 | `users`/`teachers`/`schools` | 读 | S0 |
| 宪法 / 规则 | 配置文件 | 读 | S2 / S4 |
| LLM 能力 | 百炼 | 调用 | S2 / S3 / S4 |

## 四、反馈与回流

| 触发 | 数据 | 流向 |
|------|------|------|
| 质检不通过 | `QualityReport.issues` | 回退 S2（改提示词）或 S3（改生成），最多 N 次 |
| 超重试次数 | `QualityReport` | 标记 `pending_human`，转人工 |
| 用户修改课件 | 编辑后的 `content` | 更新 `materials.content`（不重走全流水线） |
| 用户追加需求（"多加互动"） | 增量需求 | 回退 S2，携带原 `CoursewareSpec` + 新需求 |
| 阈值校准 | 质检统计数据 | 调整 `QualityRules` 阈值 |
