# H5课件容器与第三方对接规划（二期）

## 一、架构概述

H5课件是混编教学内容的容器，支持教案+互动练习+多媒体嵌入。来源分为两类：

| 来源 | 说明 |
|---|---|
| **自有生成** | 平台内教案导出为H5幻灯片（一期已支持） |
| **第三方生成** | 教师发指令→第三方AI平台生成课件→回调知微存储 |

## 二、容器数据模型（预留字段）

```
courseware:
  cw_source: internal | third_party:{baidu,seewo,xunfei,...}
  cw_audit_status: pending | ai_passed | audited | rejected
  cw_audit_by: 审核人ID
  cw_offline_support: true/false
  offline_package_url: 离线包下载地址
  interactive_slots[]: 互动组件插槽位置列表
  assessment_endpoint: 学生评估数据回传地址
```

## 三、三层审核机制

```
课件提交
  ├─ 第一层：平台规则（敏感词库+课标合规）    <10ms
  ├─ 第二层：腾讯天御/网易易盾（内容安全）    1-3s
  └─ 第三层：人工复核（仅前两层标记suspect时触发）
```

- 自动通过的不叫人，腾讯接口返回Pass直接放行
- 检测维度：意识形态、暴恐、色情、违法信息

## 四、第三方合约必备条款

### 1. 内容合规责任
- 乙方保证生成课件不含违规内容
- 合规标准：对接腾讯天御，PASS率≥99.5%
- 违规罚则：单次扣保证金，累计3次终止合作

### 2. 合规要求自动注入
我方发指令时自动附带年级+学科+敏感词版本号，第三方以此做第一道自检。

### 3. 知识产权
- AI生成课件成品归学校（甲方委托）
- 乙方不得将生成数据用于模型训练

### 4. 数据隔离
乙方仅接收指令文本+教学上下文，不得接收任何学生个人信息。学生姓名等由我方渲染时注入。

### 5. 审核成本
- 乙方课件触发我方审核拦截：乙方承担腾讯天御调用费
- 正常通过：我方承担

### 6. 离线支持
乙方API响应必须包含 `offline_available` 标识及离线包URL。

## 五、存储策略

| 课件类型 | 存储方式 |
|---|---|
| 在线课件 | CDN → school.ziwi.cn/cw/{id} |
| 离线课件 | CDN + ZIP打包下载 |
| 多媒体素材 | CDN按需加载，不嵌入HTML主文件 |
