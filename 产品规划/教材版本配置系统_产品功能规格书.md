# K12教材版本配置系统 · 产品功能规格书

> **版本**：v1.1  
> **最后更新**：2026-07-11  
> **关联**：主规格书 §1.4（License/Token 机制）、§2.2.1（学校与班级管理）  
> **状态**：P0 开发中

---

## 一、功能概述

K12学校中，不同年级、不同班级、不同学科可能使用不同的教材版本（如语文用部编版、数学用人教版、英语用外研版）。本模块实现学校IT管理员统一配置教材版本，教师端自动继承学校配置，无需教师自行选择，确保教材版本全校一致、准确无误。

---

## 二、核心前提：License 与产品模式

产品存在两种使用模式，决定了教材版本配置的归属：

| 模式 | 适用场景 | License | 教材版本配置归属 | Token/计费 |
|------|---------|---------|----------------|-----------|
| 学校版 | 学校/机构统一采购部署 | ✅ 学校级License（签约/续费） | 学校IT管理员统一配置 | 学校账户统一管理，按学校License配额 |
| 个人试用版（SaaS） | 教师个人自发试用 | ❌ 无学校License | 教师自行配置（仅影响个人） | 个人账户，受Token量限制，需个人续费 |

**核心规则**：
- 学校级License开通 → 学校IT管理员可配置教材版本 → 教师端隐藏配置入口，继承学校配置
- 学校级License未开通 → 教师以个人试用身份使用 → 教师端显示教材版本配置入口，自行选择（仅影响本人产出）
- License的判断依据：学校ID + 学校正式开通状态标识

## 三、学校IT管理员端 · 教材版本配置页

### 3.1 入口位置

```
系统设置 → 学校管理 → 教材版本配置
```

### 3.2 配置层级设计

配置分为三级，支持"学校统一"、"年级-学科覆盖"与"班级级精准覆盖"：

| 配置层级 | 说明 | 适用场景 |
|---------|------|---------|
| 学校级（默认） | 全校所有年级、所有学科使用同一教材版本 | 教材版本统一、无跨年级差异的学校 |
| 年级-学科级（覆盖） | 特定年级、特定学科单独配置版本 | 不同年级使用不同版本（如小学部编版、初中人教版） |
| 班级级（精细覆盖） | 特定班级的特定学科单独配置版本 | 实验班使用与普通班不同版本的教材 |

**配置优先级**：班级级 > 年级-学科级 > 学校级。高优先级覆盖低优先级。

示例：

```
学校默认教材版本：人教版

年级-学科覆盖配置：
├── 语文（全校）：部编版（覆盖学校级）
├── 三年级 英语：外研版（覆盖学校级）
└── 五年级 数学：人教版（与学校级一致，可不配置）

班级级覆盖配置：
├── 三年级（1）班 · 数学 · 北师大版（覆盖年级-学科级）
└── 五年级（2）班 · 英语 · 牛津版（覆盖学校级/年级-学科级）
```

### 3.4 交互逻辑

#### 3.4.1 学校默认教材版本设置

| 操作 | 说明 |
|------|------|
| 每个学科下拉选择 | 下拉菜单列出该学科支持的全部教材版本 |
| 默认值 | 首次配置时，系统自动填充热门版本（如语文→部编版、数学→人教版） |
| 必填 | 每个学科必须选择一个版本，不可留空 |

#### 3.4.2 年级-学科覆盖配置

| 操作 | 说明 |
|------|------|
| 点击"新增年级-学科覆盖配置" | 弹出配置弹窗 |
| 选择年级 | 下拉选择1-9年级 |
| 选择学科 | 下拉选择该年级已开设的学科 |
| 选择教材版本 | 下拉选择该学科支持的全部教材版本 |
| 保存 | 配置生效，覆盖学校级默认版本 |
| 移除 | 删除该覆盖配置，该年级-学科恢复使用学校级默认版本 |

#### 3.4.3 班级级覆盖配置（精细配置）

| 操作 | 说明 |
|------|------|
| 点击"新增班级级覆盖配置" | 弹出配置弹窗 |
| 选择年级 | 下拉选择1-9年级 |
| 选择班级 | 下拉选择该年级下已创建的班级（如1班、2班、实验班） |
| 选择学科 | 下拉选择该班级已开设的学科 |
| 选择教材版本 | 下拉选择该学科支持的全部教材版本 |
| 保存 | 配置生效，覆盖年级-学科级及学校级配置 |
| 移除 | 删除该覆盖配置，该班级-学科恢复使用年级-学科级或学校级配置 |

**配置弹窗示例（班级级）** ：

```

├─────────────────────────────────────────────────────┤
│  年级：[三年级 ▼]                                  │
│  班级：[1班（实验班）▼]                           │
│  学科：[数学 ▼]                                    │
│  教材版本：[北师大版 ▼]                            │
│                                                    │
│  ─── 当前配置预览 ───                             │
```

## 四、教师端 · 教材版本继承逻辑

### 4.1 核心规则

| 条件 | 教师端行为 |
|------|-----------|
| 学校已开通License + 学校IT已配置教材版本 | 教师配置教材版本权限隐藏，直接继承学校IT配置（含班级级精细配置） |
| 学校已开通License + 学校IT未配置教材版本 | 显示提示信息："学校尚未配置教材版本，请联系管理员完成配置" |
| 学校未开通License（个人试用/SaaS） | 教师自行选择教材版本（仅影响个人产出，不导出、不共享给其他教师） |

## 五、个人试用模式 · 跨设备同步与功能锁定

### 5.1 跨设备同步

个人试用模式下，教师自行配置的教材版本支持跨设备同步，同步范围仅限于教师个人账号下的设备。

| 设备端 | 同步行为 |
|--------|---------|
| PC Web端 | 配置后保存至云端 |
| 小程序端 | 自动拉取个人配置，与PC端保持一致 |
| 其他设备 | 登录同一账号后自动加载配置 |

### 5.2 家长端功能锁定

个人试用模式下，家长端功能默认锁定，不开放使用。

| 功能 | 是否可用 | 说明 |
|------|:---:|------|
| 教材版本配置（跨设备同步） | ✅ | 个人配置，仅自己可见 |
| 教案生成 | ✅ | 完整可用 |
| 出题组卷 | ✅ | 完整可用 |
| 学情分析（个人模拟数据） | ✅ | 使用模拟学生数据，非真实学生信息 |
| 家长端关联 | ❌ | 锁定，不开放 |
| 家长签字 | ❌ | 锁定，不开放 |
| 成长关爱 | ❌ | 锁定，不开放 |
| 真实学生信息上传 | ❌ | 锁定，不开放 |

**锁定原因**：
- 个人试用模式下，教师未通过学校认证，无权上传/管理学生及家长个人信息
- 处理学生（未成年人）个人信息须有学校作为数据控制者的合法基础
- 个人试用账号的安全级别低于学校License模式，不应承载敏感信息

## 六、个人试用 → 学校License · 历史教案重新锚定

### 6.1 批量重新锚定

学校开通License后，教师个人试用期产生的历史教案，允许批量重新锚定到学校统一配置的教材版本。

**交互设计**：

```
学校IT完成教材版本配置 → 教师登录后收到通知
  │
  ▼
┌─────────────────────────────────────────────────────┐
│  📢 学校教材版本已配置                              │
│  学校IT管理员已完成教材版本配置。您个人试用期间      │
│  生成的历史教案，是否重新锚定到学校统一版本？        │
│                                                    │
│  影响范围：XX份教案                                 │
│  当前配置：部编版（个人）→ 学校配置：人教版         │
│                                                    │
│  [重新锚定全部]  [稍后手动处理]  [保持个人配置]    │
└─────────────────────────────────────────────────────┘
```

### 6.2 操作行为定义

| 操作 | 行为 |
|------|------|
| 重新锚定全部 | 全部历史教案批量切换至学校配置的教材版本，知识点映射自动更新 |
| 稍后手动处理 | 通知收起，教师可在"教案列表"中逐份手动选择"重新锚定"或"保持个人配置" |
| 保持个人配置 | 全部历史教案保持个人试用期配置，不受学校配置影响 |

## 七、数据流向总览

```
学校IT管理员配置（学校License模式下）
        │
        ├── 学校级配置（学科→版本）
        │
        ├── 年级-学科级覆盖（年级+学科→版本）
        │
        └── 班级级覆盖（年级+班级+学科→版本）
        │
        ▼
    存入数据库（教材版本配置表，关联school_id）
        │
        ▼
    教师端读取
        │
        ├── school_id关联到开通License → 教师隐藏配置入口
        │                  ├── 按优先级获取版本：班级级 > 年级-学科级 > 学校级
        │                  ├── 教案生成 → 自动锚定对应版本
        │                  ├── 出题组卷 → 自动匹配对应版本
        │                  └── 知识图谱 → 加载对应版本图谱
        │
        └── school_id未关联License → 教师个人模式
                         ├── 教师自行配置 → 跨设备同步（PC+小程序）
                         ├── 仅影响个人产出
                         ├── 不导出、不共享
                         ├── 家长端功能锁定（不开放）
                         ├── 个人Token消耗独立计费
                         └── 学校License开通后 → 历史教案可批量重新锚定
```
