## 一、页数口径（已定 · 已实现）

**封面不计入页数**，两端同规则：

| 端 | 展示 |
|---|---|
| PPT 编辑态 | 「页面（N）」，N = 内容页数 |
| PPT 查看态 | 「封面」/「第 N/M 页」 |
| H5 | 封面屏页码「封面」；内容屏 `N/(M-1)`；首屏为合成封面 |

判据：H5 场景总数 = 内容页 + 1；`M` 取内容页数。质量报告的 `pages` 同口径。

## 二、封面（已定 · 已实现）

1. **H5 有真封面页**：合成一屏（课题 + 学科·年级 + 授课教师），元信息不再常驻页头
   （此前 H5 压根没有封面页，元信息以「常驻页头」出现在每一屏）
2. **封面素材可替换**，且**在页面内完成**：
   - 空封面：画布上出现「＋ 点击添加封面素材（底图 / 元素）」→ 点开素材库面板
   - 已有装饰：点选槽位 → 右键替换
   - **不开自由元素编辑**：封面是合成的，教师拖出的元素无处落盘、保存即丢
3. **封面底图 = 衬底**：半透明 + 高斯模糊（`opacity 0.18` + `blur(16px)` + `scale(1.08)`），
   保留主题底色与文字对比度。**单档，不设多级**

## 三、风格与模板（口径）

- 「风格」= 版式骨架 + 配色 DNA；「装饰」= 真实图片元件。**换风格不改内容，换装饰不改结构**
- 两端共用一份 `DecorSlots` 槽位语义（换图走 `background`，换元素走 `corners/floating`）
- **口径统一原则**：同一件事在两个端/两个入口只能有一套值。已统一的例子：
  H5 发布标题去掉 `_课件` 后缀（与草稿保存一致）· 衬底透明度两端同值 · KG 单元排序与单元下拉同判据

## 四、持久化约定（2026-09-17 起 · 血泪）

> 起因：**封面装饰**与**内容页装饰**都曾"保存后丢失"——因为它们不在 outline 结构里，没落盘。

| 数据 | 落点 |
|---|---|
| 内容页装饰 | 页内 `<!-- CW-DECOR:base64 -->` |
| 封面装饰 | 文档前沿 `<!-- CW-COVER:base64 -->` |
| 元素层 / 互动组件 / 可视化 | `<!-- CW-EL -->` / `<!-- CW-IT -->` / `<!-- VISUAL -->`（早于本次）|

**规则**：任何"不在 outline 结构里"的新数据，**必须同时定义它在 markdown 里的落点与读回**，
否则一律会在"保存/发布 → 由 markdown 重建"这一步丢失。空值不写（旧文档逐字节不变）。
