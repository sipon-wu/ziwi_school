## 第一章：产品概述

### 1.1 产品定位

知微教学（AI）是一套面向中小学教师的 **AI 辅助教学备课与学情管理平台**。系统以「校区·班级·学科·教材版本」为运行坐标系，将 AI 生成能力嵌入教学工作的全流程。

**双 AI 助手体系**：
- **小微**（萤火虫形象） — 服务于教师端，知识生成与学情分析
- **知了**（蝉形象） — 服务于平台运营与运维端，数据统计与实时告警

### 1.2 角色体系

#### 教学角色（校区级）

| 角色 | 登录态 | 首页 | 侧边栏 | 班级锚点 |
|------|--------|------|--------|----------|
| **教师** | 独立 | 工作概览 Dashboard | 五大模块：备课/作业/数据/家校/个人 | 需要（校区·班级·学科） |
| **班主任** | 同教师 | 增加班级管理入口 | 同教师 + 班级管理入口 | 固定为本班 |
| **教研组长** | 同教师 | 增加教研管理入口 | 同教师 + 教案互审池/教研数据 | 需要 |
| **教务员** | 独立 | 教务管理 Dashboard | 班级调度/课程安排/教师分配 | 全局视角 |
| **校长** | 独立 | 仪表盘（全校数据总览） | 数据洞察+管理 | 无需，全局视角 |
| **学校IT管理员** | 独立 | 系统管理 Dashboard | 用户管理/权限配置/数据管理/集成管理 | 无需 |

#### 平台角色（全网级）

| 角色 | 登录态 | 首页 | 侧边栏 | 职责 |
|------|--------|------|--------|------|
| **平台运营** | 独立 | 运营 Dashboard | 内容审核/教材审核/方法论审核/公告管理/客服 | 自编教材审核、方法论审核、平台公告、用户支持 |
| **平台运维** | 独立 | 运维 Dashboard | 系统监控/日志/性能/安全/基础设施 | 系统稳定性、性能优化、安全监控 |

### 1.2.2 知了——平台运营与运维 AI 助手

#### 定位
「知了」是服务于平台运营与运维人员的专用 AI 助手，与教师端「小微」属于同体系但不同角色。

| 对比维度 | 小微（教师端） | 知了（平台端） |
|----------|---------------|---------------|
| **服务对象** | 教师/教务/校长 | 平台运营、平台运维 |
| **拟人形象** | 萤火虫（点亮知识） | 蝉（知了声声，实时知晓） |
| **核心能力** | 内容生成、学情分析、知识助手 | 数据统计、报告输出、实时告警 |
| **知识层** | 学科知识 + 教师风格 | 运营知识库 + 运维知识库 |
| **输出形式** | 教案/习题/试卷/学情报告 | Excel 统计报表、告警通知 |
| **消息通道** | —（站内 + 家长端小程序） | 微信直达（运营/运维人员） |

#### 知了核心能力（一期）

| 能力 | 说明 |
|------|------|
| 对话问答 | 基于运营知识库和运维知识库的智能问答 |
| Excel 报表生成 | 自然语言指令输出统计报表（如「本月各学校 Token 消耗 Top10」→ 输出 .xlsx） |
| 微信消息推送 | 向运营/运维人员发送实时通知（告警、审核待办、异常事件） |
| 知识库检索 | 检索运营手册、运维手册、SOP 文档 |

#### 微信消息通道评估

| 通道 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| **公众号模板消息** | 无需用户安装额外应用；支持跳转 H5 页面；模板可定制 | 需用户先关注公众号；有模板 ID 限制 | 定时报表推送、审核待办提醒 |
| **小程序订阅消息** | 推送更稳定；可长期订阅（一次性/长期）；消息类型丰富 | 需用户打开过小程序；有推送次数限制 | 告警通知（需即时到达） |
| **企业微信** | 无推送限制；可双向交互；支持富文本 | 需企业微信账号体系 | 内部运营/运维沟通 |

> **建议方案**：**双通道并行**。
> - **公众号模板消息**：用于日常通知（审核待办、报表生成完毕）
> - **小程序订阅消息**：用于紧急告警（服务异常、Token 耗尽预警），利用「长期订阅」能力确保送达
> - 二期评估是否接入企业微信

#### 知了详细规划
> 知了的功能细节、交互设计、知识库建设等详细规划属于**二期**。

一期核心：构建运营知识库与运维知识库的基础架构，支持对话问答和 Excel 报表输出。

### 1.3 六条架构铁律

```
铁律1：系统设置是唯一配置源（校区→班级→学科→教材版本，一次性绑定）
铁律2：顶部锚点 = 同校区快速切换，班级切换弹窗 = 跨校区全量切换
铁律3：个人中心 = 全局层，其余所有菜单 = 上下文层（校区·班级·学科坐标系）
铁律4：小微 AI 运行在上下文层内，知识图谱锚定在「学科·教材版本」
铁律5：角色决定侧边栏（教师/教研/教务/校长/IT/家长/学生，不同角色完全不同的工作台）
铁律6：知识图谱是横跨教案/出题/组卷/作业的多模块基础组件，非教案专属
```

### 1.4 Token 与 License 机制

#### Token 机制
- Token 是 AI 生成能力的计量单位（生成教案、出题、小微对话等消耗 Token）
- 教师端顶部栏显示剩余配额百分比
- 配额由平台运营在后台统一分配（按学校/校区/教师维度）
- Token 耗尽时：教师端显示「Token 已用完」提示 + 入口引导至充值/联系管理员
- 平台运营可设置 Token 预警阈值（如剩余 10% 时自动提醒教师）

#### License 机制

产品存在两种使用模式，决定了教材版本配置、家长端开放范围等核心功能的归属：

| 模式 | License | 教材版本配置 | 家长端 | Token |
|------|---------|-------------|:---:|------|
| **学校版** | ✅ 学校级License（签约/续费） | 学校IT管理员统一配置 → 教师端继承，教师隐藏配置入口 | ✅ 开放 | 学校配额统一管理 |
| **个人试用版（SaaS）** | ❌ 无学校License | 教师自行配置（仅影响个人），不可导出/共享 | ❌ 锁定 | 个人Token限制，需个人续费 |

- License = 学校/校区的平台使用许可
- 由平台运营管理：授权开通、到期提醒（提前30天/15天/3天）、续费处理
- License 过期时：禁止新建内容（教案/出题/组卷），已发布内容只读可访问
- License判断依据：`school.license_status`（active/trial/none）
- 个人试用模式下，家长端功能（签字/成长关爱等涉及学生个人信息的功能）默认锁定

> 教材版本配置的完整规格见独立文档：`产品规划/教材版本配置系统_产品功能规格书.md`

#### 财务与发票
- Token 消耗账单和 License 费用统一由平台运营管理
- 支持按学校/校区/月度导出对账报表（Excel）
- 发票申请 → 平台运营处理 → 开具 → 邮寄/电子发票发送

#### B2C 个人版

除学校统一采购（B2B）外，提供教师个人付费使用模式，覆盖偏远学校、经费不足学校、个人意愿强烈的教师。

| 版本 | 月费 | Token 配额 | 目标用户 |
|------|------|:--:|------|
| 免费体验 | ¥0 | 500/月 | 试用 |
| 基础版 | ¥19.9 | 5,000/月 | 轻度使用教师 |
| 专业版 | ¥49.9 | 20,000/月 | 重度使用教师 |

- 功能与学校版完全一致，差异仅在 Token 配额和校园角色（个人版无校长/教务/IT 角色）
- 学校开通后，教师可一键迁移数据到学校版
- 不向学生和家长收取任何费用

### 1.5 课件预览页

课件是教案的配套输出。当教师引用素材库中的课件资源或系统生成课件内容时：

- 课件预览页：新标签页打开，展示完整课件内容（PPT 式逐页渲染）
- 与教案详情页的「使用脚本」联动——点击教案中的课件引用标记，可跳转到课件对应页面
- 支持缩略图导航、全屏预览
- 课件内容来自素材库（教师上传或 AI 生成）

## 第二章：全局层——个人中心与系统设置

> 唯一个人中心不受校区·班级·学科上下文约束。

### 2.1 班级切换弹窗

#### 功能
教师从已认领的所有校区+班级+学科中，选择当前工作上下文。

#### 交互
1. 入口：个人中心 → 班级切换（或首页顶部锚点下拉）
2. 顶部锚点下拉：仅显示当前校区下的班级（同校区快速切换）
3. 班级切换弹窗：展示所有校区、所有已认领班级+学科（跨校区全量切换）
4. 二次确认：切换时如有未保存工作，弹窗提醒「当前有未保存内容，确定切换？」
5. 切换后：全部界面数据刷新，小微上下文更新，知识图谱重新锚定

### 2.2 系统设置

#### 2.2.1 学校与班级管理

**功能**：教师认领学校/校区、班级、学科、教材版本的基础配置模块。

**数据模型**：
```
学校信息
├── 全称（如：成都市金牛区第一小学）
├── 简称（由全称自动生成，管理员可修改）
├── 别名列表（用于搜索匹配，如"金牛一小"）
├── 学制（六三制/五四制）
└── 分校/校区（多校区教师可认领多个）

班级认领（在每个校区下）
├── 认领班级（如四(1)班）
├── 认领学科（如语文）
└── 绑定教材版本（如部编版→人教版四下）
```

**教材版本配置**：
- 学校级（默认）：全校统一教材版本
- 年级级覆盖：某年级所有学科使用统一版本
- 学科级覆盖：某年级某学科使用特定版本
- 自编版本新增机制：
  ```
  方式：C方案——AI辅助提取+自动审核+同步运营审核
  流程：
    1. 教师在教材版本下拉框点击「未找到版本？申请新增」
    2. 上传教材 PDF → AI 自动提取目录结构和知识点
    3. 系统自动审核通过，立即可供该教师使用
    4. 同步通知运营平台人工审核
    5. 运营审核通过后，纳入平台版本库，可提供本校或全网可选使用
  ```

**任课角色配置**：
- 单班单科任课
- 同校区多班同科任课（如四(1)、四(2)班语文）
- 班主任任命（每班唯一班主任）
- 岗位排重规则（防止同一教师在同时段被分配到两个班级的同一学科）

**班主任唯一性约束**：同一班级只能有一名班主任。

#### 2.2.2 小微风格训练

**功能**：通过会话式引导，让小微学习教师的个人教学风格。

**核心原则**：
- 训练全程以对话形式展开（小微主动引导，教师响应）
- 渐进式推进（分步骤完成，不一次交付）
- 任务可中断（教师可随时暂停或跳过）
- 训练完成后可重新训练（版本交替）

**三类训练素材**：

| 素材 | 说明 | 学习内容 |
|------|------|----------|
| 教案 | 教师自己编写的教案 Word/PDF | 教学目标表述、环节结构、过渡语、板书偏好 |
| 学生评语 | 教师给学生写的评语片段 | 称呼方式、表扬语气、建议句式 |
| 课后反思 | 教师写的教学反思 | 反思深度、关注维度、改进风格 |

**提取的风格维度**：

| 维度 | 示例 |
|------|------|
| 教学目标 | 动词偏好（掌握/理解/运用） |
| 教学环节 | 结构偏好（四环节/五环节/探究式） |
| 过渡语 | 风格偏好（自然衔接/问题引导） |
| 板书设计 | 信息组织（关键词/思维导图/表格） |
| 称呼方式 | 孩子们/同学们/各位同学 |
| 表扬语气 | 热情鼓励/冷静肯定/具体描述 |
| 建议句式 | 「如果…就更好了」/「建议在…方面加强」 |
| 反思深度 | 描述型/分析型/行动型 |
| 关注维度 | 学生表现/教学调整/知识达成 |
| 改进风格 | 具体可操作/方向性建议 |

**训练完成度判断**：
- 不采用逐项勾选完成方式
- 系统通过综合评分判断：风格置信度（Style Confidence）
- 三个评估维度：素材覆盖度（三类是否覆盖）+ 样本量充足度 + 模式一致性
- 任务完成时平均置信度达到阈值即完成

**风格摘要确认**：
训练完成后生成自然语言摘要：
```
您的教学风格摘要：
- 过渡语倾向于自然衔接型
- 板书偏好关键词+板书结构
- 评语风格温和鼓励
- 反思偏重学生表现和教学调整
- 改进建议偏向具体、可操作
综合判断：您的语言风格偏亲切温和，教学目标表述清晰可测。
→ 【确认】或【修改不准确的特征】
```

**跨端支持**：PC 端开始训练，小程序端可继续（自动恢复到上次中断步骤）。

**数据归档**：
- 教师离职时：风格蒸馏成果归档（属于个人信息）
- 教学成果（教案/素材/题/卷/作业/学生数据）移交继任者
- 手机号一个月只能修改一次
- 账号（邮箱）不限次数修改

#### 2.2.3 个人信息

| 字段 | 说明 | 限制 |
|------|------|------|
| 姓名 | 教师真实姓名 | 可修改 |
| 头像 | 教师头像 | 可修改 |

#### 知识图谱与出题联动

| 联动方式 | 说明 |

| 图谱标记已覆盖 | 已有题目的知识点节点显示题量标记（如「已出3题」） |

#### 题目八要素构成规范
根据教育测量学，一道完整的作业题目包含：

| 要素 | 说明 |
|------|------|
| 题干 | 题目的主体，提出问题、创设情境或指明答题方向 |
| 答案 | 题目的标准结果，批改依据 |
| 解析 | 解题思路、考查知识点、错误选项分析 |
| 题型 | 选择/填空/判断/解答/简答等 |
| 分值 | 该题在整体作业或考试中所占分数 |
| 知识点 | 考查的具体知识内容和所属章节（从知识图谱点选） |
| 难度 | 量化指标（L1-L4） |
| 区分度 | 题目区分高/低水平学生的能力（选填，模考/选拔考启用） |
| 来源 | 教材/考试真题/原创 |

#### 题目标记

| 状态 | 说明 |
|------|------|
| 未使用 | 新创建，未被任何作业/考试引用 |
| 已使用 | 已被某次作业/考试使用过 |
| 使用次数 | 累计被引用次数 |

#### 区分度标准
区分度 = 高分组的正确率 − 低分组的正确率。用于衡量题目选拔能力。

| 区分度 | 等级 | 说明 | 适用场景 |
|:------:|------|------|----------|
| >0.40 | 优秀 | 能有效区分学生水平 | 选拔性考试 |
| 0.30-0.39 | 良好 | 区分度较好 | 常规考试 |
| 0.20-0.29 | 一般 | 需要修改选项 | 保留但改进 |
| <0.20 | 差 | 建议淘汰 | 不使用 |

> 常规作业不启用区分度筛选；模考/选拔考启用。区分度数据从平台学情数据中积累计算。

> 排重规则：相同题目不重复出现在同一份作业中；但允许相同题型不同题目反复练习。

#### 题库浏览
- 按知识点/难度/题型/来源筛选
- 按使用次数/创建时间排序
- 批量导入（CSV）
- 题目容器：每道题独立容器

### 4.3 作业布置（AI 增强版）

#### 核心设计
分两层：基础层（教师手动布置批改）+ AI 增强层（自动化辅助）。

AI 增强层不替代教师，而是做三件事：
1. 重复性劳动自动化（定时发送、自动批改客观题）
2. 高价值判断辅助化（作文预打分、低置信度标记）
3. 数据资产可视化（错题归集、学情报告、家长推送）

#### 知识图谱与作业联动
- 知识图谱标注「上次作业已覆盖的知识点」和「薄弱知识点」
- 教师布置作业时可参考图谱标注，优先覆盖薄弱点
- 小微可根据学情分析 + 图谱，推荐本周作业应覆盖的知识点

#### 作业布置类型

| 类型 | 说明 |
|------|------|
| 常规作业 | 教师预设规则，系统按规则自动执行（周测、每日一练） |
| 临时作业 | 教师手动创建的即时作业 |
| 调整性作业 | 针对个别学生或班级情况的补充作业 |

#### 布置流程
1. 选择班级和学科（自动带入当前上下文）
2. 选择作业模板（或新建）
3. 选题：手动勾选题库 / AI 智能组卷 / 上传自定义内容
4. 设置时间：相对时间（如发送后48小时截止）或绝对时间
5. 发送

#### 作业批阅工作台
```
┌──────────┬────────────────────┬──────────────┐
│ 左栏      │ 中栏                │ 右侧悬浮面板   │
│ 学生列表   │ 批阅内容区           │ 小微 AI 助手   │
│ ├ 姓名    │ ├ AI 批改结果        │ ├ 查询学情    │
│ ├ 提交时间 │ ├ 低置信度红色标记    │ ├ 操作批阅    │
│ └ 批改状态 │ ├ 教师修改入口       │ └ 对话互动    │
│            │ └ 提交/退回按钮     │              │
└──────────┴────────────────────┴──────────────┘
```

#### AI 批改流程
1. 学生拍照提交作业 → AI 多模态模型直接识别图片（文字+符号+公式+图形）
2. 客观题（选择/判断/填空）：全自动批改（结果比对）
3. 主观题（简答/作文）：AI 自动提取关键词预打分
4. 低置信度标记：置信度 < 85%（固定，不开放配置），在批阅工作台中用红色高亮显示
5. 教师复核：AI 显示评分依据和建议，教师可修改

#### 手写识别
- 采用 AI 多模态直识（参考豆包爱学拍题模式）
- 单字识别置信度 < 70%：该字标记「待确认」
- 整篇平均置信度 < 60%：整篇推送人工复核
- 教师端批阅工作台显示每篇识别置信度评分
- 教师可接受率目标：≥80%

#### AI 评分免责与双字段
- 批阅工作台顶部固定提示：「AI 评分结果仅供参考，教师复核确认后方可生效。」
- 作文批阅结果展示：AI 预评分 与 教师确认分 分两个字段显示

#### 批阅效率增强
- **键盘快捷键**：← → 切换学生，Enter 确认批改，Tab 切换题目
- **批量操作**：全选/反选 → 一键标记「已阅」/ 一键退回所有低置信度题目 / 批量发送催交提醒
- **进度条**：顶部显示批改进度（18/42），教师随时感知工作量
- **筛选排序**：按提交时间/批改状态/正确率排序，优先处理问题作业

#### 错题归集与家长报告

**错题归集维度**：学生每次作业批改完成后，错题自动归集到个人错题本。按知识点归类。

**家长报告发送机制（双周期）**：

| 周期 | 触发 | 内容 |
|------|------|------|
| 月报 | 按周或按月自动归集（学校统一配置） | 完整错题详情 |
| 期末 | 期中、期末各一次 | 学期阶段性总结报告 |

**报告结构**：

| 版本 | 内容模块 |
|------|----------|
| 综述版（家长先看到） | 已掌握知识点（绿）/ 建议巩固知识点（黄）/ 重点突破知识点（橙）/ 3条积极建议 |
| 详细版（点击展开） | 错题列表（按知识点归类）/ 原题+学生答案+正确答案+知识点标签 / 各维度掌握情况对比 / 历次同类错题对比 / 一键生成同类巩固练习 |

#### 家长端提醒
- 每周/每月定时生成报告（可配置）
- 家长可设置免打扰时段（默认 22:00-7:00）
- 逾期未交等紧急通知不受免打扰限制

#### 作业全生命周期状态
```
布置 → 已发布 → 学生提交中 → 提交截止
              → 批阅中 → 批阅完成 → 错题归集 → 报告生成 → 家长签字
```

### 5.1 学情分析（教师端）

#### 模块定位
一个面向任课教师的轻量级班级学情仪表盘，让教师用最短时间了解班级整体学习状况。不做复杂下钻，复杂问题交给小微对话式解答。

#### 设计原则
| 原则 | 说明 |
|------|------|
| 一屏可见 | 核心数据在一个页面内完整呈现，无需滚动或切换 Tab |

| 可提问 | 每个数据卡片旁提供小微入口，点击直接向小微提问 |

#### 与小微的分工
| 场景 | 学情看板负责 | 小微负责 |
|------|-------------|----------|
| 数据呈现 | 直观展示核心指标 | 补充说明、归因分析 |
| 深度分析 | — | 回答"为什么"和"怎么办" |
| 趋势判断 | 展示变化趋势 | 分析变化原因 |

#### 七卡片布局（一屏展示，三行排列）

| 行 | 卡片 | 核心数据 | 小微提问入口 |
|----|------|----------|-------------|
| 1 | 作业完成率 | 85%（36/42人） | 问小微：为什么完成率变化了？ |
| 1 | 平均正确率 | 72% | 问小微：正确率下降的原因？ |
| 1 | 待批阅/待订正 | 6份待批阅｜12人需订正 | 问小微：哪些学生需要重点关注订正？ |
| 2 | 知识点掌握度 | 已覆盖12/20个知识点 | 问小微：哪些知识点需要重点关注？ |
| 2 | 正确率趋势 | 近7天正确率曲线 | 问小微：正确率波动的原因是什么？ |
| 3 | 共性问题 | 错误率最高TOP3知识点 | 问小微：运算定律错误率高的原因及建议 |
| 3 | 标签速览 | 系统自动打标 | 问小微：计算能力偏弱的具体表现和建议 |

#### 数据层级与更新频率
| 数据层级 | 更新频率 |
|----------|----------|
| 今日数据 | 实时（作业提交/批阅情况） |
| 本周数据 | 每日凌晨更新（周一到当日累计） |
| 本月数据 | 每日凌晨更新（当月累计） |
| 趋势数据 | 每次批阅完成后增量更新（正确率曲线、知识点掌握度） |

### 5.2 成长足迹

#### 模块定位
学生个人学习档案，记录学生各阶段的变化轨迹。由教师观察记录 + 系统数据自动记录共同构成。

#### 功能
- 班级学生列表 → 进入学生详情页
- 学生详情页：学习概览 / 时间线 / 观察记录 / 数据趋势
- 教师可添加观察记录：描述具体行为或表现
- 学期末生成成长报告

> 严禁标签化：系统不存储任何固定标签字段。所有描述带时间戳，反映的是「该生在[时间]在[知识点]上需要额外关注」的状态描述。

## 第六章：上下文层——家校沟通

### 6.1 家长签字

#### 模块定位
一个让家长通过点击确认「已查看孩子作业」的轻量工具。不强制、不手写、不涉及法律效力，仅作为家校协同的辅助手段。

#### 设计原则
| 原则 | 说明 |
|------|------|
| 自愿原则 | 家长可签可不签 |
| 一步完成 | 点击即确认，无需手写签名 |
| 不强制 | 未签字无系统级后果 |

#### 教师端功能
- 作业批阅完成 → 推送确认请求到家长端
- 查看签字统计：已签/未签人数、家长回复情况
- 催办：系统发送红点提醒至家长小程序端（仅通知，不承载消息内容）→ 家长点击进入小程序查看完整消息
- 次数追溯：按月/学期统计漏签次数，供教师识别家长配合度

> 未签字无任何系统级后果。仅提供数据留痕给教师端，由教师自行识别家长配合度。

### 6.2 成长关爱

#### 模块定位
一个针对需要个性化关注学生的轻量级干预工具。教师在成长足迹中勾选学生后，小微每周结合学情数据和教师观察，动态生成个性化提升方案，经教师确认后执行。

#### 严禁标签化原则
- 系统中不存储任何学生标签字段
- 评估结果用自然语言描述（如「该生目前在分数比较方面需要额外关注」）
- 所有评估描述带时间戳，反映的是快照而非定性
- 教师添加观察记录时提示：「请描述您观察到的具体行为或表现」

#### 评估文案教育善意度审查
小微生成的评估文本在发送家长端前，须经「教育善意度审查」：

- 禁止使用比较性表述（如「远低于班级平均」「排名倒数」）
- 禁止使用绝对化判断（如「基础很差」「完全不懂」）
- 必须配合建设性建议（指出问题的同时提供改进方向）
- 示例对比：
  - ❌「该生计算能力远低于班级平均水平」
  - ✅「该生在分数计算方面正确率为 52%，本周建议每天进行 10 分钟分数专项练习，具体题目已附在练习安排中」

#### 入组流程
1. 教师在成长足迹中进入某学生档案 → 点击「纳入成长关爱」
2. 系统弹出确认框：展示当前学情概览（正确率、薄弱知识点、近期趋势）
3. 教师基于专业判断确认
4. 小微自动标记该生学情数据中的波动详情作为辅助参考
5. 向家长发送入组诊断书

#### 分组方式（非标签化）
- 教师可自定义分组名称（如「分数专项组」），仅用于批量发送同类练习
- 分组名称不外显、不导出给家长端
- 仅作为操作便利工具使用

#### 双评估机制

| 评估来源 | 说明 | 示例 |
|----------|------|------|
| 小微评估（基于数据） | 每周自动检索该生数据，生成自然语言描述 | 「该生当前正确率低于班级平均，在分数比较题型上需要关注」 |
| 教师观察（基于经验） | 教师可随时添加观察记录 | 「该生近期课堂专注度有所下降」 |

#### 方案生成与审阅
每周方案草案包括：

| 模块 | 内容 |
|------|------|
| 本周聚焦 | 当前需要关注的学习方面（自然语言描述，非标签） |
| 练习安排 | 题型、题量、预计用时 |
| 学习任务 | 如「每天完成3道分数比较专项练习」 |
| 教师建议 | 教师可添加一段话，发送给家长 |

#### 小学 vs 初中方案差异
| 维度 | 小学 | 初中 |
|------|------|------|
| 练习类型 | 计算练习、口算打卡 | 专项题型训练、错题变式 |
| 练习频次 | 每周3-4次，每次10-15分钟 | 每周4-5次，每次20-30分钟 |
| 反馈语气 | 鼓励性、趣味性 | 目标导向、数据驱动 |

#### 教师审阅界面
- 查看方案草案列表
- 操作：确认 / 修改（调整练习内容或频次）/ 补充观察 / 退回重生成

#### 家长确认与沟通
- 入组通知：教师确认后发送 → 家长确认 → 开始执行
- 家长每周收到学情周报
- 家长可在周报页面留言，教师查看并回复
- 续期管理：每学期末发起下学期入组确认邀请

#### 数据存储规范
**禁止存储**：
- 任何形式的标签字段（如「学困生」「后进生」）
- 对学生进行等级划分或定性判断的描述
- 学生间的横向比较结果（排名对比仅存于教师端临时查询）

**评估描述格式**：
- 描述具体行为或数据，不做归因论断
- 示例：「该生目前在分数比较题型上的正确率为52%，低于其自身前两周的68%」

## 第七章：知识图谱系统

### 7.1 图谱边界

| 维度 | 边界 | 说明 |
|------|------|------|
| 知识节点 | 学科+教材版本锚定 | 当前上下文=语文·部编版 → 仅展示部编版知识树 |

| 跨班对比 | 明确切换上下文 | 切换班级 → 图谱刷新为该班数据 |
| 跨学科 | 不在同一坐标系 | 语文图谱和数学图谱是两棵独立的树 |

### 7.2 图谱可视化

#### 视图模式
| 视图 | 适用场景 |
|------|----------|
| 树状 | 层级结构，展示知识的前置后继关系 |
| 螺旋 | 螺旋排列，展示知识的递进或循环关系 |
| 网状 | 网络拓扑，展示知识的多维关联 |

#### 维度切换（着色/筛选）
| 维度 | 着色规则 |
|------|----------|
| 知识点 | 按知识分类着色 |
| 能力 | 按核心素养能力维度着色（思维/表达/审美等） |
| 难度 | 按 L1-L4 难度等级着色 |
| 课标 | 按课程标准要求着色（必学/选学/拓展） |

#### 难度标尺
| 等级 | 含义 |
|------|------|
| L1 | 基础/识记 |
| L2 | 理解/应用 |
| L3 | 分析/综合 |
| L4 | 评价/创造 |

#### 默认视图策略
- **首次使用**：默认展示「聚焦当前课时」简化视图（仅显示直接相关的 5-8 个节点）
- **3 秒引导提示**：「图谱上的节点是本节课涉及的知识点，点击可查看详情。」（自动消失）
- **切换模式**：「展开全部」/「聚焦当前课时」两种模式，切换后记住偏好

### 7.3 与各工作台的联动

#### 教案工作台
- 选单元/课时 → 图谱自动聚焦到该课时
- 知识点从图谱中点选 → 精确绑定教案与知识图谱节点
- 教案发布后 → 学情分析可追踪到每个知识点的教学效果

#### 出题·题库
- 图谱点选知识点 → 自动填入题目知识点字段
- 图谱节点标记「已出题数」和「学情薄弱度」
- 未覆盖知识点灰色标记，提示教师补充
- 小微出题建议：「帮我为正确率低于70%的知识点各出2道选择题」

#### 组卷·试卷库
- 图谱按难度着色，当前试卷每题对应节点高亮 → 一眼看清难度覆盖
- 知识点覆盖率：实心=已覆盖，空心=未覆盖，显示百分比
- 选中题目 ↔ 图谱节点双向联动定位
- 空白知识点闪烁提醒补题
- 组卷完成 → 试卷质量评估面板（覆盖率/难度分布/题型分布/预估分/课标对齐度）

#### 作业布置
- 图谱标注「上次作业已覆盖知识点」和「薄弱知识点」
- 教师布置参考图谱标注，优先覆盖薄弱点
- 小微推荐本周作业应覆盖的知识点清单

## 第八章：小微 AI 系统

### 8.1 小微能力边界

**小微能做的**：
- 理解自然语言指令 → 调用后端 API 生成内容
- 检索素材库、知识图谱
- 分析学情数据，生成描述性评估（非标签）
- 生成教案/习题/试卷/作业
- 学习教师个人教学风格
- 回答基于上下文的教学问题

**小微不需要做的**：
- 操作页面 DOM（点击按钮、填写表单）
- 导航到某个页面
- 截图当前页面
- 执行浏览器宏

> 小微是内容引擎和知识助手，不是浏览器机器人。

### 8.2 知识层架构（三层）

```
┌─────────────────────────────────────────┐
│          公共知识层 (Global)              │
│  ├── 课标体系（平台统一维护）              │
│  ├── 教材结构（平台统一维护）              │
│  └── 领域方法论（教师贡献 + 平台审核）       │
│      ├── 来源：小微识别 → 教师授权 → 平台审核 │
│      ├── 归属：贡献教师署名                │
│      └── 范围：可全校共享，优秀者全网共享      │
├─────────────────────────────────────────┤
│          个人风格层 (Personal)            │
│  语言风格/环节偏好/板书习惯/反思风格         │
│  → 教师个人训练，仅本人可见                 │
│  → 离职时风格蒸馏成果归档（不转移）          │
└─────────────────────────────────────────┘
```

#### 方法论贡献机制（B→A）
1. 小微从教师使用数据中**被动识别**高价值教学模式
2. 推荐教师**授权共享**（展示摘要：如「您在分数教学上的三步法模式独特，是否愿意分享给本校同级科任教师？」）
3. 教师确认 → 进入平台审核
4. 审核通过 → 纳入领域方法论库，署名贡献教师

### 8.3 小微面板交互

| 触发方式 | 面板形态 | 使用场景 |
|----------|----------|----------|
| 工作台底部黑色按钮 | 右侧滑出侧边面板 | 教案/组卷工作台，需要对话辅助时 |
| 非工作台页面点击小微 | 右侧滑出侧边面板 | 首页/学情/批阅/草稿等页面 |
| 训练小微子模块 | 居中预置面板 | 风格训练会话 |

> 所有面板统一从右侧滑出，交互一致。

### 8.4 小微上下文注入

小微 prompt 自动注入当前上下文：`{校区, 班级, 学科, 教材版本, 当前页面, 知识图谱锚点}`

教师不需要每句话重复「四年级语文部编版」，小微已经在上下文里。

### 8.5 小微会话连续性

#### 同任务内跨页面
- 后端维护 `session_id + conversation_id`
- 小微面板无论从哪个页面唤起，都挂载同一会话
- 切页面时不重置对话，小微知道历史上下文
- 切换页面时自动注入新的页面上下文

#### 跨任务会话
当教师在同一会话内切换任务意图时（如从"聊教案"转向"出题"）：

| 决策 | 方案 | 说明 |
|------|------|------|
| 意图切换方式 | 小微识别意图转换 → 提示教师确认 | 「检测到您想基于观潮的知识点出题，确认切换？」→ 教师确认后切换上下文 |
| 历史保留策略 | 保留最近 3 轮对话摘要 | 后续监控会话复用频率数据，动态调整 N 轮赋值 |
| 面板关闭行为 | 关闭=暂停会话（保留状态） | 基于历史保留策略，关闭不销毁会话数据 |
| 历史检索 | ✅ 支持全文检索 | 教师在会话界面可搜索历史对话关键词，返回匹配片段的会话列表 |

**会话数据模型**：
```
conversation {
  conversation_id       // 唯一会话标识
  teacher_id            // 教师ID
  status                // active / paused / archived
  messages[]            // 完整消息记录（每条含 role/content/timestamp/page_context）
  summaries[]           // 每3轮的摘要快照
  current_task_context  // { page, knowledge_graph_anchor, workbench_type }
  search_index          // 全文检索引擎索引（用于历史检索）
  created_at
  updated_at
}
```

#### 面板关闭行为
- 关闭侧边面板 = 暂停会话（保存状态）
- 同一页面短期内重新打开 = 恢复上次会话
- 手动点击「新会话」= 清除历史，开启新对话

### 8.10 AI 选题智慧（因材施题）

**面向全班（共同提分）**：

- 权重以共同提分为优先目标

**面向成长关爱学生（因材施题）**：

### 8.11 非工作会话识别与防护

#### 工作边界定义

| AI助手 | 工作范围 | 典型非工作请求 |

#### 识别机制（三层防护）

| 层 | 机制 | 说明 |

## 第十一章：数据治理与合规

### 11.1 家长端数据提示
家长端查看学生数据时，顶部固定显示：
> 「本数据仅用于教学改进，不作其他用途。」

### 11.2 数据保留与脱敏
- 学生在校期间：数据正常保留
- 毕业后：数据保留 3 年
- 超过 3 年：自动脱敏归档（移除个人标识，仅保留统计级数据）
- 隐私政策中明确：数据存储位置、保留期限、访问权限

### 11.3 教育善意度审查
（详见 §6.2 成长关爱）

### 11.4 未成年人信息保护
- 不满十四周岁学生个人信息属于敏感个人信息
- 家长首次使用需单独弹窗获得监护人同意
- 语音跟读模块采用本地处理（详见 §12）

### 11.5 自编教材版权
- 教师上传自编教材申请时，弹窗提示：「您确认上传内容不侵犯他人版权，本校对其合规性负责。」
- 校内私有库：学校自行负责版权合规，平台方不主动审查、不干涉（避风港原则）
- 平台公共资源库：平台方对提交内容启动版权审查
- 平台方收到版权方合规通知后，配合下架处理

### 11.6 教材知识点蒸馏策略
- 从公开教材目录中提取知识结构（章节、知识点、课标映射），不复制课文原文
- 蒸馏内容：知识图谱节点名称、层级关系、章节对应关系
- 不收录：课文全文、受版权保护的原文段落
- 现代课文：仅关联到章节元数据，不收录原文（待与出版社建立授权合作后扩展）

### 11.7 AI 使用指引
系统设置中新增「AI 使用指引」入口，包含：

## 第十二章：家长端·语音跟读

### 12.1 模块定位
一个在家长端小程序内运行的语音跟读工具。孩子跟读英语单词/句子或拼音后，系统在设备本地完成语音评测并给出即时反馈，原始录音不上传服务器。

### 12.2 合规架构（核心决策：本地处理）
- 原始录音留在设备本地，处理完即删，不上传服务器
- 不提取、不存储声纹特征
- 仅上传评测结果（分数/错误统计），不含语音数据
- 监护人首次使用需单独弹窗获得同意
- 法律依据：《个人信息保护法》第28/29条 + 《未成年人网络保护条例》第19条

### 12.3 适用场景
| 场景 | 说明 |
|------|------|
| 英语单词跟读 | 教材词汇、课外阅读词汇发音练习 |
| 英语句子跟读 | 课文句子、日常对话流利度练习 |
| 拼音跟读 | 声母/韵母/整体认读音节练习 |
| 课文朗读 | 语文/英语课文朗读（进阶） |

### 12.4 技术架构
- 端侧语音识别：微信同声传译插件 / 离线语音SDK
- 发音评测：端侧评测SDK（仅返回评分，不返回原始音频）
- 本地存储：不存储任何录音文件（处理完即释放）
- 云端存储：仅存储评测结果（exercise_id / score / error_type / duration）

### 12.5 内容分级
| 级别 | 适用年级 | 内容特征 |
|------|----------|----------|
| L1 | 一年级 | 单音节词、短句（3-5词）、拼音声母/韵母 |
| L2 | 二年级 | 双音节词、中句（5-8词）、拼音拼读 |
| L3 | 三年级 | 多音节词、长句（8-12词） |
| L4 | 四年级+ | 复杂句、段落朗读 |
