## ① 教育专家（学习科学 / 认知科学视角）

**总体评价**：框架有认知科学底子，比"题海"叙事高级，愿意背书"循证精练"。

**认同亮点**
- 7 机制对应刻意练习、合意难度、提取练习，理论自洽。
- 双场景权重区分"教学/应试"，避免"一种方法通吃"的常见错误。
- 价值坐标系扩到素养/习惯/动机/应试策略，不再只盯分数。

**主要质疑**
1. **权重非实证**：§3.2 权重是启发式，若对外宣称"科学权重"需教研实证（德尔菲法或提分 A/B 对照），否则有夸大嫌疑。
2. **变式自动生成质量**：⑦变式与迁移依赖 AI 生成，质量参差会直接损害"真理解"目标。
3. **（已澄清）话语**：V0.1 曾建议弱化"提分"，经用户拍板**撤回**——国内 K12 应试内核不可忽视，营销应直击痛点；素养作并行叙事而非替代。本视角接受此澄清。

**修改建议**
- 权重表标注"待教研标定"，并规划标定实验。
- 增加"命题质量双人校验"机制，AI 变式不直达学生。
- 价值坐标系的"德育/价值观"轴明确标注"平台约束不产品化"，避免越界。

**是否支持推进**：✅ 支持，条件=补教研验证 + 质量校验。

## ② 一线名师（学科教学实操视角）

**总体评价**：痛点真实（挑题耗时、覆盖漏），但落地细节要小心。

**认同亮点**
- 覆盖度看板能帮教师发现"自以为讲了其实没覆盖"的盲区。
- 分层作业接入训练坐标、双轴画像桥接，逻辑顺。

**主要质疑**
1. **AI 标 R 易错**：训练角色 R 涉及教学法判断，AI 初标错标率高，教师逐题校正反而增负。
2. **教师没时间看板**：日常满课，复杂看板成摆设，要"轻量推送"而非"主动去看"。
3. **架空专业性**：目标编排器若默认替教师组好题，老教师会觉得被架空；应定位为"建议+教师拍板"。
4. **冷启动**：本校题库初始覆盖薄，编排出来质量差，先别主打编排。

**修改建议**
- R 标注默认"仅标注高置信项"，低置信留空由教师按需补，不强制全标。
- 看板改为"首页一条薄弱提示 + 钻取"，而非独立复杂页。
- 编排器输出"推荐题组 + 理由"，教师一键采纳或改，保留主导权。
- Phase 0 先上"覆盖度看板 + 补题引导 + 成长关爱透出"，编排器后置。

**是否支持推进**：🟡 审慎支持，先小范围（1–2 校同科）试用原型。

## ③ 教培方法论顾问（应试方法论借鉴视角）

> 角色重定义：本方案**不服务教培机构**（校内 SaaS 定位），机构人士在此仅作"方法论顾问"——借其限时套卷、分层冲刺、错题重做、习惯培养经验打磨产品，不以"卖不卖得动"衡量。

**总体评价**：应试权重排得对，方法论值得借鉴，但我们的生意逻辑和"题库编排"不完全重合。

**认同亮点**
- ①自动化 10、②套路 9、⑤限时 8 的排法符合机构冲刺班实战。
- "限时耐力"被单列且权重高，说明懂套卷训练——很多产品忽略。
- 双轴画像里的"限时完成率/耐力""错因图谱"正是机构训练法的数据化。

**主要质疑**
1. **机构不靠题库编排提分**：机构核心竞争力是真题库、秘押、名师讲义，不是"通用题库+AI 编排"。本功能对机构卖点有限——故重定义为顾问而非客户。
2. **质量承诺边界**：一旦打"编排提分"，家长期待被抬高，AI 题质量波动会反噬口碑。
3. **数据飞轮对机构价值低**：机构学员流动快，薄弱信号跨期积累价值不如校内。

**修改建议**
- 借鉴机构方法论打磨"模拟/纠错"两模式与错因图谱，但不对机构销售。
- 质量承诺只敢说到"辅助"，不敢说"保证提分"。
- 对外营销讲两个版本：校内"编排提分+减负+数据"；顾问侧讲"模考诊断+报告"。

**是否支持推进**：✅ 务实支持，定位为方法论顾问。

## ④ 重点校校长 / 教研室主任（区域落地与采购视角）

**总体评价**：戳中采购决策点（减负、数据说服家长、**升学率/绩效**），但区域差异与合规是硬门槛。

**认同亮点**
- "教师挑题耗时→系统编排减负"是校长最愿买单的叙事。
- 覆盖度看板 + 学情数据，是向家长/上级交代的现成材料。
- **双飞轮的组织层出口（教师绩效仪表盘 + 学校升学率支撑报告）**把采购动机从"减负"升级到"政绩/续费"，极具说服力。

**主要质疑**
1. **区域/学段差异大**：城乡、重点/普通、文理差异，权重与坐标不能一套通吃，须可配置。
2. **增负风险**：若看板/编排增加操作步，一线会抵触，推广失败。必须"减负可感知"。
3. **学情隐私**：薄弱信号、错题数据属敏感学情，跨班级/校区的权限与合规要讲清。
4. **采购决策链**：校长拍板但教研室落地，文档要给"教研室能用的操作手册视角"。

**修改建议**
- 权重/坐标做成"区域模板 + 校本覆盖"，默认用国标，学校可微调。
- 首屏即"今日可一键生成的练习"，把减负做成可感知动作。
- 学情数据加权限分级（教师看本班、教研看年级、校长看全校），合规先行。
- 绩效/升学率出口须配套合规说明，避免数据滥用。
- 补一份"教研室落地操作手册"作为方案附件。

**是否支持推进**：✅ 支持，条件=区域可配置 + 隐私合规 + 减负可感知 + 绩效合规。

## ⑤ 家长代表（底层推力 / 替代教培叙事支点）

**总体评价**：关切点真实——提分焦虑、课外班贵且累、不知孩子弱在哪。校内精准精练若透明，是"替代教培"的叙事支点，反过来强化学校采购与续费。

**认同亮点**
- 成长关爱入组生的学情透明，让家长"知道孩子弱在哪、在怎么练、进步没"，正是教培高价提供的价值，校内免费给。
- 顶部"本数据仅用于教学改进"合规提示，降低家长对被滥用的担忧。

**主要质疑**
1. **仅关爱组可见是否够**：未入组学生家长只能看作业/签字，若孩子"没被老师放进关爱组"，家长会不会觉得被差别对待、或被忽视？
2. **数据安全焦虑**：学情画像（错因、薄弱点）属敏感，即便仅关爱组，家长也关心"谁还能看、会不会外泄"。
3. **透明≠减负**：看到孩子弱，家长可能更焦虑、回家加练，反而加剧负担——系统是否引导"适度"？

**修改建议**
- 明确"成长关爱 = 教师重点关注生"，家长端话术讲清"重点关爱生进展透明"，非差别对待；普通生基础信息（作业/签字）本就可见。
- 家长视图复用成长关爱模块，强化"仅本人子女、仅关爱组"的隐私边界明示。
- 在家长端加入"适度引导"文案（如建议练习频次），避免透明变加压。

**是否支持推进**：✅ 支持，须明确透明边界 + 数据安全明示。

## 跨视角共性结论与修订清单

1. **话语定案（已落 V0.2）**：恢复并强化"提分"主叙事，素养作并行叙事；营销直击痛点，校方 PR 非我职责（用户拍板）。撤回 V0.1"弱化提分"建议。
2. **实证化**：双场景权重标注"待教研标定"，规划标定实验（①）。
3. **减负可感知**：编排器/看板做成"轻量推送 + 教师拍板"，不增负（②+④）。
4. **冷启动策略**：Phase 0 先覆盖度看板 + 补题引导 + 成长关爱透出，编排器后置（②）。
5. **质量边界**：AI 题/变式不直达学生，双人校验；营销只敢说"辅助"（①+③）。
6. **区域可配置 + 隐私合规**：权重模板化、学情权限分级（④）。
7. **机构重定义**：方法论顾问，非目标客户；双营销版本（③）。
8. **家长透明边界（新增）**：学情严格限定成长关爱入组生，未入组仅作业/签字；数据安全明示 + 适度引导（⑤）。
9. **绩效/升学率出口（新增）**：组织层飞轮出口须配套合规说明（④）。
