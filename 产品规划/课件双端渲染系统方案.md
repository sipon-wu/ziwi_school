## 1. 核心设计理念：内容与布局分离

- **内容层**：纯文本、数据、图片等实质信息（`slots: Record<key, string[]>`）。
- **布局层**：版式结构（`LayoutSkeleton` 的 placeholder + 几何）。
- **渲染层**：最终输出（PPT 由浏览器 `pptxgenjs` 生成 `.pptx`；H5 本期预留）。

核心原则：**内容是核心骨架，布局是外在皮肤；骨架不变，皮肤可换**。

本仓库已有实现（`cwTemplate.ts` 的 `EDU_LAYOUT_SKELETONS` + `exportPptx.ts` 的 `effSlots`/`distributeToSlots`/`markdownToOutline`）即采用此模型——模板用 `key` 声明占位符，渲染器按 `key` 取内容填充，换模板即换 `key` 映射。本方案在其基础上**扩展通用版式骨架与自适应切换**。

---

## 2. 数据模型（沿用现有，向后兼容）

`OutlineSlide` / `CwSlide` 的 `slots?: Record<string, string[]>` 字段：

- 有 `slots` → 渲染/导出/编辑一律按 `skeleton[key]` + `slots[key]`；
- 无 `slots`（旧数据）→ 回退现有按行号/扁平 bullets 逻辑，不破坏已有课件。

---

## 3. 布局骨架体系（本期扩展后）

### 3.1 教学专用骨架（已有，`edu-*`）
`edu-goal` / `edu-explain` / `edu-example` / `edu-summary` / `edu-homework` —— 各声明语义 placeholder（如 `question`/`solution`、`basic`/`improve`/`expand`）。

### 3.2 通用版式骨架（本期新增）
覆盖方案文档中 PPT 与 H5 共用的通用页面类型，与教学骨架并存：

| layout key | 占位符 | 说明 | 自适应 |
|---|---|---|---|
| `content-1col` | `title`, `body` | 单栏内容 | — |
| `content-2col` | `title`, `left`, `right` | 双栏 | `items≤1` 降级单栏 |
| `content-3col` | `title`, `col1`/`col2`/`col3` | 三栏 | `items≤2` 降级 |
| `content-4col` | `title`, `col1`~`col4` | 四栏 | `items≤3` 降级 |
| `content-grid` | `title`, `items[]` | 网格（2–6 项自适应列数） | 按 items 数算列 |
| `chart` | `title`, `data` | 图表页（占位，几何预留） | — |
| `timeline` | `title`, `events[]` | 时间线（≤6 节点） | — |
| `comparison` | `title`, `left`, `right` | 对比页 | — |
| `section` | `title` | 分隔页 | — |
| `summary` | `title`, `items[]` | 总结页（≤6） | — |
| `cover` | `title`, `subtitle`, `info` | 封面 | — |
| `toc` | `title`, `items[]` | 目录（≤6） | — |

### 3.3 骨架格式
```ts
type Rect = { x: number; y: number; w: number; h: number } // 百分比
interface Placeholder { key: string; type: 'text'|'bullets'|'image'; label: string; rect: Rect; columns?: number }
interface LayoutSkeleton { placeholders: Placeholder[] }
```

## 4. 自适应布局切换（content 类）

`items.length` 驱动版式升级/降级（仅在 `content-*` 系列内联动，不跨教学骨架）：

| 内容数 | 选用 layout |
|---|---|
| 0–1 | `content-1col` |
| 2 | `content-2col` |
| 3 | `content-3col` |
| 4 | `content-4col` |
| 5–6 | `content-grid` |

触发点：`markdownToOutline` / `outlineToSlides` 解析时按 `bullets.length` 选 layout；教师增减要点时若 `layout` 仍为 `content-*`，自动重映射（同名 key 对应，多余进溢出区 `__overflow`）。这与现有 `distributeToSlots` 的「按列数均分 + 溢出」逻辑一致，复用即可。

---

## 5. PPT 渲染引擎（前端 `pptxgenjs`）

- 保持 `exportPptx.ts` 浏览器端生成 `.pptx`（`pptxgenjs`）。
- `exportCoursewareToPptx` 按 skeleton 几何把每个 slot 写成独立文本框（百分比 → 厘米换算），修复旧链路「丢 layout」问题。
- 主题（配色 + 字体）沿用 `cwTemplate.PPT_TEMPLATES` 的 `themeId`，**不引入 Node 母版**。

---

## 6. 模板范例（本期 10–15 套）

复用现有 `PPT_TEMPLATES`（已含 `fresh-illustration` 等），按「学段标签 × 学科标签 × 课型标签 × 风格」组织，并关联上述骨架。首期挑选覆盖高频场景的 10–15 套做验证，确认「内容→骨架→渲染」全链路正确后，再批量扩充。

模板仅含「结构 + 系统自有配色」，零外部二进制（与既有纪律一致）。

---

## 7. 简化装饰（本期）

仅主题色（primary/secondary/background/text/accent）+ 基础角标/分隔线，**不做**四层递进装饰系统。

## 9. 关键约束（沿用方案文档 + 纪律）

- 所有 PPT 模板适配 16:9（10″×5.625″，百分比几何）。
- 同一套模板不同版式保持视觉一致（配色/字体/装饰不变）。
- 内容重排不得丢失信息（超出槽位进溢出区）。
- 向后兼容旧课件（无 slots 回退）。
- 不自动部署生产，先 staging 真浏览器验证。
