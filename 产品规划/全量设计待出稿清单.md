- 布局：左侧边栏 + 顶部白色标题栏 + 内容区
- 色值：brand #02A7F0 / 文字 #353535 / 边框 #E7E7EB / 背景 #F6F7F8
- 字体：PingFang SC 13px
- 卡片：1px border #E7E7EB，无阴影
- 图标：icons/ 目录下自定义SVG
- 状态：空态 / loading-skeleton / 错误态 / 提示态 四项齐全
