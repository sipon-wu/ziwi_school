## 二、左侧面板 — 表单字段逐项识别

### 2.1 基本信息区（固定上下文，不可编辑）

| 字段 | 值 | 来源 | 可编辑 |
|------|-----|------|--------|
| 学科 | 语文 | 系统设置（当前班级绑定的学科） | ❌ 只读 |
| 年级 | 四年级(1)班 | 系统设置（当前班级） | ❌ 只读 |
| 校区 | 成都市金牛区第一小学 | 系统设置（当前校区） | ❌ 只读 |
| 教材 | 人教版四年级下册 | 系统设置（当前教材版本） | ❌ 只读 |

**关键设计**：基本信息四项是**自动带入的上下文**，教师不需要手动填写，只作为当前工作坐标系的确认。

### 2.2 标题输入

| 字段 | 状态 |
|------|------|
| 输入框 | 空，占位符「请在这里输入标题（0/12）」 |
| 字数限制 | 12字符 |
| 必填 | 是（默认） |

### 2.3 单元与课时选择（级联联动）

| 字段 | 当前值 | 数据源 |
|------|--------|--------|
| 单元 | 第七单元 | 根据当前教材版本（人教版四下）自动列出所有单元 |
| 课时 | 25 挑山工 | 选择单元后，自动列出该单元下的课次+课题 |

**关键设计**：级联联动——选单元→自动填充课时选项，选课时→自动关联到具体课文/知识点。

### 2.4 教案模板选择

| 选项 | 当前值 | 说明 |
|------|--------|------|
| 下拉 | 核心素养模板 | 预设教案结构模板，不同学科可能有不同模板 |

> 可扩展：教师可自定义模板，学校/校区可统一配置模板。

### 2.5 知识点选择（5/5 已选）

| 显示 | 内容 |
|------|------|
| 已选 | 知识点1、知识点2、知识点3、知识点4 |
| 可展开 | 「更多学知识点5+」 |
| 限制 | 最多5个（(5/5)） |

**关键设计**：知识点是**知识图谱的提取结果**，非自由文本——教师从图谱中选择已有节点，保证教案与知识图谱的精确绑定。

### 2.6 自定义标签（1/3）

| 显示 | 内容 |
|------|------|
| 已选 | 自定义标签1 |
| 可添加 | + 请输入（还有2个名额） |

### 2.7 补充内容（AI协作对话框）

| 元素 | 内容 | 详细交互 |
|------|------|----------|
| 输入框 | 占位符「请补充要求，可按Enter换行」 | 支持多行、换行；这是教师与AI协作的主要接口 |
| **+ 按钮** | 上传/引用素材 | **双重功能**：①上传本地资料到素材库，并入本次教案生成；②从已有素材库选择内容并入本次生成 |
| 会话提示 | AI自动生成 | 对话框提供**对话式提示**，引导教师如何利用已上传/引用的素材 |
| 教师风格 | 自由输入 | 教师可添加**侧重点**等体现个人教学风格的要求 |
| 附件按钮 | 上传本地文件 | 图片/文档等 |
| AI生成按钮 | ⚡ | 配置完成后一键生成教案 |

> **完整交互流**：
> 1. 教师点击 **+** → 弹窗选择：上传本地资料 OR 浏览素材库
> 2. 资料/素材选中后，对话框出现 AI 提示：「检测到您上传了XX素材，是否需要重点展开这部分内容？」
> 3. 教师可追加侧重点：「本班学生基础较薄弱，请从基础概念讲起」
> 4. 点击 ⚡ → AI 基于：知识点配置 + 素材 + 侧重点 → 生成教案

### 2.8 操作按钮（底部）

| 按钮 | 样式 | 行为 |
|------|------|------|
| 保存为草稿 | 蓝色实心 | 保存当前配置，不生成内容，返回草稿列表 |
| 预览 | 灰色/白色 | 基于当前配置生成教案，进入预览模式（可编辑） |
| 发布 | 灰色/白色 | 预览确认后正式发布到教案发布库 |

## 三、右侧区域 — 知识图谱可视化

### 3.1 视图切换

| 视图 | 说明 |
|------|------|
| 树状 | 层级结构，适合展示知识的前置后继关系 |
| 螺旋 | 螺旋排列，适合展示知识的递进或循环关系 |
| 网状 | 网络拓扑，适合展示知识的多维关联（当前选中） |

### 3.2 维度切换（图谱着色/筛选维度）

| 维度 | 作用 |
|------|------|
| 知识点 | 按知识点分类着色/展示节点 |
| 能力 | 按核心素养能力维度着色（如思维、表达、审美） |
| 难度 | 按难度等级着色（与底部L1-L4标尺对应） |
| 课标 | 按课程标准要求着色（如必学、选学、拓展） |

### 3.3 图谱可视化

- 当前显示：网状视图，大量蓝色节点 + 少量红色节点
- 红色节点：可能是当前课时（25 挑山工）的核心知识点/锚点
- 蓝色节点：关联知识点、前置知识、后续知识
- 连线：知识之间的关联关系

### 3.4 难度标尺（L1-L4）

| 等级 | 含义 | 与图谱关联 |
|------|------|------------|
| L1 | 基础/识记 | 图谱中难度L1的节点高亮 |
| L2 | 理解/应用 | ... |
| L3 | 分析/综合 | ... |
| L4 | 评价/创造 | ... |

> 切换「难度」维度时，图谱节点按L1-L4着色，教师可直观看到当前课时覆盖的难度分布。

## 四、与之前架构的变化对比

### 4.1 新增设计（之前分析未覆盖）

| 设计 | 说明 | 影响 |
|------|------|------|
| **左表单+右图谱** 分栏布局 | 创作与可视化并排，非上下堆叠 | 教师配置时实时看到知识关联 |
| **教材封面展示** | 人教版四年级下册的教材缩略图 | 视觉确认，防误操作 |
| **单元-课时级联** | 下拉联动，从教材目录自动推导 | 减少手动输入，保证与教材一致 |
| **教案模板选择** | 核心素养模板等多套模板 | 不同教学流派/学校要求可切换 |
| **知识点图谱提取** | 从右侧图谱点选，非自由文本 | 教案与知识图谱精确绑定，后续学情分析可追踪 |
| **自定义标签** | 3个自定义标签位 | 教师个性化标记（如"公开课""重点班"） |
| **补充内容=AI提示框** | 多行文本，明确为AI指令输入 | 降低使用门槛，教师知道这里写什么 |
| **三态操作按钮** | 草稿/预览/发布 | 渐进式工作流：配置→生成→确认→发布 |
| **图谱视图切换** | 树状/螺旋/网状 | 不同认知风格教师可选不同视图 |
| **图谱维度切换** | 知识点/能力/难度/课标 | 同一知识网络，多维度着色分析 |
| **难度标尺L1-L4** | 底部可视化难度轴 | 与图谱联动，一眼看出难度覆盖 |

### 4.2 与架构宪法的契合度

| 宪法铁律 | 本页体现 | 评价 |
|----------|----------|------|
| **铁律3**：个人中心外全部上下文层 | 基本信息自动带入校区·班级·学科·教材 | ✅ 完美契合 |
| **铁律4**：小微AI运行在上下文层 | 补充内容框自动在当前坐标系下生成 | ✅ 契合 |
| **铁律4**：知识图谱锚定学科·教材版本 | 右侧图谱为人教版四下语文的知识网络 | ✅ 契合 |
| **铁律1**：系统设置是唯一配置源 | 单元/课时/教材从系统设置自动推导 | ✅ 契合 |

## 五、优劣评审

### 5.1 优势（设计亮点）

#### A. 创作与可视化并排，认知闭环
```
左：配置（输入）              右：图谱（可视化反馈）
    ↓                              ↓
 选单元/课时 → 自动              图谱自动聚焦到该课时
 提取知识点 → 点选               节点高亮，关联清晰可见
 补充要求 → AI生成              生成后可对照图谱验证覆盖度
```
教师不是「盲填表单」，而是「看着知识地图备课」——**所见即所得的认知增强**。

#### B. 知识点非自由文本，而是图谱节点提取
- 避免教师输入「比喻」但实际想讲「明喻」的歧义
- 教案与知识图谱精确绑定 → 后续学情分析、作业出题、试卷组卷全部可追踪到知识点
- 为 AI 生成教案提供**结构化输入**，而非模糊的自然语言

#### C. 三态操作按钮（草稿→预览→发布）
- 降低心理门槛：先「保存草稿」不害怕，再「预览」看看效果，满意再「发布」
- 避免误操作：发布前必须预览确认
- 支持迭代：草稿可随时回来修改，预览可反复调整

#### D. 多维度图谱着色
- 同一知识网络，教师可按需求切换视角：
  - 备课初期看「知识点」维度：确认知识覆盖完整
  - 备课中期看「能力」维度：确认核心素养培养
  - 备课后期看「难度」维度：确认分层教学设计
- L1-L4 标尺与图谱联动，直观看到难度分布是否合理

#### E. 补充内容框的明确语义
- 占位符「请补充要求」明确告诉教师：这里是**给 AI 的指令**
- 支持换行，可写多段需求
- 附件上传按钮：教师可上传参考材料、学生作业样例等
- AI 生成按钮：配置完成后一键生成

### 5.2 劣势（潜在问题）

#### A. 知识图谱右侧独占，空间利用低
- 当前图谱区域高度约占屏幕 60%，宽度占 60%
- 当教师主要关注左侧表单时，右侧大片区域成为「装饰画」
- 建议：支持**左侧面板展开/收起图谱**，或**小屏默认折叠图谱**

#### B. 知识点5个上限可能不足
- 复杂课文（如《观潮》）可能涉及修辞、写景、抒情、结构、语言等多个知识点
- 5个上限是否足够？需要验证实际教学场景
- 建议：可改为「推荐5个，最多N个」或「必选项+可选项」模式

#### C. 单元-课时级联的数据源维护成本
- 单元/课时数据需与教材版本严格同步
- 教材改版时，系统需及时更新单元/课时映射
- 建议：AI 辅助维护——从教材PDF/目录自动提取更新

#### D. 自定义标签的语义模糊
- 当前仅显示「自定义标签1」，没有预设标签库
- 教师可能不知道标签有什么用、怎么打
- 建议：提供常用标签推荐（如「公开课」「复习课」「分层教学」）

#### E. 预览与发布的状态差异不够明显
- 按钮颜色差异较小（截图中预览/发布都是灰色，仅保存为草稿是蓝色）
- 教师可能误点击「发布」而非「预览」
- 建议：发布按钮用更明显的视觉区分（如红色、二次确认弹窗）

#### F. 缺少「学情关联」入口
- 当前配置中，没有看到「关联班级学情数据」的选项
- 理论上：AI 生成教案时，应参考当前班级的历史学情（薄弱点、易错点）
- 建议：在补充内容框上方或下方，增加「参考本班学情」复选框

#### G. 难度标尺的交互性不明确
- 当前底部有L1-L4标尺，但不清楚是否支持：
  - 点击某个等级筛选图谱节点？
  - 拖拽调整课时的难度目标？
  - 与教案的难度预设联动？
- 建议：明确标尺的交互行为

### 5.3 建议优化方向

| 优先级 | 建议 | 说明 |
|--------|------|------|
| P1 | 图谱区域支持收起/展开 | 小屏或专注编辑时节省空间 |
| P1 | 发布按钮二次确认 + 视觉强化 | 防止误操作 |
| P2 | 自定义标签推荐库 | 降低教师使用门槛 |
| P2 | 学情数据关联开关 | 让AI生成教案时参考本班历史数据 |
| P2 | 知识点数量验证 | 确认5个上限是否满足实际教学需求 |
| P3 | 难度标尺交互明确化 | 点击/拖拽等行为定义 |
| P3 | 图谱节点点击联动 | 点击图谱节点→自动勾选/反选对应知识点 |
| P3 | 保存草稿自动触发 | 每次修改后自动保存，避免丢失 |

## 六、与首页架构的连贯性

### 6.1 从首页到教案编辑的流转

```
首页 → 新的创作 → 教案
  │
  → 顶部锚点：语文·四年级(1)班（自动带入）
  → 基本信息：学科/年级/校区/教材（自动带入）
  → 配置：单元/课时/模板/知识点/标签（教师填写）
  → 生成：补充内容 → AI生成 → 预览 → 发布
  → 发布后：首页统计数据+1，草稿列表更新
```

### 6.2 上下文一致性

| 上下文 | 首页 | 教案编辑 | 一致性 |
|--------|------|----------|--------|
| 校区 | 底部常驻 | 基本信息只读 | ✅ 一致 |
| 班级 | 顶部锚点 | 基本信息只读 | ✅ 一致 |
| 学科 | 顶部锚点 | 基本信息只读 | ✅ 一致 |
| 教材 | 系统设置推导 | 基本信息+封面只读 | ✅ 一致 |
| Token | 顶部栏 | 顶部栏 | ✅ 一致 |

## 七、总体评价

| 维度 | 评分 | 说明 |
|------|------|------|
| **架构契合度** | ⭐⭐⭐⭐⭐ | 完全遵循上下文层架构，与首页/知识图谱边界清晰 |
| **交互设计** | ⭐⭐⭐⭐☆ | 三态按钮、并排布局、级联联动优秀，但图谱空间利用率待优化 |
| **AI协作体验** | ⭐⭐⭐⭐⭐ | 补充内容框语义明确，AI生成按钮位置合理，渐进式工作流降低门槛 |
| **知识图谱融合** | ⭐⭐⭐⭐⭐ | 知识点从图谱提取、多维度着色、难度标尺——真正的「AI+知识图谱」备课体验 |
| **数据可追溯** | ⭐⭐⭐⭐⭐ | 教案绑定精确知识点 → 后续学情、作业、试卷全部可追踪 |

**总分：4.6/5.0** — 优秀的设计，有潜力成为产品核心竞争力。

> 主要建议：优化图谱空间利用、增强发布安全、补充学情关联。
