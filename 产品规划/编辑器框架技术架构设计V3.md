依据：`产品规划/编辑器共用框架技术方案.md`（V2 收口稿）+ `产品规划/知微教育工作台标注版.xmind`

## 1. XMIND「框架」标签覆盖图（概念层）

```
[框架标签]                                   ← 所有场景完全一致
├─ 编辑器外壳

│  │  ├─ 模板区（固定插槽）                          ← productTemplateSlot
│  │  ├─ 知识点（已选显示 + 可删）
│  │  ├─ 其他标签 / 附加关键字
│  │  ├─ 小微会话（入口+展开面板+外发光）
│  │  └─ 保存区：自动保存 / 存草稿 / 预览 / 发布
│  ├─ 右栏：AI模式=知识图谱画布 / 文档模式=产品编辑器
│  └─ 底栏：生命周期 footer（统一渲染，不各自画底栏）
├─ 模式切换
│  ├─ AI 模式 ↔ 文档模式（左栏不变，仅右栏换）
│  └─ 内容态桥接（AI生成→写入文档模式 & 预后编辑）
├─ 预览 → 全屏预览承载层（不可编辑；框架统一接管）
│  └─ 文字类=锁定只读版式 ; PPT=放映态 ; H5=运行态
├─ 保存
│  ├─ 自动保存（混合 C：debounce 8s + 失焦/离开 flush）
│  ├─ 草稿（前端 UI 态，后端存量位）
│  └─ 发布
└─ 右侧面板（批注 / 版本历史）—— 框架通用容器，产品注入内容
```

## 3. 重新设计的 EditorLayout Props 接口（收口后）

```tsx
interface EditorLayoutProps {
  // ── 模式 ──
  mode: 'ai' | 'doc'
  onModeChange: (mode: 'ai' | 'doc') => void

  // ── 信息栏（框架渲染通用字段 + 产品插槽） ──
  productTemplateSlot?: ReactNode   // 模板区（教案模板/试卷版式/PPT风格/无）
  productExtraSlot?: ReactNode      // 额外插槽（关联课件/题单间隔等）
  hiddenFields?: string[]           // 隐藏通用字段（如"题单"场景不显示班级？）

  // ── 右栏主编辑器 ──   ← 原来分离的 primaryRight / secondaryRight 合并
  aiRightPanel?: ReactNode          // 知识图谱画布（所有场景一样）
  docRightPanel?: ReactNode         // 产品特定编辑器（教案=TipTapEditor / 出题=题单流 / 组卷=多栏 / PPT=画布）

  // ── 全屏预览（框架统一接管） ──
  previewSlot: ReactNode            // 预览内容（文字类=锁定版式 / PPT=放映态 / H5=运行态）
  previewTitle: string

  // ── 生命周期 footer（框架统一渲染） ──
  saveDraftLabel: string
  publishLabel: string
  onSaveDraft: () => void
  onPublish: () => void
  status?: EditorStatus
  saving?: boolean

  // ── 右侧批注/版本面板 ──
  annotationSlot?: ReactNode        // 批注面板内容（产品注入）
  historySlot?: ReactNode           // 版本面板内容（产品注入）

  // ── 导出（在工具栏上渲染） ──
  exportActions?: ReactNode         // Word/PDF 等导出按钮（文案框架统一，回调产品提供）

  // ── 场景元数据 ──
  sceneName: string                 // "教案"/"习题"/"试卷""题单"
}
```

去掉的旧 prop：`primaryLeft` / `secondaryLeft` / `primaryRight` / `secondaryRight` / `modeLabels` / `subtitle` / `leftCollapsible` / `leftCollapsed` / `onToggleLeft` / `footerLeft` / `footerRight` / `footerExtra` / `hidePreviewBtn` / `onPreview` / `footerAlign` —— 全部由框架内部统一处理或不再需要。

## 4. 产品层（page）变化

| 项 | 教案 | 出题 | 试卷 | 题单 |
|---|---|---|---|---|
| `productTemplateSlot` | 教案模板选择器 | 无 | 试卷版式选择器 | 无 |
| `hiddenFields` | 无 | 无 | 无 | 隐藏"班级"（题单是个人练习？待确认） |
| `docRightPanel` | TipTapEditor（A4） | 题单流式（A4 + 分割间隔 + 可编辑） | 多栏编辑（虚线所见即所得） | 同出题（内部视图） |
| `previewSlot` | 锁定版式 A4 | 锁定版式 A4 | 组卷四版式全屏 | 锁定版式题纸 |
| `exportActions` | Word/PDF | 无导出（单题无载体） | Word/PDF | 题纸 Word/PDF |
| `saveDraftLabel` | "保存为草稿" | "保存到题库" | "保存为草稿" | "保存为草稿" |

**所有场景共用的东西从 page 移到框架**：
- `modeLabels=['AI 模式', '文档模式']` — 框架内置，page 不再传
- 左栏通用字段渲染 — 框架内置
- 预览按钮/全屏按钮 — 框架内置（不再需要每个页面的 toolbarExtra 手写）
- 小微入口 — 框架内置
