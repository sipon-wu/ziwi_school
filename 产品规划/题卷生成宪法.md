# 题卷生成宪法

> 以"还原真实答卷纸"为最高准则，AI 生成的所有题卷必须仿照真实考卷/练习册的排版与交互。

---

## 第一条 · 通用排版宪法

### 1.1 页面尺寸
- 尺寸：A4（210mm × 297mm）
- 边距：上下 `1.2cm`，左右 `1.5cm`
- 必须在 CSS 中声明 `@page { size: A4; margin: 1.2cm 1.5cm; }`

### 1.2 字体体系
```css
font-family: "SimSun", "STKaiti", "KaiTi", "楷体", serif;
font-size: 15px;
line-height: 1.9;
color: #222;
max-width: 740px;
```
- 正文 **必须使用衬线/楷体**，符合中文试卷传统
- 低年级可在关键词旁注拼音（字号 10px，灰色 `#888`）

### 1.3 标题层级
```
书名 → 大标题 → 副标题 → 题号 + 题名
```
- 书名：`13px`，居中，灰色
- 大标题：`22px`，居中，加粗，字距 `4px`
- 副标题：`13px`，居中（如"不会写的字可以用拼音代替"）
- 题号：`16px`，加粗（如"一、"）

### 1.4 打印规范
```css
@media print {
    .no-print { display: none !important; }
    body { padding: 0; }
}
```
- 打印按钮必须添加 `.no-print` 类
- 所有颜色仅限 **黑、白、灰**
- 图片必须为黑白线稿风格（见第二条）

### 1.5 分页
- 使用 `page-break-after: always` 控制分页
- 每个大题尽量在同一页内

## 第二条 · 插图宪法

### 2.1 风格锁定（"放风筝"标准）
| 特性 | 规范 |
|------|------|
| 色彩 | 纯黑白，无彩色 |
| 线条 | 粗细变化的钢笔/墨水笔触，轮廓清晰 |
| 阴影 | 黑色实心底色 + 细腻排线（hatching） |
| 人物 | 圆脸卡通风格，五官简洁，表情温馨 |
| 背景 | 场景简洁，主体突出，大面积留白 |
| 打印 | 高对比度，适合黑白印刷 |

### 2.2 插图用途分类
| 用途 | 尺寸建议 | 风格要求 |
|------|---------|---------|
| 看图说话主图 | 占版宽 38% | 必须遵循 2.1 标准 |
| 数学几何图 | SVG 矢量 | 线条精确，标注清晰 |
| 化学实验图 | SVG 矢量 | 器材比例正确 |

### 2.3 无水印守则
- AI 生成的插图**不得带有** "AI生成" 水印
- 若生成结果带水印，必须重新生成或裁剪去除
- 备选方案：SVG 纯矢量绘制（零水印风险）

## 第三条 · 数学试卷宪法

### 3.1 公式渲染：KaTeX
**绝对禁止** 使用 `renderMathInElement` 自动分隔符模式。

**唯一允许方式** —— 手动逐元素渲染：
```javascript
document.querySelectorAll('.math').forEach(el => {
    katex.render(el.textContent, el, { throwOnError: false });
});
```
- 每个公式包裹在 `<span class="math">...</span>` 中
- LaTeX 语法：`\frac{}{}`、`\sqrt{}`、`\angle`、`\triangle`、`\pi` 等
- 验证标准：刷新页面后 `$` 符号计数必须为 0

### 3.2 几何图形：SVG
- 圆、抛物线、立体几何必须用 **内联 SVG** 绘制
- SVG 上叠加 KaTeX 渲染的标注符号（角度、线段标记）
- 关键尺寸标签不可遗漏

### 3.3 化学式排版
- 必须使用 HTML `<sub>` 标签，不用 LaTeX
- 例：H<sub>2</sub>O、CO<sub>2</sub>、Na<sub>2</sub>CO<sub>3</sub>
- 化学方程式可混用：中文 + `<sub>` 下标 + KaTeX 复杂公式

### 3.4 题型结构（参照南通卷）
```
一、填空题（每题 X 分，共 X 分）
二、判断题
三、选择题
四、计算题
五、应用题/解答题
```
- 每题标注分值
- 卷首注明总分和考试时间

## 第四条 · 看图说话/写话宪法

### 4.1 排版结构（参照"小学生同步专项练习本"）
**左右分栏**，不可上下堆叠：
```
┌──────────────┬──────────────────────────────┐
│              │  ① 看一看，说一说，填一填      │
│   插图       │  kàn yi kàn shuō yi shuō      │
│   (38%)     │  tián yi tián                  │
│              │  1. 图中都有谁？  ___________  │
│              │  2. 在哪里？      ___________  │
│              │  3. 在干什么？    ___________  │
│              │                               │
│              │  ② 关键词：春天 公园 放风筝    │
│              │          (含拼音)              │
│              │                               │
│              │  ③ 写一写：                    │
│              │  ──────────────────────        │
│              │  ──────────────────────        │
│              │  ──────────────────────        │
│              │  ──────────────────────        │
└──────────────┴──────────────────────────────┘
```

### 4.2 三步骤不可缺一
| 步骤 | 标题 | 内容 |
|------|------|------|
| ① | 看一看，说一说，填一填 | 3个引导问句 + 填空线 |
| ② | 关键词 | 4个中文字词 + 拼音，用下划线分隔 |
| ③ | 写一写 | 4行田字格/横线书写区 |

### 4.3 拼音标注规则
- 步骤标题下方配拼音（`font-size: 11px`，灰色）
- 关键词下方标注拼音（`font-size: 10px`，居中）
- 副标题区注明"不会写的字可以用拼音代替"

### 4.4 书写线规范
```css
.line {
    border-bottom: 1px solid #333;
    height: 26px;
    margin-bottom: 3px;
}
```

## 第五条 · 预览与验证宪法

### 5.1 本地预览
- 所有题卷必须在浏览器本地打开验证
- 检查项：公式渲染率 100%、插图无水印、打印预览正常

### 5.2 打印输出
- 提供 `🖨️ 打印 / 另存为 PDF` 按钮
- 打印样式中隐藏按钮（`.no-print`）
- PDF 另存后检查：公式不丢、图片完整、页码对齐

### 5.3 文件命名规范
```
{地区}{年级}{学科}{试卷/练习}.html
例：南通四年级数学试卷.html
例：低年级看图说话样例.html
```

## 第六条 · 交互宪法（未来实现）

当系统支持在线编辑时：

1. **教师侧**：语音或文字提出修改意见，AI 自动调整并生成预览
2. **不公开** 复杂的参数面板，降低教师使用门槛
3. 编辑历史可追溯，支持版本对比
4. 最终输出：一键导出 PDF（含打印样式）

## 第七条 · 学科扩展规则

### 英语看图写话
- 题干使用英文，关键词标注中文释义
- 书写线保留（手写体练习）
- 插图风格与语文一致（2.1 标准）

### 理化生实验题
- 化学式 → `<sub>` 标签
- 实验装置图 → SVG 矢量
- 数据表格 → `<table>` + 简洁边框

### 低年级数学
- 题目需配插图（小动物、水果计数等）
- 插图遵循 2.1 黑白线稿标准
- 字号可适当放大至 16-18px

> *所有后续题卷生成任务必须逐条遵循。*
