每道题放在独立容器里，支持宽度调节、高度自适应、可拖拽——在出题组卷场景中确实有实际价值。


下面我从可行性、设计建议、技术实现三个角度分析。


一、这个交互的价值是什么

使用场景     教师为什么需要拖拽调整

组卷排版     某道题是图文混排（如几何题带图），需要更宽的显示区域

试卷预览     调整题目展示宽度，模拟不同终端（手机/平板/电脑）的呈现效果

批量编辑     拖拽重新排列题目顺序，比“点击上移/下移”更直观

分栏排版     同一份试卷中，选择题想两栏展示减少页数，解答题需一栏展示保证可读性

打印适配     预览打印效果时微调每道题的占位宽度，使整体版式更紧凑或更疏朗

价值判断：有用，但不是核心功能。如果开发资源有限，先做“拖拽调整顺序”，宽度调节放后面。


二、交互设计建议

2.1 容器结构

每个题目容器（可命名为 .question-item）包含：

│  │  └───────────────────────────────────┘ │ │

│  │  └───────────────────────────────────┘ │ │

│  └─────────────────────────────────────────┘ │

└─────────────────────────────────────────────┘

元素说明：


元素     功能

拖拽手柄 (::)     鼠标悬停显示，点击拖拽移动题目位置

宽度调节手柄 (│)     容器右侧边或底部角落，拖拽调节宽度

序号/分值     固定显示，便于识别

删除按钮 (×)     从试卷中移除该题（非删除题库）

题目标签     显示难度、知识点等元数据

2.2 宽度调节方式

方式     操作     适用场景

右侧拖拽     鼠标悬停容器右边缘 → 光标变为双向箭头 → 拖拽     调节单题宽度

整体宽度滑块     顶部工具栏滑块，统一调整所有题目容器的宽度     批量调节

预设宽度     点击“窄/中/宽”三档快速切换     快速适配不同终端

双击重置     双击容器边缘，恢复默认宽度     快速还原

2.3 排列方式

排列模式     说明

流式排列（默认）     容器从左到右排列，宽度不足自动换行

列表排列     每个容器占满一行，上下排列

自由排列（高级）     容器可拖拽到页面任意位置，需要“网格吸附”或“对齐线”辅助

分栏排列     选择题两栏、解答题一栏的混合排版

建议：前期只做“流式排列 + 列表排列”，自由排列后期再做。


三、技术实现方案

3.1 技术选型

技术     用途

Vue 3 + 组合式 API     容器组件驱动

Grid 或 Flexbox     容器排列布局

拖拽库     vuedraggable 或 @dnd-kit/sortable（支持触摸事件）

ResizeObserver     监听容器尺寸变化，自动调整内部内容布局

CSS resize 属性     原生可拖拽调整大小（简单方案）

CSS 变量     容器宽度由父组件统一控制

3.2 示例代码：Vue 3 组件

父组件：试卷编辑器


vue

<template>

  <div class="paper-editor">

    <!-- 工具栏 -->

    <div class="toolbar">

      <button @click="setWidth('narrow')">窄</button>

      <button @click="setWidth('medium')">中</button>

      <button @click="setWidth('wide')">宽</button>

      <span>当前列数：{{ columns }}</span>

    </div>


    <!-- 题目容器（使用 Grid 布局） -->

    <div class="question-grid" :style="gridStyle">

      <QuestionItem

        v-for="(q, index) in questions"

        :key="q.id"

        :question="q"

        :index="index"

        :width="itemWidth"

        @delete="removeQuestion(index)"

        @move="moveQuestion"

      />

    </div>

  </div>

</template>


<script setup>

import { ref, computed } from 'vue'

import QuestionItem from './QuestionItem.vue'


const questions = ref([

  { id: 1, type: 'choice', content: '...', options: [...] },

  { id: 2, type: 'fill', content: '...' },

  // ...

])


// 宽度控制

const widthMode = ref('medium') // 'narrow' | 'medium' | 'wide'

const itemWidthMap = {

  narrow: '200px',

  medium: '300px',

  wide: '100%'

}

const itemWidth = computed(() => itemWidthMap[widthMode.value])


// 计算列数

const columns = computed(() => {

  if (widthMode.value === 'wide') return 1

  if (widthMode.value === 'medium') return 2

  return 3

})


const gridStyle = computed(() => ({

  gridTemplateColumns: `repeat(auto-fill, minmax(${itemWidth.value}, 1fr))`

}))


// 删除题目

const removeQuestion = (index) => {

  questions.value.splice(index, 1)

}


// 移动题目（drag & drop 回调）

const moveQuestion = (from, to) => {

  const [removed] = questions.value.splice(from, 1)

  questions.value.splice(to, 0, removed)

}


const setWidth = (mode) => {

  widthMode.value = mode

}

</script>

3.3 移动端支持

触屏拖拽：提供长按拖拽，或显示“移动”按钮，点击后出现上下箭头


宽度调节：不支持手指拖拽调节宽度，改为下拉选择“窄/中/宽”三档


四、推荐方案

功能     推荐实现     理由

拖拽排序     VueDraggable 或 @dnd-kit/sortable     成熟方案，支持触屏

宽度调节     顶部预设宽度 + 右侧边缘拖拽     满足90%场景，开发成本低

排列布局     Grid + auto-fill     自动换行，无需计算位置

高度自适应     自然撑开，不加固定高度     避免内容溢出

触屏适配     长按拖拽     移动端标准交互

五、功能边界建议

需要做     不需要做（一期）

拖拽调整题目顺序     自由放置（任意坐标拖拽）

预设宽度切换（窄/中/宽）     每个容器独立像素级宽度调节

Grid自动换行排列     多栏混合排版（选择题两栏、解答题一栏）

高度自适应     容器最小/最大高度限制

容器边框+阴影（视觉区分）     容器内嵌套容器

移动端长按拖拽     触屏双指缩放容器
