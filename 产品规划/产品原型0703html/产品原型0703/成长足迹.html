【模块】成长足迹

【版本】v1.0

【最后更新】2026-07-02



第1部分：模块定位


1.1 一句话定义

一个面向全班学生的成长记录档案模块，自动归集每个学生的作业记录、考试成绩、错题归集和教师评语，形成可查看、可追溯的成长时间线。


1.2 模块归属

路径：教学数据 → 成长足迹


1.3 设计原则

原则              说明

─────────────────────────────────────────────────────

全班覆盖          全班学生均有成长档案，无需教师手动开通

自动归集          作业、成绩、错题等数据自动落入档案

叙事型呈现        按时间线展示，而非冷冰冰的表格

教师可补充        教师可在时间线上添加评语、观察记录

家长可查看        家长端可查看自己孩子的成长档案（只读）


1.4 与成长关爱的关系

成长足迹          成长关爱

─────────────────────────────────────────────────────

范围：全班学生     范围：被教师勾选的学生

定位：记录与查看   定位：个性化干预

行为：被动归集     行为：主动推送

输出：成长档案     输出：个性化方案 + 练习



第2部分：数据来源


成长足迹的数据自动来自以下来源：


数据来源          说明                    更新时机

─────────────────────────────────────────────────────

作业记录          每次作业的得分、完成状态   批阅完成后

考试成绩          教师上传的单元/期中/期末   上传完成后

错题归集          作业和考试中的错题         批阅完成后

教师评语          教师在批阅时留下的评语     批阅完成后

课堂表现（可选）   教师手动添加的观察记录     教师主动录入


2.1 成绩数据录入（学情分析模块提供）

教师在学情分析模块中通过上传入口录入单元测试、期中、期末等考试成绩，

成绩数据自动落入对应学生的成长档案中。



第3部分：页面功能


3.1 入口与列表页

路径：教学数据 → 成长足迹


页面顶部展示班级整体统计卡片：

- 全班人数

- 本学期人均作业数

- 班级平均正确率

- 进步学生数 / 退步学生数


列表展示全班学生：

- 学生姓名

- 本学期作业平均正确率

- 本学期成绩趋势（上升/平稳/下降）

- 薄弱知识点数量

- 操作：查看详情


3.2 单个学生成长档案

点击学生行进入该生成长档案。


3.2.1 顶部概览卡片

- 学生姓名、班级

- 本学期作业数、平均正确率

- 最近一次考试成绩

- 与上学期末对比（进步/退步/持平）


3.2.2 成长时间线

按周/月展示该生的成长轨迹，每条记录包含：


记录类型        展示内容

─────────────────────────────────────────────────────

作业记录        作业名称、得分、班级平均分对比

考试成绩        考试名称、得分、班级平均分对比

错题归集        错题知识点、正确率趋势

教师评语        评语内容、时间

教师观察记录    教师手动添加的观察记录


3.2.3 知识点掌握度（可视化）

展示该生各知识点的掌握度雷达图或条形图：

- 绿色：掌握良好（≥80%）

- 黄色：建议巩固（60%-79%）

- 橙色：重点突破（<60%）


3.2.4 学期对比

展示本学期与上学期各维度对比：

- 平均正确率变化

- 各知识点掌握度变化

- 作业完成率变化


3.3 教师端操作

教师在学生成长档案中可执行以下操作：


操作              说明

─────────────────────────────────────────────────────

添加观察记录      手动录入文字观察记录，出现在时间线上

添加评语          针对该生某阶段表现添加评语

查看错题本        跳转至该生错题本详情

查看完整成绩单    跳转至该生成绩单视图

勾选进入成长关爱  将该生标记为“需要个性化关注”，进入成长关爱模块



第4部分：家长端


4.1 入口

家长登录小程序后，在“孩子”页面或“成长”Tab中查看。


4.2 家长端展示内容

- 孩子本学期作业完成情况

- 孩子各知识点掌握度

- 孩子成绩趋势

- 教师评语

- 错题记录（可查看原题和正确答案）

- 教师添加的观察记录


4.3 权限说明

- 只读，不可编辑

- 仅显示自己孩子的数据

- 不显示班级排名或其他学生数据



第5部分：数据更新与通知


5.1 实时更新

- 作业批阅完成后，该生档案立即更新

- 成绩上传后，该生档案立即更新


5.2 家长通知

- 学生档案发生重要更新时（如成绩录入、教师添加评语），家长端收到提醒

- 提醒频率：不高于每天1次



第6部分：关键数据指标


指标              说明                    目标值

─────────────────────────────────────────────────────

档案覆盖率        全班学生均有成长档案       100%

家长查看率        家长查看孩子档案的比例     ≥60%

教师补充率        教师在档案中添加评语/观察   ≥30%
