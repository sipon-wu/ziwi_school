## 一、模板的作用域（现状）

「模板」在系统里承担两件事，**必须分开看**，混在一起是早期口径混乱的主因：

| 层 | 载体 | 存什么 | 换它会怎样 |
|---|---|---|---|
| **A · 风格/骨架层** | `theme_id`（素材库字段）| 版式骨架 + 配色 DNA（`color_root`）| 重排页面结构，**内容不变**；可撤销 |
| **B · 装饰资产层** | 装饰槽位（页内 `decor`）| 真实图片元件：底图 / 四角 / 浮动 / 页眉页脚 | 只换贴花，不动结构 |

**源数据 = 提纲（`material.content` 的 markdown）+ 模板引用（`theme_id`）**，渲染随时由模板重算 ——
这是 `PPT内容与模板分离技术方案.md` 定下的原则，也是"套模板不动内容"的实现基础。

## 二、模板清单与族（现状）

- PPT 侧：`PPT_TEMPLATES`；H5 侧：`H5_TEMPLATES`；通用结构：`basicTemplateForFamily(family)`
  - id 形如 `basic-<family>-<kind>`（如 `basic-blue-ppt`）
  - ⚠ 注意：**勾选高亮必须与该 id 一致**（2026-09-17 修过一次 `basic-${f.id}` 永不相等导致的"套用后不高亮"）
- 聚类维度：风格标签（`STYLE_LABELS`）+ 色系（`COLOR_FAMILIES`）
- 缩略图：`renderTemplateThumb` / `renderFamilyThumb`（画布与缩略图**必须同源**）

## 三、换肤的两条入口（现状）

1. **左栏模板库面板** → 套用 / 撤销套用
2. **小微指令 `zhiwei:switch-style`** → 轻档（只换配色/HTML）与重档（重排几何）

两条入口**共用一份状态与"上次套用前"的存档**（`useCwTemplate`：`tplAppliedId` / `tplPrev{Theme,Layouts,Elements}`）。
⚠ 约束：重档会改元素几何 → 撤销时必须连 `prevElements` 一起回退，只回退 layout 撤不掉位置变化。

## 四、装饰槽位（现状 · 已统一）

`DecorSlots = { header[] · footer[] · corners[] · background(string) · floating[] }`

| 端 | 渲染 | 备注 |
|---|---|---|
| PPT | `DecorLayer` | 背景层 `opacity 0.18`，**封面另加 `blur(16px)` + `scale(1.08)`**（衬底策略）|
| H5 | `.cover-underlay` + `.cover-deco` | 与 PPT 同值；层级：衬底 0 < 元素 1 < 内容 2 |

**落盘约定（2026-09-17 起）**：
- 内容页装饰 → 页内 `<!-- CW-DECOR:base64 -->`
- 封面装饰 → 文档前沿 `<!-- CW-COVER:base64 -->`（封面不在 outline 内）
- 空值一律不写 → 旧文档 markdown 逐字节不变

## 五、缺口 / 待决

1. ⚠ **素材面板是否按 `page_type=cover` 筛**（现为全库可选）—— 需产品定
2. ⚠ **模板与封面的关系**：封面当前是**渲染时合成**（不吃 outline），换模板时封面只跟随 theme 变化；
   是否需要"模板自带封面样式"的显式设定，待定
3. ⚠ **计价/资产域**：模板是否进入 `模板资产域架构与计价抽象层.md` 的计价范围，未决
4. **导出件保真**：画布衬底依赖 CSS（透明度/模糊），`.pptx` 导出件（pptxgenjs）**不支持 CSS 滤镜**，
   需实测确认观感差异 —— 列为待验
