# 教师（teacher）— 交互流程图

> 角色：教师 | 来源：产品规格 0703-v6 §1.2 + §3-§6
> 版本：v1.0 | 日期：2026-07-04 | 作者：品姐

---

## 角色概述

教师是平台的核心用户，使用全部教学功能。登录后默认进入首页Dashboard，侧边栏包含五大模块：备课/作业/数据/家校/个人。运行在「校区·班级·学科·教材版本」坐标系内。

---

## 1. 系统设置 — 初始配置流程

```
[教师登录] 
  → [系统设置]（个人中心入口）
    → 1. 学校与班级管理
        → 搜索并认领学校/校区
        → 认领班级（如四(1)班）
        → 认领学科（如语文）
        → 绑定教材版本（如部编版→四年级下册）
        → [保存] → 班级锚点生效，全平台上下文更新
          ⚠️ 异常：搜索不到学校 → 提示联系学校管理员创建
          ⚠️ 异常：自编版本不存在 → 点击"申请新增"→上传PDF→AI自动提取→立即可用
    → 2. 小微风格训练（可选）
        → 上传教案Word/PDF（三类素材之一）
        → 小微引导式对话（渐进式推进）
        → 训练完成 → 查看风格摘要 → [确认] 或 [修改不准确的特征]
          ⚠️ 异常：训练中断 → 小程序端可继续（跨端支持）
          ⚠️ 异常：风格置信度不足 → 继续补充素材
    → 3. 个人信息
        → 查看/修改：姓名/头像/手机号（月限1次）/邮箱/微信绑定
    → 4. 权限与共享
        → 教案互审开关（默认关闭）
        → 自动审核勾选（默认不勾选）
        → 素材库共享开关（默认关闭）
```

## 2. 教案 — 核心备课流程

```
[首页] → [新的创作] → [教案]
  OR [教学备课] → [教案草稿箱] → [+ 新建教案]

  → [教案工作台（新建）]
    ├── 基本信息区（只读，自动带入）
    │   学科/年级班级/校区/教材封面（来自系统设置）
    ├── 表单配置区
    │   标题输入（必填，0/12字）
    │   单元-课时级联选择（根据教材版本自动列出）
    │   教案模板选择（空白/标准/探究式/项目式/翻转课堂/复习课/习题课/校本模板）
    │   知识点选择（从知识图谱点选，必选1-5个）
    │   自定义标签（最多3个）
    │   补充内容框（文本输入）+ 素材选入（+按钮）
    ├── 知识图谱区（左侧面板）
    │   树状/螺旋/网状三模式
    │   维度切换（知识点/能力/难度/课标）
    │   默认聚焦当前课时（5-8节点，3秒引导提示自动消失）
    └── 操作按钮三态
        ├── [保存为草稿] → 保存到草稿箱，不生成内容
        ├── [预览] → 新标签页打开预览（可编辑调整）
        └── [发布]
            ├── 互审关闭 或 自动审核勾选 → 直接发布到教案发布库
            └── 互审开启 → [提交送审] → 进入互审流程
              ⚠️ 异常：无人审核 → 教研组长分配审核人

  → [教案草稿箱]
    ├── 单击草稿 → 新标签页打开工作台，恢复上次编辑状态
    ├── 批量送审：勾选多个草稿 → 一键提交送审（需开启互审模式）
    └── 操作：编辑/删除/复制/发布

  → [教案发布库]
    ├── 查看已发布教案列表（标题/适用信息/发布时间/状态/引用统计）
    ├── 教案详情页（完整教案内容+课件使用脚本+知识图谱锚点高亮）
    └── 操作：查看详情/引用/复制

  → [教案互审 — 教师视角]
    ├── 我的送审列表 → 查看审核进度和判定结果
    ├── 被退回列表 → 点击唤起教案工作台，加载原稿进入编辑
    └── 待我审核列表（作为审核人时）
        → 查看教案详情 → 在线批注 → [通过]/[退回修改（附退回理由）]
```

## 3. 出题·题库 — 作业准备流程

```
[首页] → [新的创作] → [出题]
  OR [作业练习] → [出题·题库]

  → [题库浏览页]
    ├── 筛选：按知识点/难度/题型/来源
    ├── 排序：按使用次数/创建时间
    └── [新建题目] → [题目编辑页]
        ├── 八要素表单
        │   题干（必填）/答案（必填）/解析/题型（必选）/分值/知识点(图谱点选，必选1+)/难度(L1-L4)/区分度(选填)/来源
        ├── 知识图谱联动
        │   图谱点选知识点→自动填入
        │   图谱标记已出题数+薄弱度
        │   未覆盖知识点灰色标记
        └── [保存] → 存入题库
          ⚠️ 异常：重复题目 → 提示"该题目已存在"
  → [批量导入] → 上传CSV → 解析导入
```

## 4. 组卷·试卷库 — 考试准备流程

```
[首页] → [新的创作] → [组卷]
  OR [作业练习] → [组卷·试卷库]

  → [试卷编辑器]
    ├── 试卷信息：标题/满分/考试时间
    ├── 知识图谱联动（左侧面板）
    │   难度分布可视化（L1-L4着色）
    │   知识点覆盖率（实心=已覆盖/空心=未覆盖，显示百分比）
    │   题目↔图谱双向联动定位
    │   空白知识点闪烁提醒补题
    ├── 题目容器（拖拽排序/宽度调节/分栏排版）
    │   流式排列（默认）/列表排列
    │   双击重置宽度
    │   移除题目（不删除题库）
    ├── [+ 添加题目] 
    │   ├── 从题库手动勾选
    │   └── [AI智能组卷] → 小微根据条件自动选题
    ├── [试卷质量评估] → 知识点覆盖率/难度分布/题型分布/预估平均分/课标对齐度
    ├── [预览] → [发布到试卷库]
    └── ⚠️ 异常：AI组卷Token不足 → 提示充值
```

## 5. 作业布置 — 日常教学流程

```
[作业练习] → [作业布置]

  → [布置作业]
    ├── 选择班级和学科（自动带入当前上下文）
    ├── 选择作业模板（或新建）
    ├── 选题：手动勾选题库 / AI智能组卷 / 上传自定义内容
    ├── 设置时间：相对时间（发送后48小时截止）/ 绝对时间
    └── [发送] → 作业发布
      ⚠️ 异常：未选题目 → 提示"请至少选择一道题目"

  → [作业批阅工作台]（三栏布局）
    ├── 左栏：学生列表（姓名/提交时间/批改状态）
    ├── 中栏：批阅内容区
    │   ├── AI批改结果（客观题自动批改，主观题预打分）
    │   ├── 低置信度红色标记（<85%）
    │   ├── 教师修改入口（双字段：AI预评分/教师确认分）
    │   └── 键盘快捷键：←→切换学生，Enter确认，Tab切换题目
    ├── 右栏：小微AI助手（查询学情/操作批阅/对话互动）
    ├── 批量操作：全选→一键标记"已阅"/退回低置信度/批量发送催交
    └── 进度条：顶部显示批改进度（18/42）

  → 错题归集（批改完成后自动触发）
    ├── 按知识点归类错题
    └── 生成家长报告（综述版+详细版）

  → [催办] → 系统发送红点提醒至家长小程序端
```

## 6. 学情分析 — 数据洞察流程

```
[教学数据] → [学情分析]

  → [七卡片仪表盘]（一屏展示，三行排列，默认当前上下文）
    ├── 第一行：作业完成率 | 平均正确率 | 待批阅/待订正
    ├── 第二行：知识点掌握度 | 正确率趋势
    ├── 第三行：共性问题TOP3 | 标签速览
    └── 每卡片旁 [问小微] 入口 → 补充说明/归因分析
      ⚠️ 异常：无数据 → 显示"暂无教学数据，开始布置作业后自动生成"
```

## 7. 成长足迹 — 学生档案流程

```
[教学数据] → [成长足迹]

  → [班级学生列表] → [进入学生详情页]

    ├── 观察记录（教师添加：描述具体行为或表现）
```

## 8. 家校沟通 — 协同流程

```
[家校沟通]

  → [家长签字]
    ├── 作业批阅完成 → 推送确认请求到家长端
    ├── 查看签字统计：已签/未签人数
    ├── [催办] → 红点提醒至家长小程序
    └── 次数追溯：按月/学期统计漏签次数
      ⚠️ 未签字无系统级后果（自愿原则）

  → [成长关爱]
    ├── 在成长足迹中勾选学生 → [纳入成长关爱]
    │   → 确认框：展示当前学情概览
    │   → 小微自动标记该生学情数据波动
    │   → 向家长发送入组诊断书
    ├── 每周方案审阅
    │   ├── 小微评估（基于数据）+ 教师观察（基于经验）
    │   ├── 方案草案：本周聚焦/练习安排/学习任务/教师建议
    │   └── 操作：[确认]/[修改]/[补充观察]/[退回重生成]
    ├── 教育善意度审查（提交前自动触发）
    │   ⚠️ 严禁比较性表述/绝对化判断
    │   ⚠️ 必须配合建设性建议
    └── 续期管理：每学期末发起下学期入组确认
```

## 9. 素材库 — 资源管理流程

```
[教学备课] → [素材库]

  → [素材列表页]
    ├── 多形态管理：图片/文档/音频/视频/组件
    ├── AI自动标签：学科/年级/场景/关键词/风格
    ├── 版本管理：保留历史版本，可回溯
    ├── 分组管理：自定义文件夹
    ├── 5级热度：根据引用次数自动评分（冷/温/热/火/爆）
    └── 共享权限：默认仅本人 → 开启后本校同级同科共享（可跨年级，不可跨学科）

  → [上传素材]
    ├── 选择文件 → AI自动打标签 → 存入素材库
    ├── [版权确认弹窗] → 原创/转载/公共领域三选一
    │   ⚠️ 转载需注明来源
    └── 教案/试卷/作业中引用（不重复上传）
```

## 10. 小微AI — 对话交互流程

```
[底部黑色按钮] → [右侧滑出侧边面板]

  → 小微上下文自动注入
    {校区, 班级, 学科, 教材版本, 当前页面, 知识图谱锚点, 教师风格}

  → 教师输入自然语言指令
    ├── "帮我生成《观潮》第一课时教案" → AI生成教案（SSE流式推送）
    ├── "为正确率低于70%的知识点各出2道选择题" → AI出题
    ├── "分析四(1)班本周作业正确率波动原因" → AI学情分析
    └── 生成完成后展示AI生成依据（可解释性）

  → 非工作会话防护
    ├── 第1次："我是教学助手小微，专注于帮您备课..."
    ├── 第2次："小微目前只能协助教学工作哦～"
    └── 第3次：⚠️ 警示提醒 + 上报统计（按周重置）

  → 面板关闭 = 暂停会话（保留状态）
  → 手动点击"新会话" = 清除历史

  → [会话历史检索]
    ├── 全文检索（默认近3个月）
    ├── 按月分表，每次展示20条
    └── 点击任务单元 → 展开完整对话记录
```

## 加载态

| 场景 | 加载态表现 | 降级方案 |
|------|----------|---------|
| 知识图谱加载 | 骨架屏占位 | 加载失败→降级为全宽表单模式（规格§10.2） |
| 教案列表加载 | 骨架屏（3行占位） | 加载失败→错误态+重试 |
| 题库列表加载 | 骨架屏（表格占位） | 加载失败→错误态+重试 |
| 学情看板加载 | 卡片骨架屏 | 加载失败→错误态+重试 |
| AI生成中（SSE流式） | 逐段渲染 + 进度指示 | 超时→提示重试 + Token不消耗 |
| 素材库加载 | 网格骨架屏 | 加载失败→错误态+重试 |
| 作业批阅列表加载 | 学生列表骨架屏 | 加载失败→错误态+重试 |

## 必填项校验

| 操作 | 必填项 | 校验规则 |
|------|--------|---------|
| 新建教案 | 标题 | 必填，≤12字 |
| 新建教案 | 知识点 | 至少选1个，最多5个 |
| 新建教案 | 单元+课时 | 必选（级联选择） |
| 新建题目 | 题干 | 必填 |
| 新建题目 | 答案 | 必填 |
| 新建题目 | 题型 | 必选 |
| 新建题目 | 知识点 | 至少选1个（从图谱点选） |
| 新建试卷 | 标题 | 必填 |
| 新建试卷 | 题目列表 | 至少1道题 |
| 布置作业 | 班级+学科 | 必选（自动带入上下文） |
| 布置作业 | 题目列表 | 至少1道题 |
| 系统设置 | 班级认领 | 必选（至少1个班级+学科+教材版本） |
| 上传素材 | 文件 | 必选，≤50MB |

## 异常路径汇总

| 场景 | 异常 | 处理 |
|------|------|------|
| 班级切换 | 有未保存工作 | 弹确认框"当前有未保存内容，确定切换？" |
| 路由跳转 | 草稿编辑中 | 自动保存草稿 + Toast"草稿已自动保存" |
| 浏览器关闭 | — | 浏览器原生 beforeunload 确认框 |
| 会话超时 | 到期前5分钟 | 倒计时提醒 + 自动保存草稿 |
| 多标签页编辑 | 版本冲突 | 弹窗"另一标签页已修改，是否覆盖？" |
| Token不足 | 生成内容时 | "Token已用完"提示 + 引导充值。阻断AI生成操作（教案生成/出题组卷/小微对话/AI批阅/风格训练），查看/下载已有内容不受影响 |
| License过期 | 新建操作 | 禁止新建（教案/题目/试卷/作业/素材上传/小微对话），已发布内容只读可访问 |
| 自编版本不存在 | 教材版本下拉 | "未找到版本？申请新增" → AI提取→自动审核 |
| 必填项缺失 | 点击保存/生成 | 红色边框标记缺失字段 + Toast提示具体缺失项 |
| AI生成超时 | SSE流中断 | 提示"生成超时，请重试" + Token不消耗 |
| 知识图谱加载失败 | 图谱区 | 降级为全宽表单模式 + 提示"图谱加载失败，可继续编辑" |
