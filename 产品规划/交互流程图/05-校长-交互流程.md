# 校长（principal）— 交互流程图

> 角色：校长 | 来源：产品规格 0703-v6 §1.2
> 版本：v1.0 | 日期：2026-07-04 | 作者：品姐

---

## 角色概述

校长独立登录，拥有全校数据总览仪表盘。侧边栏包含：数据总览/教学质量/教师发展/学期对比/Token用量/操作审计。全局视角，无需班级锚点。所有数据为只读，不可编辑。

---

## 核心用户旅程

```
[校长登录] → [数据总览 Dashboard]

  → [KPI大数字卡片]
    在校教师(68) / 教学班级(24) / 本月教案数(48) / 题库总量(1,286) / Token使用率(64%)
    └── 每卡片含环比/同比变化

  → [图表区第一行]
    ├── 教案通过率与课标对齐率趋势（近6月折线图）
    │   ⚠️ 异常：某月骤降 → 点击下钻到学科/年级
    └── 各学科教学质量对比（语文9.2/数学8.5/英语8.0/科学7.5/道法7.0）
        ├── 教案数/通过率/评分
        └── 条形图可视化

  → [图表区第二行]
    ├── 各年级教学活跃度（柱状图：教案数+出题数）
    │   四年级最活跃 → 可下钻到具体班级
    └── AI使用统计
        ├── 饼图：教案生成45%/出题组卷30%/学情分析15%/小微对话10%
        └── 无效算力消耗 TOP5（仅排名占比，不展示对话内容）
            ⚠️ 隐私保护：仅呈现统计数据，不公开具体对话内容

  → [关注事项告警区]
    ├── 科学学科课标对齐率偏低（75%）→ 建议教研组长关注
    ├── Token月度消耗接近预警线（64%）→ 建议提前规划配额
    ├── 教师请假/代课交接提醒
    └── 期末数据归档提醒

  → [教师教学贡献排行 Top 7]
    排名/教师/学科/教案数/出题数
    └── 可查看教师详细数据（不可编辑）

  → [教学质量]（侧边栏子页）
    ├── 各学科教案质量趋势
    ├── 各年级成绩分布对比
    └── 课标对齐率全校总览

  → [教师发展]（侧边栏子页）
    ├── 教师活跃度趋势
    ├── 教研活动参与统计
    └── 教师成长档案

  → [学期对比]（侧边栏子页）
    ├── 本学期 vs 上学期数据对比
    └── 同比/环比变化分析

  → [Token用量]（侧边栏子页）
    ├── 全校Token消耗趋势
    ├── 各学科Token使用分布
    └── 无效算力消耗统计（仅统计，不展示内容）

  → [操作审计]（侧边栏子页）
    ├── 查看全校操作审计日志（只读）
    └── 筛选：按操作类型/时间/用户
```

---

## 权限边界

| 操作 | 校长 |
|------|:--:|
| 查看全校数据 | ✅ |
| 下钻查看详情 | ✅ |
| 导出报表 | ✅ |
| 编辑任何数据 | ❌ |
| 创建教案/出题 | ❌ |
| 管理用户/权限 | ❌ |
| Token/License管理 | ❌ |

---

## 异常路径

| 场景 | 处理 |
|------|------|
| 学校数据为空（新学校） | 空态："暂无教学数据，教师开始使用后自动生成" |
| 数据加载失败 | 错误态：显示重试按钮 |
| 下钻数据无权限 | 校长只能查看本校数据，跨校提示无权限 |
