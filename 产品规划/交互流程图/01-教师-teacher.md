## 一、角色进入首页完整路径

```
[未登录]
  → 访问 school.ziwi.cn
  → 登录页：手机号 + 密码 → [登录]
  → 首次登录？ → 是 → 系统设置引导（选择学校/校区 → 认领班级 → 绑定学科 → 选择教材版本）
               → 否 → 直接进入首页 Dashboard

[已登录 + 已完成系统设置]
  → 首页 Dashboard（工作概览）
  → 顶部栏显示：当前校区 | 班级锚点 | Token 配额 | 通知铃铛 | 头像
  → 侧边栏：备课(教案/出题/组卷) / 作业 / 数据 / 家校 / 个人
```

### 首页 Dashboard 操作路径

```
首页 Dashboard
├── 消息通知弹窗（点击铃铛 → 下拉通知列表 → 标记已读/查看详情）
├── 全部草稿页（点击「查看全部草稿」→ 教案草稿箱列表）
├── 用户菜单（头像下拉 → 个人信息/班级切换/系统设置/退出登录）
├── Token 详情弹窗（点击 Token 显示 → 弹窗展示配额/已用/预估剩余天数）
├── 新的创作入口（教案/试卷/出题 → 跳转对应工作台）
└── 小微按钮（底部黑色按钮 → 右侧滑出小微面板）
```

## 二、备课模块交互流程

### 2.1 教案工作台（新建教案）

```
侧边栏点击「教案草稿箱」
  → 草稿箱列表页（展示已有草稿）
  → 点击「新建教案」按钮
  → 进入教案工作台（新标签页）

教案工作台交互：
┌────────────────────────────────────────────────────────────┐
│ 1. 基本信息区（只读，自动带入）                                │
│    学科/年级班级/校区/教材封面 ← 来自 teachingContextStore      │
│                                                              │
│ 2. 表单配置区                                                 │
│    标题输入 → 文本输入框，12字以内，实时计数                     │
│    单元选择 → 下拉（级联）→ 根据教材版本列出所有单元             │
│    课时选择 → 下拉（级联）→ 选单元后列出课次+课题               │
│    教案模板 → 下拉 → 核心素养/三维目标/单元教学等模板             │
│    知识点选择 → 左侧知识图谱点选节点，最多5个                    │
│    自定义标签 → 输入框+系统推荐，最多3个                        │
│    补充内容 → 多行文本框，教师额外指令                          │
│    素材选入 → 点击[+]按钮                                     │
│              ├── 上传本地资料 → 文件选择器 → AI自动打标签 → 存入素材库
│              └── 从素材库浏览 → 素材列表弹窗 → 勾选 → 确认       │
│                                                              │
│ 3. 操作按钮（三态）                                           │
│    [保存为草稿] → 保存配置，不生成内容 → Toast「草稿已保存」      │
│    [预览] → AI 生成教案 → SSE 流式推送 → 新标签页预览            │
│    [发布] → 检查互审状态                                      │
│           ├── 互审开启 → 提交送审 → 待审核状态                   │
│           └── 互审关闭/自动审核勾选 → 直接发布 → 教案发布库        │
│                                                              │
│ 4. 知识图谱面板（左侧，280-560px）                              │
│    默认聚焦当前课时（5-8个节点）                                │
│    可切换：展开全部 / 聚焦当前课时                              │
│    维度切换：知识点着色 / 能力着色 / 难度着色 / 课标着色          │
│    视图切换：树状 / 螺旋 / 网状                                │
│    点击节点 → 选中填入知识点字段                                │
│                                                              │
│ 5. 小微面板（底部黑色按钮唤起，右侧滑出）                        │
│    自动注入上下文 {校区, 班级, 学科, 教材版本}                   │
│    三板斧入口：SOP / FAQ / 资源推荐（空会话状态）                 │
│    支持自然语言指令：「帮我为《观潮》第一课时生成教案」              │
└────────────────────────────────────────────────────────────┘
```

### 2.2 教案草稿箱

```
教案草稿箱列表页
├── 列表项：草稿标题 / 类型(教案) / AI摘要(50字) / 更新时间 / 操作
├── 单击草稿 → 新标签页打开教案工作台，恢复上次编辑状态
├── 操作按钮：编辑 / 删除 / 复制 / 发布
├── 批量送审（勾选多个 → 一键提交送审，需开启互审模式）
├── 筛选：按学科/年级/状态筛选
└── 空态：引导文案 + 「新建教案」快捷入口
```

### 2.3 教案发布库

```
教案发布库列表页
├── 列表项：教案标题 / 适用信息 / 发布时间 / 状态 / 引用统计 / 操作
├── 点击标题 → 教案详情页（只读预览，含课件使用脚本）
├── 操作：查看详情 / 引用 / 复制
├── 状态筛选：已发布 / 已审核通过 / 退回修改
└── 教案详情页
    ├── 完整教案内容（含课件使用脚本标记）
    ├── 知识图谱锚点高亮
    ├── 引用与分享入口
    └── 课件联动：点击教案中课件引用标记 → 跳转课件对应页面
```

### 2.4 教案互审

```
互审配置（系统设置 → 权限与共享 → 教案互审开关）

教师A提交送审流程：
教案工作台 → [发布] → 检测互审开启
  → 审核人指定（三选一）
      ├── 系统自动配对：同年级同科教师随机互为审核人
      ├── 教师自行指定：从同科教师列表中选择
      └── 教研组长分配：无人指定时由教研组长手动分配
  → 提交成功 → 状态变为「待审核」→ 进入「我的送审」列表

教师B审核流程：
侧边栏 → 教案互审 → 待我审核列表
  → 列表项：教案标题 / 提交人 / 提交时间 / 状态
  → 点击「查看详情」→ 审核详情页
      ├── 教案预览（只读）
      ├── 在线批注工具（高亮/划线/文字批注）
      └── 判定入口
          ├── [通过] → 教案发布到发布库
          └── [退回修改] → 填写退回理由 → 通知提交人

被退回处理：
我的送审 → 被退回列表 → 点击「编辑」
  → 直接唤起教案工作台，加载原稿进入编辑
  → 修改后 → 重新送审

不可自审：审核人不能审核自己提交的教案
```

### 2.5 素材库

```
侧边栏 → 素材库
  → 素材列表页
      ├── 网格/列表视图切换
      ├── 筛选：按素材类型（图片/文档/音频/视频/组件）
      ├── 排序：按热度（冷/温/热/火/爆）/ 更新时间
      ├── 分组管理：自定义文件夹/标签组合
      ├── 共享开关：默认仅本人 → 开启后本校同级同科可互相引用
      └── 上传入口：点击 → 文件选择器 → AI自动打标签 → 存入素材库

素材详情页
  ├── 预览（图片/文档/视频播放）
  ├── AI标签展示（学科/年级/场景/关键词/风格）
  ├── 版本历史（素材更新保留历史版本）
  ├── 引用统计（被引用次数）
  └── 操作：编辑 / 删除 / 下载 / 分享

素材生命周期：
新创作 → AI自动打标签 → 存入素材库
  → 教案/试卷/作业中引用（不重复上传）
```

## 三、出题与组卷模块

### 3.1 出题·题库

```
侧边栏 → 出题·题库
  → 题库浏览页（知识图谱左侧 + 题目编辑区右侧）

题库浏览页交互：
┌────────────────────────────────────────────────────────────┐
│ 左侧知识图谱面板                                            │
│   - 节点标记：已出题数 / 学情薄弱度                          │
│   - 未覆盖知识点：灰色标记，提示补充                         │
│   - 点击图谱节点 → 自动填入题目知识点字段                    │
│                                                              │
│ 右侧上方：题目编辑区（八要素表单）                             │
│   题干 → 富文本输入                                         │
│   答案 → 文本输入                                           │
│   解析 → 多行文本                                           │
│   题型 → 下拉（选择/填空/判断/解答/简答）                      │
│   分值 → 数字输入                                           │
│   知识点 → 从图谱点选（自动填入）                             │
│   难度 → L1-L4 下拉                                         │
│   区分度 → 数字输入（选填，模考/选拔考启用）                    │
│   来源 → 下拉（教材/考试真题/原创）                            │
│                                                              │
│ 右侧下方：题库列表                                           │
│   筛选：知识点/难度/题型/来源                                 │
│   排序：使用次数/创建时间                                    │
│   批量导入：[导入] → CSV文件上传 → 解析 → 确认导入             │
│   题目标记：未使用/已使用/使用次数                             │
└────────────────────────────────────────────────────────────┘

小微出题建议（图谱面板小微入口）：
点击小微 → 「帮我为正确率低于70%的知识点各出2道选择题」
  → 小微读取学情数据 → 自动出题 → 确认后存入题库

排重规则：相同题目不重复出现在同一份作业中
```

### 3.2 组卷·试卷库

```
侧边栏 → 组卷·试卷库
  → 试卷列表页（已有试卷列表）
  → 点击「新建试卷」→ 进入试卷编辑器

试卷编辑器交互：
┌────────────────────────────────────────────────────────────┐
│ 试卷信息区                                                  │
│   标题输入 / 满分 / 考试时间                                 │
│                                                              │
│ 知识图谱面板（左侧）                                         │
│   - 难度维度着色（L1-L4）                                   │
│   - 已覆盖知识点 = 实心，未覆盖 = 空心                        │
│   - 显示知识点覆盖率百分比（如 12/20, 60%）                   │
│   - 空白知识点闪烁提醒补题                                   │
│   - 选中题目 ↔ 图谱节点双向联动定位                          │
│                                                              │
│ 试卷编辑区（右侧）                                           │
│   题目容器列表：                                             │
│     - 拖拽排序（调整题目顺序）                                │
│     - 宽度调节（容器右侧/角落拖拽）                            │
│     - 分栏排版（选择题两栏、解答题一栏）                       │
│     - 双击容器边缘 → 恢复默认宽度                             │
│     - 移除（非删除）：从试卷移除，不删除题库                    │
│                                                              │
│ 操作按钮：                                                   │
│   [+ 添加题目] → 弹窗：从题库手动勾选 / AI智能组卷             │
│   [预览] → 新标签页预览试卷                                   │
│   [发布] → 发布到试卷库                                       │
│                                                              │
│ 试卷质量评估面板（右下角）                                    │
│   知识点覆盖率 / 难度分布图 / 题型分布图 / 预估平均分 / 课标对齐度 │
└────────────────────────────────────────────────────────────┘

AI智能组卷流程：
点击「AI智能组卷」
  → 小微面板唤起 → 输入指令：「覆盖第3-5单元，难度L2为主，L3占比30%」
  → 小微读取图谱分析知识点分布 → SSE流式生成试卷
  → 题目填入编辑器 → 教师调整排序和排版 → 质量评估确认
  → 预览 → 发布
```

## 四、作业模块交互流程

### 4.1 作业布置

```
侧边栏 → 作业列表
  → 作业列表页（按班级/学科/状态筛选）
  → 点击「布置作业」

布置流程：
1. 选择班级和学科（自动带入当前上下文，可切换）
2. 选择作业模板（或新建）
3. 选题方式：
     ├── 手动勾选题库 → 题目搜索弹窗 → 筛选/勾选 → 确认
     ├── AI智能组卷 → 小微面板 → 自然语言指令 → 自动生成
     └── 上传自定义内容 → 文件选择器
4. 设置时间：
     ├── 相对时间：发送后 N 小时截止
     └── 绝对时间：指定截止日期时间
5. 设置作业类型：常规作业 / 临时作业 / 调整性作业
6. [发送] → 确认弹窗 → 发布到班级

知识图谱联动：
- 图谱标注「上次作业已覆盖知识点」和「薄弱知识点」
- 教师布置时可参考图谱，优先覆盖薄弱点
- 小微推荐本周作业应覆盖的知识点清单
```

### 4.2 批阅工作台

```
作业列表 → 点击某次作业 → 批阅工作台

批阅工作台三栏布局：
┌──────────┬────────────────────┬──────────────┐
│ 左栏      │ 中栏                │ 右侧悬浮面板   │
│ 学生列表   │ 批阅内容区           │ 小微 AI 助手   │
│           │                     │              │
│ ├ 姓名    │ ├ AI批改结果（每道题）│ ├ 查询学情    │
│ ├ 提交时间 │ ├ 客观题：自动比对   │ ├ 操作批阅    │
│ └ 批改状态 │ ├ 主观题：AI预打分   │ └ 对话互动    │
│           │ ├ 低置信度红色标记   │              │
│           │ ├ 教师修改入口       │              │
│           │ └ [确认]/[退回]按钮  │              │
│           │                     │              │
│ 筛选/排序  │ 进度条：18/42       │              │
│ 批量操作   │                     │              │
└──────────┴────────────────────┴──────────────┘

AI批改流程：
1. 学生拍照提交 → AI多模态识别（文字+符号+公式+图形）
2. 客观题：全自动批改（结果比对）
3. 主观题：AI提取关键词预打分
4. 低置信度标记：置信度 < 85% → 红色高亮
5. 教师复核：查看AI评分依据 → 确认或修改 → [确认批改]

手写识别：
- 单字置信度 < 70%：该字标记「待确认」
- 整篇平均置信度 < 60%：整篇推送人工复核
- 批阅工作台显示每篇识别置信度评分

批阅效率增强：
- 快捷键：← → 切换学生 / Enter 确认批改 / Tab 切换题目
- 批量操作：一键标记已阅 / 一键退回所有低置信度 / 批量催交
- 进度条：顶部显示批改进度
- 筛选排序：按提交时间/批改状态/正确率排序

AI评分免责提示（批阅工作台顶部固定）：
「AI 评分结果仅供参考，教师复核确认后方可生效。」
作文批阅：AI预评分 与 教师确认分 两个字段分别显示
```

### 4.3 错题归集与家长报告

```
批阅完成 → 自动触发
  → 错题归集：按知识点归类 → 存入学生个人错题本
  → 家长报告生成（双周期）：
      ├── 月报：按周或按月自动归集
      └── 期末：期中、期末各一次

报告结构：
  综述版（家长先看到）：
    - 已掌握知识点（绿）
    - 建议巩固知识点（黄）
    - 重点突破知识点（橙）
    - 3条积极建议
  详细版（点击展开）：
    - 错题列表（按知识点归类）
    - 原题+学生答案+正确答案+知识点标签
    - 各维度掌握情况对比
    - 历次同类错题对比
    - 一键生成同类巩固练习

家长端提醒：
- 每周/每月定时生成报告
- 免打扰时段：22:00-7:00（可配置）
- 逾期未交等紧急通知不受免打扰限制

作业全生命周期：
布置 → 已发布 → 学生提交中 → 提交截止
  → 批阅中 → 批阅完成 → 错题归集 → 报告生成 → 家长签字
```

## 五、教学数据模块

### 5.1 学情分析（七卡片仪表盘）

```
侧边栏 → 学情分析
  → 七卡片布局（一屏展示，三行排列，无需滚动）

卡片布局：
第1行（3卡片）：
  [作业完成率] 85%（36/42人） → [问小微：为什么完成率变化了？]
  [平均正确率] 72% → [问小微：正确率下降的原因？]
  [待批阅/待订正] 6份待批阅｜12人需订正 → [问小微：哪些学生需要重点关注订正？]

第2行（2卡片）：
  [知识点掌握度] 已覆盖12/20个知识点 → [问小微：哪些知识点需要重点关注？]
  [正确率趋势] 近7天正确率曲线 → [问小微：正确率波动的原因是什么？]

第3行（2卡片）：
  [共性问题] 错误率最高TOP3知识点 → [问小微：运算定律错误率高的原因及建议]
  [标签速览] 系统自动打标 → [问小微：计算能力偏弱的具体表现和建议]

设计原则：
- 一屏可见（不滚动不切换Tab）
- 默认当前上下文（自动带入班级和学科）
- 不下钻（所有卡片只读展示）
- 可提问（每卡片旁小微入口）

数据更新频率：
- 今日数据：实时
- 本周/本月数据：每日凌晨更新
- 趋势数据：每次批阅完成后增量更新
```

### 5.2 成长足迹

```
侧边栏 → 成长足迹
  → 班级学生列表
      ├── 按姓名/学号排序

```

家长端交互：

## 九、加载态规范

> 小Q验证反馈：加载态是最大盲区。本节补充7个核心场景的加载态设计。

| 场景 | 加载态表现 | 降级方案 |
|------|----------|---------|
| 知识图谱加载 | 骨架屏占位（AntV G6容器区域） | 加载失败→降级为全宽表单模式，提示「图谱加载失败，可继续编辑」 |
| 教案列表加载 | 骨架屏（3行占位，模拟表格行高） | 加载失败→ErrorState + 「重新加载」按钮 |
| 题库列表加载 | 骨架屏（表格占位，表头+5行数据行） | 加载失败→ErrorState + 「重新加载」按钮 |
| 学情看板加载 | 卡片骨架屏（7个卡片区域灰色占位） | 加载失败→ErrorState + 「重新加载」按钮 |
| AI生成中（SSE流式） | 逐段渲染 + 进度指示器（「正在生成教案…」+ 脉冲动画） | 超时30s→提示「生成超时，请重试」+ Token不消耗 |
| 素材库加载 | 网格骨架屏（6个缩略图灰色占位） | 加载失败→ErrorState + 「重新加载」按钮 |
| 作业批阅列表加载 | 学生列表骨架屏（左侧列表3行占位） | 加载失败→ErrorState + 「重新加载」按钮 |

## 十一、异常路径处理

### 数据为空
| 场景 | 处理 |
|------|------|
| 草稿箱为空 | 引导文案 + 「新建教案」快捷入口 |
| 题库无题目 | 引导上传或AI出题 |
| 学情无数据 | 「暂无批阅数据，布置一份作业开始吧」 |
| 素材库为空 | 「上传您的第一份素材」引导入口 |

### 网络错误
| 场景 | 处理 |
|------|------|
| AI生成失败 | Toast「生成失败，请稍后重试」+ 保留草稿 |
| AI生成超时（SSE流中断） | 提示「生成超时，请重试」+ Token不消耗 |
| 保存失败（网络断开） | 本地缓存 + Toast「网络异常，内容已本地暂存，恢复网络后将自动同步」 |
| 页面加载失败 | ErrorState 组件 + 「重新加载」按钮 |
| 小微面板SSE连接断开 | Toast「连接已断开，正在重新连接…」+ 自动重连（最多3次） |

### Token耗尽
| 场景 | 处理 |
|------|------|
| Token用尽 | 顶部栏红色提示 + 生成按钮禁用（灰色不可点击态） |
| Token不足时AI智能组卷 | 按钮禁用 + Tooltip「Token不足，无法使用AI组卷」 |
| Token不足时小微生成方案 | 面板显示「Token不足」提示 + 输入框禁用 |
| Token不足时AI选题智慧 | 功能入口灰色 + Tooltip「Token不足」 |
| 预警提醒 | 剩余10%时弹窗提醒「您的Token配额即将用尽，剩余X%」 |
| 恢复路径 | 引导入口 → Token充值弹窗 / 联系管理员 |

### License过期保护
| 场景 | 处理 |
|------|------|
| 教案/题目/试卷/作业 新建 | 按钮禁用 + Tooltip「License已过期，仅支持查看已有内容」 |
| 素材上传 | 上传入口禁用 + Tooltip同上 |
| 小微对话（消耗Token） | 面板禁用 + 提示 |
| 批阅确认（写操作） | 确认按钮禁用 |
| 成长关爱方案确认 | 确认按钮禁用 |
| 已发布内容查看/下载/导出 | ✅ 正常可用（只读） |

### 权限异常
| 场景 | 处理 |
|------|------|
| 会话超时 | 到期前5分钟倒计时提醒 + 自动保存草稿 |
| 多标签页编辑冲突 | 保存时版本号比对 → 冲突弹窗「另一标签页已修改，是否覆盖？」 |
| 互审退回后重新送审 | Toast「已重新提交，请等待审核」+ 状态更新为「待审核」 |

### 自动保存
| 场景 | 间隔 | 行为 |
|------|:--:|------|
| 教案工作台 | 30秒 | 自动保存草稿 |
| 组卷编辑器 | 30秒 | 自动保存 |
| 题目编辑 | 30秒 | 自动保存 |
| 浏览器关闭/刷新 | — | beforeunload确认框 |
| SPA路由跳转 | — | Route Guard自动保存+静默恢复 |
