# IT管理员（it_admin）核心交互流程图

> 版本：v1.0 | 日期：2026-07-04 | 作者：小艺（UI/UX设计师）
> 依据：产品功能规格说明书 0703-v6 + 架构设计 v3.1 + 二期设计稿（用户管理与权限/校园通讯录/教材版本库管理）

---

## 一、角色定位与入口

```
IT管理员 = 独立登录态 + 系统管理 Dashboard + 学校级管理

权限矩阵：
├── user:manage （用户管理）
├── permission:* （权限配置）
├── data:export （数据导出）
├── integration:* （集成管理）
├── textbook_version:* （教材版本库）
├── campus_contacts:* （校园通讯录）
└── system_config:* （系统配置）

侧边栏：
  用户管理 / 权限配置 / 校园通讯录 / 教材版本库 / 数据管理 / 集成管理

特点：无需班级锚点，全局视角，管理全校IT基础设施
```

```

## 三、用户管理

```
侧边栏 → 用户管理
  → 用户列表页

用户列表：
├── 按角色筛选：教师/班主任/教研组长/教务员/校长/学生/家长
├── 按状态筛选：在职/禁用/离职
├── 搜索：姓名/手机号/邮箱

[创建教师账号]
  ├── 姓名（必填）
  ├── 手机号（必填，唯一）
  ├── 邮箱（选填）
  ├── 角色选择：教师/班主任/教研组长/教务员/校长/IT管理员
  ├── 初始密码（或发送短信设置链接）
  └── [创建] → 账号生成

[批量导入]
  ├── 下载CSV模板
  ├── 上传CSV文件 → 解析 → 预览
  ├── 校验：手机号重复/格式错误 → 标记错误行
  ├── [确认导入] → 批量创建账号
  └── 导入结果：成功N条 / 失败N条（含失败原因）

账号操作：
├── 编辑信息（姓名/手机号/邮箱）
├── 禁用/启用账号（禁用后不可登录）
├── 角色变更（如教师→教研组长）
├── 重置密码（发送短信验证码重置）
└── 离职处理（标记离职 → 数据移交 → 归档）

教师离职交接：
1. 标记教师状态为「已离职」
2. 风格蒸馏成果归档（不转移）
3. 教学成果移交继任者账号
4. 手机号一个月后可重新分配
```

## 四、权限配置

```
侧边栏 → 权限配置
  → 权限矩阵页

权限模板：
├── 预设角色模板（teacher/head_teacher/research_lead/registrar/principal/it_admin）
│     └── 每个模板展示权限列表
├── [自定义模板]
│     ├── 模板名称
│     ├── 勾选权限项（从权限矩阵中选择）
│     └── [保存] → 模板生效
│
├── 细粒度权限调整
│     ├── 选择教师 → 查看当前权限
│     ├── 增删权限项
│     └── [保存] → 权限生效（立即刷新该教师token）
│
└── 权限审计
      ├── 查看各教师权限变更历史
      └── 导出权限配置报告
```

## 七、数据管理

```
侧边栏 → 数据管理
  → 数据管理页

数据管理内容：
├── 数据概览卡片
│     ├── 全校教案总数 / 题目总数 / 试卷总数
│     ├── 作业总批阅量 / 素材总量
│     └── Token总消耗 / 无效算力占比
│
├── 数据导出
│     ├── 导出类型：教案/试卷/作业/学情/用户/素材
│     ├── 筛选条件：时间范围/班级/学科/教师
│     ├── 导出格式：Excel/CSV/JSON
│     ├── [预览导出内容] → 确认数据范围和数据量
│     └── [导出] → 后台生成 → 下载链接（有效期24h）
│           ⚠️ 异常：数据量过大 → 分批导出提示 + 异步任务队列
│
├── 学期归档
│     ├── 选择学期 → [归档]
│     ├── 归档预览：展示归档数据统计（教案N篇/试卷N份/成绩N条）
│     ├── [确认归档] → 归档后数据只读可查，不可编辑
│     ├── 归档状态查看（已归档/未归档/归档中）
│     └── [取消归档] → 仅限24h内撤销
│
├── 数据备份
│     ├── 备份概览：最近备份时间/备份大小/备份状态
│     ├── [手动触发备份] → 选择备份范围（全量/增量）→ 确认
│     ├── 备份历史列表（时间/类型/大小/状态）
│     ├── [下载备份] → 生成加密下载链接
│     └── [删除过期备份] → 批量选择 → 确认删除
│
├── 无效算力统计
│     ├── 每周自动生成《无效算力消耗统计》报表
│     ├── 按教师维度统计（教师名/无效请求数/消耗Token/占比）
│     ├── 按时间趋势（周度/月度折线图）
│     ├── [导出报表] → Excel下载
│     └── 仅统计数据，不展示具体对话内容（隐私保护）
│
└── 数据生命周期
      ├── 学生在校期间：数据正常保留
      ├── 毕业后：数据保留3年
      ├── 超过3年：自动脱敏归档（移除个人标识，保留统计级数据）
      └── 数据保留策略配置（可调整保留年限）
```

```

  → 系统配置页

系统配置内容：

│
├── 安全配置
│     ├── 密码策略（最小长度/复杂度要求）
│     ├── 登录失败锁定（次数/锁定时长）
│     ├── IP白名单（可选，限制校内网访问）

      ├── 关键操作标记（用户创建/权限变更/数据导出/批量操作）

## 十、异常路径

### 手机号冲突
```
场景：创建教师账号时手机号已被占用
  → 提示：「该手机号已被[姓名]使用」
  → 检查是否为已离职教师（离职满1个月可重新分配）
```

### CSV批量导入错误
```
场景：CSV格式错误或数据重复
  → 解析阶段标记错误行（红色高亮）
  → 展示错误原因（手机号重复/格式错误/必填缺失）
  → 用户可选择：仅导入正确行 / 修正后重新上传
```

### 权限变更生效延迟
```
场景：修改教师权限后，教师需刷新才能生效
  → 系统自动使该教师JWT Token失效
  → 教师下次请求时自动刷新权限
```

### 数据为空
| 场景 | 处理 |
|------|------|
| 无用户 | 「暂无用户，创建第一个教师账号吧」 |
| 无权限模板 | 展示系统预设模板 |
| 无集成配置 | 「暂无集成配置，添加第一个对接」 |
