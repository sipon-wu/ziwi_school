# 校长（principal）核心交互流程图

> 版本：v1.0 | 日期：2026-07-04 | 作者：小艺（UI/UX设计师）
> 依据：产品功能规格说明书 0703-v6 + 架构设计 v3.1 + 二期设计稿（校长仪表盘）

---

## 一、角色定位与入口

```
校长 = 独立登录态 + 全校仪表盘（只读）+ 数据洞察

权限矩阵：
├── dashboard:principal （校长仪表盘）
├── analytics:school （全校数据分析）
└── audit:read （审计日志查看）

侧边栏：
  仪表盘 / 数据洞察 / 关注事项

特点：全局视角，无需班级锚点，所有数据为全校级别
```

---

## 二、登录与首页

```
[登录] → 身份识别为 principal
  → 校长仪表盘（全校数据总览）

仪表盘内容（基于二期设计稿 校长仪表盘.html）：
├── KPI大数字卡片（5列）
│     ├── 学校总数（多校区）
│     ├── 教师总数（在职/离职）
│     ├── 学生总数
│     ├── 本学期教案产出数
│     └── Token 消耗总量
│
├── 图表区（2列布局）
│     ├── 教案产出趋势图（折线图，按年级/学科）
│     ├── 作业完成率趋势（折线图，按班级）
│     ├── 教师活跃度分布（按年级/学科）
│     ├── 学情整体趋势（正确率变化）
│     ├── 各年级各学科对比（柱状图）
│     └── Token使用效率（工作请求占比）
│
├── 班级对比表格
│     ├── 各班级作业完成率 / 平均正确率
│     ├── 进度条可视化
│     └── 按年级分组
│
├── 排行列表
│     ├── 教案产出TOP5教师
│     ├── 教案引用TOP5教师
│     └── 教研活跃度TOP5教师
│
├── 无效算力消耗TOP5
│     ├── 仅显示排名和占比
│     ├── 不显示具体聊天内容（隐私保护）
│     └── 按自然周更新
│
└── 告警区
      ├── License即将到期（30/15/3天提醒）
      ├── Token配额预警（剩余不足10%的教师/班级）
      ├── 异常数据（正确率骤降、教师活跃度异常）
      └── 系统通知（平台公告/版本更新）
```

## 三、数据洞察

```
侧边栏 → 数据洞察
  → 全校数据分析页

数据洞察内容：
├── 按年级维度
│     ├── 选择年级 → 查看该年级全部数据
│     ├── 各班级对比
│     └── 各学科对比
│
├── 按学科维度
│     ├── 选择学科 → 查看该学科全校数据
│     ├── 各年级对比
│     └── 各教师对比
│
├── 按时间维度
│     ├── 本学期 / 本学年 / 自定义时间段
│     └── 趋势对比（同比/环比）
│
├── 教师维度
│     ├── 教师个人数据总览（选择教师查看）
│     ├── 教案/作业/学情数据汇总
│     └── 教研参与度
│
└── 导出报表
      ├── 导出全校数据报告（Excel/PDF）
      └── 自定义导出字段
```

## 四、关注事项

```
侧边栏 → 关注事项
  → 关注事项列表

关注事项内容：
├── 预警项
│     ├── License到期提醒（30/15/3天）
│     ├── Token配额不足的班级/教师
│     ├── 教师流失风险（长期不活跃）
│     └── 学情异常波动班级
│
├── 审计日志
│     ├── 关键操作记录（教案发布/成绩修改/权限变更）
│     ├── 按时间/操作人/操作类型筛选
│     └── 异常操作标记
│
├── 无效算力消耗
│     ├── 每周自动生成《无效算力消耗统计》
│     ├── TOP5教师排名（仅排名占比，不显示对话内容）
│     └── 全校无效算力占比趋势
│
└── 关注设置
      ├── 设置关注项提醒阈值
      ├── 选择提醒方式（站内/微信）
      └── 免打扰时段设置
```

## 五、异常路径

### License到期
```
场景：学校License即将到期
  → 校长仪表盘告警区显示红色预警
  → 30天/15天/3天逐级提醒
  → 到期当天：禁止全校新建内容，已发布内容只读可访问
  → 校长需联系平台运营续费
```

### Token耗尽
```
场景：全校Token配额即将耗尽
  → 仪表盘告警区显示预警
  → 校长可查看各教师Token消耗排名
  → 联系平台运营追加配额
```

### 数据为空
```
场景：新学校无数据
  → 仪表盘显示引导：「学校数据将在教师开始使用后呈现」
  → 可查看教师激活情况、班级配置情况
```

### 权限限制
```
校长所有操作均为只读，无写入权限
  → 任何编辑操作提示：「您仅有查看权限，请联系教务员或IT管理员操作」
```
