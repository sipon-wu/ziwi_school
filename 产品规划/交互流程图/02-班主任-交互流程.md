# 班主任（head_teacher）— 交互流程图

> 角色：班主任 | 来源：产品规格 0703-v6 §1.2
> 版本：v1.0 | 日期：2026-07-04 | 作者：品姐

---

## 角色概述

班主任拥有教师全部权限 + 班级管理入口。侧边栏与教师相同，但增加班级管理入口。班级锚点固定为本班，不可切换其他班级。

---

## 核心用户旅程

```
[班主任登录] → [首页Dashboard]（与教师相同 + 班级管理入口）

  → [班级管理入口]（侧边栏/首页额外入口）
    ├── 本班学生名单查看
    ├── 家长关联关系维护
    ├── 学生转班/调班申请
    └── 班级通知（仅本班可见）

  → [成长关爱]（班主任专属重点功能）
    ├── 在成长足迹中勾选本班学生 → [纳入成长关爱]
    │   → 确认框：展示当前学情概览
    │   → 小微自动标记该生学情数据波动
    │   → 向家长发送入组诊断书
    ├── 每周方案审阅（与教师相同流程）
    ├── 教育善意度审查（提交前自动触发）
    └── 家长沟通：查看家长留言并回复

  → [家长签字统计]（班主任视角）
    ├── 查看本班全部签字统计
    └── 催办：系统发送红点提醒至家长小程序

  → [学情分析]（班主任可查看全班数据）
    ├── 七卡片仪表盘（默认本班数据）
    └── 可查看每位学生的成长足迹详情

  → [所有教师功能]（教案/出题/组卷/作业/素材库/系统设置）
    └── 与教师完全相同
```

---

## 班主任 vs 教师差异

| 功能 | 教师 | 班主任 |
|------|:--:|:--:|
| 班级锚点 | 可切换多个班级 | 固定为本班 |
| 班级管理入口 | 无 | 有 |
| 成长关爱 | 可发起 | 可发起 + 家长沟通 |
| 家长签字统计 | 查看自己班级 | 查看本班全部 |
| 学情分析 | 查看自己班级 | 查看全班 + 可下钻个体 |
| 教案/出题/组卷/作业 | ✅ | ✅ |

---

## 异常路径

| 场景 | 处理 |
|------|------|
| 班主任唯一性约束 | 同一班级只能有一名班主任，任命时检测冲突 |
| 离职交接 | 班主任离职→班级管理权移交继任者→通知全班家长 |
