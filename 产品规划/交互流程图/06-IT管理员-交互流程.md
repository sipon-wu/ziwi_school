# IT管理员（it_admin）— 交互流程图

> 角色：IT管理员 | 来源：产品规格 0703-v6 §1.2.1
> 版本：v1.0 | 日期：2026-07-04 | 作者：品姐

---

## 角色概述

IT管理员独立登录，负责学校级系统管理。侧边栏包含：系统Dashboard/用户管理与权限/校园通讯录/教材版本选择池/数据管理/系统配置/操作日志。全局视角，无需班级锚点。

---

## 1. 用户管理与权限 — 账户管理流程

```
[系统管理] → [用户管理与权限]

  → Tab 1: [用户列表]
    ├── 统计卡片：总用户(93)/教师(68)/教务员(3)/管理员(4)/已禁用(2)
    ├── 筛选：按角色/状态/年级
    ├── [添加用户弹窗]
    │   姓名/角色(教师/教务员/IT管理员/校长/教研组长)
    │   手机号（用于登录和密码找回）
    │   学科/任教班级（选填，多选）
    │   → [添加] → 默认密码短信发送
    │     ⚠️ 异常：手机号已存在 → 提示"该手机号已注册"
    ├── [编辑] → 修改用户信息/角色
    ├── [改角色] → 切换用户角色（如教师→教研组长）
    ├── [禁用] → 用户无法登录，数据保留
    │   ⚠️ 异常：禁用自己 → 禁止操作
    ├── [启用] → 恢复已禁用用户
    └── [导出Excel] → 下载全校用户列表

  → Tab 2: [角色与权限]
    ├── [权限矩阵表格]
    │   行：功能模块（教案/出题/组卷/作业/学情/成长/签字/关爱/班级调度/教师管理/用户管理/数据管理/校长看板/系统配置）
    │   列：6种校内角色（教师/班主任/教研组长/教务员/校长/IT管理员）
    │   ✓ = 有权限 / — = 无权限 / 可配 = 教师自行配置
    └── [+ 自定义角色] → 创建新角色 + 配置权限

  → Tab 3: [批量导入]
    ├── 下载导入模板（CSV/Excel）
    ├── 拖拽或点击上传文件
    │   必填：姓名/角色/手机号
    │   选填：学科/年级/班级/邮箱
    └── 上传 → 解析预览 → [确认导入]
      ⚠️ 异常：格式错误 → 显示错误行号+原因
```

## 2. 校园通讯录 — 人员管理流程

```
[系统管理] → [校园通讯录]

  → [左侧树形导航]
    ├── 学校根节点
    ├── 年级节点（展开：班级→教师/学生/家长）
    └── 管理人员节点
    └── 搜索框：搜索教师/学生/家长姓名

  → [右侧详情面板]
    ├── 点击节点 → 显示该组成员列表
    ├── 成员卡片：头像/姓名/角色标签/学科/手机号/邮箱
    ├── [编辑关联] → 修改教师-班级-学科关联
    └── [导出通讯录] → 下载Excel
```

## 3. 教材版本选择池 — 版本管理流程

```
[系统管理] → [教材版本选择池]

  → [统计卡片]
    已发布版本(12) / 待审核(3) / 本校自编(5) / 已下架(2)

  → [版本列表]
    ├── 已发布版本（绿色左边框）
    │   版本名称/学科/年级/发布者/使用班级数
    │   操作：查看/下架
    ├── 待审核版本（黄色左边框）
    │   本校自编版本 → ⏳ 待平台审核
    │   操作：查看详情/撤回
    └── 已下架版本（灰色+半透明）
        操作：查看/重新上架

  → [新增版本弹窗]
    版本名称/学科/适用年级/版本类型（平台标准/本校自编）
    上传教材文件（PDF，最大50MB，AI自动提取目录和知识点）
    → [提交] → 系统自动审核 → 立即可供本校教师使用
    → 同步推送至平台运营人工终审
      ⚠️ 异常：AI提取失败 → 提示手动填写知识点

  → 与教材审核联动说明
    教师提交自编版本 → AI自动审核通过 → 本校立即可用
    → 同步推送平台运营 → 人工终审
    → 审核通过 → 纳入平台版本库
    → 审核不通过 → 通知教师修改
```

## 4. 数据管理 — 数据操作流程

```
[系统管理] → [数据管理]

  → [数据导出]
    ├── 选择导出范围：全校 / 指定年级 / 指定班级
    ├── 选择导出内容：教案/题库/试卷/学情数据/用户列表
    ├── 选择格式：Excel(.xlsx) / CSV
    ├── [预览导出结果] → 确认数据量和文件大小
    ├── [确认导出] → 下载文件
    │   ⚠️ 异常：数据量过大（>10万条）→ 提示"数据量较大，生成可能需要几分钟，完成后通知下载"
    └── 导出记录：记录导出操作到审计日志

  → [学期数据归档]
    ├── 选择学期 → [归档]
    │   → 学生数据脱敏归档（移除个人标识，保留统计级数据）
    │   → 毕业后保留3年，超3年自动清理
    ├── [查看归档] → 浏览历史学期数据
    └── [恢复归档] → 从归档中恢复数据（限时操作）

  → [数据备份管理]
    ├── 查看备份状态：最近备份时间/大小/类型
    ├── [手动备份] → 立即触发全量备份
    └── 备份下载（限IT管理员权限）
```

## 5. 系统配置 — 系统级设置流程

```
[系统管理] → [系统配置]

  → [学期轮转配置]
    ├── 查看当前学期信息
    ├── [手动触发轮转] → 升年级预览 → 确认执行
    ├── [轮转规则配置]
    │   自动升年级：开/关
    │   毕业班处理：归档/保留
    └── 轮转历史记录

  → [系统参数配置]
    ├── 自动保存间隔（默认30秒）
    ├── 会话超时时间（默认2小时）
    ├── Token预警阈值（默认10%，可调）
    ├── 数据保留期限（毕业后保留3年）
    └── 通知免打扰时段（默认22:00-7:00）

  → [集成管理]
    ├── 对接学校现有教务系统
    │   ├── 配置API接口地址和认证信息
    │   ├── [测试连接] → 验证连通性
    │   └── [同步数据] → 从教务系统导入学生/教师/班级数据
    ├── 对接学生信息库
    │   └── 学生基础信息同步（姓名/学号/班级）
    └── 单点登录（SSO）配置（二期）
      ⚠️ 异常：连接失败 → 显示具体错误信息+配置建议
```

## 6. 操作日志 — 审计流程

```
[系统管理] → [操作日志]

  → 查看全校操作审计日志
    ├── 筛选：按操作类型/时间/用户
    └── 详情：操作者/操作/资源/IP/时间/状态
```

## 异常路径

| 场景 | 处理 |
|------|------|
| 手机号重复 | 添加用户时检测，提示"该手机号已注册" |
| 禁用自己 | 禁止操作，提示"不能禁用当前登录账号" |
| 批量导入格式错误 | 显示错误行号+具体原因 |
| 自编版本AI提取失败 | 提示手动填写知识点结构 |
| 权限矩阵修改 | 立即生效，谨慎操作提示 |
