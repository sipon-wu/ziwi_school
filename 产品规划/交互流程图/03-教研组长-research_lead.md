# 教研组长（research_lead）核心交互流程图

> 版本：v1.0 | 日期：2026-07-04 | 作者：小艺（UI/UX设计师）
> 依据：产品功能规格说明书 0703-v6 + 架构设计 v3.1 + 二期设计稿（互审池/教研数据看板/模板与方法论/教研活动）

---

## 一、角色定位与入口

```
教研组长 = 教师全部权限 + 教研管理入口

权限矩阵：
├── teacher:* （继承教师所有权限）
├── review_pool:* （教案互审池管理）
├── research_data:* （教研数据查看）
├── methodology:* （方法论管理）
└── template:manage （教案模板管理）

侧边栏：
  备课 / 作业 / 数据 / 家校 / 个人 / [教研管理]
    ├── 教案互审池
    ├── 教研数据看板
    ├── 模板与方法论
    └── 教研活动
```

---

## 二、登录与首页

```
[登录] → 身份识别为 research_lead
  → 首页 Dashboard（工作概览，与教师相同）
  → 侧边栏增加教研管理入口组
  → 顶部栏班级锚点可选择（教研组长通常跨班）
```

---

## 三、教案互审池

```
侧边栏 → 教案互审池
  → 互审池总览页

互审池总览：
├── KPI卡片
│     ├── 待审核总数
│     ├── 今日审核完成数
│     ├── 平均审核时长
│     └── 退回率
│
├── 审核进度列表
│     ├── 按教师维度：每位教师的提交数/通过数/退回数/审核中
│     ├── 按学科维度：各学科审核进度
│     └── 状态筛选：待审核/已通过/已退回
│
├── 审核分配（无人指定时）
│     ├── 查看未分配审核人的教案列表
│     ├── [分配审核人] → 从同科教师列表中选择
│     └── [批量分配] → 一键随机分配
│
└── 审核质量统计
      ├── 每位审核人的审核数/通过率/退回率/平均审核时长
      ├── 退回原因分布（饼图）
      └── 审核人活跃度排名
```

## 五、模板与方法论管理

### 5.1 教案模板管理

```
侧边栏 → 模板与方法论 → 模板管理

模板列表：
├── 系统预设模板（核心素养/三维目标/单元教学等）
├── 本组自定义模板
├── [新建模板] → 模板编辑器
│     ├── 模板名称
│     ├── 适用学科/年级
│     ├── 模板结构编辑（拖拽排列教学环节）
│     └── [保存] → 本组教师可选
│
└── 操作：编辑 / 删除 / 设为默认 / 分享到全校
```

### 5.2 方法论管理

```
侧边栏 → 模板与方法论 → 方法论管理

方法论列表：
├── 待审核方法论（本组教师提交，教研组长初审）
│     ├── 查看方法论详情
│     ├── [初审通过] → 提交平台运营终审
│     └── [初审退回] → 填写退回理由
│
├── 已通过方法论（本组贡献）
│     ├── 署名贡献教师
│     ├── 审核状态：教研组长通过/平台运营通过
│     └── 共享范围：本校/全网
│
└── 方法论贡献机制（B→A）：
      小微从教师使用数据中被动识别高价值教学模式
      → 推荐教师授权共享（展示摘要）
      → 教师确认 → 进入教研组长初审
      → 教研组长通过 → 提交平台运营终审
      → 审核通过 → 纳入领域方法论库，署名贡献教师
```

## 七、交叉场景：教师提交教案→教研组长审核→运营终审

```
完整审核链路：
教师提交教案 → 送审
  ├── 互审模式1：同年级同科教师互为审核人（自动配对）
  │     └── 审核通过 → 发布到教案发布库
  │     └── 退回修改 → 教师修改 → 重新送审
  │
  ├── 互审模式2：教师自行指定审核人
  │     └── 同上
  │
  └── 互审模式3：教研组长分配（无人指定时）
        └── 教研组长在互审池中查看未分配列表
        └── [分配审核人] → 指定同科教师
        └── 审核人审核 → 通过/退回

方法论审核链路：
教师贡献方法论 → 教研组长初审
  ├── 初审通过 → 提交平台运营终审
  │     └── 运营终审通过 → 纳入领域方法论库 → 署名贡献教师
  │     └── 运营终审退回 → 返回教研组长
  └── 初审退回 → 教师修改 → 重新提交

自编教材审核链路：
教师申请新增自编版本 → AI自动提取+自动审核
  → 立即可供该教师使用
  → 同步通知运营平台人工审核
  → 运营审核通过 → 纳入平台版本库 → 可选全校/全网使用
```

## 八、异常路径

### 互审池无审核人可选
```
场景：同科教师仅1人（教研组长自己）
  → 系统提示：「同科教师不足，无法自动配对」
  → 建议：教研组长可作为审核人（需上级授权）
  → 或由跨校教研组长代为审核
```

### 审核超时
```
场景：教案提交后超过N天未审核
  → 系统自动提醒审核人
  → 教研组长可查看超时列表
  → 可重新分配审核人
```

### 数据为空
| 场景 | 处理 |
|------|------|
| 互审池无待审核 | 「暂无待审核教案」+ 查看已完成审核 |
| 教研数据无数据 | 「暂无足够数据，开始教研活动后将有数据呈现」 |
| 无方法论贡献 | 「暂无教师提交方法论，鼓励教师分享教学经验」 |
| 无教研活动 | 「创建第一次教研活动」快捷入口 |
