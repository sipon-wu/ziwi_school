# 班主任（head_teacher）核心交互流程图

> 版本：v1.0 | 日期：2026-07-04 | 作者：小艺（UI/UX设计师）
> 依据：产品功能规格说明书 0703-v6 + 架构设计 v3.1

---

## 一、角色定位与入口

```
班主任 = 教师全部权限 + 班级管理入口 + 班级数据视角

权限矩阵：
├── teacher:* （继承教师所有权限）
├── class:manage （班级管理）
└── growth_care:* （成长关爱管理）

侧边栏（与教师共用，增加入口）：
  备课 / 作业 / 数据 / 家校 / 个人 / [班级管理入口]
```

---

## 二、登录与首页

```
[登录] → 手机号+密码 → 身份识别为 head_teacher
  → 首页 Dashboard（工作概览，与教师相同）
  → 顶部栏增加：当前班级标识（固定为本班，不可切换）
  → 侧边栏增加：班级管理入口

首次登录 → 系统设置引导 → 自动绑定班主任身份班级
  → 班级已由教务员分配，教师认领后自动成为班主任
```

---

## 三、班级管理入口

```
侧边栏 → 班级管理
  ├── 班级概览
  │     ├── 班级基本信息（年级/班级类型/人数）
  │     ├── 学生列表（姓名/学号/家长关联状态）
  │     ├── 任课教师列表（各学科任课教师）
  │     └── 班级数据速览（作业完成率/平均正确率）
  │
  ├── 学生管理
  │     ├── 查看学生详情（跳转成长足迹-学生详情页）
  │     ├── 添加观察记录（同成长足迹）
  │     └── 查看学生学情概览
  │
  ├── 家长关联
  │     ├── 查看家长关联状态（已关联/未关联）
  │     ├── 邀请家长认领（发送邀请链接/小程序码）
  │     └── 家长信息查看
  │
  └── 班级通知
        ├── 发布班级通知
        ├── 查看通知已读/未读
        └── 推送至家长端
```

## 四、成长关爱增强（班主任视角）

```
班主任在成长关爱模块拥有增强权限：

侧边栏 → 成长关爱
  → 本班学生列表（自动过滤，仅显示本班）
  → 比普通教师多：
      ├── 批量入组：勾选多个学生 → 一键纳入成长关爱
      ├── 分组管理：创建/编辑/删除自定义分组
      ├── 方案审阅：查看本班所有学生的关爱方案
      ├── 家长沟通记录：查看本班所有家长留言和回复
      └── 续期管理：学期末批量发起续期确认

入组流程增强：
1. 班级管理 → 学生列表 → 勾选学生
2. 点击「纳入成长关爱」→ 批量确认弹窗
3. 系统展示每位学生学情概览
4. 班主任确认 → 小微为每位学生生成初始方案
5. 向家长发送入组诊断书
```

---

## 五、家长签字增强（班主任视角）

```
班主任可查看本班所有学生的家长签字情况：

侧边栏 → 家长签字
  → 按作业维度展示
  → 比普通教师多：
      ├── 全班签字统计（已签/未签/催办次数）
      ├── 按家长维度统计（漏签次数排名）
      ├── 批量催办（勾选未签家长 → 一键发送提醒）
      └── 家长配合度趋势（按月/学期）
```

---

## 六、作业布置（班主任视角）

```
作业布置时：
  → 班级选择自动锁定为本班（不可切换）
  → 学科可切换（班主任可能任教多个学科）
  → 其余流程与教师相同

批阅工作台：
  → 学生列表自动过滤为本班学生
  → 与教师批阅流程完全一致
```

## 七、异常路径

### 班主任唯一性约束
```
场景：教务员尝试为已有班主任的班级再指定班主任
  → 系统拦截：「该班级已有班主任[教师姓名]，请先解除后再指定」
  → 班主任不可自解除，需教务员操作
```

### 家长未关联
```
场景：学生没有关联家长
  → 班主任端显示「未关联」状态
  → 点击 → 发送邀请链接/小程序码给家长
  → 家长扫码认领 → 建立关联
```

### 班主任离职
```
流程：
1. 教务员解除班主任身份 → 指定新班主任
2. 教学成果（教案/素材/题/卷/作业/学生数据）移交继任者
3. 风格蒸馏成果归档（不转移）
4. 提醒新教师自行训练小微
```

### 数据为空
| 场景 | 处理 |
|------|------|
| 班级无学生 | 引导联系教务员分配学生 |
| 无家长关联 | 引导发送邀请链接 |
| 无作业数据 | 「暂无数据，布置第一份作业吧」 |
