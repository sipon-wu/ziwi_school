# 多角色交叉场景清单

> 版本：v1.0 | 日期：2026-07-04 | 作者：品姐
> 说明：以下场景涉及多个角色协作，需在流程图中明确标注角色切换节点

---

## 场景1：教案审核链

```
教师 → 教研组长

教师端：
  教案工作台 → [提交送审] → 教案进入待审核状态
  ⚠️ 前提：互审模式已开启
  ⚠️ 异常：无人审核 → 教研组长分配审核人

教研组长端：
  [互审池] → 查看待审核列表
  → [查看教案] → 在线批注
  → [通过] → 教案发布到教案发布库 → 教师端状态更新
  → [退回修改] → 附退回理由 → 教师端收到通知

教师端（退回后）：
  被退回列表 → 点击唤起教案工作台 → 加载原稿编辑
  → 修改完成后 → [重新提交送审]
  ⚠️ 退回后重新送审需教研组长重新审核
```

## 场景2：自编教材审核链

```
教师 → AI自动审核 → 平台运营

教师端：
  教材版本下拉 → [未找到版本？申请新增]
  → 上传教材PDF
  → AI自动提取目录结构和知识点
  → 系统自动审核通过 → 立即可供该教师使用
  → 同步通知平台运营人工审核

平台运营端：
  [教材审核] → 查看待审核教材
  → AI审核结果展示（知识点覆盖率/课标匹配率）
  → [审核通过] → 发布至平台版本库（可全校/全网选用）
  → [退回] → 附退回原因 → 通知教师修改

IT管理员端（同步）：
  [教材版本选择池] → 教师申请的自编版本状态更新
  → 待审核版本显示"⏳待平台审核"
  → 审核通过后自动纳入本校选择池
```

## 场景3：作业批阅链

```
教师 → 学生 → AI → 教师 → 家长

教师端：
  [作业布置] → 选择班级/学科/题目 → [发送]

学生端：
  待完成作业列表 → 点击进入作业
  → 拍照/输入提交答案 → [提交]

AI服务（自动）：
  客观题：自动批改（结果比对）
  主观题：AI预打分
  低置信度标记：<85%红色高亮
  手写识别：单字<70%标记待确认，整篇<60%推送人工复核

教师端：
  [批阅工作台] → 三栏布局
  → 查看AI批改结果
  → 低置信度题目红色标记 → 教师复核
  → 双字段：AI预评分/教师确认分
  → [确认批改] → 批改完成

系统（自动）：
  错题归集（按知识点归类）
  生成家长报告（综述版+详细版）

家长端：
  收到签字提醒 → 查看报告 → [确认签字]
  ⚠️ 未签字无系统级后果（自愿原则）
```

## 场景4：成长关爱链

```
教师/班主任 → 小微AI → 教师 → 家长

教师端：
  [成长足迹] → 选择学生 → [纳入成长关爱]
  → 确认框：展示当前学情概览
  → 小微自动标记该生学情数据波动

小微AI（自动）：
  每周结合学情数据 + 教师观察
  → 生成个性化提升方案草案
  本周聚焦/练习安排/学习任务/教师建议

教师端（审阅）：
  [方案审阅列表] → 查看草案
  → [确认] / [修改] / [补充观察] / [退回重生成]
  → 提交前触发教育善意度审查弹窗
    ⚠️ 严禁比较性表述/绝对化判断
    ⚠️ 必须配合建设性建议

家长端：
  入组通知 → [确认] → 开始执行
  每周收到学情周报
  可在周报页面留言
  每学期末 → 续期确认邀请
```

## 场景5：License过期链

```
平台运营 → 系统自动提醒 → 全校教师 → 平台运营

平台运营端：
  [License管理] → 新增授权 → 签发License

系统（自动提醒）：
  到期前30天 → 第1次提醒（平台运营 + 学校IT管理员）
  到期前15天 → 第2次提醒
  到期前3天 → 第3次提醒（紧急）
  到期当天 → License过期

全校教师端：
  License过期后：
    ❌ 禁止：新建/编辑教案、新建题目、新建试卷、布置作业、上传素材、小微对话
    ✅ 允许：查看所有已发布内容、导出数据、查看学情报告

平台运营端：
  [续费] → 选择续费时长 → [确认] → License恢复
  → 全校教师恢复全部功能
```

## 场景6：方法论贡献链（B→A）

```
教师（被动）→ 小微AI识别 → 教师授权 → 教研组长审核 → 平台运营终审

小微AI（自动）：
  从教师使用数据中被动识别高价值教学模式
  → 推荐教师授权共享："您在分数教学上的三步法模式独特，是否愿意分享？"

教师端：
  收到授权请求 → [确认共享] / [拒绝]

教研组长端：
  [模板与方法论] → 方法论管理 → 查看待审核条目
  → [审核通过] / [退回]

平台运营端：
  教研组长审批通过后 → [教材审核] 或 方法论审核入口
  → [终审通过] → 纳入领域方法论库 → 署名贡献教师
```

## 场景7：班级创建同步链

```
教务员 → 教师

教务员端：
  [班级调度] → [创建班级]
  → 分配年级/班级名称/类型/班主任/开设科目
  → [创建] → 自动同步到全校教师的"班级认领"可选池

教师端：
  [系统设置] → 学校与班级管理
  → 认领班级 → 选择教务员创建的班级
  → 认领学科 → 绑定教材版本
  → [保存] → 班级锚点生效
```

## 场景8：Token配额管理链

```
平台运营 → 教师端（消耗）→ 系统预警 → 平台运营

平台运营端：
  [Token管理] → [调整额度] → 为学校/教师分配配额

教师端：
  每次AI生成操作消耗Token（教案生成/出题组卷/小微对话等）
  → 顶部栏实时显示剩余配额百分比

系统（自动预警）：
  Token使用率达到预警阈值（默认10%）→ 教师端显示提示
  Token耗尽 → 教师端显示"Token已用完" → 引导充值

平台运营端：
  [Token管理] → 查看预警学校 → [追加额度]
  → 查看无效算力消耗统计 → 优化配额策略
```

## 场景9：教师离职交接链

```
教师 → IT管理员 → 继任教师

教师端（离职前）：
  [个人中心] → [离职交接]
  → 确认离职信息
  → 系统展示待移交资产清单：
      教案(N篇)/素材(N个)/题库(N题)/试卷(N份)/作业记录(N条)/学生数据

IT管理员端：
  [用户管理] → 选择离职教师 → [禁用账号]
  → [指定继任者] → 从教师列表选择继任教师
  → [确认移交] → 二次确认
      "确认将XX教师的所有教学成果移交给YY教师？"
  → 教学成果移交完成
    ├── 教案/素材/题库/试卷/作业 → 移交继任者（可编辑/使用）
    └── 学生数据（成长足迹/学情报告）→ 移交继任者（只读关联）

系统（自动）：
  风格蒸馏成果归档（属于个人信息，不转移）
  手机号冻结（月限1次，离职后不可修改）
  通知继任教师："您已接收XX教师的教学成果，请自行训练小微"

继任教师端：
  收到通知 → 查看接收的教学资产
  → [确认接收] → 资产纳入个人工作台
  ⚠️ 提示："原教师的小微风格已归档，建议您自行训练小微以获得个性化体验"
```

## 场景10：学期轮转链

```
教务员 → 系统自动执行 → IT管理员确认 → 全校教师

教务员端：
  [学期管理] → [创建新学期]（如2026-2027第一学期）
  → 设置起止日期
  → 勾选"自动继承班级结构/教师分配/课表"
  → [创建] → 新学期生成

系统（自动）：
  当前学期结束后自动触发升年级：
  一年级→二年级、二年级→三年级、...、六年级→毕业
  → 毕业班学生数据归档
  → 毕业班教师释放（解除班级绑定）
  → 升年级结果生成预览

IT管理员端：
  [系统配置] → [学期轮转配置]
  → [预览升年级结果] → 查看每班新年级+学生数
  → [手动调整] → 个别学生留级/跳级处理
  → [确认执行] → 二次确认（不可撤销）

全校教师端：
  收到通知："新学期已创建，请更新班级认领"
  → [系统设置] → 学校与班级管理
  → 班级锚点自动更新为新年级（如四(1)班→五(1)班）
  → 确认认领 → 新班级锚点生效
  ⚠️ 异常：教师未重新认领 → 学期开始前每日弹窗提醒
```
