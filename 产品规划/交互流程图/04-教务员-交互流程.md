# 教务员（registrar）— 交互流程图

> 角色：教务员 | 来源：产品规格 0703-v6 §1.2.1
> 版本：v1.0 | 日期：2026-07-04 | 作者：品姐

---

## 角色概述

教务员独立登录，拥有教务管理Dashboard。侧边栏包含：班级调度/课程安排/教师管理/学期管理。全局视角，无需班级锚点。教务员的配置结果自动同步到教师的"班级认领"可选池。

---

## 1. 班级调度 — 班级创建管理流程

```
[教务管理] → [班级调度]

  → [统计卡片]
    总班级数(24) / 在校学生(1,086) / 在职教师(68) / 未分配班级(2)

  → [班级网格]（按年级分组）
    ├── 年级标题 + 班级数量统计
    ├── 班级卡片
    │   班级名称 + 类型标签（普通班/实验班）
    │   班主任/学生数/开设科目
    │   操作：编辑/调班/删除
    ├── [+ 创建新班级]（虚线卡片）
    └── [调班] → 展开学生科目人数表 + 调班学生入口

  → [创建班级弹窗]
    年级（下拉）/ 班级名称（如四(7)班）
    班级类型（普通班/实验班）
    班主任（下拉，暂不指定可选）
    开设科目（多选checkbox：语文/数学/英语/科学/道法/信息/音乐/美术/体育）
    → [创建] → 自动同步到教师"班级认领"可选池
      ⚠️ 异常：班主任唯一性 → 检测同一班级是否已有班主任
```

---

## 2. 课程安排 — 排课流程

```
[教务管理] → [课程安排]

  → [视图切换] 周课表 / 日课表 / 列表视图

  → [筛选栏]
    年级（下拉）/ 班级（下拉）
    教师冲突检测 → 显示冲突徽章

  → [课程表（周课表视图）]
    ├── 行：节次/时间（第一节08:00-08:40 ~ 第六节14:50-15:30）
    ├── 列：周一~周五
    ├── 每格显示：科目/教师/教室
    ├── 点击格子 → 编辑课程
    ├── 拖拽调整（暂不实现）
    └── [添加课程弹窗]
        班级/科目/任课教师/星期/节次/教室
        → [添加]
          ⚠️ 异常：教师冲突 → 提示"该教师该时段已被分配到X班"

  → [批量导入]
    上传Excel/CSV课表文件 → 批量导入课程
```

## 3. 教师管理 — 教师分配流程

```
[教务管理] → [教师管理]

  → [统计卡片]
    在职教师(68) / 在岗(62) / 请假(5) / 离职(1)

  → [教师列表表格]
    ├── 列：教师(姓名+头像) / 学科 / 任教班级 / 班主任 / 状态 / 操作
    ├── 筛选：按学科/状态/年级
    ├── [批量导入] → 上传CSV批量导入教师
    ├── [添加教师弹窗]
    │   姓名/学科/任教班级（多选）/任命班主任（可选，唯一性约束）/手机号
    │   → [添加] → 默认密码短信发送
    └── 操作：
        [分配班级] → 选择班级+学科 → 保存
        [任命班主任] → 选择班级 → 检测唯一性 → 保存
        [编辑] → 修改教师信息
        ⚠️ 异常：班主任唯一性 → 提示"该班级已有班主任XX，确认替换？"
```

## 4. 学期管理 — 学期配置流程

```
[教务管理] → [学期管理]

  → [学期列表]
    ├── 当前学期卡片（蓝色边框 + 进度条88%）
    │   2025-2026学年 第二学期
    │   起止：2026-02-17 ~ 2026-07-05
    ├── 上学期卡片（已结束，查看归档）
    └── 历史学期（已归档）

  → [学制与校历配置]
    ├── 学制类型：六三制 / 五四制（下拉切换）
    ├── 学年起止日期
    ├── 春季学期起止日期
    ├── 秋季学期起止日期
    └── 自动升年级：勾选→新学期自动升年级

  → [创建新学期弹窗]
    学期名称（如2026-2027学年第一学期）
    起始日期 / 结束日期
    继承上一学期配置（勾选：自动继承班级结构/教师分配/课表）
    → [创建]
      ⚠️ 轮转提醒：学期结束前提示升年级操作

  → [轮转提醒]
    "当前学期将在2026-07-05结束。系统将自动执行升年级操作
    （四→五、五→六、六→毕业）。请确认班级分配和教师安排。"

  → [升年级操作]（学期结束后自动触发，教务员可提前预览）
    ├── 系统自动计算升年级方案
    │   一年级→二年级、二年级→三年级、...、六年级→毕业
    ├── [预览升年级结果] → 展示每个班级的新年级+学生数
    │   ⚠️ 异常：毕业班 → 学生数据归档，教师释放
    ├── [手动调整] → 个别学生留级/跳级处理
    ├── [确认执行] → 二次确认弹窗
    │   "确认执行升年级操作？此操作不可撤销。"
    │   → 班级年级更新 → 教师锚点自动更新
    └── 升年级完成后 → 通知全校教师更新班级认领
      ⚠️ 异常：教师未重新认领 → 学期开始前弹窗提醒
```

---

## 异常路径

| 场景 | 处理 |
|------|------|
| 班主任唯一性冲突 | 弹窗提示已有班主任，确认是否替换 |
| 教师时间冲突 | 添加课程时检测该教师是否已在同时段被分配 |
| 学期轮转异常 | 毕业班学生自动归档，教师分配需重新确认 |
| 班级删除 | 检测是否有学生/教师关联，有则提示不可删除 |
