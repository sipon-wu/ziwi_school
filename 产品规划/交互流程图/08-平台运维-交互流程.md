# 平台运维（platform_devops）— 交互流程图

> 角色：平台运维 | 来源：产品规格 0703-v6 §1.2
> 版本：v1.0 | 日期：2026-07-04 | 作者：品姐

---

## 角色概述

平台运维独立登录，负责系统级运维管理。侧边栏包含：运维Dashboard/系统监控/日志管理/性能管理/安全管理/告警配置。跨学校平台级视角，专注于系统稳定性、性能优化和安全监控。

---

## 1. 系统监控 — 实时监控流程

```
[平台运维] → [系统监控]

  → [服务状态指示灯]（5个服务）
    ├── API服务：🟢 P99:42ms · 正常
    ├── AI服务：🟢 P99:1.2s · 正常
    ├── 数据库：🟢 P99:8ms · 正常
    ├── Redis：🟡 内存使用78%（接近80%阈值）
    └── Nginx：🟢 QPS:1,284 · 正常
    └── 异常服务：🔴 红色闪烁动画

  → [核心指标]
    QPS峰值(1,284,↑12%) / P99延迟(42ms) / 错误率(0.12%) / CPU·内存(62%/78%)

  → [趋势图]
    ├── QPS/P99/错误率 24h趋势（折线图，三指标）
    └── CPU/内存使用率 24h趋势（面积图）

  → [实时告警列表]
    ├── ⚠警告：Redis内存使用率达到78%
    ├── ℹ信息：AI服务响应时间恢复正常
    └── ℹ信息：数据库自动备份完成
    └── 时间范围切换：最近24h/7天/30天

  → [操作日志]
    时间/操作者/操作/详情/状态
    ├── Token调整记录
    ├── 用户管理操作
    ├── 自动备份记录
    └── 服务重启记录
```

---

## 2. 日志管理 — 日志查询流程

```
[平台运维] → [日志管理]

  → 集中日志查询
    ├── 筛选：按时间/服务/日志级别(INFO/WARN/ERROR)
    ├── 关键词搜索
    └── 日志详情展开

  → 告警配置
    ├── 设置告警阈值（CPU>80%/内存>80%/错误率>1%）
    ├── 告警通知方式（微信/邮件/短信）
    └── 告警静默时段配置
```

---

## 3. 性能管理 — 性能优化流程

```
[平台运维] → [性能管理]

  → 资源使用率监控
    ├── CPU/内存/磁盘/网络实时数据
    └── 历史趋势图

  → 自动扩缩容配置（二期）
  → 性能瓶颈分析
```

---

## 4. 安全管理 — 安全审计流程

```
[平台运维] → [安全管理]

  → 权限审计
    ├── 异常登录检测
    ├── 敏感操作审计（批量导出/权限变更）
    └── 安全事件告警

  → 安全策略配置
    ├── IP白名单
    ├── 登录失败锁定策略
    └── 会话超时配置
```

---

## 5. 数据备份 — 备份管理流程

```
[平台运维] → [数据备份]

  → 备份策略管理
    ├── 全量备份：每日02:00，保留30天（pg_dump -Fc + AES-256加密）
    ├── WAL连续归档：实时，保留7天
    └── 快照备份：每周日，保留12周

  → 备份状态监控
    ├── 最近备份时间/大小/状态
    └── ⚠️ 备份失败告警

  → 灾难恢复
    ├── RPO ≤ 1小时 / RTO ≤ 2小时
    └── 恢复演练记录
```

## 加载态

| 场景 | 加载态表现 | 降级方案 |
|------|----------|---------|
| 监控大盘加载 | 5个服务指示灯+核心指标+趋势图骨架屏 | 加载失败→错误态+重试 |
| 日志查询加载 | 日志列表骨架屏 | 超时→缩小时间范围重试 |
| 性能数据加载 | 图表骨架屏 | 加载失败→显示上次缓存数据+刷新按钮 |
| 备份状态刷新 | 状态卡片骨架屏 | 加载失败→显示上次备份时间+重试 |

## 空态

| 场景 | 空态表现 |
|------|---------|
| 无告警 | "当前无活跃告警，系统运行正常" ✅ |
| 无操作日志 | "所选时间范围内无操作记录" |
| 无备份记录 | "暂无备份记录，请配置备份策略" + 快捷入口 |

## 异常路径

| 场景 | 处理 |
|------|------|
| 服务宕机 | 🔴红色闪烁告警 → 自动通知运维人员（微信/短信） |
| 备份失败 | 告警 + 自动重试 → 连续失败3次升级为紧急告警 |
| Redis内存超80% | ⚠黄色告警 → 建议扩容或清理缓存 |
| 异常登录检测 | 记录审计日志 + 告警通知 |
| 监控数据获取失败 | 错误态：显示重试按钮 |
