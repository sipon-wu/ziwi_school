# 平台运营（platform_ops）— 交互流程图

> 角色：平台运营 | 来源：产品规格 0703-v6 §1.2 + §1.4
> 版本：v1.0 | 日期：2026-07-04 | 作者：品姐

---

## 角色概述

平台运营独立登录，负责全网运营管理。侧边栏包含：运营Dashboard/Token管理/License管理/公告管理/教材审核/教材版本库/财务对账/发票管理/客服工单。跨学校平台级视角。

## 1. Token管理 — 配额管理流程

```
[平台运营] → [Token管理]

  → [统计卡片]
    本月总消耗(12.8M) / 接入学校(47) / 预警学校(5) / 已耗尽学校(2) / 工作请求占比(94.2%)

  → [图表区]
    ├── 月度Token消耗趋势（近6月折线图）
    └── 学校用量排行 Top 10（条形图+进度条）

  → [学校用量明细表格]
    ├── 列：学校/本月已用/总额度/使用率(进度条)/有效期/状态/操作
    ├── 筛选：按状态(正常/预警/已耗尽)/时间段
    ├── 状态：正常(绿色)/预警(黄色>70%)/已耗尽(红色>80%)
    ├── [调整额度弹窗]
    │   学校/调整类型(追加/扣减/重置)
    │   调整数量(Token) / 有效期 / 备注
    │   → [确认调整] → 立即生效
    │     ⚠️ 异常：扣减后低于已用量 → 提示"扣减额度不能低于已用量"
    └── [导出报表] → 下载Excel

  → [最近充值记录]
    学校/充值额度/操作人/时间/备注
```

## 2. License管理 — 授权管理流程

```
[平台运营] → [License管理]

  → [统计卡片]
    授权学校总数(47) / 即将到期(8) / 已过期(3) / 本月续费(12)

  → [License列表]
    ├── 正常卡片（绿色图标 + 版本标签）
    │   学校/版本(标准版/专业版/旗舰版)/到期日期/教师数/学生数
    │   操作：续费/升级/停用
    ├── 即将到期卡片（黄色左边框 + ⚠图标）
    │   到期提醒：剩余42天，已发送提醒（第2次）
    │   操作：续费（优先）/升级
    └── 已过期卡片（红色左边框 + 半透明）
        已过期64天 → 操作：续费/停用

  → [新增授权弹窗]
    选择学校/版本选择（标准版¥9,800/专业版¥19,800/旗舰版¥39,800）
    起始日期/到期日期/备注
    → [确认授权] → License生效

  → License到期三级提醒机制
    ├── 到期前30天 → 第1次提醒
    ├── 到期前15天 → 第2次提醒
    ├── 到期前3天 → 第3次提醒（紧急）
    └── 到期后 → 禁止新建内容，已发布内容只读可访问

  → 续费流程
    [续费] → 选择续费时长 → [确认] → License延长
    [升级] → 选择目标版本 → 差价计算 → [确认升级]
    [停用] → 二次确认 → License立即失效
```

## 3. 公告管理 — 通知发布流程

```
[平台运营] → [公告管理]

  → [公告列表表格]
    公告标题/发布时间/状态(已发布/已下架)/阅读量/操作

  → [新建公告弹窗]
    公告标题/公告内容（富文本编辑器：加粗/斜体/标题/列表/链接/图片）
    发布范围（全部学校/指定学校/仅内部可见）
    立即发布（勾选）/保存为草稿（不勾选）
    → [发布] → 所有学校首页通知栏显示
```

## 4. 教材审核 — 内容审核流程

```
[平台运营] → [教材审核]

  → Tab 1: [待审核]
    ├── 审核卡片列表
    │   教材名称/提交学校/提交人/学科/年级/提交时间
    │   AI自动审核结果（✅已通过 / ⚠待确认）
    ├── [通过] → 版本发布至平台版本库
    ├── [退回] → 退回原因弹窗 → 通知提交教师
    │   ⚠️ 常见退回原因：版权问题/内容重复/格式不符合要求
    └── [查看详情] → 教材详情 + AI审核报告

  → Tab 2: [已通过]
    └── 已审核通过的教材列表

  → Tab 3: [已退回]
    └── 已退回的教材 + 退回原因
```

## 5. 教材版本库管理（平台级）— 版本库维护流程

```
[平台运营] → [教材版本库]

  → [统计卡片]
    已发布版本(48) / 待审核(7) / 学校自编(23) / 已下架(5)

  → [版本列表]
    ├── 平台标准版本（蓝色标签）
    ├── 学校自编已通过版本
    └── 待审核版本（学校自编，黄色标签）

  → [审核弹窗]
    ├── AI审核结果展示（知识点覆盖率/课标匹配率/建议）
    ├── 审核意见（文本输入）
    ├── 发布范围：仅限提交学校 / 发布至平台版本库
    ├── [审核通过] → 发布
    └── [退回修改] → 附原因 → 通知提交学校

  → [版本使用排行 Top 5]
    版本名称/学科/使用学校数/使用班级数/活跃教师/状态

  → [新增标准版本弹窗]
    版本名称/学科/适用年级/适用学期/版本说明
    上传教材PDF（AI自动提取目录和知识点）
    → [创建并发布] → 立即纳入平台版本库
```

## 7. 发票管理 — 发票处理流程

```
[平台运营] → [发票管理]

  → [统计卡片]
    待处理申请(12) / 本月已开具(48) / 本月开票总额(¥386,500) / 邮寄中(3)

  → Tab 1: [待处理]
    ├── 发票申请卡片（黄色左边框）

    ├── 已开具发票列表（绿色左边框）
    │   发票号/开具日期/类型
    ├── [查看发票] / [重新发送] / [作废]
    └── 纸质发票：快递单号+物流追踪

  → Tab 3: [邮寄跟踪]
    └── 物流时间线：已揽收→运输中→派送中→已签收
```

## 8. 客服工单 — 用户支持流程

```
[平台运营] → [客服工单]

  → [统计卡片]
    待处理(8) / 处理中(5) / 本月已关闭(126) / 满意度(4.6/5)

  → Tab 1: [待处理]
    ├── 工单卡片（紧急红色/普通蓝色/低灰色左边框）
    │   工单号/标题/学校/提交人/时间/优先级/分类
    ├── 优先级：紧急(4h响应)/普通(24h响应)
    ├── 分类：功能问题/使用咨询/Bug反馈/建议/投诉
    ├── [接单处理] → 工单进入"处理中"
    ├── [查看详情] → 查看完整描述
    └── [转派] → 转给其他运营人员

  → Tab 2: [处理中]
    ├── 工单详情含回复面板
    │   回复列表（运营↔用户双向沟通）
    │   输入框 + [回复] 按钮
    ├── [关闭工单] → 确认关闭 → 用户满意度评价
    └── [转派]

  → Tab 3: [已关闭]
    └── 已关闭工单列表 + 满意度评分（★评级）
```

## 异常路径

| 场景 | 处理 |
|------|------|
| Token调整超额 | 扣减后不能低于已用量，提示错误 |
| License重复授权 | 同一学校已有有效License，提示确认 |
| 发票信息不全 | 必填字段（抬头/税号）未填时提示 |
| 教材审核退回 | 必须填写退回原因才能提交 |
| 客服工单超时未响应 | 紧急4h/普通24h超时自动告警 |
