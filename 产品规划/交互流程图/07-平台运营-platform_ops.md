# 平台运营（platform_ops）核心交互流程图

> 版本：v1.0 | 日期：2026-07-04 | 作者：小艺（UI/UX设计师）
> 依据：产品功能规格说明书 0703-v6 + 架构设计 v3.1 + 二期设计稿（Token管理/License管理/公告管理/教材审核/教材版本库管理平台/财务对账/发票管理/客服工单）

## 一、角色定位与入口

```
平台运营 = 独立登录态 + 运营 Dashboard + 全网级管理

权限矩阵：
├── token:* （Token管理）
├── license:* （License管理）
├── finance:* （财务对账）
├── announcement:* （公告管理）
├── content_audit:* （教材/方法论审核）
├── invoice:* （发票管理）
└── customer_support:* （客服工单）

侧边栏：
  Token管理 / License管理 / 公告管理 / 教材审核 / 平台版本库 / 财务对账 / 发票管理 / 客服工单

特点：全网级，跨学校，管理所有学校/校区/教师
```

## 十一、异常路径

### Token预警
```
场景：学校/教师Token即将耗尽
  → 自动发送预警通知（站内+微信）
  → 运营Dashboard显示预警列表
  → 运营可主动联系学校追加配额
```

### License到期
```
场景：学校License即将到期
  → 30天/15天/3天自动提醒
  → 运营可主动联系学校续费
  → 到期后系统自动限制写操作
```

### 审核冲突
```
场景：多个运营人员同时审核同一教材
  → 乐观锁机制：先审核者锁定 → 后审核者提示「已被[姓名]审核」
```

### 数据为空
| 场景 | 处理 |
|------|------|
| 无待审核 | 「暂无待审核内容」 |
| 无工单 | 「暂无客服工单」 |
| 无发票申请 | 「暂无发票申请」 |
