# 教研组长（research_lead）— 交互流程图

> 角色：教研组长 | 来源：产品规格 0703-v6 §1.2.1
> 版本：v1.0 | 日期：2026-07-04 | 作者：品姐

---

## 角色概述

教研组长拥有教师全部权限 + 教研管理权限。侧边栏在教师基础上增加：教研Dashboard/互审池/教研数据看板/模板与方法论/教研活动。运行在学科组坐标系内（如语文组）。

---

## 1. 互审池 — 教案审核管理流程

```
[教研管理] → [互审池]

  → [互审统计卡片]
    待审核(12) / 审核中(8) / 本月通过(34) / 退回修改(5)

  → [待审核列表]
    ├── 筛选：按状态/教师/年级
    ├── 批量操作：勾选→批量分配审核人/批量通过
    ├── [指定审核人] → 从本组教师列表选择
    │   ⚠️ 不可自审规则：审核人不能审核自己提交的教案
    ├── [查看教案] → 教案预览（只读）
    │   → 在线批注工具（高亮/划线/文字批注）
    │   → [通过] → 教案发布到教案发布库
    │   └── [退回修改] → 附退回理由 → 教师端收到通知
    └── [查看进度] → 查看审核中教案的审核人+进度

  → 审核人指定规则（三选一）
    ├── 同年级同科教师互为审核人（系统自动配对）
    ├── 教师提交时自行指定
    └── 教研组长分配（无人指定时）
```

## 2. 教研数据看板 — 质量监控流程

```
[教研管理] → [教研数据看板]

  → [KPI卡片]
    教案通过率(87.5%) / 教师活跃度(92%) / 课标对齐率(89.3%) / 人均批注数(6.8)

  → [图表区]
    ├── 教案质量趋势（近6月折线图：通过率+课标对齐率）
    ├── 教师活跃度分布（柱状图：各教师本月教案提交数）
    └── [教师排行 Top 10]
        排名/教师/学科/教案数/通过率/课标对齐/综合评分

  → [导出报表] → 下载Excel
```

## 3. 模板与方法论 — 教研资产管理流程

```
[教研管理] → [模板与方法论]

  → Tab 1: [教案模板]
    ├── 查看本学科组模板库（平台模板 + 校本模板）
    ├── [上传校本模板] → 创建本校专属教案模板
    └── [创建新模板] → 定义模板结构和适用学科

  → Tab 2: [方法论管理]
    ├── 条目类型：教学策略/课堂活动/评价方式
    ├── 查看本组教师贡献的方法论条目
    ├── [审核通过] → 条目状态变为"已审核"
    ├── [提交平台] → 优秀方法论提交平台运营终审
    │   → 终审通过 → 纳入平台公共知识层，署名贡献教师
    └── [新增条目] → 直接添加方法论内容

  → 方法论贡献机制（B→A）
    小微被动识别高价值教学模式
    → 推荐教师授权共享
    → 教师确认
    → 教研组长审核通过
    → 提交平台运营终审
    → 纳入领域方法论库
```

## 4. 教研活动 — 团队协作流程

```
[教研管理] → [教研活动]

  → [统计概览]
    进行中活动(3) / 本学期已完成(12) / 待开始活动(5)

  → Tab 1: [全部活动]
    ├── 活动卡片列表（共同备课/听评课）
    │   ├── 进行中（绿色左边框）
    │   ├── 待开始（蓝色左边框）
    │   └── 已完成（灰色+半透明）
    └── 每卡片：标题/类型/时间/学科/发起人/参与教师/操作按钮

  → Tab 2: [共同备课]
    ├── 备课卡片网格
    │   标题/学科/参与人数/备课进度条/最近更新
    ├── [进入备课] → 共享教案编辑区
    ├── [查看教案] → 已完成备课的教案详情
    └── [发起活动] → 弹窗：类型/主题/学科/年级/时间/描述/参与教师

  → Tab 3: [听评课]
    ├── 听课评价列表
    │   授课教师/课题/班级/时间/待评人数
    ├── 四维评分：教学目标/课堂互动/AI工具运用/学生参与度
    ├── [提交评价] → 填写评分+评语
    └── [查看评价详情] → 汇总评分+评语摘要

  → [发起活动弹窗]
    活动类型：共同备课/听评课
    活动主题/学科/年级/时间/描述
    参与教师选择（默认全组）
    → [创建] → 通知参与教师
```

## 5. 教师功能（继承）

教研组长同时拥有教师全部功能：教案工作台/草稿箱/发布库/出题题库/组卷试卷库/作业布置/学情分析/成长足迹/家校沟通/素材库/系统设置。

---

## 异常路径

| 场景 | 处理 |
|------|------|
| 无待审核教案 | 空态："暂无待审核教案" |
| 审核人不可自审 | 提交时检测，自己的教案不能分配给自己 |
| 方法论提交平台被退回 | 显示退回原因，教研组长可修改后重新提交 |
| 教研活动参与教师不足 | 至少1人参与，发起人默认参与 |
