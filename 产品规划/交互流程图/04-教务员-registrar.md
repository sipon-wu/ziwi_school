# 教务员（registrar）核心交互流程图

> 版本：v1.0 | 日期：2026-07-04 | 作者：小艺（UI/UX设计师）
> 依据：产品功能规格说明书 0703-v6 + 架构设计 v3.1 + 二期设计稿（班级调度/课程安排/教师管理/学期管理）

---

## 一、角色定位与入口

```
教务员 = 独立登录态 + 教务管理 Dashboard + 全局视角

权限矩阵：
├── class:* （班级管理）
├── course:* （课程安排）
├── teacher_assign:* （教师分配）
├── semester:* （学期管理）
└── system_config:* （学制配置）

侧边栏：
  班级调度 / 课程安排 / 教师管理 / 学期管理

特点：全局视角，不需要班级锚点，所有操作跨班级/跨年级
```

---

## 二、登录与首页

```
[登录] → 身份识别为 registrar
  → 教务管理 Dashboard

Dashboard 内容：
├── 学校概览卡片
│     ├── 班级总数 / 教师总数 / 学生总数
│     ├── 本学期课程数
│     └── 学期进度（已过天数/总天数）
│
├── 待办事项
│     ├── 未分配教师班级数
│     ├── 未指定班主任班级数
│     └── 即将到期的学期
│
└── 快捷入口
      ├── 创建班级
      ├── 分配教师
      └── 学期配置
```

---

## 三、班级调度

```
侧边栏 → 班级调度
  → 班级列表页

班级列表：
├── 按年级分组展示
├── 每个班级：名称 / 类型 / 班主任 / 学生数 / 状态
├── [创建班级]
│     ├── 班级名称（如"四(1)班"）
│     ├── 所属年级（下拉选择）
│     ├── 班级类型（普通班/实验班）
│     ├── 所属校区（多校区学校选择）
│     └── [创建] → 班级生成
│
├── 班级操作
│     ├── 编辑班级信息
│     ├── 删除班级（需确认：该班级下无学生和教师分配）
│     ├── 指定班主任（唯一性约束：每班仅一个班主任）
│     │     └── 选择教师 → [确认] → 自动同步到教师端系统设置
│     └── 升年级操作（学期结束时）
│           └── 四(1)班 → 五(1)班
│
└── 班级数据
      ├── 查看班级学生列表
      ├── 查看班级任课教师
      └── 导出班级花名册
```

---

## 四、课程安排

```
侧边栏 → 课程安排
  → 课程安排总览页

课程安排：
├── 按班级维度：选择班级 → 查看该班课程表
├── 按教师维度：选择教师 → 查看该教师课程表
├── 按学科维度：查看各学科在各班级的分布

[添加课程]
  ├── 选择班级
  ├── 选择学科（语文/数学/英语/...）
  ├── 设定课时（每周几节）
  ├── 选择任课教师
  └── [保存] → 课程生成

岗位排重规则：
系统自动检测：同一教师在同时段被分配到两个班级的同一学科
  → 拦截提示：「[教师姓名] 在 [时段] 已被分配到 [班级名称]」
  → 需调整课程安排
```

---

## 五、教师分配

```
侧边栏 → 教师管理
  → 教师分配列表页

教师分配：
├── 教师列表（姓名/学科/已分配班级）
├── [分配教师]
│     ├── 选择教师（从学校教师池中选择）
│     ├── 选择班级（可多选）
│     ├── 选择学科
│     ├── 设置是否为主教学科
│     └── [确认分配] → 自动同步到教师端「系统设置 → 班级认领」可选池
│
├── 教师班级调整
│     ├── 增加班级 → 同上
│     ├── 移除班级 → 确认弹窗（移除后教师失去该班教学权限）
│     └── 更换学科 → 确认弹窗
│
├── 班主任任命
│     ├── 从已分配该班级的教师中选择
│     ├── 唯一性约束：同一班级只能有一名班主任
│     ├── 指定后自动同步教师端
│     └── [解除班主任] → 选择新班主任 → 确认
│
└── 教师信息
      ├── 查看教师基本信息
      ├── 查看教师任课情况
      └── 查看教师工作量统计
```

## 六、学期管理

```
侧边栏 → 学期管理
  → 学期配置页

学期配置：
├── 当前学期信息
│     ├── 学期名称（如"2026-2027学年第一学期"）
│     ├── 起止日期
│     └── 学期进度条
│
├── [新建学期]
│     ├── 学期名称
│     ├── 起止日期选择
│     ├── 学期类型（上学期/下学期）
│     └── [创建] → 新学期待生效
│
├── 学制配置
│     ├── 六三制 / 五四制 切换
│     ├── 切换确认：「切换学制将影响班级年级体系，确认切换？」
│     └── 切换后自动调整年级命名
│
├── 校历配置
│     ├── 节假日设置
│     ├── 考试周设置
│     ├── 家长会日期
│     └── 其他重要日期标记
│
├── 学期轮转（学期结束后自动触发，教务员可提前预览）
│     ├── 系统自动计算升年级方案
│     │     ├── 一年级→二年级、二年级→三年级、…、六年级→毕业
│     │     └── 九年级→毕业
│     ├── [预览升年级结果] → 展示每个班级的新年级+学生数
│     │     ⚠️ 异常：毕业班 → 学生数据归档，教师释放（解除班级绑定）
│     ├── [手动调整] → 个别学生留级/跳级处理
│     ├── [确认执行] → 二次确认弹窗
│     │     └── 「确认执行升年级操作？此操作不可撤销。」
│     │     → 班级年级更新 → 教师锚点自动更新
│     ├── 升年级完成后 → 通知全校教师更新班级认领
│     │     ⚠️ 异常：教师未重新认领 → 学期开始前每日弹窗提醒
│     ├── [毕业班处理] → 九年级/六年级毕业班标记为已毕业
│     └── [新一年级] → 创建新一年级班级
│
└── 学期归档
      ├── 归档当前学期数据（教案/试卷/成绩）
      └── 归档后只读可查
```

## 七、数据同步

```
教务员操作 → 自动同步到教师端

同步链路：
班级创建 → 教师端「系统设置 → 班级认领」可选池
教师分配 → 教师端自动显示已认领班级+学科
班主任任命 → 教师端身份切换为班主任
学期轮转 → 教师端班级锚点更新
学制切换 → 教师端知识图谱年级范围更新
```

## 八、异常路径

### 班主任唯一性冲突
```
场景：尝试为已有班主任的班级再指定班主任
  → 系统拦截：「该班级已有班主任[教师姓名]」
  → 需先解除原班主任，再指定新班主任
```

### 教师排重冲突
```
场景：同一教师在同时段被分配到两个班级的同一学科
  → 系统拦截：展示冲突详情
  → 教务员调整课程安排
```

### 毕业班处理
```
场景：学期结束时九年级/六年级班级
  → 系统提示：「以下班级为毕业班，确认后学生将标记为已毕业」
  → 教务员确认 → 毕业生数据保留3年后自动脱敏
```

### 数据为空
| 场景 | 处理 |
|------|------|
| 无班级 | 「暂无班级，创建第一个班级吧」 |
| 无教师可选 | 「教师池为空，请联系IT管理员添加教师账号」 |
| 无课程 | 「为班级添加课程安排」 |
