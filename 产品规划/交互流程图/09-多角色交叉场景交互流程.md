## 场景1：教案审核链（教师 → 教研组长）

```
[教师] 教案工作台
  → [发布] → 检测互审状态
      ├── 互审关闭 / 自动审核勾选 → 直接发布 ✅
      └── 互审开启 → [提交送审]
            → 审核人指定（三选一）
            │   ├── 系统自动配对：同年级同科教师随机互为审核人
            │   ├── 教师自行指定：从同科教师列表选择
            │   └── 教研组长分配：无人指定时
            → 教案状态变为「待审核」
            → 教师端「我的送审」列表显示

[教研组长] 教案互审池
  → 查看待审核列表（教案标题/提交人/提交时间）
  → [分配审核人]（无人指定时）
      └── 从同科教师列表选择 → 确认分配
  → [查看教案详情] → 只读预览
  → 在线批注（高亮/划线/文字批注）
  → 判定：
      ├── [通过] → 教案发布到教案发布库 → 通知教师
      └── [退回修改] → 填写退回理由 → 通知教师

[教师] 被退回处理
  → 我的送审 → 被退回列表
  → 点击 → 直接唤起教案工作台，加载原稿
  → 修改 → [重新提交送审]
  → Toast「已重新提交，请等待审核」

⚠️ 不可自审：审核人不能审核自己提交的教案
⚠️ 审核超时：超过N天未审核 → 自动提醒审核人 → 教研组长可重新分配
```

## 场景2：自编教材审核链（教师 → AI → 平台运营）

```
[教师] 系统设置 → 教材版本下拉
  → 点击「未找到版本？申请新增」
  → 上传教材PDF
  → AI自动提取目录结构和知识点
  → 系统自动审核通过 → 立即可供该教师使用
  → 同步通知平台运营人工审核

[平台运营] 教材审核
  → 待审核列表 → 查看教材详情
  → AI审核结果展示（知识点覆盖率/课标匹配率）
  → [审核通过] → 纳入平台版本库
      ├── 发布范围：全校可选 / 全网可选
      └── 通知教师 + IT管理员
  → [审核退回] → 填写退回原因 → 通知教师修改

[IT管理员] 教材版本选择池（同步更新）
  → 教师申请的自编版本状态：⏳待平台审核
  → 审核通过后 → 自动纳入本校选择池 → 状态变为「已启用」
```

## 场景3：作业批阅链（教师 → 学生 → AI → 教师 → 家长）

```
[教师] 作业布置
  → 选择班级+学科 → 选题 → 设置截止时间 → [发送]
  → 作业状态：已发布

[学生] 学生端
  → 待完成作业列表 → 点击进入
  → 拍照/输入提交答案 → [提交]
  → 提交状态更新

[AI服务] 自动批阅（学生提交后触发）
  → 客观题：自动比对答案 → 自动批改
  → 主观题：AI提取关键词 → 预打分
  → 低置信度标记：<85% → 红色高亮
  → 手写识别：单字<70%标记待确认，整篇<60%推送人工复核

[教师] 批阅工作台（三栏布局）
  → 左栏：学生列表（按提交时间/批改状态排序）
  → 中栏：批阅内容
      ├── AI批改结果展示
      ├── 低置信度题目红色高亮
      ├── 作文：AI预评分 / 教师确认分（双字段）
      └── [确认批改] / [修改分数]
  → 右栏：小微AI助手
  → 进度条：18/42
  → 快捷键：← → 切换学生 / Enter 确认 / Tab 切换题目
  → 批量操作：一键标记已阅 / 一键退回低置信度 / 批量催交

[系统] 批阅完成后自动触发
  → 错题归集：按知识点归类 → 存入学生错题本
  → 家长报告生成：综述版 + 详细版

[家长] 家长端小程序
  → 收到红点提醒 → 点击进入小程序
  → 查看报告（综述版：掌握/巩固/突破 + 3条建议）
  → 点击展开详细版（错题列表/原题对比/同类巩固练习）
  → [确认已查看] → 签字完成
  → 可选：在周报页面留言

⚠️ 自愿原则：家长可签可不签，未签字无系统级后果
⚠️ 免打扰时段：22:00-7:00（逾期未交紧急通知不受限制）
```

## 场景4：成长关爱链（教师/班主任 → 小微AI → 教师 → 家长）

```
[教师] 成长足迹
  → 学生详情页 → [纳入成长关爱]
  → 确认弹窗：展示当前学情概览（正确率/薄弱知识点/近期趋势）
  → 教师基于专业判断确认
  → 小微自动标记该生学情数据波动详情

[小微AI] 每周自动
  → 检索该生学情数据
  → 结合教师观察记录
  → 生成个性化提升方案草案
      本周聚焦 / 练习安排（题型/题量/预计用时）/ 学习任务 / 教师建议

[教师] 方案审阅
  → 方案草案列表 → 查看详情
  → 操作：
      ├── [确认] → 提交
      ├── [修改] → 调整练习内容或频次
      ├── [补充观察] → 添加教师建议（发送给家长）
      └── [退回重生成] → 小微重新生成
  → 提交前 → 触发教育善意度审查弹窗
      ├── 禁止比较性表述（「远低于班级平均」）
      ├── 禁止绝对化判断（「基础很差」）
      └── 必须配合建设性建议

[家长] 家长端
  → 入组通知 → [确认] → 开始执行
  → 每周收到学情周报
  → 可在周报页面留言 → 教师查看并回复
  → 每学期末 → 续期确认邀请

⚠️ 严禁标签化：不存储任何标签字段
⚠️ 分组名称不外显、不导出给家长
⚠️ 小学方案：每周3-4次，每次10-15分钟
⚠️ 初中方案：每周4-5次，每次20-30分钟
```

## 场景5：License过期保护链（平台运营 → 系统 → 全校 → 平台运营）

```
[平台运营] License管理
  → [签发License] → 选择学校/套餐/有效期 → 签发
  → [续费License] → 延长有效期 → 更新

[系统] 自动提醒Cron（每日凌晨扫描）
  → 到期前30天 → 第1次提醒（平台运营 + 学校IT管理员 + 校长Dashboard）
  → 到期前15天 → 第2次提醒
  → 到期前3天 → 第3次提醒（紧急）
  → 到期当天 → 自动切换状态为expired

[全校教师] License过期后
  ❌ 禁止：新建/编辑教案、新建题目、新建试卷、布置作业
  ❌ 禁止：上传素材、小微对话（消耗Token）、批阅确认
  ❌ 禁止：成长关爱方案确认
  ✅ 允许：查看所有已发布内容、导出数据、查看学情报告
  → 操作按钮禁用 + Tooltip「License已过期，仅支持查看已有内容」

[平台运营] 续费处理
  → License列表 → 选择到期License
  → [续费] → 选择续费时长 → [确认]
  → License恢复 → 全校教师恢复全部功能
```

## 场景6：方法论贡献链 B→A（小微识别 → 教师授权 → 教研组长 → 平台运营）

```
[小微AI] 被动识别（后台自动）
  → 从教师使用数据中识别高价值教学模式
  → 推荐教师授权共享
      展示摘要：「您在分数教学上的三步法模式独特，是否愿意分享给本校同级科任教师？」

[教师] 收到授权请求
  → [确认共享] → 进入审核流程
  → [拒绝] → 结束

[教研组长] 模板与方法论 → 方法论管理
  → 待审核列表 → 查看方法论详情
  → [初审通过] → 提交平台运营终审
  → [初审退回] → 填写退回理由 → 通知教师

[平台运营] 教材审核 / 方法论审核入口
  → 教研组长初审通过后 → 待终审列表
  → [终审通过] → 纳入领域方法论库
      ├── 署名贡献教师
      ├── 共享范围：本校/全网
      └── 通知贡献教师
  → [终审退回] → 填写退回理由 → 返回教研组长
```

## 场景7：班级创建同步链（教务员 → 教师）

```
[教务员] 班级调度
  → [创建班级]
      年级/班级名称/类型/班主任（可选）/开设科目（多选）
  → [创建] → 班级生成
  → 自动同步到教师端「系统设置 → 班级认领」可选池

[教师] 系统设置 → 学校与班级管理
  → 认领班级 → 选择教务员创建的班级
  → 认领学科 → 绑定教材版本
  → [保存] → 班级锚点生效
  → 全平台上下文更新（小微/知识图谱重新锚定）

[教务员] 教师分配（后续操作）
  → 教师管理 → [分配教师] → 选择班级+学科+教师
  → 保存 → 教师端自动显示已认领班级+学科
```

## 场景8：Token配额管理链（平台运营 → 教师 → 系统预警 → 平台运营）

```
[平台运营] Token管理
  → [调整配额] → 选择学校/教师 → 输入新配额 → 确认
  → 配额调整记录（时间/操作人/调整量/原因）

[教师] 日常使用消耗
  → 每次AI操作消耗Token：
      教案生成 / 出题组卷 / 小微对话 / AI批阅 / 风格训练
  → 顶部栏实时显示剩余配额百分比

[系统] 自动预警
  → Token使用率达到预警阈值（默认10%）
      → 教师端弹窗提醒：「您的Token配额即将用尽，剩余X%」
  → Token耗尽
      → 顶部栏红色提示 + 生成按钮禁用
      → 引导充值 / 联系管理员

[平台运营] 监控与追加
  → Token管理 → 查看预警学校/教师
  → [追加额度] → 输入追加量 → 确认
  → 查看无效算力消耗统计 → 优化配额策略
```

## 场景9：教师离职交接链（教师 → IT管理员 → 继任教师）

```
[教师] 个人中心 → 离职交接
  → 确认离职信息
  → 系统展示待移交资产清单：
      教案(N篇) / 素材(N个) / 题库(N题) / 试卷(N份) / 作业记录(N条) / 学生数据

[IT管理员] 用户管理
  → 选择离职教师 → [禁用账号]
  → [指定继任者] → 从教师列表选择继任教师
  → [确认移交] → 二次确认弹窗
      「确认将XX教师的所有教学成果移交给YY教师？」
  → 移交完成

[系统] 自动处理
  → 教学成果移交：
      ├── 教案/素材/题库/试卷/作业 → 移交继任者（可编辑/使用）
      └── 学生数据（成长足迹/学情报告）→ 移交继任者（只读关联）
  → 风格蒸馏成果归档（属于个人信息，不转移）
  → 手机号冻结（离职后不可修改，满1个月后可重新分配）
  → 通知继任教师

[继任教师] 接收通知
  → 查看接收的教学资产
  → [确认接收] → 资产纳入个人工作台
  → ⚠️ 提示：「原教师的小微风格已归档，建议您自行训练小微以获得个性化体验」
```

## 场景10：学期轮转链（教务员 → 系统 → IT管理员 → 全校教师）

```
[教务员] 学期管理
  → [创建新学期]（如2026-2027第一学期）
  → 设置起止日期
  → 勾选「自动继承班级结构/教师分配/课表」
  → [创建] → 新学期生成

[系统] 当前学期结束后自动触发
  → 自动计算升年级方案：
      一年级→二年级、二年级→三年级、…、六年级→毕业、九年级→毕业
  → 毕业班学生数据归档（毕业后保留3年）
  → 毕业班教师释放（解除班级绑定）
  → 升年级结果生成预览

[IT管理员] 系统配置 → 学期轮转配置
  → [预览升年级结果] → 查看每班新年级+学生数
  → [手动调整] → 个别学生留级/跳级处理
  → [确认执行] → 二次确认弹窗（不可撤销）
      「确认执行升年级操作？此操作不可撤销。」
  → 班级年级更新

[全校教师] 收到通知
  → 「新学期已创建，请更新班级认领」
  → 系统设置 → 学校与班级管理
  → 班级锚点自动更新为新年级（如四(1)班→五(1)班）
  → 确认认领 → 新班级锚点生效
  → ⚠️ 异常：教师未重新认领 → 学期开始前每日弹窗提醒
```
