## 0. 背景与问题

现状 H5 课件（代码库 `exportH5.ts`）能力偏弱：
- 互动只有 **reveal + quiz** 两种，且只能从提纲 `notes` 派生，教师无法手动挂；
- 视觉写死深蓝背景，相对 PPT 模板"不够炫"；
- 后端 `Material` 无 H5 容器字段，规格规划未落库。

用户判断（已对齐）：**只有 reveal/quiz 的 H5 与"PPT 加动画"无本质区别**。H5 不可替代价值在"活的"——能播/翻/弹/交互 + 投屏与手机扫码同款横屏随身看。

本期目标：把 H5 互动做成一等公民组件，**不引入自由画布/像素定位**（微媒工作台思路，school 用不到），用户只选组件+传素材+启用，布局皮肤系统自动。

---

## 1. 技术路线总纲（已定型）

**"插槽式组件化"，不是"画布式"。**
- 互动锚定提纲页 `OutlineSlide.interactive`，非绝对定位画布；
- 用户只产出"类型+内容 URL"，不产出坐标/尺寸；
- 布局皮肤由 `exportH5.ts` 呈现策略机制自动决定；
- PPT/Word/PDF 导出忽略 `interactive`，保持同源不裂。

## 2. 互动组件枚举（已定型）

### 第一档：本期做（纯前端、无后端实时依赖）
| 组件 | 教学用法 | 用户操作 |
|---|---|---|
| 音频 audio | 课文朗读/听力/背景乐 | 上传或素材库选音频 URL |
| 视频 video | 实验演示/微课/名家朗读 | 上传或素材库选视频 URL |
| 图册 gallery | 美术欣赏/文物/生物图谱 | 素材库多选图片 URL，选横/竖滑动 |
| 按钮+弹层 popup | 拓展阅读/知识卡 | 填触发文字 + 弹层内容 |
| 随堂选择题 quiz | 全班即时反馈（已有，扶正） | 填题干+选项+正确项 |
| 点击揭示 reveal | 答案翻牌（已有，扶正） | 填揭示引导 + 答案 |
| **点读 readalong（句粒度）** | 英语/语文整句朗读（按标点断句，句粒度绑音频） | 启用整页 → 系统按标点断句 → 每句上传/勾选音频 |

> **不做学科硬分流**：readalong 入口全开放，但 UI 加场景说明"适用于单词/课文/拼音点读"，不预设隐藏。
> **readalong 降级为句粒度**（V2.1 修订）：V2.0 的"逐字切分"经评审确认教师不可用（30 字=30 次上传），改为按标点（。！？；.）断句，句粒度绑音频，成本降一个数量级。

### 第二档：本期缓做（P2）
班级投票 / 表单作答回传 / 拖拽连线 / 倒计时计时器。

### 明确不做
轮播广告、地图、日期等微媒营销组件。

## 3. 素材链路（V2.1 修订：后端需补 1 行静态路由）

后端 `UploadMaterial`（`material_handler.go:47`）已存在，接收 `file` 存 `uploads/`，返回 `Material{URL:"/uploads/xxx"}`。**但经评审发现 `main.go` 未注册 `/uploads/` 静态路由**，扫码访问时资源 404。

- **上传**：前端选文件 → `POST /api/materials/upload` → 取 `URL`（相对 `/uploads/xxx`）→ 写入 `interactive.src/images`；用户无感。
- **从素材库选**：`GET /api/materials?type=image|audio|video` 勾选。
- **存储**：提纲 `interactive` 只存素材库 URL，不存 dataURL。
- **⚠ 修订点 A（HOST 运行时化）**：`exportH5.ts` 的 `abs(url)` **不能**用 `location.origin` 在导出时求值（会写死教师端域名，下载 file:// 或扫码跨域即裂）。改为 HTML 运行时求值：`new URL(src, location.href).href`——扫码在服务器域、下载在本地均正确。
- **⚠ 修订点 B（静态路由）**：`main.go`（~246 公开路由处）补 `r.Static("/uploads", "./uploads")`，否则 §10"扫码可开"必红。本期后端**新增 1 行静态路由**（非零新增，但须如实记录）。

## 4. 呈现策略机制（动态装配，已定型）

6 维策略原语：媒体 / 排版 / 互动 / 皮肤 / 端适配 / 学科。套路不写死，按素材+会话要求+学科语义动态装配。本期不做固定大模板库。

### 4.3 端适配（V2.1 修订：规则判定，非 AI）
经评审，"AI 判定竖屏"无契约、不可测。改为**确定性规则判定**（AI 留 P2）：
- **判定规则**：若页面含 `video` / `gallery` / `readalong` ⇒ `portraitHint=false`（提示"建议横屏使用"）；其余（纯文字/reveal/quiz/audio/popup）⇒ 不提示，自适应竖屏。
- 不强制横屏：仅按规则轻提示。

## 5. 版式律（V2.1 数值化，编码级）

经评审，V2.0 伪代码无数值、不可测。改为**写死判定表**：

```
layoutSlide(slide, theme):
  若 slide.isTitle: return coverLayout(slide)          # 封面页纯净，不挂组件
  hasMedia = interactive.type in {video, gallery}      # 媒体主导判定
  媒体占比 = hasMedia ? 60% : 0%                        # 媒体主导页媒体区 60%/文字 40%；纯文字页隐藏媒体区
  结构:
    <div class="h5-title">title</div>
    <div class="h5-points">points</div>                # 文字要点恒上半区
    [if hasMedia] <div class="h5-media">renderMedia</div>   # 媒体区（video/gallery 放大）
    <div class="h5-interactive">renderInteractive</div> # 互动区下半区统一容器
    <div class="h5-popup-layer"></div>
  若 portraitHint==false: 前置 <div class="h5-orient-tip">建议横屏使用 ↻</div>
```

皮肤只控配色/圆角/阴影/字号/进度条（3 套：ocean/vibrant/fresh），不控布局。

## 6. 数据结构（V2.1 修订：持久化通道 + 显式校验 + XSS）

### 6.1 提纲层 `OutlineSlide.interactive`（exportPptx.ts ~225）
```ts
export type H5Component =
  | { type:'reveal';  prompt?:string; answer:string }
  | { type:'quiz';    question:string; options:string[]; correct:number }
  | { type:'audio';   src:string; title?:string }
  | { type:'video';   src:string; poster?:string }
  | { type:'gallery'; images:string[]; direction?:'h'|'v' }   // 空数组/坏URL降级为纯文字
  | { type:'popup';   triggerText:string; content:string }     // content 经 esc 后入 DOM（富文本本期不吃）
  | { type:'readalong'; sentences:{ text:string; src:string }[] } // 句粒度（按标点断句）

export interface OutlineSlide {
  title:string; bullets:string[]; notes?:string; layout?:string; elements?:CwElement[];
  interactive?: H5Component
}
```

### 6.2 ⚠ 持久化通道（V2.1 最关键修订，V2.2 加固）
经评审确认：`outlineToMarkdown`（exportPptx.ts:301）只序列化 title/bullets/notes/elements，`interactive` 经"保存→重开"会丢失（回填走 `markdownToOutline`）。**必须加往返**。

⚠ **V2.2 加固（@技哥 复审打回点）**：原 V2.1 计划"裸 `JSON.stringify` 仿 `CW-EL` 进 `<!-- -->`"——经查 `CW-EL` 本身也是裸 stringify，但 elements 多为数字侥幸没炸；`interactive` 含 `-->`（popup 教师粘贴内容/文件名）、含 `\n`（题干/备注换行），裸放注释会**截断**或**正则贪婪失败**，`markdownToOutline` 的 `catch` 还会**静默吞** → 用户"保存后互动没了且无提示"。故：

- `outlineToMarkdown`：`if (s.interactive) lines.push('<!-- CW-IT:'+ b64enc(s.interactive) +' -->')`，其中 `b64enc = btoa(unescape(encodeURIComponent(JSON.stringify(x))))`（base64 化，彻底规避 `-->`/换行/引号问题）；
- `markdownToOutline`（~243）：`const itMatch = line.match(/^<!--\s*CW-IT:([A-Za-z0-9+/=]+)\s*-->$/)` → 命中则 `try { cur.interactive = JSON.parse(decodeURIComponent(escape(atob(itMatch[1])))) } catch(e){ reportPersistError('CW-IT 解析失败', e) }`（**失败上报，不静默吞**）；
- `interactive_slots` 后端字段仅作"发布时摘要快照"，不参与回填（持久化靠 CW-IT base64 往返）。

> 注：`CW-EL` 同期建议一并改为 base64（同隐患），属顺手修复，不在本期主路径但编码时一并做。

### 6.3 H5 渲染层（exportH5.ts）
```ts
// 替换原 H5Interactive；abs 内嵌 esc，防 XSS
function abs(url:string):string {
  if (!url) return ''
  const safe = url.startsWith('/uploads/') ? new URL(url, location.href).href : url
  return esc(safe)   // 转义后入属性，防 javascript:/引号注入
}
function isValidComponent(it:any):boolean {
  return it && typeof it.type==='string' && ['reveal','quiz','audio','video','gallery','popup','readalong'].includes(it.type)
}
function renderInteractive(it: H5Component|null|undefined): string {
  if (!isValidComponent(it)) return ''   // ⚠ 显式校验，替代 ?? 静默丢互动
  switch (it.type) {
    case 'reveal': ...
    case 'quiz': ...
    case 'audio': return `<audio controls src="${abs(it.src)}">${esc(it.title||'音频')}</audio>`
    case 'video': return `<video controls ${it.poster?`poster="${abs(it.poster)}"`:''} src="${abs(it.src)}"></video>`
    case 'gallery': /* images.map(img=>`<img src="${abs(img)}">`)；空数组→''；容器加 onpointerdown=stopPropagation 隔离全局翻页手势 */
    case 'popup': return `<button class="h5-popup-btn" onclick="togglePopup(this)">${esc(it.triggerText)}</button>
                         <div class="h5-popup-mask" onclick="togglePopup(this)"><div class="h5-popup-box">${esc(it.content)}</div></div>`
    case 'readalong': /* sentences.map(s=>`<span class="rd" data-src="${abs(s.src)}" onclick="playRd(this)">${esc(s.text)}</span>`) */
  }
  return ''
}
```
**⚠ 手势隔离**：gallery 容器 `stopPropagation` 全局 `touchstart` 翻页监听（exportH5.ts:184），否则滑动图片会误翻页。
**⚠ XSS**：`abs()` 转义后入属性；`popup.content`/`readalong.text` 经 `esc()`（富文本本期不吃，避免注入）。

### 6.4 派生桥 `buildH5Slides`（CoursewareBuilder.tsx ~371，显式校验）
```ts
const buildH5Slides = (): H5Slide[] => cwOutline.map((s,i) => {
  const bs = s.elements?.length ? extractBullets(s.elements) : (s.bullets||[])
  // 手动插槽优先；null=显式无互动；残缺对象经 isValidComponent 过滤
  const interactive = isValidComponent(s.interactive) ? s.interactive
    : (s.notes ? { type:'reveal', prompt:'点击揭示：教师讲解要点', answer:s.notes } : null)
  return { title:s.title, points:bs, body:'', isTitle:i===0, interactive }
})
```

## 10. 验证计划（staging，不动生产）

扩展 `qa/verify_h5_interactive.cjs`，补充评审要求的缺失用例：
- **7 组件渲染**：audio/video 可播、gallery 可滑动（断言 scrollLeft 变化，非 waitForTimeout）、popup 可弹、quiz 可答、reveal 可翻牌、readalong 点句播音（断言 `playRd` 被调 + `data-src` 正确，不断真实出声）；

- **PPT 导出快照**：含 interactive 的提纲导出 pptx，页数/文本与无 interactive 一致（验证同源不裂）；

- **gallery 降级**：空数组/坏 URL → 不崩溃、纯文字；
- **HOST 运行时**：导出 HTML 在 staging 域 `/api/materials/:id/h5` 打开，`/uploads/` 资源用运行时 `location.href` 解析正确。
