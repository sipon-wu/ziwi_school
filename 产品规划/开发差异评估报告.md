## 零、整体技术架构

```
┌──────────────────────────────────────────────────────┐
│  Frontend (React 18 + TS + Vite + Tailwind + G6)     │
│  Port :5173 dev                                       │
├──────────────────────────────────────────────────────┤
│  Nginx (端口 80/443, 反代 + 静态资源)                 │
├──────────────────────┬───────────────────────────────┤
│  Backend (Go 1.22)   │  AI Service (Python FastAPI)  │
│  Gin + GORM          │  Qwen + LangChain + pgvector  │
│  Port :8080          │  Port :8000                   │
│  ┌──────────────────┐│  ┌──────────────────────────┐ │
│  │ 23 Handler       ││  │ /api/ai/chat/stream      │ │
│  │ 4 Service        ││  │ /api/ai/generate/lesson  │ │
│  │ 16 Repository    ││  │ /api/ai/... (12+ RAG)   │ │
│  │ JWT + RBAC       ││  │ Qwen Turbo/Plus/Max     │ │
│  └──────────────────┘│  └──────────────────────────┘ │
├──────────────────────┴───────────────────────────────┤
│  PostgreSQL 16 (pgvector) + Redis 7                   │
│  Docker Compose 管理 6 个容器                         │
└──────────────────────────────────────────────────────┘
```

**部署架构**：
- Docker Compose：6 容器（business-api / ai-service / postgres / redis / nginx / reset-cron）
- Nginx 域名分流：school.ziwi.cn → 前端 + API 代理到 :8080
- 预发布服务器：193.112.163.147（腾讯轻量云）

**数据层**：PostgreSQL 16（pgvector 嵌入向量）→ GORM ORM → 16 个 Repository  
**缓存**：Redis 7（会话 / Token / 限流）  
**AI 模型**：通义千问 Qwen Turbo/Plus/Max，百炼工作空间 API  
**向量检索**：pgvector（课标知识库 RAG）  

**鉴权**：JWT → 租户隔离 → RBAC 权限（admin / teacher / student / parent / it_admin）→ 审计日志

## 三、技术架构层面差异

| 项 | 现有 | 新设计 | 操作 |
|----|------|--------|:--:|
| 样式方案 | Tailwind CSS 3 | CSS Variables (`design-tokens.css` + `base.css`) | **tailwind.config.js extend theme** 映射 token |
| 图标方案 | lucide-react | 自定义 68 SVG (`icons/`) | 封装 `<Icon>` 组件或 `<img>` 直接引用 |
| 全局布局 | Dark topbar + sidebar（top:48px） | Sidebar（top:0 含 Logo）+ white main-header | 重写 `DashboardLayout` |
| 颜色体系 | Tailwind 默认 | `#02A7F0` / `#353535` / `#E7E7EB` | extend colors |
| 阴影 | `shadow-sm/md` | **无阴影，仅 1px 边框** | 全局去除 |
| 字体 | Tailwind 默认栈 | `PingFang SC / 微软雅黑` | fontFamily extend |
| 状态组件 | Spin/Empty/Error（基础） | 新增 Skeleton/Disabled/Focus/Tooltip | 增强 `StateComponents.tsx` |
