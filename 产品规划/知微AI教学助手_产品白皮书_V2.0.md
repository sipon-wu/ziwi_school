## 一、概述

### 1.1 我们是谁

知微是一家专注于基础教育教学场景的 AI 产品公司。我们相信，AI 的价值不是取代教师，而是把教师从重复、机械的备课与批改劳动中解放出来，让他们把精力真正放在"育人"上。

「知微」之名，出自"见微知著"——从细微处洞察教育本质；平台内的 AI 助教取名「小微」，呼应"微"字，寓意它像一名谦逊、可靠的实习生，始终在教师身边，知微知彰、不抢风头。

### 1.2 时代背景

2025 年，《教育部等九部门关于加快推进教育数字化的意见》（教办〔2025〕3 号）明确提出"全面推进智能化，促进人工智能助力教育变革"。2026 年，教育部等五部门联合印发《"人工智能+教育"行动计划》（教科信〔2026〕1 号），系统部署 AI 赋能教育的四大重点任务，强调"推动人工智能融入教育全要素、全过程、全场景"。

教育数字化已从"辅助工具"跃升为"战略变量"。知微 AI 教学助手，应国家战略而生，为一线教师而来。

### 1.3 产品定位

**知微 AI 教学助手**是面向中小学教师的"全链路 AI 备课与教学辅助平台"。它覆盖从备课（教案 / 课件 / 习题 / 试卷）→ 授课支撑 → 练习与批改 → 学情分析 → 家校沟通的完整教学闭环，让教师在一处完成过去需要多个工具间来回切换才能完成的工作。

- **服务对象**：中小学教师、班主任、教研组长、校长、学校 IT 管理员
- **使用终端**：教师端为 PC Web（生产型创作）；学生端 / 家长端为微信小程序（消费型查看与轻交互）
- **核心载体**：AI 助教「小微」贯穿全流程，既是生成执行者，也是教师的私人对话助手

### 1.4 一句话价值

> 教师只管"教什么、怎么教"，备课的繁、出题的累、批改的苦，交给知微。

### 1.5 核心亮点速览

知微能在同类产品中脱颖而出，靠的不是把"AI 生成"堆砌得更多，而是把"生成得准、靠得住、用得省心"做到了实处。以下八项，是中小学教师与学校决策者最直观能感知到的差异化优势：

1. **教材知识边界 · 治"答非所教"**：以「锚点—轨道—边缘」受控发散模型，让 AI 产出严格扎根当前年级 · 学科 · 版本 · 单元的真实教材，既不跑题，也保留适度启发。
2. **课标对齐到底线**：所有教案、课件、习题均可溯源到课标条款。课标库 1587 条标准条款 + 763 条教材—课标映射已结构化入库，合规有据可查。
3. **知识图谱显式圈定**：右侧固定知识图谱面板，教师可"画圈"式按学科 / 年级 / 学期显式圈定知识点范围，与教材边界互补，生成结果更可控。
4. **四维教材版本配置 · 千校千面**：支持"年级 + 班级 + 学科 + 版本"四维精准指定，平台维护权威版本库（300+ 条），学校可"自用覆盖"仅本校生效，全平台上下文一致。
5. **预分片向量检索 · 算力可控**：底料库按"年级 + 学科 + 版本"预分片（32 片独立索引），检索先裁剪分片再语义排序——把向量开销从全表降到单分片，避免每次生成都全表轮巡。
6. **多模态习作批改 · 拍照即改**：作文 / 习作学生拍照上传 → 多模态识别 → AI 预打分 + 卷面字迹评估 → 低置信度推教师复核，把最耗时的批改变轻。
7. **AI 助教「小微」全程陪伴**：既是备课 / 出题 / 组卷 / 课件的生成执行者，也是教师随叫随到的私人对话助手（浮窗 + 指令），一处入口贯通全流程。
8. **合规先手 · 数据安全底线**：ICP / 教育 APP / 算法 / 等保二级备案齐全；学生仅用校内"学号"、照片本地处理、签字全程可追溯，从设计之初就把合规做在前面。

## 四、核心功能详述

### 4.1 教学备课

**教案生成**：输入课题（或选择教材单元），小微生成结构化教案：教学目标、重难点、教学过程、板书设计、作业布置等模块齐备。每份教案自动溯源到对应课标条款，确保合规底线。教师可在编辑器内逐段 AI 微调、复制为新版本，定稿后进入发布库。

**课件生成（PPT 优先）**：AI 将教案要点精炼为可编辑提纲（标题 + 要点 + 讲稿），教师可改标题、调顺序、删页、调用"AI 润色提纲"重渲染。提纲是唯一可编辑态，导出 / 预览 / 保存均由其派生：在线播放（含教师备注）、导出 PPTX、导出 Word / PDF、保存进素材库。H5 互动课件预留即将上线。

**教材版本配置（四维精准）**：支持"年级 + 班级 + 学科 + 版本"四维指定。平台维护权威教材版本库（覆盖主流版本 300+ 条），学校可在不改公共库的前提下做"学校自用覆盖"（仅本校生效）。教师的"当前教材"按"个人偏好 > 学校配置 > 平台默认"优先级自动解析，全平台一致。

**知识图谱**：右侧固定知识图谱面板，按学科 / 年级 / 学期预选知识点，支撑教师在生成时显式圈定知识点范围，与教材边界互补。

**板书嵌入**：板书可作为独立素材嵌入教案详情页，导出文档可含板书页。

### 4.2 作业练习

**智能出题 / 组卷**：出题产物为习题（A4 版面），组卷产物为试卷（A4 版面，预览可选 A3 / A4 双栏）。均支持"AI 模式 / 文档模式"切换，教师可混合 AI 生成与手工录入。

**习题 / 试卷库**：题目与试卷独立成库，支持题库快照（发布时冻结）、分层作业（难度 tier + 预估时长）、批量导入（CSV 解析）。

**自动批改**：客观题（选择 / 填空 / 计算）全自动批改。作文 / 习作：学生拍照上传 → 多模态识别 → AI 预打分 + 卷面字迹评估 → 低置信度项推教师复核队列。教师始终是最终确认者。

### 4.3 教学数据

**班级学情**：自动汇总班级作业完成率、正确率、错题分布，支持班主任查看全班学情。小微可就班级学情做自然语言讲解。

**校长驾驶舱**：校长视角看全校教学质量、各年级 / 学科对比、统考成绩分析，数据驱动管理决策。

**错题本与质量分析**：学生错题自动归集，教师可据此做针对性讲评；质量分析支撑教研与家长会。

### 4.4 家校沟通

**学生端小程序**：查看作业、客观题作答、错题本、个人学情，绿色系轻量界面。

**家长端小程序**：只读查看孩子作业、接收提醒、手写签字确认（过程可追溯）。支持学生评语功能化：批量选班 → 双版本评语（详细版 ≤147 字 / 手抄版 ≤25 字）→ 逐条修改 → 群发家长端，状态可追踪。

**统一小程序策略**：一个代码仓 + 角色分包路由，小程序承载审阅 / 审批 / 消息 / 配置开关 / 家长轻操作，不承载富文本编辑器等多步重交互。

## 五、关键技术创新

### 5.1 教材知识边界 ·「锚点—轨道—边缘」受控发散模型

这是知微最核心的差异化能力，专门解决"AI 答非所教"的顽疾。

传统 AI 生成要么无差别全库搜索（内容飘忽），要么死板锁死（缺乏启发）。知微采用三层约束：

- **锚点（硬约束，必覆盖）**：所选单元 + 前置知识点，AI 产出必须扎根于当前教材实际内容。
- **轨道（受控发散）**：允许适度跨界、跨 ±1 年级档、对标课标 ±1，并在"发散预算"内拓展——每一条发散都必须回溯锚点，确保不跑题。
- **边缘（价值观 / 行为 / 情感）**：靠课堂互动承载，不污染正文；边缘知识本质为学科原生拓展（科学拓展 / 课外阅读 / 同级奥数 / 英语拓宽），杜绝亚文化商业符号与不当民族差异化表达。

**工程实现**：底料库由单表改造为按"年级 + 学科 + 版本"预分片的向量库（HASH 固定 32 片，每片独立 HNSW 索引）。检索时先裁剪到对应分片、再在分片内按单元（含上一 / 下一单元）过滤、最后按课时语义排序取 Top-N——把向量开销从全表降到单分片，避免每次生成都做全表轮巡。命中的教材边界内容作为锚点注入教案 / 课件 / 习题组卷 / 会话四大环节，使 AI 产出严格贴合教材实际。

> 草稿永远可编辑，只有"发布进素材库"才过闸；不过闸则列出问题提醒修改，而非锁死草稿。

### 5.2 课标对齐为底线

"对不齐课标"是 AI 教案最容易被学校否定的硬伤。知微把课标对齐做成**可溯源的底线**而非口号：课标库（1587 条标准条款）与教材—课标映射（763 条）已结构化入库，每份教案、课件、习题在生成时即自动标注对应课标条款，教师可在产出中直接看到"本条对应课标 X.Y.Z"。它既是合规依据，也是教研组长做质量抽检的抓手——产出可查、可审、可追责。

### 5.3 教师偏好记忆（风格学习）

知微记录教师对 AI 产出的修改与纠正（如"这个扣分标准记住了"），以 RAG 方式蒸馏为个人偏好，在后续生成中注入。前端措辞为"偏好记忆"，教师可一键关闭注入。风格蒸馏仅占产出质量的小权重，专家把关的教学逻辑才是主干——小微即实习生，给惊喜也给可控。

### 5.4 模型热替换架构

底层大模型（通义千问等）通过 AI 网关统一调用，架构支持模型热替换，随大模型版本迭代自然进化，不因单一模型绑定而受限。

### 5.5 知识图谱 · 知识点显式圈定

右侧固定知识图谱面板，按学科 / 年级 / 学期预选知识点，支撑教师在生成时"画圈式"显式圈定知识点范围。它与教材知识边界（5.1）互补：教材边界回答"教到哪一页"，知识图谱回答"这一页牵动哪些前后续知识点"，二者并列注入 prompt，使生成既贴教材、又成体系，杜绝知识点遗漏或超纲跳跃。

### 5.6 多模态习作批改 · 拍照即改

作文 / 习作是批改负担最重的一环。知微支持学生拍照上传 → 多模态识别转写 → AI 预打分（含立意 / 结构 / 语言维度）+ 卷面字迹评估 → 低置信度项自动推入教师复核队列。教师始终是最终确认者，但机械性预处理的耗时被大幅压缩，让教师把精力放在"育人性反馈"而非"认字与统分"。

### 5.7 AI 助教「小微」· 全程陪伴的生成 + 对话双角色

「小微」不是隐藏在按钮后的黑盒，而是贯穿全流程的具象化助手：在备课 / 出题 / 组卷 / 课件环节它是**生成执行者**，一键产出结构化结果；在教师需要答疑、讲解班级学情、追问教学策略时，它是**私人对话助手**（浮窗 + 指令），随叫随到。一个入口贯通"生产"与"咨询"，降低教师的工具切换成本。

### 5.8 双端协同与统一身份（知微云 IdP）

教师端为 PC Web（生产型创作，承载富文本编辑、表格、多步向导）；学生 / 家长端为微信小程序（消费型查看与轻交互，承载审阅 / 审批 / 消息 / 签字）。两端通过统一身份「知微云」打通：RS256 签名 + JWK 分发 + 租户 / 产品授权 + 刷新令牌，学校账号可一键绑定，实现跨产品统一登录，既便利又满足企业级安全基线。

### 5.9 合规先手 · 数据安全底线

知微把合规做在前面而非事后补救：ICP / 教育 APP 提供者 / 算法 / 等保二级备案齐全；数据保护遵循"最小暴露"原则——学生不采集教育学籍号、仅用校内"学号"，原始照片本地处理不上传服务器，家校签字与关怀记录可追溯 / 加密存储。对区域教育主管与学校决策者而言，这意味着"能用、敢用、合规用"。

## 七、部署与数据安全

### 7.1 部署形态

- **SaaS 多租户**：一校一实例，逻辑隔离（每校独立数据库 / schema，缓存按 `{school_id}` 前缀隔离）。
- **私有化部署**：面向大校 / 教育局可选，数据不出校。
- **多校区支持**：同一学校内可设多个校区，班级 / 师生归属校区，满足集团化办学。

### 7.2 技术与数据架构

- 前端：React（教师端 PC Web）+ 微信小程序（学生 / 家长端）
- 后端：Go（用户 / 作业 / 家校 / 权限等核心服务）+ Python FastAPI（AI 生成与检索服务）
- 数据：PostgreSQL 16 + pgvector（业务库与教材向量库同库）；Redis 缓存
- 教材向量检索：预分片 HNSW（见 5.1 节）

## 八、典型工作流

**场景：一位四年级数学教师准备"长方形正方形的面积"单元**

1. 顶部切换"数学 · 四年级 · 人教版"，全平台上下文一致。
2. 打开教案生成，选"第一单元" → 小微产出结构化教案，自动标注课标条款。
3. 一键生成配套课件提纲，微调要点后导出 PPT 投屏。
4. 调用出题，按"面积计算"知识点生成 10 道分层习题；另组一份单元测验卷（A3 双栏）。
5. 发布作业到班级，学生小程序作答，客观题自动批改、作文类推教师复核。
6. 小微汇总班级正确率与错题分布，教师据此讲评；校长可在驾驶舱看全校同单元质量。
7. 家长端收到作业提醒并手写签字确认，过程留痕。

全程 AI 产出的内容都锚定在"人教版四年级面积单元"的真实教材边界内，既不跑题，也保留适度启发。

- **课标对齐为底线**：所有产出可溯源。
- **证据驱动**：功能以真实课堂验证为准，不凭印象。
