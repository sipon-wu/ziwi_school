# 知微AI教学助手 — 首页设计评审纪要

**日期**：2026-07-03  
**来源**：微信公众平台后台风格借鉴 + 产品原型  
**产出**：18页静态HTML + Design Tokens + Style Guide

---

## 一、核心设计决策

| 决策项 | 结论 | 依据 |
|--------|------|------|
| 主配色 | `#02A7F0` 蓝 + `#212529` 侧边栏 | 原型提取 + 微信后台借鉴 |
| 字体 | PingFang SC (Apple) / 微软雅黑 (Win) | 微信后台风格，替换 Axure 默认 Arial |
| 正文色 | `#353535` | 微信标准 |
| 边框色 | `#E7E7EB` | 微信标准（原 `#F0F0F0`） |
| 辅助灰 | `#9A9A9A` | 微信标准 |
| 圆角 | 3px(S) / 4px(M) | 微信标准 |
| Logo | 侧边栏顶部、圆角5px | 对照截图修正 |
| CTA Orange | 已删除，仅保留蓝/灰/白 | 微信后台无此色 |
| 卡片阴影 | **已移除**，改为1px边框 | 微信克制风格 |
| 演示环境提示 | **已移除**，不留痕 | 设计稿不需要 |

## 三、关键交互修正记录

| # | 初始问题 | 最终方案 |
|---|---------|---------|
| 1 | Logo在顶部栏横跨 | Logo移入侧边栏顶部，侧边栏从top:0开始 |
| 2 | 右侧无标题栏 | 白色main-header: 收起图标 + 班级切换 + Token + 通知 + 头像 |
| 3 | 左卡片排版松散 | 标签左数字右，stat-row自然跟随，13px |
| 4 | 右卡片有7日/30日Tab | 去掉Tab，直接3个大数字(标签上数字下) |
| 5 | 统计时间为区间"00:00-24:00" | 改为"统计截止时间：6月29日" |
| 6 | 课标对齐率在卡片内 | 改为可关闭通知条(×按钮) |
| 7 | 立即催办独立一行 | 与家长签字同行右侧，margin-left:auto |
| 8 | 摘要侵占其他列 | table-layout:fixed + max-width:0 + text-overflow:ellipsis + tooltip |
| 9 | 收起图标为文档图标 | 改为icons/nav-collapse.svg |
| 10 | 收起图标未贴左 | padding-left:0，icon再左移4px |
| 11 | 语文下拉未与卡片对齐 | main-content padding-left:8px |
| 12 | 内建横向滚动条 | 去掉overflow-x:auto，用浏览器默认 |
| 13 | 操作列缺图标 | 增加预览(眼睛) + 打印(文档)图标 |
