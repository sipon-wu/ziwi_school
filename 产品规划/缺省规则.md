# 缺省规则（Defensive Defaults）· 规格附录 R1–R3

> 版本：v1.0 ｜ 日期：2026-09-16 ｜ 状态：已定档（回填自代码，来源为单一事实源模块）
> 定位：本文件是**规格附录**，不是实现说明。凡"边界情况该怎么表现"，以本文件为准；
> 实现细节见各自模块（下方"单一事实源"列），**两者不一致时以本文件为准并修实现**。
> 复核方法：每条都给出了"怎么验"，任何接手者可独立复核（见 `qa/文档评审_20260916.md`）。

## R0 总则

> **不依赖模型守规矩，不依赖操作者守规矩。** 凡是"模型偶发、教师无法控制"的边界情况，
> 系统必须给出**确定的、可预期的**结果，而不是把不确定性直接印到成品上。

## R1 版式法则（`lib/layoutLaw.ts`）

**单一事实源**：`code/frontend/src/lib/layoutLaw.ts`（导出 `SPACE / TEXT / PT_TO_MM / TYPE / floorMm / PPT / H5`）

| # | 规则 | 说明 |
|---|---|---|
| R1-1 | 版式**由法则派生**，不逐页硬编码 | 间距/字号/毫米换算统一从法则取值 |
| R1-2 | 字号层级为**不变量** | 正文永不压过小标题（`bodyMax < h3`） |
| R1-3 | 字号夹在**投影可读硬下限**与上限之间 | 层阶之外再断言"教室投影看得清" |
| R1-4 | 字体合法性在法则内**自证** | 非法则的字体不进入产物（在 `styleRegistry` 计算字号阶梯时断言） |

**复核方法**：`grep -rn "from '../layoutLaw'\|from './layoutLaw'" code/frontend/src` → 消费方应覆盖 H5 渲染器、PPT 元素/组件渲染、预览字号阶梯；再确认这些消费方**没有**绕开法则写死字号。

## R2 展示文本清理（`lib/textClean.ts`）

**单一事实源**：`code/frontend/src/lib/textClean.ts`（导出 `stripDecorMarkers`）

| # | 规则 | 说明 |
|---|---|---|
| R2-1 | 行首**列表符**（`-` `*` `•`）与**引用符**（`>` 一个或多个）一律剥掉 | 模型常把 `>` 当装饰写（实测 `- > 地球46亿岁…`，11 页里 6 页中招） |
| R2-2 | 行尾孤立的 `>` 也去掉 | 同上 |
| R2-3 | 占位符（"—"）**不出现在成品** | 没值的项宁可不显示，也不印破折号 |
| R2-4 | H5 场景文本与 PPT 元素文本**共用同一函数** | 两端观感必须一致 |

**复核方法**：`grep -rn "stripDecorMarkers" code/frontend/src` → 应命中 `mdToStory.ts`（H5）与 `PptxPreview.tsx`（PPT）两处消费；构造含 `- > 文字` 的内容渲染，确认不出现 `>`。

## R3 版本粒度（`lib/versionPolicy.ts`）

**单一事实源**：`code/frontend/src/lib/versionPolicy.ts`（导出 `decideVersion / CLICK_COALESCE_MS / AUTO_THROTTLE_MS`）

| # | 规则 | 说明 |
|---|---|---|
| R3-1 | **生成 / 保存草稿 / 发布** = 三个版本时机，各形成一版 | 每次触发都留可回退点 |
| R3-2 | **点击保存**：1 分钟内的连续保存合并为一版 | `CLICK_COALESCE_MS` |
| R3-3 | **自动保存**：3 分钟节流 | `AUTO_THROTTLE_MS` |
| R3-4 | **覆盖式重写（重新套版等）执行前自动存版本快照** | 让"可回退"成为跨刷新/跨会话的真承诺 |
| R3-5 | 生成内容**自动成为一稿草稿**（不等教师点保存） | 生成即上手可编辑的稿件 |

**复核方法**：`grep -rn "decideVersion\|CLICK_COALESCE_MS\|AUTO_THROTTLE_MS" code/frontend/src qa/` → 消费点 + 单测（`qa/verify_version_policy.cjs`）；再看 `CoursewareBuilder` 的保存/生成/套版三条调用路径是否都过 `decideVersion`。
