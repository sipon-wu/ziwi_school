## 一、整体布局识别

页面采用 **经典三栏式后台管理布局**：

```
┌────────────────────────────────────────────────────────────┐
│  [顶部横幅] 品牌标识 | 课程锚点选择器 | Token | 通知 | 头像    │
├────────────────────────────────────────────────────────────┤
│  ┌──────────┬─────────────────────────────────────────┐ │
│  │          │  用户概览卡（头像/姓名/待办/数据概览）     │ │
│  │  左侧    │  时间维度Tab + 统计数据面板               │ │
│  │  导航栏  │  ────────────────────────────────────   │ │
│  │          │  新的创作（7类快捷入口）                    │ │
│  │          │  ────────────────────────────────────   │ │
│  │          │  近期草稿（列表+操作）                      │ │
│  │          │  分页/底部信息                            │ │
│  └──────────┴─────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

### 1.1 配色体系（2026-07-04 修正，参见设计评审纪要）

## 二、顶部导航栏（Top Bar）

| 元素 | 内容 | 功能分析 |
|------|------|----------|
| 品牌标识 | 知微教学(AI) + 图标 | 跳转首页，品牌露出 |
| **学校/校区** | `成都市金牛区第一小学` / 分校名 | 当前所在校区，系统设置中认领 |
| **课程锚点** | `语文·四年级(1班)` + 下拉箭头 | **核心锚点**：班级运行时选择器（仅显示当前校区下的班级） |
| **小微搜索** | 输入栏（待确认位置） | 自然语言检索全平台内容（素材/教案/试卷等） |
| Token | 5% | AI服务额度指示 |
| 通知 | 铃铛 + 红点 | 系统通知/待办提醒 |
| 用户 | 头像 + 张真真 | 个人信息/退出入口 |

### 架构关键：两级班级切换 + 配置与运行时分离

**系统设置 = 初始化配置中心，班级切换分两档。**

| 档位 | 入口 | 范围 | 交互 | 场景 |
|------|------|------|------|------|
| **快速切换** | 顶部锚点下拉 | 仅当前校区下的班级 | 下拉选择 | 日常同校区换班 |
| **全局切换** | 个人中心 → 班级切换 → **弹窗** | 所有校区、所有已认领班级+学科 | 弹窗全列表 | 跨校区换班、初登选班 |

| 层 | 位置 | 职责 | 变更频率 |
|----|------|------|----------|
| **配置层** | 个人中心 → 系统设置 | 认领校区 → 认领班级 → 关联学科 → 绑定教材版本 | 学期初一次性配置 |
| **运行时-快速** | 顶部锚点 | 从当前校区已配置班级中快速切换 | 日常高频 |
| **运行时-全局** | 个人中心 → 班级切换弹窗 | 跨校区切换，显示所有认领的班级+学科 | 偶尔使用 |

- 展示：`学科·年级(班级)` — 如"语文·四年级(1班)"
- 下拉选择器：列出该教师在系统设置中已配置的所有班级
- 切换后整个工作台数据全部过滤

> **设计逻辑**：班级、学科、教材版本是一一绑定的初始化配置项，不应在主工作流中频繁变更。教师初始化后，日常只需要切换"当前在哪个班级工作"，其余信息由系统从配置中自动推导。

### 3.1 与之前架构的对比

| 新架构 | 旧架构 | 变化分析 |
|--------|--------|----------|
| 教学备课 | 教学备课 | 新增"教案互审"（协作评审） |
| 作业练习 | 作业练习 | 合并为统一的"出题·题库" |
| 教学数据 | 班级学情/校长仪表盘 | 统一为"教学数据"，个人视角 |
| 家校沟通 | 家校沟通 | 保持不变 |
| 个人中心 | 系统设置 | 新增"班级切换"，更贴近用户场景 |

### 3.2 关键变化
1. **去掉教师侧边栏的"校长仪表盘"入口**：校长角色有独立登录态，其首页即为仪表盘，不与教师侧边栏混排。
2. **新增"教案互审"**：教师间的教案协作评审机制，这是之前讨论中缺失的环节。
3. **新增"素材库"**：教学资源的独立管理入口，之前分散在教案中。
4. **新增"班级切换"**：与顶部快速切换不同——顶部仅限当前校区下拉选择，班级切换弹出弹窗展示**所有校区+所有已认领班级+学科**，支持跨校区换班。

| 入口 | 图标 | 状态 | 说明 |
|------|------|------|------|

| 习题 | 文档图标 | 默认 | 快速创建习题 |
| 试卷 | 文档图标 | 默认 | 快速创建试卷 |
| 作业 | 文档图标 | 默认 | 快速布置作业 |

| 音频 | 音乐图标 | 默认 | **新增**：AI生成教学音频 |
| 视频 | 视频图标 | 默认 | **新增**：AI生成教学视频 |

### 关键发现：多媒体内容生成已纳入创作体系

之前的讨论中仅聚焦教案/作业/试卷的**文本内容**。新布局显示：
- **插图**：AI生成教学用图（如看图说话插图、几何图）
- **音频**：课文朗读、听力材料生成
- **视频**：微课、知识点讲解视频

这意味着 AI 内容生成能力已从纯文本扩展到**多模态**（文、图、音、视）。

### 插图生成 → 素材库链路

插图完整生命周期：

```
新的创作 → 插图 → AI生成（遵循题卷宪法第二条插图标准）
                │
                ▼
          AI自动打标签（学科/年级/风格/场景/关键词）
                │
                ▼
          存入素材库 ← 可复用、可分享
                │
         ┌──────┼──────┐
         ▼      ▼      ▼
      教案引用  试卷引用  作业引用
```

| 环节 | 说明 |
|------|------|
| 生成 | 教师描述需求，AI生成黑白线稿插图（符合宪法第2.1条） |
| 打标签 | AI自动标注：学科、年级、场景关键词、风格、尺寸 |
| 入库 | 存入素材库，标记为可复用 |
| 分享 | 同校/同学科教师可检索使用 |
| 引用 | 教案/试卷/作业中插入素材库图片（不重复上传） |

### 4.5 检索交互：搜索框 vs 小微口令

问题：素材库/教案/试卷等内容的检索，是传统搜索框还是直接唤醒小微？

| 方式 | 适用场景 | 交互 |
|------|----------|------|
| **小微口令** | 自然语言模糊检索 → "找一个去年四年级的看图写话插图" | 语音/输入 + AI理解意图 + 精准返回 |
| **搜索框** | 已知关键词精确搜索 → 输入"放风筝""部编版"快速定位 | 传统搜索栏，作为备选 |

> **建议**：以**小微口令**为主入口（顶部常驻小微输入栏），搜索框作为每页内的辅助。理由：教师词汇丰富但不确定标签体系，自然语言更适合"帮我找四年级上册的看图写话素材"这种模糊描述，AI可以理解意图后从素材库的AI标签中精准匹配。

### 4.4 近期草稿（Recent Drafts）

表格结构：

| 列 | 说明 |
|----|------|
| 草稿内容 | 标题，如《观潮》第一课时 |
| 类型 | 教案/作业/试卷等 |
| 摘要(AI) | AI自动生成的内容摘要（50字以内） |
| 更新时间 | 时间戳 |
| 操作 | 编辑 ✎ / 删除 🗑 / 复制 ⎘ / 发布 📤 |

**关键交互**：
- AI摘要为**纯展示**，不可手动编辑
- 作用：用户快速扫一眼就知道这个草稿是什么内容、什么状态，无需点进去
- 摘要默认截断，鼠标移入显示全部（tooltip）
- 操作为图标按钮，简洁直观
- 右上角有"全部草稿"入口，跳转完整列表

## 五、架构调整总结

### 5.1 信息架构变更

```
旧架构（课程组锚点）              → 新架构（配置层 + 运行时层分离）

TeachingContext                  →  SystemConfig（一次性） + RuntimeClass
  ├── 年级（年级选择器）           →  系统设置：创建班级时绑定
  ├── 学科（学科标签）             →  系统设置：每班关联学科
  └── 教材版本（下拉）             →  系统设置：学科→教材版本绑定（如语文→部编版）

  顶部锚点 = 运行时工作上下文切换（只选班级，其余自动推导）

SideBar（课程组+功能列表）        →  SideBar（纯功能导航）
  ├── 班级学情                    →  教学数据（学情分析/成长足迹）
  ├── 校长仪表盘                  →  ❌ 移除（角色独立）
  └── 其他功能                    →  基本保留，结构重组
```

### 5.2 数据流推断

```
用户登录
  → 加载该教师在系统设置中认领的校区列表
  → 默认进入上次离开的校区（或第一个校区）
  → 加载该校区下已认领的班级列表
  → 默认进入上次离开的班级（或第一个班级）
  → 从班级反查：学科、年级、教材版本（已在系统设置中绑定）
  → Dashboard 加载该校区+班级数据：
      - 待办数（待批改/待审/待签）
      - 统计数据（教案/题型/试卷）
      - 近期草稿（该教师+该校区+该班级+该学科）
  → Token 状态同步
  → 左侧导航底部显示当前校区名

侧边栏底部切换校区
  → 顶部锚点下拉列表自动过滤为该校区下的班级
  → 当前工作班级若不属于新校区，自动切到该校区第一个班级
  → Dashboard 等全部数据刷新

顶部锚点快速切换班级（仅当前校区内）
  → 下拉列表仅显示当前校区下的班级
  → 重新反查班级绑定的学科、教材版本
  → 所有内容区重新加载过滤数据

个人中心 → 班级切换 → 弹窗全局切换（跨校区）
  → 弹窗展示所有校区 + 所有已认领班级 + 学科
  → 选中后：切换校区 + 切换班级（一步完成）
  → 顶部锚点 + 侧边栏底部同步更新
```

### 5.3 关键新增功能

| 功能 | 位置 | 说明 |
|------|------|------|
| **教案互审** | 教学备课 → 教案互审 | 教师间协作，教案质量保障 |
| **素材库** | 教学备课 → 素材库 | 教学资源独立管理，跨教案复用 |
| **班级切换** | 个人中心 → 班级切换 | 管理多班级，比顶部锚点更全面 |
| **插图生成** | 新的创作 → 插图 | AI生成教学插图（符合题卷宪法） |
| **音频生成** | 新的创作 → 音频 | AI生成朗读/听力材料 |
| **视频生成** | 新的创作 → 视频 | AI生成微课/知识点讲解 |
| **立即催办** | 用户概览卡 | 一键催促家长签字/审批 |

### 5.4 角色权限模型

系统基于角色**完全区隔**侧边栏与首页：

| 角色 | 首页 | 侧边栏 | 班级锚点 |
|------|------|--------|----------|
| **教师** | 工作概览（待办+创作+草稿） | 五大模块：备课/作业/数据/家校/个人 | ✅ 需要选择班级 |
| **校长** | 仪表盘（全校数据总览） | 精简，以数据洞察+管理为主 | ❌ 无需，全局视角 |
| **家长** | 待推演 | 待推演 | 子女生绑定 |
| **学生** | 待推演 | 待推演 | 本人班级 |

> **关键设计**：同一系统，不同角色登录看到完全不同的首页和侧边栏。角色切换 ≠ 页面内切换，而是登录态/RBAC决定。

### A.3 注释揭示的新信息

1. **分校概念**：「学校或分校名称」→ 系统支持多校区部署，顶部展示当前校区名称
2. **催办链路**：固定模板自动推送至家长小程序端，非站内通知
3. **试卷=组卷**：原型将"新建试卷"标注为「新建试卷（组卷）」，暗示试卷创建本质是组卷流程
4. **更新时间精度**：仅显示到天（YYYY-MM-DD），但内部排序精确到秒，避免同日多草稿乱序
5. **插图即素材**：新建插图直接标为「新建一个插图素材」，与素材库打通

## 八、核心架构洞察：全局层 vs 上下文层

### 8.1 一刀切：唯一个人中心例外

```
┌─────────────────────────────────────────────────────────────┐
│                        全局层（User Scope）                    │
│                                                             │
│  📁 个人中心                                                 │
│    ├── 班级切换（弹窗：跨校区全量）                              │
│    └── 系统设置（校区认领/班级认领/个人信息）                     │
│                                                             │
│  ← 唯一不受校区·班级·学科限制的模块                             │
├─────────────────────────────────────────────────────────────┤
│                      上下文层（Context Scope）                  │
│                                                             │
│  🏫 金牛区第一小学 · 语文·四年级(1班) · 部编版                   │
│                                                             │
│  📁 教学备课     📁 作业练习     📁 教学数据     📁 家校沟通      │
│                                                             │
│  ← 所有功能均在「指定校区 + 指定班级 + 指定学科」坐标系内运行        │
└─────────────────────────────────────────────────────────────┘
```

### 8.2 小微 AI 的边界

有了明确的两层划分，小微 AI 的边界天然成立：

| 维度 | 边界 | 说明 |
|------|------|------|
| **数据范围** | 上下文层内 | 只检索当前校区·班级·学科的教案、作业、素材、学情 |
| **意图理解** | 免追问 | "这个班"→当前班级，"这个单元"→当前学科教材进度，"上次作业"→当前班级当前学科 |
| **创作生成** | 上下文约束 | 生成教案→匹配当前教材版本，出题→匹配当前课标+难度 |
| **跨上下文** | 明确指令 | "帮我对比四(1)和四(2)的成绩" → 需要明确跨班指令，小微自动获取两个班级权限 |

> 核心价值：教师不需要每句话都重复"四年级语文部编版"，小微已经在上下文里了。

### 8.3 知识图谱的边界

| 维度 | 边界 | 说明 |
|------|------|------|
| **知识节点** | 学科+教材版本锚定 | 当前上下文=语文·部编版→图谱展示部编版知识树，不混入人教版、PEP版 |
| **学情关联** | 班级维度 | 知识节点叠加当前班级的掌握度、薄弱点 |
| **教学进度** | 班级维度 | 当前班级已教/未教节点自动标记 |
| **跨班对比** | 明确切换上下文 | 切换班级→图谱刷新为该班数据 |
| **跨学科** | 不在同一坐标系 | 语文的知识图谱和数学的知识图谱是两棵独立的树 |

> 核心价值：知识图谱不是一张无限大的网，而是「当前学科·当前教材版本」的有限、可控的知识空间。

### 8.4 为什么这个边界是"宪法级"的

| 好处 | 说明 |
|------|------|
| **AI 不越界** | 不会把四(1)班的学情数据泄露给四(2)班的查询 |
| **Prompt 精准** | 小微 prompt 自带 `{campus, class, subject, textbook}`，零歧义 |
| **Token 省** | 不需要每轮对话重复上下文信息 |
| **知识图谱可控** | 每个学科一棵树，不会出现"小学数学题里用了英语单词"的混乱 |
| **权限天然隔离** | 教师能访问的 = 系统设置里认领的校区+班级，不多不少 |
| **未来可扩展** | 新增学科→新树，新增校区→新命名空间，架构不变 |

## 附录B：架构宪法更新

基于今日全文分析，提炼以下架构铁律：

```
铁律1：系统设置是唯一配置源（校区→班级→学科→教材版本，一次性绑定）
铁律2：顶部锚点 = 同校区快速切换，班级切换弹窗 = 跨校区全量切换
铁律3：个人中心 = 全局层，其余所有菜单 = 上下文层（校区·班级·学科坐标系）
铁律4：小微 AI 运行在上下文层内，知识图谱锚定在「学科·教材版本」
铁律5：角色决定侧边栏（教师/校长/家长/学生，四种完全不同的工作台）
```
