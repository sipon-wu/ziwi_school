## 2. 关键发现

### 2.1 知识图谱数据纠正

**交付文档 v1 标注"138 样例节点"已过时。** 经查询 staging 实库（`tb_kg_node` + `tb_kg_edge`），实际已落库的 KG 规模远大于此：

| 学段 | 节点数（估算） | 覆盖学科 |
|---|---|---|
| 小学 | ~2,716 | 语文(1028)、数学(902)、英语(463)、科学(323) |
| 初中 | ~1,659 | 英语、语文、数学、历史、物理、化学等 |
| 高中 | ~1,540 | 生物、历史、物理、化学、政治、语文等 |
| **总计** | **7,132** | 全学段核心学科 |

- 边数：8,606 条
- parent_id 回填率：89%（6,369/7,132）
- 来源：`cmd/seed/knowledge` 程序从结构化 JSON 灌入，可重跑

**结论：知识图谱已具备全学段覆盖能力，交付文档需同步更新。**

### 2.2 课标条款落库差异

| 来源 | 条数 | 差异 |
|---|---|---|
| 交付文档 v1 宣称 | **1,879** | — |
| staging 实库（`tb_standard_clause`） | **1,587** | -292 |

按学段拆解：
- 义务教育：宣称 869 → 实库 764，差 **105** 条
- 普通高中：宣称 960 → 实库 775，差 **185** 条

**待数据团队确认：292 条差异是 seed 导入程序遗漏还是有意分批导入。**

### 2.4 教材正文 P0 样板质量

| 指标 | 数值/描述 |
|---|---|
| 样本量 | 1本教材（冀教版数学一年级上册），64条 chunk |
| 平均置信度 | **0.768** |
| 拼音页置信度 | 0.599~0.653（教学场景最敏感内容） |
| 文字页置信度 | 0.74~0.806 |

质量问题示例（"人民教育出版社" 在 P0 样板中至少出现 6 种错误版本）：
- 龙府出饭社 / 店育出版社 / 龙育出版社 / 龙京出版社 / 居府出版社 / 老府出版社

**当前 教材正文识别 质量不适合直接用于教案生成，需定义阈值（建议文字页≥0.85、拼音/公式页≥0.75）并补充多学科样板。**

## 3. 产品评估（品姐）

**结论："建议先上"，核心链路能跑通。**

- 教案生成路径：选教材 → 课标约束 → 教材原文 → AI 生成，数据基础具备
- 备课包 46,918 chunks 覆盖 99.6% 教材，是最大底气
- 知识图谱 7,132 节点全学段覆盖（纠正了"只有初中 138 样例"的误判）
- 章节树覆盖率 17%（624/3,637），需要确认主流教材覆盖率；备课包层的单元字段可作为兜底

**必须补齐（上线前 or 1-2 周内）**：
1. 知识图谱：纠正文档描述，数据本身已合格
2. 主流教材章节树补充（624 → 覆盖 Top 10 版本全年级）
3. 课标剩余 292 条确认成因而后入库

**可以缓**：
- 教材正文识别 全量（v1.1+）
- 非主流教材章节树
- 学校名录落库
