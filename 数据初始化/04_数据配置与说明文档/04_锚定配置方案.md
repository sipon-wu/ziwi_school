# 知微教学平台「教学就绪」数据锚定配置方案

> 生成时间：2026-07-08 12:36
> 版本：v0.7（P0 六科补深至全分册完整骨架 + P1 物化生单元级图谱 + 课标条目精确化：数学学段修正与结构路径、语文按学习任务群重映射、英语子主题编号校正、物化生等逐单元重映射与初中物理一级主题编号校正；小学核心四科(语数英+科学)按 2022 官方结构路径锚定并接入全分册骨架）

## 一、总体架构

教材版本、课程标准（课标）、知识图谱三者以「教材版本」为锚点建立关联：

```
教材版本库(平台表)  ──1:N──▶  教材-课标映射表  ──▶  课标条目(教育部课标)
        │
        └──1:N──▶  知识图谱节点表 + 关系表  ──▶  单元/章节 → 知识点 → 子知识点
```

教师选择教材版本后，系统按 `教材版本标识` 自动联表取出：
- 该版本每个单元对应的课标条目（来自教材-课标映射表）
- 该版本对应的知识图谱 JSON（加载至教案工作台知识图谱面板）

## 二、数据导入路径

| 源数据 | 目标平台表 | 关键字段 | 导入方式 |
|--------|-----------|----------|----------|
| 教材版本清单.xlsx | `tb_textbook_version` | version_key(唯一), 学段, 年级, 学科, 出版社, 册别 | 全量导入，version_key=学科+学段+版本标识+年级+册别 生成 |
| 教材-课标映射表.xlsx | `tb_version_standard_map` | version_key, 单元, 课标条目编号, 课标原文, 匹配度 | 全量导入，外键关联 tb_textbook_version |
| 知识图谱*.json | `tb_kg_node` + `tb_kg_edge` | node_id, parent_id, name, prereq[], level, ability_dim | 解析 JSON 树，节点入 `tb_kg_node`，前置关系入 `tb_kg_edge` |

### 表结构要点
- `tb_textbook_version.version_key`：唯一标识，用于版本选择器定位，例 `初中_数学_人教版_七年级_上册`。
- `tb_version_standard_map.standard_id`：引用课标原文库（建议另建 `tb_standard_clause` 存放教育部课标条目全文，便于跨教材复用与修订追溯）。
- `tb_kg_node` 层级：`学科→年级→单元→知识点→子知识点`，用 `level`(1-5) 与 `parent_id` 表达。
- `tb_kg_edge`：`(from_node, to_node, relation_type)`，relation_type ∈ {prereq(前置), belong(归属)}。

## 三、版本选择器交互逻辑

1. 学校管理员在**后台**依次选择：学段 → 年级 → 学科 → 教材版本。
2. 选择器每个层级选项由上一层级过滤（如选「初中/七年级/数学」后，版本仅显示该组合下存在的版本：人教版、北师大版…）。
3. 选择完成后点击「确认锚定」，系统执行：
   - 写入该校/班级的 `school_textbook_binding` 记录（version_key + 生效学年）。
   - 触发锚定：读取 `tb_version_standard_map` 得到课标映射，读取 `tb_kg_node/tb_kg_edge` 得到知识图谱。
4. **教师端**「教案工作台」中：
   - 知识图谱面板自动加载该 version_key 对应的图谱数据（按单元分组展示）。
   - 课标要求面板展示每单元对应的课标条目原文与匹配度。

## 四、动态完善机制

- 知识图谱初始为平台内置骨架（本交付物），教师在使用中可新增/调整知识点，写入 `tb_kg_node` 并标记 `source=teacher_edit`，与 `source=seed` 区分。
- 课标修订（如后续新课标发布）只需更新 `tb_standard_clause` 与映射表，不影响图谱结构。
- 版本新增：管理员导入新版本清单 + 映射 + 图谱 JSON 即可，无需改代码。

## 五、校验与回滚

- 导入前校验：version_key 唯一、课标条目编号存在于 `tb_standard_clause`、图谱节点 parent_id 闭环。
- 导入按「版本」为单位事务化，单版本失败不影响其他版本；支持按 version_key 回滚。
