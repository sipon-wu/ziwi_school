## 2. 数据来源与处理说明

- **原始材料**：20 份教育部课程标准 Word 文档（用户线下 PDF→Word 转换）。构成 = 义务教育 9 科 + 普通高中 9 科 + 课程方案 2 份。
- **解析方式**：所有正文段落均为 `Normal` 样式（无 Word 标题层级），因此**不依赖样式、完全靠编号+关键词正则解析**：
  - 一级模块：`一、二、…六、`
  - 二级主题：`（一）（二）…`
  - 条目：`1. 2. 3.` 或 `1.1.1` 等
  - 内容标签：`【内容要求】` / `【学业要求】` / `【教学提示】`（全角方括号）
- **版本识别**：从文件名/前言正则提取，义教 = `2022`，高中 = `2017`。
- **结构适配**：高中数学正文无 `一、二、` 一级标题，直接用 `（一）课程性质` 作一级模块——解析器已自动识别该结构（`has_top_module` 预扫描），数学正确解析为 17 个一级模块。

## 4. 字段字典（每条记录 9 个字段）

| # | 字段名 | 类型 | 必填 | 含义 | 取值 / 枚举 | 示例 |
|---|---|---|---|---|---|---|
| 1 | `学段` | string | 是 | 课标适用的学段 | `普通高中` / `义务教育` / `课程方案` | `普通高中` |
| 2 | `学科` | string | 是 | 学科名称；课程方案学段用专名 | `数学` `语文` `英语` `物理` `化学` `生物`(存储为`生物学`) `历史` `地理` `思想政治` `道德与法治` `科学` `普通高中课程方案` `义务教育课程方案` | `数学` |
| 3 | `版本` | string | 是 | 课标颁布年份 | `2017`（高中）/ `2022`（义教）| `2017` |
| 4 | `一级模块` | string | 是 | 顶层模块名（原始标题清洗后）| 见下方"一级模块取值" | `课程性质` |
| 5 | `二级主题` | string | 可空 | 一级模块下的主题；课程方案类常为空 | 如 `物质` `运动和相互作用` `能量` `数与代数` … | `物质` |
| 6 | `条目编号` | string | 可空 | 条款条目序号；**空=模块/节级文本块** | `1` `1.1` `1.1.1` 等 | `1.1.1` |
| 7 | `条目标题` | string | 是 | 该记录首行文本（标题或导语首句）| 见下方说明 | `一、课程性质` 或 `1.立足学生核心素养发展…` |
| 8 | `类型` | string | 是 | 一级模块的**归一分类**（用于跨科对齐）| 见下方"类型取值" | `课程性质` |
| 9 | `原文` | string | 是 | 该条款完整原文，保留段落换行 | 多行文本 | `一、课程性质\n…（完整正文）` |

### 4.1 一级模块取值（原始标题，按学段）

- **义教 / 高中 学科标准（常规）**：`课程性质` `课程理念` `课程目标` `课程内容` `学业质量` `课程实施`
- **高中数学（括号型结构）**：`课程性质` `基本理念` `学科核心素养` `课程目标` `课程结构` `课程内容` `学业质量` `课程实施` `教学与评价` `附录` 等共 17 个扁平模块
- **课程方案（2 份）**：`培养目标` `基本原则` `课程设置` `课程结构` `课程标准编制与教材编写` `条件保障` `管理与监督` `课程内容确定的原则` 等

### 4.2 类型（归一）取值

### 4.3 条目标题字段说明（重要）

- 当 `条目编号` **为空**时，该记录是**模块级 / 节级文本块**（如模块导语、主题导语），`条目标题` 通常为模块标题行本身（如 `一、课程性质`）。**这不是脏数据**，而是课标正文中独立成段的导语文字。
- 当 `条目编号` **非空**时，该记录是**带编号的具体条款**，`条目标题` 为该条款首句（如 `1.立足学生核心素养发展，充分发挥历史课程的育人功能`）。
- 开发团队如需"仅条款、不含导语"，可用 `条目编号` 是否非空过滤；如需保留完整层级，则全量入库。

## 6. 已知边界与注意事项（供联调参考）

1. **数学高中结构特殊**：一级模块为扁平 `（一）…（十七）` 形式，模块数 17，与其他学科不同，联调时勿以"6 模块"假设校验。
2. **课程方案 2 份为学段级元数据**：非学科标准，模块/类型体系不同，建议单独建表或加 `学段=课程方案` 标识区分。
3. **`原文` 保留原换行**：入库时若字段不支持多行，需做转义或拆分，建议存 TEXT/CLOB 类型。
4. **内容标签（【内容要求】等）已并入 `原文`**：未单独拆字段；如需把"内容要求/学业要求/教学提示"拆成独立子字段，可在入库层按正则 `【内容要求】|【学业要求】|【教学提示】` 进一步切分（解析器已验证该正则有效）。
5. **解析器可复跑溯源**：若后续补充新课标文件，将 docx 放入对应目录后重跑 `extract_standards.py --all` 即可重新生成全部 JSON，无需手工编辑。
