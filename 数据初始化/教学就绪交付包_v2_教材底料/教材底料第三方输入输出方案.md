# 知微教育 · 教材正文 教材正文识别 第三方输入输出方案

## 1. 项目背景

知微教育正在构建 K12 教材内容的底料数据，供 AI RAG 蒸馏使用。已从**国家中小学智慧教育平台**提取 3637 本电子教材的元数据与预览图 URL，**原图一张未存**（只有公开 URL）。现需将教材预览图 教材正文识别 成文本，用于后续 AI 校对与结构化。

**数据提供方（知微）** → 输入清单（图片 URL + 元数据）
**第三方 教材正文识别 团队** → 输出结果（每页 教材正文识别 文本）
**知微继续** → AI 校对（纠错 + 回填章节 + 质量分层）

## 2. 数据规模

| 范围 | 学段 | 学科 | 本数 | 预览页数（图片 URL 条数） |
|---|---|---|---|---|
| **全量一次性** | 全部学段（小学/初中/高中/五·四/特教） | 全部学科（37 个学科标签） | **3,350 本**（有预览页） | **154,920 条** |

> 教材层共 3,637 本，其中 287 本无预览页（无法 教材正文识别），自动跳过。全量一次性交付，不分批次。

## 3. 输入格式（知微 → 教材正文识别 团队）

### 3.1 载体

优先采用 **JSONL**（每行一条独立 JSON），可批量传输。也支持 CSV 格式。

### 3.2 字段定义

JSONL 每行包含以下字段：

| 字段名 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| `bookId` | string | 是 | 教材唯一标识（UUID） | `1c73b348-e8b6-47d6-84b0-6dbacbe28268` |
| `页码` | int | 是 | 此图在教材中的页码（从 1 开始） | `1` |
| `图片URL` | string | 是 | 预览图的完整 CDN 地址，**公开可拉取**（已验证 HEAD 200） | `https://r1-ndr.ykt.cbern.com.cn/edu_product/esp/assets/.../transcode/image/1.jpg` |
| `学段` | string | 是 | 学段枚举值 | `小学` |
| `学科` | string | 是 | 学科名称 | `语文` |
| `年级` | string | 是 | 年级名称 | `一年级` |
| `册别` | string | 是 | 上册/下册/全一册 | `上册` |
| `版本` | string | 是 | 教材版本 | `统编版` |
| `教材标题` | string | 否 | 教材正文识别 结果校对用 | `义务教育教科书·语文一年级上册` |
| `出版者` | string | 否 | 已知的结构化元数据 | `人民教育出版社` |

```jsonl
{"bookId":"1c73b348-e8b6-47d6-84b0-6dbacbe28268","页码":1,"图片URL":"https://r1-ndr.ykt.cbern.com.cn/edu_product/esp/assets/1c73b348-e8b6-47d6-84b0-6dbacbe28268.t/zh-CN/1756191806467/transcode/image/1.jpg","学段":"小学","学科":"语文","年级":"一年级","册别":"上册","版本":"统编版","教材标题":"义务教育教科书·语文一年级上册","出版者":"人民教育出版社"}
{"bookId":"1c73b348-e8b6-47d6-84b0-6dbacbe28268","页码":2,"图片URL":"https://r2-ndr.ykt.cbern.com.cn/edu_product/esp/assets/1c73b348-e8b6-47d6-84b0-6dbacbe28268.t/zh-CN/1756191806467/transcode/image/2.jpg","学段":"小学","学科":"语文","年级":"一年级","册别":"上册","版本":"统编版","教材标题":"义务教育教科书·语文一年级上册","出版者":"人民教育出版社"}
```

## 4. 输出格式（教材正文识别 团队 → 知微）

### 4.1 核心要求

**每入一条图 → 出一条 教材正文识别 记录**，严格对齐输入的 `bookId` + `页码`，以便合并校对。

### 4.2 推荐 JSONL 格式

| 字段名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `bookId` | string | 是 | 对应输入中的 bookId，**联合键** |
| `页码` | int | 是 | 对应输入中的页码，**联合键** |
| `教材正文识别文本` | string | 是 | 教材正文识别 识别的全文文本 |
| `教材正文识别平均置信度` | float | 是 | 整页平均置信度（0~1），供质量筛选用 |
| `教材正文识别置信度详情` | object | 否 | 可选：每字符/每行置信度分布，用于精细校对 |
| `图片URL` | string | 否 | 回传溯源链接（若输入提供） |
| `教材正文识别引擎` | string | 否 | 所用 教材正文识别 引擎名称+版本（如 `PaddleOCR 4.0`） |
| `特殊内容标记` | string | 否 | 该页包含的特殊内容类型，逗号分隔。如 `拼音,数学公式`；无特殊内容可留空 |
| `耗时_ms` | int | 否 | 该页 教材正文识别 耗时（毫秒） |
| `异常标记` | string | 否 | 若该页因故未识别（图片损坏/下载失败），填原因 |

### 4.3 输出样例（JSONL）

```jsonl
{"bookId":"1c73b348-e8b6-47d6-84b0-6dbacbe28268","页码":1,"正文文本":"语文\n一年级上册\n统编版\n人民教育出版社","识别平均置信度":0.92,"图片URL":"https://r1-ndr.ykt.cbern.com.cn/edu_product/esp/assets/.../1.jpg","识别引擎":"PaddleOCR 4.0","耗时_ms":1250}
{"bookId":"1c73b348-e8b6-47d6-84b0-6dbacbe28268","页码":2,"正文文本":"第一单元\n识字\n1 天地人\n2 金木水火土","识别平均置信度":0.95,"图片URL":"https://r2-ndr.ykt.cbern.com.cn/edu_product/esp/assets/.../2.jpg","识别引擎":"PaddleOCR 4.0","耗时_ms":980}
```

### 4.4 质量建议

- **教材正文识别 语言**：中文简体为主，含各学科特殊符号，建议选择**支持中英混排 + 数学符号**的模型。
- **图片特点**：印刷体、清晰度高、偶尔有手写批注/印章。建议不跳过仅含页码/装饰的无文字页（返回空文本即可）。

### 4.5 特殊内容处理要求 ⬅ 关键

教材涉及大量特殊排版内容，**不同学科要求不同**，以下是逐类说明：

**① 数学式**（数学/物理学科，占比较大）
- 包含分数 `½`、根号 `√`、指数 `ⁿ`、下标 `ₙ`、积分 `∫`、求和 `∑` 等
- **要求**：优先使用支持**数学公式识别**的 教材正文识别 模型；若引擎不支持，至少保留 LaTeX 符号或原始排列，**不要丢弃或误转为普通字母**。无法准确还原的复杂公式，请在文本中用 `[数学公式]` 占位标记，**不要静默跳过或不输出**。
- 涉及学科：数学（254本）、物理（74本）、化学（42本）等

**② 化学式与反应式**（化学学科）
- 包含化学式 `H₂O`、`CO₂`、离子态 `Na⁺`、化学方程式 `2H₂ + O₂ → 2H₂O`、结构式和苯环等
- **要求**：下标/上标/箭头需尽量保留（如 `→` `⇌` `↑` `↓`）；复杂结构式无法识别的用 `[化学结构式]` 占位标记。

**③ 拼音（带声调）**（语文 1-2 年级）
- 如 `bá cǎo`（拔草）、`shī féi`（施肥）、`xiǎo`（小）等，声调符号附着在拉丁字母上
- **要求**：普通 教材正文识别 对声调字母（ā/á/ǎ/à/ī/í/ǐ/ì/ū/ú/ǔ/ù）识别弱，易误为无调字母或数字。建议使用**明确支持带声调拼音**的模型（如 PaddleOCR / 百度高精度版）。若仍无法准确识别，请在文本中输出识别的**汉字部分**，拼音行用 `[拼音]` 标记，不做静默错误输出。
- 涉及教材：小学语文一年级上册（49页/本，拼音集中在前 2 个单元，约占 10-15 页）

**④ 注音符号**（语文/特教）
- 部分教材使用汉语拼音注音（汉字上方标注拼音），极少数涉及注音符号（ㄅㄆㄇㄈ）
- **要求**：尽量输出汉字与注音的对齐文本；若上下排版导致混排困难，按"先汉字后注音"分行输出。

**通用原则**：
> **宁可占位标记，不可静默丢字。** 任何无法识别/无法精确还原的特殊内容，请在对应位置插入 `[XX]` 标记（如 `[数学公式]` / `[化学式]` / `[拼音]` / `[表格]` / `[图示]`），避免"认不出就忽略"导致文本断裂。出文本时附带 `特殊内容标记` 字段（逗号分隔的类型列表）可辅助后续校对。

## 5. 交接流程

```
知微 ──── [输入 JSONL] ────→ 教材正文识别 团队
教材正文识别 团队 ──── [输出 JSONL] ────→ 知微
知微 ──── [AI 校对 + 结构化] ────→ 最终底料 chunk
```

1. **交付输入**：附件 `教材底料输入清单_全量.jsonl`（154,920 条 URL，3,350 本教材的逐页展开，约 70MB）
2. **教材正文识别 执行**：第三方按 URL 拉图 → 教材正文识别 → 输出 JSONL
3. **回传结果**：输出 JSONL（bookId+页码 必须一一对应即可合并）
4. **知微校对**：回传后我做 AI 校对：
   - 用元数据纠正出版者/书名的 教材正文识别 错误
   - 从 `chapter_tree` 回填 单元/章节
   - 基于置信度给质量分层
   - 对齐底料 chunk schema，产出 `底料_教材正文_校对后.jsonl`

## 6. 注意事项

### 图片 URL 访问
- 预览图 URL 当前为**公开访问**（直接 GET 即可，HTTP 200 / image-jpeg），**无防盗链**。
- CDN 域名为 `r1-ndr.ykt.cbern.com.cn` 至 `r5-ndr.ykt.cbern.com.cn`（输入清单已给出完整 URL）。
- 若第三方 教材正文识别 环境有网络白名单限制，请放行上述域名。

### 版权
- 预览图来源于国家中小学智慧教育平台，教材正文识别 文本为版权派生内容。回传后知微侧会标注版权标识，并私有存储。
- 第三方如需暂存原图用于处理，建议处理后删除，不保留副本。

### 校验要求
- **bookId + 页码 必须唯一**。输入与输出的记录数应一致（空文本页也需返回一行）。
- 若某页 教材正文识别 失败（图片无法下载/解码失败），请在 `异常标记` 字段说明，该行仍需保留。
