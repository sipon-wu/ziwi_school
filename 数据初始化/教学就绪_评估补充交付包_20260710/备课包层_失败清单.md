## 原因分析

这 13 本都是**新教材（2022 版新课标）**的英语教科书。这些教材对应的备课课程包**尚未在平台上架**（或上架但 API 尚未返回数据），导致 `parts.json` 返回 `None`，脚本在解析时报 `NoneType object is not iterable`。

**非脚本 bug**，而是平台数据可及性问题。定期重跑即可自动补全（脚本幂等，skips duplicates）。
