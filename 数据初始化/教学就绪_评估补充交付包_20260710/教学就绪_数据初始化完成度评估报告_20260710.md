## 二、各模块详细说明

### 模块 ①-④：课标条款库（v1 交付包）

路径：`教学就绪数据初始化/教学就绪交付包_全.zip`（14MB / 178文件）

内容：
- 课标条款库（语文/数学/英语/科学等 20 个分科，共 1,879 条主库 + 数据字典）
- 教材版本与课标映射（764行映射表 + KG骨架）
- 学校参照名录（县区版21.3万行 + 带地理版21.4万行）
- 知识图谱样例（138个样例节点）
- 初始化SQL（建表+入库脚本）
- 课标解析器 `extract_standards.py`（v5，可复跑）

评估要点：开发团队可据此实现课标护栏、认知层级上限、单元白名单等边界规则。

### 模块 ⑤：备课课程包底料

| 条目 | 值 |
|---|---|
| 数据源 | 国家中小学智慧教育平台 `prepare_lesson` 命名空间（公开API，无需登录） |
| 教材数 | **2,918 本成功**（目标 2,931 本，13 本因 API 超时/数据缺失失败） |
| 课程包 chunks | **46,918 条**（每条为一个课程包/课时的完整结构化信息） |
| 覆盖率 | 全学段（小学1,188 / 初中799 / 高中515 / 五·四428）全学科 |
| 每个 chunk 含 | 学段、学科、年级、册别、版本、单元、章节、课程包标题、教师/提供方、时长、评分、来源标识、关联KG单元、版权标识 |
| 产出文件 | `output/底料_课程包_全.jsonl`（41MB） |
| 汇总报告 | `output/底料_课程包_全_summary.json`（552KB） |
| 提取脚本 | `extract_all_coursepackages.py`（可过滤学段/学科重新子集，支持断点续跑） |
| BookId 映射 | `output/bookid_map_full.jsonl`（2,931 本元数据） |

**文本质量**：备课包层本身含课件/教学设计/视频文本，**零OCR、准确率高**，是课程内容底料的主力来源。

**特殊内容要求**：数学式、化学式、拼音（带声调）、注音符号 均已写入方案文档，第三方需按"宁可占位标记，不可静默丢字"原则处理。
