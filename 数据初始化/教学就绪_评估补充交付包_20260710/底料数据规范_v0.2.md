## 一、全局字段（所有底料 chunk 共用）

## 二、备课课程包层（`底料_课程包_全.jsonl`）

**来源**：国家平台 `prepare_lesson` 公开 API，零 OCR，直接取课件/教案/视频文本

**正文 JSON 结构**：

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| `课程包标题` | string | 是 | 课时/课程包名称 | `1 "北京双奥"荣耀中华` |
| `所属单元` | string | 是 | 单元归属（与顶层字段一致） | `第一单元 体育文化与体育精神` |
| `所属章节` | string | 是 | 章节归属 | `1."北京双奥"荣耀中华` |
| `章节路径` | string | 是 | 单元/章节 全路径 | `第一单元 体育文化与体育精神/1."北京双奥"荣耀中华` |
| `教师` | string | 否 | 授课教师姓名（覆盖率 63.6%） | `刘娱楠` |
| `提供方` | string | 是 | 资源提供方（覆盖率 99.8%） | `人民教育出版社` |
| `学习时长(秒)` | int | 否 | 课时长度（覆盖率 58.7%） | `3600` |
| `平均评分` | float | 否 | 评分（覆盖率 56.2%，均值 4.35/5.0） | `4.9` |
| `评价数` | int | 否 | 评价人数 | `2995` |
| `新旧教材` | string | 否 | 新课标/旧课标标识 | `新教材` / `旧教材` / `""`(未知) |

**统计**：46,918 条，56.2% 有评分，63.6% 有教师，99.8% 有提供方，17.2% 年级为空

## 四、教材正文 OCR 层（`底料_教材OCR.jsonl`）

**来源**：教材预览图 OCR 产出，初始版本由数据提供方内销 OCR 引擎产生（P0 样板），全量由第三方执行后回传

**正文 JSON 结构**：

| 字段 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| `教材标题` | string | 是 | 与教材层一致 | `义务教育教科书·语文一年级上册` |
| `教材bookId` | string | 是 | 对应教材的唯一标识 | `1c73b348-...` |
| `页码` | int | 是 | 教材页码（从 1 开始） | `1` |
| `学制` | string | 否 | 学段/学科/年级/册别/版本 签名 | `小学/语文/一年级/上册/统编版` |
| `OCR文本` | string | 是 | OCR 识别全文文本 | `语文\n一年级上册\n统编版` |
| `OCR平均置信度` | float | 是 | 整页 OCR 平均置信度（0~1） | `0.742` |
| `预览图本地路径` | string | 否 | 仅首次P0样板有值 | — |

**全量 OCR 输入清单**（`OCR输入清单_全量.jsonl`）：
- 每行 = 一页，含 `bookId` / `页码` / `图片URL` / `学段` / `学科` / `年级` / `册别` / `版本` / `教材标题` / `出版者`
- 共 154,920 页，3,350 本
- 字段与当前规范对齐，第三方执行 OCR 后按 `bookId` + `页码` 回传即可合并

## 五、字段值规范化

### 5.1 学段枚举值

平台实际出现的学段值（8 个）：
`小学`, `初中`, `高中`, `特殊教育`, `初中（五•四学制）`, `小学（五•四学制）`, `学前教育`（罕见）, `其他`（为空，624 本教材层记录）

> 注：教材层有 624 条记录的 `学段` 字段为空（tag_list 缺失学科标签），这 624 本多为特教/专题类教材。建议入库时标记为 `学段_未知` 待核。

### 5.2 新旧教材标识

备课课程包层标记了 `新旧教材` 字段（`新教材` / `旧教材` / 空），对应 2022 版新课标前后。教材层无此字段，可通过 `教材标题` 含 "（根据2022年版课程标准修订）" 字符串判断。

### 5.3 版本规范化建议

教材层的 `版本` 标签粒度更细（如 `人教版（B版）（主编：高存明）`），备课包层的标签相对简略（如 `人教版（B版）`）。合并时建议：
1. 优先用 `teachmeterial_ids` 精确关联（624 本）
2. 其余按 `学段|学科|年级|册别` 签名匹配后，用**教材层版本**覆盖备课包层版本（保留冗余）
